# v1 组件消融

这轮固定 v1 的三份单源权重、默认点云采样种子 0 和两轮四参照解码。使用已登记的普通 TRAIN 录制面板，每个目标平台 512 条描述，由另外两个源模型分别预测。共 1,536 条描述、3,072 条方向记录。六方向等权汇总，Acc@25 和 Acc@50 使用有向 3D IoU 的严格大于门槛。 [协议](protocol.json) · [评测回执](results/audit.json)

## 主要结果

- **输出 PCA 与候选重叠概率校正的贡献最大。** 固定赢家，只恢复输出朝向，Acc@50 提高 4.427 pp，151 条跨过门槛，15 条反向跨越。恢复重叠概率校正，Acc@50 增加 2.148 pp，100 条改善、34 条受损。加入内部 PCA 的增量较小。
- **联合解码有小幅收益，主要来自末轮配对项。** 相对同信息直接选框，完整 v1 的三项增量是 0.488／0.130／0.230 pp。只恢复末轮配对项，整体增量为 0.456／0.098／0.198 pp，明确左右关系子集为 1.142／0.457／0.509 pp。单独恢复一路消息、主体几何反馈、配对投影项或谓词向量的总体变化较小。
- **关闭 RGB 特征在本面板提高 Acc@50。** 提高 0.618 pp，五个方向提高，Drone→Quad 降低 0.781 pp。关闭前端竞争残差也提高 0.130 pp，增益集中在 Quad 作为源的两个方向。这两项独立开关分别测量，没有叠加值。 [分方向配对](results/paired.csv)

## 核验与复现

封存之后评估 49,152 个端点，独立 CPU 有向框计算的最大绝对 IoU 差为 7.77e-16，两个阈值的判定差异为零。直接选框臂与同清单历史结果的最大汇总差为 1.07e-14 pp。所有逐例标量保存在匿名结果文件中。 [全部配对变化](results/paired.csv) · [录制重采样区间](results/recording_intervals.json)

本实验验证现有预训练权重下关闭组件的效果。普通 TRAIN 面板此前参与过研究，目标录制数为 Waymo 94、Drone 2、Quad 2。两个源方向对同一目标录制共用重采样权重。结果范围限于本面板和已封存的普通 Validation 对照。 [清单与计算口径](protocol.json)

在具备 v1 运行环境和已登记数据的工作区，将公开的两个脚本及协议放到 `studies/3eed_v1_component_ablation_20261119/`。先运行 `run_ablation.py` 封存六方向预测，再运行 `score_ablation.py`。独立评分沿用工作区的 `batch_yaw_iou.py` 和 `tools/obb_iou.py`。
