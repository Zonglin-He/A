# v1 前端精简复核

当前 v1 移除 RGB 特征计算和前端候选竞争残差。点云适配器和匹配投影复用原有权重。保留原始 256 个候选、候选重叠概率校正、四个主体槽、四个参照槽、两轮联合解码和 PCA。图像宽高、标定、投影与可见性仍用于几何读出。

## 核验范围

六个方向各检查一条真实输入。简化前向的 256 个匹配概率与归档实现同时关闭这两项的计算逐值相等。替换为同宽高黑图后，六条输出框逐值一致。隔离发布包的 CLI 在禁止解码图像像素时复现封存框。

封存全部 3,072 条新预测后，使用独立 CPU 几何计算复核 15,360 个端点，Acc@25 和 Acc@50 的阈值判定差异均为零。所有负例保留在匿名逐例文件中。

本面板此前参与过研究。Waymo 94 个录制，Drone 和 Quad 各两个录制。结果适用于这一清单。18,620 条普通 Validation 的结果对应精简前的实现。

使用原工作区中的封存输入与前次消融结果，从研究目录运行 `verify.py predict` 生成新预测，再运行 `verify.py score` 评分。六方向等价性检查复用归档版本的匹配实现。
