# 3EED 跨平台语言—实例联合推理

工作分支 `research/codex-overnight-20261119`。上游实验基点为 [R172](https://github.com/Zonglin-He/A/commit/89a3dca18ac40a53e03ec9b8984365c63c4448b6)。本地工作区根目录没有 Git 元数据，使用独立研究目录记录补丁和结果。截止为北京时间 2026-11-19 09:30。

## 瓶颈与证据

1. 正确实例已有时，竞争分数常不指向正确身份。R172 的 25 条可达失误中，主体和参照单体分别在 13 和 11 条中贡献最大分差。先检验现有模型是否有跨角色的配对证据。
2. 参照候选召回仍限制上限。R172 的 60 条双端核验记录中，只有 28 条两端都有正确候选。R171 以原生参照扩召回，未带来双端或高阈值定位净收益。第一轮冻结候选，便于定位分数问题。
3. 关系满足对身份的区分力不足。R172 的 25 条可达失误中，左右项在 16 条支持正确对，且改变单个可见种子无法反转任何已观测的赢家分差。几何先继续使用旧因子。
4. 参照不足时，现有 UNKNOWN 分支多数情况下无法赢。是否修复依赖身份证据的可靠性。R168 的源域拒绝器在目标域全部拒绝，不复用它作为默认规则。

## 首轮

在 R171 的原句 F 及参照主体化查询 D 上分别干预冻结网络最后一个跨编码器视觉到语言注意力。保持所有空间候选、RGB、点云及基础分不变。只扣掉某个候选区域的视觉 value 对句中另一角色词槽的贡献。用被扣除前后的实体匹配 log odds 差量测量条件依赖，结合正反两次查询形成两个实体之间的分数矩阵。对矩阵分离行效应、列效应和交互，检验成对依赖能否超过吸收同一批响应的单体读出及矩阵错配。相比 R66 的整体区域删除，点特征、query keys、其余词槽均保持，读出依赖两个候选身份。

先做无标签数值核验再覆盖 R171 两批 168 条。预测封存前不加载身份核验与目标框。结果包含全部 R158＋PCA、D 原生独立、D 原生联合、带响应的同信息独立、同信息旧几何联合、交互联合、交互错配。后两批合计 60 条具双端身份核验，总体定位按 168 条。两方向共享物理帧。两批既有人为核验也都已有研究曝光。
