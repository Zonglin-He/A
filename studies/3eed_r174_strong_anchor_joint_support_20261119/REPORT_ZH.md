# R174 强锚点联合实例支持校正

**保留 R158＋PCA 为主方法。** 六个迁移方向等权，完整 R174 的 Acc@25 / Acc@50 / mIoU 为 **27.385 / 10.204 / 14.502%**，相对 R158＋PCA 的 **27.340 / 10.161 / 14.496%** 改变 **+0.045 / +0.043 / +0.006 pp**。全量保留 18,620 条配对记录。

冻结三个单平台 3EED checkpoint 和原 R158 多模态匹配。每条描述保留 R158 原赢家和三个按 R158 分数筛选的原生候选。新增头使用单体分数和角色语言读取四个主体、四个参照假设的点云支持。共享三轮更新。连续中心、尺寸和朝向预测只用于内部几何。五种输出均使用原候选的位置、尺寸及同帧采样点的历史 PCA。

主体分数以 R158 对数候选分数为起点，原第一名对应零点。单体残差通过 tanh 限幅到 ±0.75。开启跨角色交互时，主体还加入按参照概率边缘化的成对增量，单对增量限幅到 ±0.50。初始候选不依赖 GT。四个学习版本共享短名单和单体残差上界。

R158 视觉路径提供了 RGB 证据。新增头使用点和文本特征及相机可见性，去掉了上一轮新增的 RGB seed 描述子。四个学习版本共享源域清单、初始参数、三轮计算、监督和每平台 12 轮 AdamW 预算，使用末轮权重。源域合成关系沿用原双端清单，用三种自然短句模板表达原关系。主体框、参照框及左右约定相同。自然描述只监督主体。目标域推理冻结，标注在所有预测封存后用于评分和干预诊断，FINAL 未访问。本批普通 Validation 已用于此前方法的比较，结果衡量该固定样本范围内的配对差异。

## 3. 给对参照是否真的帮助主体

在同一场景中，用正确参照与有独占点支持的同类干扰物做配对。第一种干预保留框、投影和支持质量统计的显式几何，替换来自该区域的点特征。该点特征本身也可能携带隐式几何。第二种同时替换参照框与参照点支持。两种干预均固定主体候选、文字及基线分数。单体版本在所有干预下的主体选择保持数值核验一致。

目标核验中，完整版本有 2 / 1 条满足“选到已知错误的参照，且主体池已有达标候选却选错”，给正确参照后救回 **1 / 1** 条。要求正确参照救回且匹配错参照未救回时，分别为 **0 / 0** 条。上述计数是匹配干预子集的观测，其分母取决于双端核验和同类干扰的可见点支持。目标诊断样本此前已用于机制核验，全部训练和预测早于本次干预。未能匹配角色、支持不足和无可用错配均在统计分母中保留，单列原因。
