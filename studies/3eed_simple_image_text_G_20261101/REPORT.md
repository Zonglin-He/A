# R26：用单一图文分数简化G

本轮完成464条真实目标观测，Waymo-only epoch100源权重、256个候选框、独立实例mask及2D↔3D关联权重固定。没有新增源域训练，没有参数TTA。开发集先选定的简单方案为 qwen_subject_raw_context，共享λ=2。

主要单因素检验：只删位置/参照评分、保留旧λ=2及其余视觉处理，P64相对旧G为 -1.178963 pp。开发集选定简单方案在P64相对旧G为 -2.665839 pp，场景聚类95%描述性区间 [-6.668139815272164, 2.050071781311037]；已暴露REPLAY192为 -1.431156 pp。

## 协议与证据边界

- D208为反复暴露的目标开发集，用其标签选择每版本共享λ及有限简单Qwen读出族；并非完全无目标标签的开发历史。选择后锁定整个464预测，再读P64本轮评分标签。
- REPLAY192及OLD400都已暴露。P64来自旧501mask帧外，按输入哈希和场景轮转选取，图像解码与XYZ哈希不重叠近期开发；全VAL历史评分、2Drone/3Quad场景重叠，不能称全新盲测。
- 主检验是 no_position_reference_fixed2 vs legacy_complex。其他删项保留fixed2单因素版本，另报告开发集重新选择λ后的版本。15个有限证据族，5个fixed2对照，source，共21臂，未按P64挑选赢家。
- 无映射、错误、退化、坏例全部保留；GT只用于开发标量选择和封存后评价，从未选mask、候选或运行时门槛。IoU差异不是独立实例身份金标。
- 旧Qwen仅主体描述，不能改名成完整文字。新full_scene把完整文字和标记候选的整张场景图输入冻结Qwen，只读取Yes/No log-odds，不再叠加位置、参照、灰图或source相对残差；它比主体裁剪多了场景上下文，不是纯单因素比较。
- CLIP简单分数为真实图文余弦，无旧G关系评分。native77右截断记录；chunk覆盖所有token但不建模跨块关系，不是联合cross-attention。

## 解释与裁决

简化方案是否替换研究默认G：False。裁决看新观测和已暴露重放的净均值，不以单个负例为否决理由；所有平台差异、坏例和聚类区间保留。少量场景不足以建立稳健跨平台优势。

本轮只检验监督/直接重排。没有新增参数更新，不从图文重排收益推导TTA额外收益。先前R24匹配投影TTA与R25源域三模态训练保留为独立分支。

去位置/参照、去灰图、改单裁剪、取消残差裁剪均有独立对照；不能从full_scene结果单独归因于关系理解，因为上下文、指令和评分条件同时不同。绝对log-odds给未对应候选的证据为0，负分候选可能被未对应候选超过，这种校准后果全部保留，未事后加门。

## 开销与复现

旧G对应464的Qwen forward数（缓存证据重建）5124；完整场景单分数673次。Token工作量分别1931938/780992，更少forward不自动等于同倍延迟降低。旧464端到端延迟未重测，实际阶段时间、显存见COSTS.json。
有池CLIP描述338条，native77截断8条，丢失30个token。

最简实现 crossplatform/round26/simple_g26.py：F = source + lambda * (weights @ image_text_evidence)，一个最终分数、固定框argmax。没有额外位置、参照、灰图或相对source winner规则。候选生成和几何对应沿用公共流程，简化的是评分G，不是声称解决全部2D/3D关联。

CPU_AUDIT核验全部464预测、框与source相同、旧336旧G排名/IoU精确复算、开发λ和族选择复算、输入哈希与封存。ALL_NEGATIVE_CASES保留所有负变化；重复臂比较不是独立样本。

文献边界：内部交互需训练接口，参见 [WildRefer](https://arxiv.org/html/2304.05645v3)；共享图文嵌入参见 [CLIP原论文](https://proceedings.mlr.press/v139/radford21a.html)。本轮是分数融合对照，不是两篇模型的完整复现。


## 删项细节与未证实解释

位置与参照一起删除，只证实合并增量，不能把收益全部归给独立参照定位。取消残差裁剪影响9条观测、49个query分数，Top1变化0；仅是本批决策无影响，不是全局数学等价。去灰图在去位置/参照条件下，OLD400 +0.310523 pp、P64 0；不能推断恢复关系评分后相同。单context相对双裁剪的bounded版本，OLD400 +0.317606 pp、P64 -0.109405 pp，缺乏稳定必需性。raw双裁剪去灰图在P64损失3.025515 pp，作用依赖读出形式。

完整文字整图单分数P64相对旧G +0.776290 pp（5条改善、4条恶化），OLD400 -2.572621 pp、REPLAY192 -2.572277 pp；是预定低调用量候选，未按P64改选主方案。D208选中的是单context主体raw，P64 -2.665839 pp。共享λ只查预定有限网格，上界最佳不等于全局调参最优，未在P64后追加扫描。

有pool时源q0在本批均有映射，不能把下降直接归为q0未映射。绝对分数、未映射候选与source评分交互为后封存描述，未建立单一因果归因。全文整图与主体裁剪还存在分辨率/上下文差异，不能把失败单独归因于关系推理。
