# 固定物理锚的图像度量几何

只读上一轮 Qwen、正式框和单帧点云。冻结 Object 和 Correction，不改变正式入口和以前的结果。模型调用和训练均为零。目标 GT 只在事后诊断/评分时读取。

1. KITTI 冻结 31 条能用正式锚的既有样本。A 为正式框，B/C 为原封存的 Waymo 类别尺度和残差目标尺寸，D 为冻结 Qwen 原始尺寸，E 为 KITTI 独立录制子集的类别中位数，F 为真值尺寸。按录制 SHA 排序取前 7 个 KITTI 驱动作为 E 的参考，其他驱动计分。训练半边每条原始车辆轨迹只贡献一次中位尺寸。全套 A–F 在同一可评分 holdout 上报告，A–D/F 另报告 31 条总样本。对比中心固定、保近水平面和底面重锚、以及物理约束后的读出。E/F 仅是诊断。核验轴约定、类别路径、遮挡和三维标注投影。
2. Qwen 比例诊断。使用实际正式 2D 裁剪一致的封存 Qwen 长宽高。同一条同时比较原原生尺寸、给定准确长/宽/高后按 Qwen 比例补其余两轴、Waymo TRAIN 类别比例和同域同预测类别打乱比例。核心为未给定两轴的逐例绝对相对误差与配对差，另报告箱体 IoU 和控制平台与类别的组内秩相关。类别比例取每条源域样本的真实比例，再取组内中位数。对零假设的停止判断用同一个锚上正确 Qwen 比例与类别/打乱比例的比较。
3. 固定正式 yaw、相机侧近水平面和底面。FGR-style 用两条锚定 BEV 边与左右相机侧平面求交保留原高。若仅一个方向有几何交点，可冻结另一轴。完整透视由固定锚的三维八角点和边界对应方程产生根，并作同一套实际畸变投影、像素带、点和射线可行性检查。所有透明候选都必须保持本来的 Selection 命中和首交（1e−6 m），并覆盖原测量与首交见证点。像素带容差为对应框跨度的 8% 或 3 像素中的大者，触到画面边界的侧不要求等式。另用基于 RGB 梯度的局部轮廓证据做确定性辅助对照。保守规则在正式框已满足图像误差带或无可信可行框时回退。形状比例只在可行框内起作用。标准二维标注框和真实三维框投影的两个 Oracle 独立评分。
4. 可辨识性用每例同池的 2,048 个均匀 Sobol 样本，在由像素尺度和测得深度构造的有限搜索范围内比较仅 LiDAR、仅图像、联合和加入 Qwen 比例带（每个比值允许乘/除 1.25）。同时报告实际 GT 尺寸按固定锚放置时的可行性、真实 GT 框的可行性、三轴可行尺寸跨度缩减和局部标准化 Jacobian 的谱。局部图像导数相对于对数尺寸，以各边像素容差标准化。LiDAR 首交导数只比较保留相同射线命中状态的稳定命中，以 0.05 m 标准化并用射线数归一，离散的命中变化和点约束由有限搜索另外检查。平台/观测角度分层用相机到锚的实际方位。该审计不把有限搜索或局部高秩等同于全局唯一性。

正式几何锚的适用覆盖、每臂实际采用和被拒绝原因、全部结果和按录制重抽样的区间都保留。实验 2/3 决定是否值得在没有新数据时继续开发；当前轮仍完整报告预定的四组诊断。本轮为既有 3EED/KITTI 面板的机制实验。
