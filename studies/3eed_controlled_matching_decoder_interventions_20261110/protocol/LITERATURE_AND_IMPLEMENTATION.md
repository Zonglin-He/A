# R61 implementation / causal interpretation boundaries

This round is a controlled intervention study, not another TTA loss or a claimed reproduction of channel-pruning work. The primary implementation evidence is the actual frozen source last-decoder class and model forward at `crossplatform/round3/p0/upstream/models/{encoder_decoder_layers.py,bdetr.py}`, plus the pinned Waymo-only checkpoint and previous matching/capture audits. The corresponding official project is https://github.com/worldbench/3EED . No new algorithm/paper performance is imported as evidence.

Checked native order: learned posembed -> self-attention residual+norm1 -> language-attention residual+norm_l -> visual-attention residual+norm_v -> FFN residual+norm2 -> existing matching MLP -> L2 normalization -> token logsumexp log-odds -> fixed R57 ABC probability transport/UNKNOWN. Native eval/dropout, normalization, bias and query order are preserved; source TF32 disabled and original FP32/source fingerprints checked.

Gains0,.5,1.5 act on the residual contribution while keeping downstream normalization/computation. Scaling the language-attention residual to zero does NOT remove all language information: previous encoders/decoders and the matching token space still contain language. Scaling visual-attention to zero likewise does NOT remove all point information. These are last-decoder component tests only. Individual visual heads are suppressed through the corresponding36input columns of the attention output projection; packedQ/K/V and the other heads remain fixed, output bias retained.

MLP strong interventions use source-reset outgoing-column zeroing. Noise8off uses the exact R60 per-input eight-column set, but its previous soft attenuation is replaced by full removal. Noise32off uses the32highest same diagnostic excess ranks; unlike the R60 trigger, some expanded ranks may have nonpositive excess and are not asserted to be faulty. Common8off and random8off reuse R60 sets. First/secondhidden energy32rankings use only original activations and outgoing weight norms. There is no task-label-based selector or parameter optimization.

All interventions operate on ABC frozen views and retain originalA256finalboxes, source text spans, transport and UNKNOWN. B/Cprefixes are recovered from the exact original samplings with all original pointindices/boxes/scores/h/query/tokens/mask bitexact; A native prefix is reused. Prefix replay avoids repeating the entire backbone for every intervention. A zero-replay gate checks the native endpoint before interpreting sensitivity.

TaskGTis read only after all predictions are sealed and independently audited. Recoverability means an original candidate has IoU>.25 while frozenABCdoes not; it is not an independently verified instance-identity label. The best arm for each input is an explicitly supervised diagnostic upper envelope over this finite intervention set, NOT an executable TTA policy or an architectural capacity bound. Any highest-scoring fixed arm is exposed-development selection, not independent confirmation. FINAL384is untouched.
