# Primary-source check and migration boundaries

[EG-3DVG official paper page](https://openaccess.thecvf.com/content/CVPR2026/html/Park_EG-3DVG_Expression_and_Geometry_Aware_Grounding_Decoder_for_3D_Visual_CVPR_2026_paper.html) describes expression-aware contrastive learning. The full PDF was blocked403 and OpenReview returned a browser challenge, so no claim to have independently read its full equations. The [official repository](https://github.com/Gwan9Wook/EG3DVG), tree174e34894aea6513442da6b5dfa9b3e2bf8a1efa, was inspected directly: src/joint_det_dataset.py lines954ff selects another description of the same class but a different target_id in the same scene, and models/losses.py lines623ff constructs supervised role/token alignment maps with attributes/pronouns/relations. This relies on annotated identities and expression maps, not arbitrary query-index negatives. R91 borrows the need to discriminate real distinct-instance competitors; its source-box-supported pairwise softplus is NOT ECL reproduction. No official source code or pretrained weights imported.

[CORE-3DVG primary paper](https://proceedings.neurips.cc/paper_files/paper/2023/file/9b91ee0da3bcd61905fcd89e770168fc-Paper-Conference.pdf), sections3.2–3.3, uses multiple phrase-conditioned contextual proposals and source-target supervision for weak relation learning. Its [official repository](https://github.com/yangli18/CORE-3DVG), treed7030e6a220f720daee2a01c1d0bfea22b2e8090, and model entry were inspected. It does not justify treating every reference proposal as ground truth. R91 retains multiple existing context hypotheses without new reference identity labels or a replacement detector.

R91 source supervision uses additional non-target object boxes already present in Waymo ground_info/others. These are used solely to support distinct same-class competitors, with target-overlap exclusion, unambiguous candidate assignment and disjoint proposal/point support. They are not point-instance masks, per-role reference labels, or target-domain annotations. Compared with target-box-only CE this changes the source supervision utilized, and the CE ablation isolates the pair loss under the same data availability. This is a finite migration hypothesis, not a novelty claim.

The original R80/R82 implementation was checked, not inferred from the proposal: two masks76001/76002,102498 adapter/interaction/gate parameters, clip1, alpha.5, weights.1P/.1RGB/.01D and original output/query preservation. R80 had DEV/VAL positive but TRAIN negative results; R82 reduced that harm with fragile increments over the direct control. Neither is assumed a validated robust method. R91 keeps exact historical scores and same-information frozen reads, and tests the original physical direction through prepared frozen candidate interfaces. Candidate-conditioned recovery remains a separate comparison, with no source/target pseudo-target identity invented.
