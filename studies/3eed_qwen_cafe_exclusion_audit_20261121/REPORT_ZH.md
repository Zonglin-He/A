## 两个原框都失败时的中心空间

对每个姿态，使用原 Qwen 尺寸、原高度中心和原 Fit 目标支持，计算目标点容纳区间 $[h_k-d_k/2,l_k+d_k/2]$。任一水平轴的跨度与尺寸不兼容，或固定高度区间无法容纳实测目标点，则该姿态无可行水平中心。扣除同高度范围内经核验规则筛出的排他点对应的开矩形，量取联合可行集的面积和坐标包络。[几何实现](center_sets.py)

| 双失败诊断 | 描述数 |
|---|---:|
| 两个原候选都未达标 | 2,769 |
| 至少一个姿态有正证据可行中心 | 2,458 |
| 加入排他证据后仍有可行中心 | 2,455 |
| 排他证据缩小至少一姿态的可行面积 | 398 |
| 正证据约束下 IoU 上界仍可能超过 0.50 | 2,378 |
| 联合约束下 IoU 上界仍可能超过 0.50 | 2,373 |
| 有单侧或两侧证据反对原姿态，且至少一个被反对姿态的联合上界仍可能超过 0.50 | 388 |

上界只需两个原始 IoU。记原候选体积为 $V$，真值体积为 $G$，原 IoU 为 $t$。若所有可行平移替换框体积的比例至多为 $s$，新交集至多为旧交集加 $sV$。由 $G\ge tV$，得到

$$\operatorname{IoU}_{\mathrm{shift}}\le \min\!\left(1,\frac{t+s}{1-s}\right).$$

$s$ 用联合可行中心的坐标包络保守求得。它允许两个轴的极值同时出现，并给新进入的体积以最有利的真值重叠。这个上界在所设约束下排除 396 条，另外 2,373 条仍无法根据已有 IoU 判定是否能救回。加入排他约束只额外排除 5 条上界机会。审计中移动框或新框 IoU 的评测次数为零。[中心集合统计](results/both_fail_center_bounds.csv)

## 决策与复算

**归档本轮规则，不推进中心恢复。** 排他证据有局部识别价值，但 348 条原错误中 236 条缺少有明确方向的证据，且 Waymo 上正确和错误的方向接近。目标分量与其他分量的几何分离只是身份代理。此次结论限定于冻结选区和相邻尺度定义，非穿透几何约束本身已有先例。[几何姿态估计中的非穿透约束](https://manipulation.csail.mit.edu/pose.html#non-penetration-and-free-space-constraints)

有本地原始普通清单和封存时，使用项目 `crossplatform/env` 依次运行 `extract.py` 与 `analyze.py`。`verify.py` 可独立复算公开统计和原方法 Acc@50。新增 Qwen 调用、训练、额外 GT 文件读取、正式预测改动和 FINAL 访问均为零。[分析回执](results/analysis_receipt.json) · [核验回执](results/verification.json)
