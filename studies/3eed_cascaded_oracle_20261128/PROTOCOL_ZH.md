# 级联 Oracle 误差分解

固定 3EED 普通 576 条（Waymo、Drone、Quad 各 192）及 KITTI Tracking 126 个预测条目中既有规则可评分的 89 条。两面板均有研发曝光。O0 从无标签阶段逐框复放并封存。其余各路在独立的离线诊断进程读取 GT。全部沿用冻结 Qwen 的 3D 回复、类别门控、相机标定、点云、四尺度几何、姿态选择与顶缩。新增模型调用和训练为零。没有 GT 子模块接入正式推理入口。

- O1 仅把 2D 区域替换为目标的标准二维标注框（3EED 提供的是标注的投影框），无有效框则记缺失并回退。不会刷新旧 Qwen 3D 回复，因此 O1 只测区域通道。
- O2 在 O1 的窗口中用 GT 框内的真实 LiDAR 返回作为目标支持代理。在与正式几何相同的 fit 数据源内只取投影落在当前窗口的返回，选择子集和独立 Audit 按原分区且用 GT 框内关联代替区域关联。沿用正式 C/H/A 路由、Qwen 3D 尺寸、地形估计、姿态选择与顶缩。最少五个有非退化水平分布的代理点。盒内点包含背景或地面且缺少逐点实例 ID。单项支持替换保持原预测 2D 窗口；没有足够目标支持时按原框计分。
- O3 使用 GT 箱体在当前预测姿态坐标中生成的两横轴近面与竖直底面位置作为锚。相机横轴坐标位于投影区间内时沿该轴以 GT 投影的中点锚定。尺寸和姿态保持 O2 的值。O4 切换为正确 yaw，沿新姿态重新表达 GT 物理锚，尺寸保持。O5 在同一物理锚和正确 yaw 下放入真实尺寸。前序没有有效框时 O3 至 O5 回退。另算 O0 上的单项区域、支持、锚、yaw、尺寸替换，以及 O2 上锚、yaw、尺寸的 2³ 组合。预测锚的 yaw-only 读出绕当前中心旋转，尺寸替换保持当前相机侧近面和底面；另报告尺寸固定中心对照。
- O6 使用完整真框，只检查兼容性。旧精确约束与已封存固定锚场景完全同对照：检查原见证点覆盖、Selection 命中与首交相对正式框 1e−6 m 等价、原图像窗口的原像素带（8% 或 3 像素较大者，截断侧单边）。用真尺寸并单独改变 anchor/yaw 构造 2×2 相容矩阵。用预测 2D、标注 2D 和未裁剪 GT 投影分别检查图像，最后者是坐标回路正对照。不得把与原预测等价当成与实测匹配。
- O6 另外以真实返回比较相机起点、经过 LiDAR 返回的视线命中及首交深差，报告 GT/O0 在原 Selection 或 Audit、替换 2D 后的 Selection/Audit、标注窗口内按原分区取的独立 Audit、和 GT 框内的 Audit 代理上的覆盖、命中、首交误差及 5 cm/20 cm 通过率。相机视线不代表传感器原生发射束。盒内点代理的包含和命中在定义上近乎必然。深差统计用于区分等价失败、显著污染和边界/物理观测模型差异，两个容差只用于描述，不调参。标注框、GT 投影在评分端核对 3EED 和 KITTI 使用的原生投影实现。

全样本用回退规则计分；另报告各平台、原 C/H/A 路由、目标 2D 已确认、O2 可用子集。按平台分层录制重采样 2,000 次，报告 mIoU、Acc@50、配对变化与区间。支持纯度用 GT 框内比例及外扩 10 cm 作敏感性，覆盖以当前窗口内、同池 GT 点为分母。报告门控、缺失、回退和参考数。级联增量依赖顺序，单项和交互并列解读。
