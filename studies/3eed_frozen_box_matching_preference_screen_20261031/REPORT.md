# R16：冻结三维框的匹配投影层TTA前提实验

**已完成Waymo-only源模型在Drone与Quad上的真实观测筛查，但当前G未产生通过接纳规则的局部候选偏好，因此没有启动真实匹配层TTA。零通过不等于偏好准确率为零，也不能解释为匹配层适应无效。**

## 协议与实际执行

- A32（Drone16、Quad16）用于G；B32（各16）未参与G、拟合或超参数选择。B为R15预留的不同RGB/点云观测；不主张同一实例对应或时间连续。
- 使用已完成100epoch训练的Waymo-only源权重。点云/文字主干、decoder、框预测及文字投影全部冻结；预定仅更新3D query匹配投影末层288→64的18496个参数。
- 完成64次严格FP32源模型前向，框和分数逐位等于R15同输入缓存；封存末层输入与固定文字token。
- 完成96次冻结Qwen2.5-VL-3B生成调用，以及307个独立mask×正确/错配描述共614次verbalizer前向。总计710次VLM调用，无新模型下载、教师或EMA。
- 同信息对照为A偏好记忆的核重排；TTA为共享投影层更新，二者都只在B读取冻结特征，不使用B RGB或G。
- 全部A/B保留；没有偏好时明确返回源模型，不能将返回分支称为TTA成功运行。

## 失败位点

| 阶段（按观测计数） | Drone16 | Quad16 |
|---|---:|---:|
| 至少两个独立mask映射到候选 | 11 | 6 |
| 存在同类可映射候选对 | 11 | 5 |
| 完整描述产生至少ln2的相对分数差 | 5 | 2 |
| 错配描述使同一对反向且达到ln2 | 0 | 0 |
| 最终局部偏好 | 0 | 0 |

这说明失败不能全部归因于坐标错位：Drone11/16、Quad5/16已有同类可映射候选对；完整文字在其中5/16与2/16产生规定幅度的相对差异，但没有一对通过强反事实反向条件。映射覆盖也不充分：两平台原Top1各只有5/16映射到获准mask组件。

**重要限制：同场景错配描述并不保证指向另一物体，反向排序不是可靠偏好的必要条件。当前零通过同时受到可靠性判据的限制，不能据此宣称RGB/文字没有信息。** 此外，神经完整描述验证不能等价于完整关系图的可执行证明；当前显式几何只核验可解析的图像位置。

## 证据边界与裁决

- 全5912目标VAL有历史模型/标签暴露。A也有近期G与评分暴露，B在R15仅捕获source。本轮不能称盲测试；B没有参与本轮G或拟合这一边界成立。
- A标签只在G/规则封存后用于固定前提门；B预测封存后单独CPU评分。没有按B选择G、更新步数或学习率。
- 只涉及1个Drone场景与2个Quad场景；逐样本数不等于独立场景证据。所有负例与零IoU样本保留。
- 单独CPU回放核对了封存成员、A/B划分、门控、参数变化、源候选框逐位成员关系及指标汇总。没有宣称第二套独立目标标注。
- 一次评分索引路径错误发生在标签读取之前；原代码、错误日志和修复记录保留，不改变方法或评价规则。

**裁决：当前G不采用；没有证据否定匹配投影层TTA。下一步需要先把真实候选对的主体/参照物核验做实，并检验可靠性判据是否误拒；不应先调大学习率或解冻更多层。当前没有排队的新GPU任务。**
