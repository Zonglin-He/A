# R128：八类外部TTA方法的六方向grounding适配试跑

**八类方法均完成真实数据运行；这是固定A256的任务适配开发实验，不是原论文任务的完整复现，也不是可直接用于宣称优于原方法的SOTA表。** 所有预测先封存，独立CPU几何与标量复算后报告；所有负例和修复前attempt保留。

三份source-only epoch100分别迁移到其余两个平台。每方向128，共768条方向—输入记录；同一目标输入被两个source分别测试，因此不是768个独立物理观测。44条受保护别名只复用历史source预测与分数，不读新媒体/特征、不索引其GT。FINAL、三份原始source权重及主方法均未改动。DEV多轮曝光，不是独立确认集。

- Tent/EATA的绝大部分下降已由BN目标统计引入；不能全部归为熵梯度失败。EATA过滤拒绝合法保留，实际Fisher/多步覆盖单列。
- MEMO相对自己的BN先验零步只有微小变化；对比增强平均的差异不能全部解释为权重更新收益，因为原始A零步本身已更强。
- MATE相对source的优势主要来自额外源域准备。只有MATE prepared zero→TTA3的差值属于本轮适应增量，当前很小。
- MM-TTA已修复诊断前向推进BN统计的问题，并用pre-cross-encoder语言保证RGB语义分支不读取LiDAR条件化文本；旧stats3/旧融合文本attempt全保留。RGB分支源验证仍明显弱于点文模型：这是当前端口的准备/任务限制，不能据此否定原分割方法。
- Uni-Adapter必须同时看清空历史和打乱键值对照；小幅绝对变化不足以证明正确检索起作用。
- CloudFixer使用作者的对象数据扩散先验作用于整场景。该端口退化严重，说明当前scene适配不适合采用；不是对其原始物体分类设置的否定。

## 适配与资源

原论文和实现入口、准确移植差异见[METHOD_CARDS.md](METHOD_CARDS.md)与[OFFICIAL_REPOSITORIES.json](OFFICIAL_REPOSITORIES.json)。Tent/MEMO/EATA重算完整原始点云和文字，MATE/MM-TTA/BFTT3D/Uni-Adapter使用已存在的原生表征缓存；后者增量耗时不含历史骨干提取与区域预处理，不能据此宣称更快部署。

源域准备每source训练192、验证64；每个准备阶段6个固定epoch，source-only选择。主MATE为Chamfer masked patch autoencoder；主MM-TTA为独立RGB/点文任务头、norm-only快慢状态。历史L2与混合文本RGB准备的成本和负记录保留。BFTT3D还使用源标注原型；Uni-Adapter使用source-prepared固定二角色空间，而非原ULIP/OpenShape/Uni3D分类接口。额外源监督/模型不与主方法混淆。

CloudFixer额外加载作者39,934,457个张量元素、159,801,477字节的ModelNet40扩散权重；30步输入优化，另30次相同噪声冻结去噪强对照；不反传扩散网络、不更新原3EED。Point-NN非参数流、缓存/图解适应均不伪装成梯度更新。

## 测量、负例与采纳决定

原始source全768条Top1与既有结果一致；native概率重放最大误差1.634e-6。独立OBB与批量IoU最大误差6.7e-16；标量与配对结果另由独立脚本重算。逐例全表、全部改善和损害、source准备历史、更新覆盖、资源与所有对照一并保存。

**本轮交付是可运行、可追溯的八类grounding适配基线。它没有建立任何方法在六方向上稳定带来TTA增量的结论，不自动替换主方法。** 尤其需要额外结构准备的几类仍是有限预算任务移植；用于论文正式外部对比前，应继续验证源准备充分性、原机制保真度及更大未选参范围，不能把本轮弱端口写成原论文已被充分击败。
