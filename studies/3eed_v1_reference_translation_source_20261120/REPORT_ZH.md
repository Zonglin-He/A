# 同一参照框的漂移能否校正主体中心

**源域实验不支持把参照框的位移直接加给主体。** 在 111 条已有参照身份代理的自然原句中，有 35 条能在正读和倒读里同时找到正确主体与参照。即使事后限定这 35 条的两端身份，按参照位移校正主体，中心误差平方均值仍从 **0.1049 增至 0.1685 平方米**。中心更准 7 条、更差 28 条，Acc@50 救回 **0** 条、误改 **9** 条。无标签部署版在全部 111 条上改选主体 0 条，精简 v1 与部署版的三源等权 Acc@50 都是 **78.3188%**。本轮在源域结束。[完整协议](PROTOCOL.json) · [中心与几何结果](results/physical.csv) · [实际选框](results/task.csv)

## 操作和可检验预测

同一帧依次输入原句、正向关系句 F 和交换两端并反转方向后的关系句 D。两次查询在同一坐标系工作。若文字改写给同一对物体造成共同的中心偏移，则可从参照的两次预测中估计这份预测偏差。设参照的预测中心是 $c_r^F,c_r^D$，取 $h=c_r^F-c_r^D$。对 D 的主体框提出新中心 $c_s^D+h$，保留 D 的边长和朝向。先在未经平移的参照框之间测重叠，随后才使用位移。比较原位、相同幅度的反向位移及打乱参照产生的位移。参照辅助定位已有相关方法，例如 ORD 使用可学习的锚点引导回归。本实验直接检验冻结模型两次预测误差之间是否存在可利用的共同平移。[平移与联合读出](transport.py) · [ORD 的锚点回归](https://openaccess.thecvf.com/content/CVPR2026/papers/Huang_ORD_Object-Relation_Decoupling_for_Generalized_3D_Visual_Grounding_CVPR_2026_paper.pdf)

设原主体框到官方目标中心的残差为 $y=c_s^*-c_s^D$。这次平移的真实误差改善量可以逐条精确求得

$$
\|y\|^2-\|y-h\|^2=2y^\top h-\|h\|^2 .
$$

另外把 $y$ 换成 $c_s^F-c_s^D$，可以测出两次主体预测是否更加一致。两个量分开计算。已知两端身份的对照只在预测封存后使用源标注，在合格组合中取原模型联合权重最高的一组。它不按真实中心误差或真实 IoU 选框。[事后计算](score.py) · [各帧误差与原始分母](results/identity_conditioned_rows.csv.gz)

## 两次查询都找到两个实例时

正向读取的四个主体槽在 111 条中均覆盖官方主体，参照槽覆盖已登记的参照代理 70 条。倒读中，按原句角色计，主体覆盖 72 条、参照覆盖 77 条，两端均覆盖 47 条。两个读法的双端覆盖交集只有 **35 条**。参照身份来自本批源清单对原始类别和上下文的唯一匹配，主体使用官方框。槽的物理归属要求和唯一一个标注物体的有向 IoU 大于 0.25。35 条来自 12 个录制，其中 Drone 只有一个录制。

| 源平台 | 合格 / 全部 | 中心更准 / 更差 | 原误差 → 校正后误差，平方米 | Acc@50 救回 / 误改 |
|---|---:|---:|---:|---:|
| Waymo | 10 / 50 | 3 / 7 | 0.1849 → 0.1883 | 0 / 1 |
| Drone | 3 / 15 | 0 / 3 | 0.1887 → 0.4743 | 0 / 2 |
| Quad | 22 / 46 | 4 / 18 | 0.0571 → 0.1178 | 0 / 6 |
| 全部合格记录等权 | 35 / 111 | 7 / 28 | 0.1049 → 0.1685 | 0 / 9 |

在 35 条上，两次主体预测之间的中心误差平方均值同样增加，由 0.0933 变成 0.1624 平方米。原框、按参照平移、反向平移的平均 IoU 依次为 0.5341、0.4430、0.4667。正确方向平移后有 5 条失去原先明确的目标归属。拿掉任意一个合格录制再算，其余数据的平均中心误差改善量均为负，范围为 −0.0965 到 −0.0428 平方米。[独立计数与去单录制复核](results/recount.json)

如果仅允许给每条的 $h$ 乘同一个系数 $a$，在这 35 条上事后能达到的最小平均平方误差对应 $a=E[y^\top h]/E[\|h\|^2]$。这里得到约 0.135。即便用这批源真值决定系数，平方误差最多下降 **0.00158 平方米**，占原误差的 **1.50%**。这是对一个标量预测方向的样本内解释上限，实验没有使用该系数部署或选参。[闭式上限复算](verify_source.py)
