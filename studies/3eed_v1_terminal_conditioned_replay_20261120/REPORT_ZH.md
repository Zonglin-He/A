# 用最终框的几何重新读取冻结 3EED

三份单源模型的原路径重放通过了全部 1,152 次逐层核对，最大差值为零。将原六层都固定到各自的终点后，192 条源域记录的 K16 赢家逐条相同。原本有 IoU>0.50 好框却漏选的 18 条，救回 0 条。按封存的首次检验规则，TCR 停在源域诊断阶段。精简 v1 继续作为主方法。[预设协议](PROTOCOL.json) · [独立复核](results/verification.json)

## 回读到底改了什么

第一次前向由原始 3EED 生成 256 个候选及它们的六层轨迹。第二次复用同一输入的 query 初态、点与文字 memory、掩码、权重和全部 query 身份。每层都以第一次前向的最终中心和原生尺寸计算位置编码，回归头只在第一遍执行。最终仍按封存的 R180 K16 原框、原尺寸和 PCA 朝向计分。三份 checkpoint 均使用六维位置编码。逐层控制重放、四种几何干预和输出均使用冻结的原生 decoder。[前向实现](replay.py) · [原生 3EED](https://github.com/worldbench/3EED/blob/843a901f5367a6be5cc484b97c6ecad462961dfa/models/bdetr.py)

本阶段直接使用原生匹配投影测量增量。令 $z_i(H)$ 为模型从原句抽取主体词后，第 $i$ 个 query 的主体词 log-odds，以 $s_i^0 + z_i(\widetilde H)-z_i(H)$ 选择赢家。192 条仅用于这个无训练诊断。另行实现的监督头为 $s_i^0+w^\top(\widetilde H_i-H_i)$；令 $w=0$ 在全部 K16 上逐值复现冻结分。其源域目标对每个有效的“记录、阈值”内的好坏候选对等权，再对这些记录和阈值等权，正的 L2 系数使目标强凸。此次实际训练步数为零。[残差与目标](linear_head.py)

## 18 条可救错误为何没有翻转

令 $e_i=z_i(\widetilde H)-z_i(H)$。在一条记录内，任意两框的相对分差至多改变 $\max_i e_i-\min_i e_i$。在 184/192 条里，冻结冠军相对第二名的既有领先已经超过这个范围。在 18 条可救错误里，16 条的冻结赢家相对最高分达标框的领先也超过这个范围。18 条的这两项中位数分别为 1.913 和 0.273 个模型分数单位。另两条虽然算术上允许翻转，实际分配到候选的修正也未使达标框获胜。[逐例分差](results/recoverable_margin_bounds.csv) · [全部记录的改分范围](results/correction_ranges.csv.gz)

此前图像核验的 10 条跨物体漏选中，7 条的达标框相对原赢家获得正修正。另 8 条同物体几何漏选中，这个数字是 4 条。上述范围只约束本轮固定的原生语义读出。对仅使用原生文字分、不使用 K16 联合分的辅助比较，自身终点让 Acc@50 从 153/192 升到 154/192。唯一跨阈值的 Quad 样本从 IoU 0.3243 到 0.6966，冻结 K16 已经选中了 IoU 0.6966 的框。它解释了这条局部改善，也解释了为何精简 v1 没有新增命中。[28 条既有好坏案例对照](results/probe_cases.csv) · [原生单独读出的复核](results/verification.json)

## 研究判断

测试的具体操作是用同一冻结 decoder 在已经生成的终点上重算语义。DAB-DETR 已研究将框几何用于逐层查询，Decoupled DETR 已分开学习分类和定位的空间特征。相对于这些工作，TCR 的区别可以落实到复用同一个初态与整套旧权重、统一六层的位置条件及保留原输出框。首次实验没有观察到这种区别带来增量纠错。[DAB-DETR，ICLR 2022](https://openreview.net/pdf/3222fb33c40d6a03db797feaa7cded67412477bf.pdf) · [Decoupled DETR，ICCV 2023](https://openaccess.thecvf.com/content/ICCV2023/html/Zhang_Decoupled_DETR_Spatially_Disentangling_Localization_and_Classification_for_Improved_End-to-End_Object_Detection_ICCV_2023_paper.html)

预设主诊断的成对胜率下降 0.0612 个百分点。现有结果限定在既有原生匹配方向，任意新线性头的可分性仍未知。已缓存原特征、三个六层回读差、单层回读差、同框点 memory 池化以及几何文字对照的 288 维特征。头部训练、源域拟合后的留出成绩以及六方向 18,620 条目标评测均未执行。本批源域录制数为 Waymo 20、Drone 1、Quad 2。FINAL 未访问。[预设停止判定](results/probe_decision.json) · [运行入口](RUN.md)
