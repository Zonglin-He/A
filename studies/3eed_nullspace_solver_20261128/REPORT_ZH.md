# 雅可比零空间前向求解器实验

把真实回波首交及首次 Qwen 二维框的雅可比接入了前向估计，完成 702 条盲推理与 665 条配对评分。**所测零空间先验方案未通过正式方法替换门槛。** 315 条有原双姿态支持的查询上，局部纯射线求解为 45.35% mIoU。加入各向同性 Qwen 先验后为 21.26%，投影到弱子空间后为 22.25%，再加连续二维边缘为 22.28%。仅替换先验的中心目标，保留投影、Qwen 尺寸和 yaw 后，回升至 44.76%。这把主要退化定位到当前目标中使用的**原生 Qwen 度量中心先验**。 [协议](PROTOCOL_ZH.md) · [聚合与回执](results.json)

## A 和 B 采用同一求解器

从相同的正式候选框出发。A 组固定残差、权重、线搜索与迭代预算，只切换先验的作用方式。B 组在 A 的投影先验上增添标定二维 AABB 的四条边缘残差。先验投影矩阵随每次外迭代重算，线搜索期间固定。首交面和极值角点发生切换时，用稳定活动集构造局部雅可比。Huber 射线项在 0.75 m 处封顶，漏击使用同样的有限损失。这里优化的是软观测目标。

硬投影只限制先验的局部梯度方向。联合目标中的二维残差可同时影响射线强、弱方向。软谱版的先验权重为 $\tau^2/(\tau^2+\sigma_i^2)$，在奇异值跨越数值秩阈值时连续变化。命中与失效的边界仍是分段的，整体求解过程有活动集切换。每臂共四步 IRLS，无类别标签进入目标。 [求解器](solver.py)

## 鲁棒权重与低证据行为

R4 的 221 条正确指代中，106 个 GT 框满足旧硬可行域，115 个被排除。在被排除组，B 的 Huber 和二次全先验分别为 **26.36%** 和 **27.08% mIoU**，两者强烈受坏中心先验影响。移除先验后，Huber 使同组相对二次代价增加 **1.10 pp [0.85, 1.35]**，达到 **59.67% mIoU**，仍低于正式框的 **62.65%**。全量无先验对照中，Huber 相对二次代价增加 **0.42 pp [0.24, 0.59]**。取消硬可行域允许估计框进入更多区域，评估检验的是选到的最终框。

无类别门控版本使用同一个前向求解器和统一的 ROI 初值。其全量从初值 **22.53% mIoU / 14.44% Acc@50** 降到 **14.19% / 4.21%**。有可用 3D 回答的 633 条里，130 条初始有效秩为 0 或 1，只有 5 条物理输入实际为空。其余低秩来自首交活动面、残差权重和输入观测几何。5 条空射线中，联合秩有 4 条升到 4，5 条主要读出都没有产生正确的 3D 重叠。数值上可退化到 RGB 与先验的求解过程，物理证据不足时的性能需要单独验证。

## 验证与复现

702 条预测先封存，之后离线评分原 665 条。新增 Qwen 调用、外部模型和训练均为 **0**。最早的形状先验控制因布尔位置参数错误与全先验重复，按预定含义修复。回放确认 **702 条的主比较框逐条一致**。在首轮评分后加入的去先验、改先验中心与匹配鲁棒损失诊断，均按单独登记的补充协议执行。合成检查覆盖首交、硬弱子空间投影、叠加秩和无证据极限。无类别门控入口抽验覆盖原四种路由，独立复算了总面板、315 条条件组和四平台的 mIoU 与 Acc@50。

10 个 CPU 工作者在本机已有缓存的环境中，702 条的全部臂预测与封存用时 **4.23 秒**。该数值不含冻结输出恢复、原封存校验和离线评分。逐例单工作者耗时中位数为 **47 ms**，一次处理整组臂。新入口作为独立实验求解器保留，论文主表继续采用有配对验证支持的正式双姿态方法。
