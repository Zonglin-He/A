# Primary-source check and scope

[TTT++ NeurIPS 2021 proceedings](https://proceedings.neurips.cc/paper/2021/hash/b618c3210e934362ac261db280128c22-Abstract.html) was opened this round. The authors explicitly report self-supervised TTT can deteriorate task performance and propose offline feature summaries/online moment matching and contrastive self-supervision. R92 borrows only the problem of auxiliary adaptation disturbing task representations; it does not implement TTT++ or treat256correlated proposals as independent domain samples.

[EATA ICML 2022 official proceedings](https://proceedings.mlr.press/v162/niu22a.html) was opened this round. It combines sample-efficient entropy adaptation and regularization to preserve critical weights. R92 does not implement its sample selection/Fisher or call its static residual retention EATA. No new regularizer coefficient introduced. A centered penalty or output KL has zero initial gradient and cannot by itself rotate this one-step proposal; engineering checks the literal new-objective gradient against the original physical direction.

The proposed change comes from current user requests and R91 code: a frozen interface still depends on adapted upstream features. R92 caches only the current observation's256delta values and applies the existing physical update to base scores. It is no external teacher, does not certify static identity correctness, and can preserve wrong residuals. Full equations/official code for the cited methods were not reimplemented or independently re-audited this round; proceedings mechanisms above bound the attribution.
