# 冻结 VLM 推理期四方向配对协议

从原有 3EED 主面板按平台和录制轮转、用固定哈希选 96 条，Waymo、Drone、Quad 各 32，RGB 去重。保留无框和回退。它是有历史曝光的开发子集。既有冻结 Qwen3-VL-4B 权重、相机标定和真实 LiDAR 是唯一模型和传感器来源。预测封存后才打开 GT。报告按录制聚类配对区间，Drone 和 Quad 的录制数很有限。

P1 比较原始格式自由续写、Qwen 原中心前缀、由冻结正式框得到的物理中心前缀和同方向错误深度前缀。另用一个数值 token 前缀树限制解码中心，在相同数值候选集合内比较均匀树权重和独立真实回波深度锚加权。数值候选和权重都在解码前冻结。解码过中心后，尺寸与姿态继续用普通贪心生成。加权树是一种有限集合上的 token 控制。主读出为尺寸误差、轴向 yaw 误差、原生及同后端框 IoU，同时保留解析覆盖。

P2 在完整相机视野的真实 LiDAR 上复用四尺度非地面连通域，按相同、固定的可见支持标准提案。提案构造不读取查询、Qwen 2D 框和 GT。去重后最多显示 8 个纯数字标记，允许选 0 表示没有匹配项。比较首次 Qwen 2D 框对同提案池的选择、SoM 选择和编号置换。记录候选覆盖与各选择的共享框读出。

P3 从所有目标评估录制之外的既有冻结帧构建独立诊断记忆。利用已封存 Selection 的正式框和独立 Audit，或者只用 Fit 窗深构造的伪标签，按审计射线代价、命中率及投影重叠排序。严格条件为 Audit 至少 5 条、命中率 ≥0.60、平均截断首交残差 ≤0.25 m 且与首次窗的 IoU ≥0.85。每个目标平台预置两个示例，严格候选不足时按冻结一致性排序补足，记录每个平台的真实严格覆盖。比较同提示的新零样本、等示例数量的同平台随机选择、物理验证筛选、跨平台物理筛选。示例从独立录制取得，当前查询和它的标注均不进入记忆。

P4 在同一数字标记和提案上加入相机坐标、实测跨度、离地高度及最近两邻居的相对度量关系。对照相同标记下无场景图和属性映射错配的场景图。评分单列空间关系表达。补充测量物理图选择后让 Qwen 按对应中心输出完整属性的效果。P2 和 P4 的原生比较共用每个提案的测量框和固定尺寸的补全读出。

所有新模型输出只用于独立实验。模型前向调用、GPU 时间、提案覆盖、示例质量和选择回退均记录。正式入口用已封存的同查询结果作为配对基线。
