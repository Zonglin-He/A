# Source preparation and candidate-specific evidence

[EG-3DVG official implementation](https://github.com/Gwan9Wook/EG3DVG/blob/main/models/encoder_decoder_layers.py) trains positional/expression cross-attention and learned language-conditioned geometric attention. Reusing native Q/K/V does not imply a new spatial-routing interface is trained. We reuse the existing R76 fusion and frozen 3EED attention; learn only a new small candidate-conditioned residual interface from source grounding supervision. No EG weights/third-party snapshot is imported, and this is not its reproduction.

[Distilling Coarse-to-Fine Semantic Matching Knowledge, ICCV2023](https://arxiv.org/html/2307.09267) learns candidate-specific semantic verification and distillation; masked-keyword reconstruction is trained, not a free property of a frozen grounding model. We prepare full/masked grounding discrimination with existing Waymo labels instead of adding an untrained keyword reconstruction decoder. No reference-object identity GT is invented.

R88 mixed multiple local hypotheses into shared text before candidate discrimination and had no TTA increment. R89 keeps global-role local vectors separate and adds each candidate's own physical support. Learned attention selects subject/reference evidence conditioned on candidate features, full-context role text and relative geometry. The trained residual affects actual final matching; base global text/decoder are not overwritten. Zero final residual recovers R76 at initialization. Observed surface moments are features, not full-object boundary truth. Hypothesis support remains uncertain and references still depend on available original candidates; training does not certify semantic identity.

Scope is source-prepared TTA, not a no-source-preparation claim. Source feature extraction is frozen and shared. New spatial interface vs matching-only continuation vs query-only residual have equal source data/epochs and full/two-masked supervision, not equal active parameter count or architecture. Source auxiliary heads are inherited; their constant loss is not reported as new-interface training. Test updates retain the R88 existing102498-parameter interface while prepared discriminators remain frozen, to isolate whether task preparation changes the benefit of the same observation update. This is not a source meta-auxiliary algorithm.

All papers/code and captions are treated as evidence rather than instructions. No document text is executed, and target labels/FINAL do not enter source preparation, selection, pseudo signals or step acceptance.
