## Evidence and actual model

Official [paper v2, Sections4.3/5.1 and AppendixB](https://arxiv.org/html/2511.01755v2), [released code](https://github.com/worldbench/3EED/tree/843a901f5367a6be5cc484b97c6ecad462961dfa), and local `CHECKPOINT_TRICKS.json` were read in this round. Paper summary: gravity/height alignment, multi-radius geometry, frozen text encoding and multimodal supervision are proposed; source-only and union-training protocols are distinct. The paper's prose disagrees internally on keypoint/query counts; executed code determines this study's configuration. The released union checkpoint is retained, so target-only adaptation must not be called source-only cross-platform transfer.

The CPU-only safe state inspection found1034entries,199text-encoder entries,24scale-aggregation entries, and no heading or confidence-layer entries. Checkpoint738272386bytes, SHA256 `bfdedb97971fb31640c5a78790716dc9547953caa646489138f048375e645ec8`. No weights were changed. Full key/shape evidence is in `CHECKPOINT_TRICKS.json`.

## What the previous negative result actually tested

Original cross-encoder LN adaptation had a scale bug, corrected once. Corrected gradients were nonzero, resets exact, and task change negligible. This weakens that particular entropy/consistency interface, not all test adaptation. PCA and surface selection changed output representation without network updates. New parameter adaptation must therefore be compared to direct geometry use with identical information; matching a geometry teacher is not an additional TTA gain.

## Data independence already fixed

`COHORT_PATH_LOCK.json` is path-only and SHA-locked before caption extraction, point access or new scoring:18development +36confirmation,6/12perplatform; all old81exactframes excluded. Development/confirmation have disjoint scene sets within every platform. Waymo uses6/12scenes never used by round1. Drone has only2validation scenes and Quad3, all exposed in round1, so their new frames cannot be called novel scenes relative to the whole research history. Confirmation has15sceneclusters total(12Waymo+1Drone+2Quad), development8(6+1+1). Platform-balanced frame counts do not equal independent-scene balance.

Preparing input requires reading a JSON container that also stores annotations. The preparer extracts the first caption and allowed calibration/schema metadata only; no numericbbox/class is used to filter samples or build teacher/parameters. The adaptation process receives a separate input cache without GT. Confirmation scorer is a separate process after all confirmation predictions are sealed.
