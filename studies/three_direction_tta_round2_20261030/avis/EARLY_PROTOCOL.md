# Round2 discriminating experiment draft

State: draft pending parent review / GPU allocation; cohorts already locked. Proposed mechanism is an engineering/research test, not a selected final TTA method.

Hypothesis: frozen video-level predictions have useful long-context identity/shape information that the frame localizer misses; moving adaptation before the local decoder can exploit it. The alternative is that both heads share incorrect source attribution or teacher trajectories suppress real appearance/activity variation, so the update harms or has no benefit.

Method: early query latent distillation (EQLD). Add zero-initialized per-video shared latent Δ∈R^(100×256) to `av_post_proj` output before initial frame queries. All pretrained weights frozen. Use eight uniformly spaced original-order anchor frames. Frozen original clip predictions provide up to100 class probabilities and per-anchor soft masks. For teacher clip candidates with foreground confidence≥0.3 and nonempty binary mask (at least4 low-resolution pixels), Hungarian-match class-compatible frame queries using class probability and Dice cost. Use only matched pairs with soft Dice≥0.5 and identical foreground argmax category. This is an uncalibrated reliability gate, not proof of correct sound attribution. Fixed pseudo correspondence is computed once, never refreshed to maximize easy matches. Loss is 2×per-pair teacher class cross entropy + 5×mask BCE + 5×Dice + 0.5×raw-dot-product identity BCE + 0.01 latent squared mean. Class/mask/Dice follow the original2/5/5 scales. The0.5 identity coefficient follows the paper; the checked-in naming mismatch is recorded in TRICKS_AUDIT. Identity uses adapted tracker pred_fq_embed, frozen source pred_cq_embed and fixed pseudo-correspondences. Different teacher IDs form negative pairs only when max mask IoU across anchors is below0.1; this is still a pseudo-identity assumption. Background queries receive no invented absence targets. Three Adam steps, proposed LR0.03, global gradient clip1, per-coordinate latent projection[-0.25,0.25]. Those numerical scales are draft and will be justified by GT-free gradient/capacity checks before main protocol lock. Re-run all original frame queries with adapted latent, then original tracker and score readout. Reset latent to zero and optimizer per video. If no gated pairs, exact source output, recorded as no-update.

Why different from round1: feedback compares two task heads at different temporal scopes, optimizes an explicit25,600dim latent BEFORE local masked attention, and includes spatial mask supervision. No time reversal or entropy objective. Teacher is the same frozen official checkpoint, no external annotated/semantic teacher. It is self-distillation and may not improve audio dependence.

Arms proposed for both dev and confirmation:

1. source: official source readout.
2. direct_teacher_fusion: same source local and clip predictions and matching; fixed0.5 soft-mask fusion for matched per-frame tracks, source classes/identity/scores retained, then same binary threshold. This controls useful extra head information without optimization. Keep unmodified source result where match gate fails. Record separate score-quality behavior rather than silently changing confidence semantics.
3. old_LN_entropy3: exact previous round20261029 implementation late audio-fusion LayerNorm6144param, 3stepsLR1e-4 and matched two-view readout. Carries its paired no-update old_views control so readout effect is separated.
4. old_views0: previous matched reversal averaging without update.
5. EQLD3: new early latent, source-only final clip readout.
6. EQLD_no_identity3: same teacher/pairs/budget and spatial/class losses, remove only identity BCE; tests the original training trick as a single-factor control.
Audio diagnostic, separate from six scored arms: for source and already-adapted latent, hold latent fixed and replace audio with fixed next-video donor within split (length mapped by floor) or shift original audio by3seconds. Compare raw early audio-query, clip logits/mask vectors and Hungarian matched class/mask instance responses against original audio. No original-label task score is assigned to these counterfactual conditions; mismatched audio is not known-negative ground truth.

Cohorts: full-video dev8, confirmation12, all disjoint from old8; metadata-only SHA sort already locked. Dev GT may be used once for mechanism decision after predictions sealed. At most one prespecified revision based on diagnosed failure, preserving all dev negatives; any revision gets new version and fresh final plan. Confirmation all arms/parameters/thresholds locked after dev decision, before any confirmation GT scoring. No parameter sweeps, no replacing bad samples, no GT-based output rollback. If mechanism is inert (zero gates / negligible signal / latent does not move outputs), report failed premise and stop rather than call it success.

Costs: process each video separately; cache frozen visual pyramid + mask features on CPU; anchor gradients in small chunks. Peak GPU/CPU memory and wall time, number gate pairs, objective components, gradient norm, latent norm and output changes recorded. GPU lease required. Oracle if necessary only on one OLD video under independent oracle-positive-control directory, masks never flow to new-cohort mechanism. All new predictions seal before native/area-only/exact-set metrics; native bugs remain explicitly scoped. Primary sound-source measure is separately defined per-frame class-compatible perfect-matching exact-set correctness, averaged over19IoU thresholds0.05…0.95 (area-zero absent). Instance tracking is native HOTA plus area-zero sensitivity. Native FSLA is historical compatibility only and cannot support adoption from tiny gains. Per-video paired differences are the unit of uncertainty and negative-tail reporting.

Decision: adopt only if confirmation improves intended sound-source/instance metric versus BOTH source and same-information no-update at acceptable costs; HOTA-only gains described as identity/track benefit. Report all per-video deltas including worst regressions, category/none/single/multi coverage after GT release, uncertainty for12 convenience-hash videos, and actual audio sensitivity rather than claiming sync/negative-label validity.
