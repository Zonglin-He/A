| Early audio interface | `avism_transformer_decoder.py:446–454`: 128→256 `av_pre_proj`, three audio-query→multiscale visual cross-attentions using learned query positional vectors, concat768→256 `av_post_proj`, add to100 learned frame query features. Zero pad to ceil(T/6)*6 with attention masks; trim before global decoder. Learned frame-query-slot positions repeat at every time, no unique absolute time code. Joint reversal can be exactly/approximately symmetric, so round1 reversal is a poor feedback signal. |
| Query identity similarity | Trained `sim_embed_frame` and `sim_embed_clip` use raw dot-product logits, not normalized cosine, BCE over within-clip pair labels. GT correspondence obtains matched frame/clip foreground identities. The raw learned embedding may be useful as a compatibility diagnostic, but pseudo matching at test time is not GT identity. |
| Training losses | Class2, mask sigmoid BCE5, Dice5; no-object0.1; 12,544 sampled points with oversample3 and importance0.75; separate frame and clip Hungarian matching, deep supervision. Training also uses identity loss. Entropy over100 mostly-background queries does not reproduce any of these objectives. |

## Mechanism implication

Round1 late-LN reversal objectives were near zero because of architecture symmetry; they did not test whether the early localizer can change. Round2 will test an explicit early query latent, supervised only by the frozen model's long-context trajectory predictions. It targets disagreement between per-frame localization and video-level identity/shape, not an assumed independent audio oracle. Source correspondence can remain confidently wrong in both heads. An audio-feature replacement diagnostic is therefore required alongside task metrics; zero VGGish vectors are not silence, and swapped audio is not labeled as absent-source truth.
