# Audio activity v1: independent evidence and explicit activity latent

Development8 was already exposed by early-latent v2. Confirmation12 remains unscored and is not used to set prompts or numerical choices. This is one finite reconstruction, not a model/prompt/temperature sweep. It can fail and all failures remain.

Teacher: official LAION-linked `laion/clap-htsat-unfused` revision8fa0f1c6d0433df6e97c127f64b2a1d6c0dcda8a,153,492,890parameters;614,525,833byte PyTorch state dict SHA1cd3c601bc4afe0fa87be3de4c13dd2cfadd249fac1e29acf74a9b296c3219bb. Primary provenance: https://github.com/LAION-AI/CLAP and https://huggingface.co/laion/clap-htsat-unfused . LAION training-corpus overlap with this benchmark has not been audited; this is a fixed external prior, not target-label supervision.

The independent frontend reads actual PCM with SoundFile float32, averages stereo, resamples44.1→48kHz via rational polyphase, takes3-second windows `[t-1,t+2)` around each official1-second bin, zero-pads outside waveform, then official CLAP repeatpad to10seconds. This is full-video episodic/noncausal context. AVISM continues to use its unchanged author-cached VGGish features, including their original PCM scaling condition. Do not substitute one frontend for the other.

PROMPTS_LOCK fixes all26 taxonomy names before CLAP scores. Instrument descriptions refer to sound/playing/music; person includes voice, speech, singing, laughter, shouting and crying. Animal/machine text follows public category semantics. Three background descriptions are fixed. Prompt vectors are independently normalized then averaged per class and normalized; background vectors are retained separately. Audio/text cosine is not a calibrated probability.

Relative multi-label evidence is `q_c(t)=sigmoid((cos_c-max(max_background_cos,max_class_cos-0.04))/0.02)`. It admits multiple supported classes and a background reference; it does not normalize to a single winning class. Margins/temperature are fixed before embeddings are inspected. Neither q nor the background prompts prove silence, visibility or source count. Arbitrary mismatched audio is never given a negative label.

The actual adaptation variable is a zero-initialized class×time activity residual r (26×video seconds), not pretrained network weights. Base activation logit3 yields an initial retained gate for every source candidate, with exact zero-step/source bridge. Only source-visible class/frame positions participate. Optimize20Adam steps atLR0.5: confidence-weighted Bernoulli cross entropy to q, plus0.1 mean adjacent activation total variation, plus0.01 mean squared residual anchor. Weight is `abs(2q-1)`, a declared relative-evidence weighting rather than calibrated reliability. Clip residual to[-8,8] and global gradient norm1. Fresh zeros/optimizer for every video. Final gate is sigmoid(3+r)≥0.5. This late decoder latent controls final per-frame active masks directly, avoiding attenuation by the frozen tracker.

All teacher arms retain original binary segmentation geometry/category/track confidence. A gated-off frame becomes a correct-size area-zero RLE; a track absent at all frames is dropped. The same rule applies to direct and adapted arms. No new objects/classes can be recovered beyond source proposals; no claim of solving within-class source selection is made. In particular, audio class evidence cannot choose among several people with the same speech category. Offscreen sounds, mixtures, short event boundaries and rare taxonomy nouns remain failure cases.

Six arms: immutable source; immutable early-latent v2; direct q≥0.5 gating; direct5-second median-smoothed q gating; activity latent with temporal penalty; activity latent without temporal penalty. Direct and smoothed-direct share exactly the same teacher/candidates and are mandatory strong controls. Any apparent gain relative to source must be checked against both direct arms. Improvement due only to the external teacher does not establish a TTA contribution.

Primary measures: separately defined per-frame complete class-compatible instance-set correctness at19IoU thresholds (area-zero absent), macro-video paired differences and frame-weighted values; instance tracking nativeHOTA and area-zero sensitivity; mAP secondary; native FSLA compatibility only. Preserve every video delta, especially regressions. All six final predictions seal before scoring; confirmation has a separate final plan gate. Teacher preprocessing/inference, source inference, adapter runtime and memory are reported, with amortization explicit. Source/global scores are not silently recalibrated.

CPU contracts passed strict safe model load, real normalized-WAV→finite512dim embedding, synthetic nonzero activity residual that changes the final gate, and exact real-source zero-step bridge. These are engineering evidence, not task scores.
