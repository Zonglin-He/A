# Coordinator independent checks

2026-10-30. These observations refer to source actually read in this round, not a claim that every historical implementation was reproduced.

- GREAT native loader uses PIL RGB resize and ImageNet normalization. Round1 matched these steps. Native point normalization retains raw float64 until normalization, then casts tofloat32; round1 cast earlier. Round2 corrects this with an explicit source bridge and does not count the correction as TTA benefit.
- Literal GREAT HM loss uses alpha.25/gamma2 focal plus positive and negative Dice ratios without the usual2×intersection. Soft self-target has nonzero gradient, so a loss reduction can include calibration effects. RankAUC/SIM/MAE and strong no-update controls remain necessary.
- Round2 AVIS early latent source/zero/reset bridges are exact, but the development exact-set metric improved by only1of9120judgments. Ground-truth count/class mismatches remain unchanged, so early controllability alone did not repair activity selection.
- AVIS independent CLAP semantic evidence was genuinely new information, but the initial relative-to-max-class reference excluded weaker co-occurring true classes. Background-only reference is a single documented structural repair; no prompts/temperature/steps were selected on confirmation. The static no-TV objective has an optimal hardgate threshold q=.5−sqrt(.03); finite20step optimization can differ from that optimum, so the direct analytic control is mandatory.
- 3EED grounding evaluator actually evaluates rotated7D GT against6D aligned predictions. The separate generic detection APhelper sets yaw0 for both, but it is not this grounding path. Adding predictedyaw is an explicit representation extension under the existing rotated grounding target, not a redefinition of GT.
- The round2 3EED task scorer initially used numpycos/sin on float32yaw, violating its general3Dconvex intersection's much tighter geometric tolerance. A separate2Dpolygon×height implementation exposed14/144wrong development scores. Doubleprecision rotations fixed it without changing predictions. Round1's affected code paths were separately checked and already castboxes tofloat64.
- The shared288-feature residual adapter moves even rejectedqueries unless masked. Both proper sourcefallback and a function-space trustregion must be distinguished from reliable task feedback. Constraint satisfaction is not task improvement.
