# 在原有 256 个查询的上下文中逐个核验未入选的点

3EED 对 1,024 个 seed 打分，取其中 256 个生成候选。我们用原 checkpoint 的六层解码器读完其余 768 个 seed，保留精简 v1 的四个主体框，检验这些点能否帮助选择同一句话指向的物体。在六方向 3,072 条开发记录上，主读出改变了 52 次选框。**Acc@50 救回 0 条、误改 0 条；Acc@25 救回 2 条、误改 5 条。** 四槽中有达标框而原赢家没有达标的 248 条 Acc@50 机会全部保留在分母。按登记的判据结束这项读出实验，主方法继续用精简 v1。[预设协议](PROTOCOL.json) · [逐例结果](results/pilot_rows.csv.gz) · [裁决](results/pilot_decision.json)

## 为什么要逐个读备用点

原生注意力使一个查询的读数取决于同时出现的其他查询。把所有备用点一次送入开放的解码器，会同时改变原有候选的内部表示和预测位置。本实验询问每个备用点**单独作为第 257 个查询**时会产生什么框、给主体词多少概率。原查询只能读取原查询；每个备用点能够读取原查询和自己。六个解码层共用这个可见性规则，所有点使用同一份冻结的点云与文本表示。该计算只用已有权重，无新增训练、标定、人工标签或目标参数更新。[原生选点与回归](https://github.com/worldbench/3EED/blob/843a901f5367a6be5cc484b97c6ecad462961dfa/models/bdetr.py#L147-L156) · [实际重放](probes.py)

在数学上，第一层的原查询输入与基准相同，每个备用查询只依赖自己的输入和这批原查询。若此性质在一层输入时成立，掩码自注意力保留该性质；跨模态读取使用相同的冻结 memory，前馈、评估态归一化及逐查询回归也保留该性质。因此归纳到第六层，同时读取 768 个备用查询可得到 768 次单点插入的结果。在开发集 48 次真实单点重放中，和并行结果比较，框中心或尺寸单一分量的最大误差为 0.00000191 米，主体词概率的最大误差为 8.37e-11。独立重算原有 256 个查询时，全开发集最大几何差为 0.00001097 米。这个性质验证了测量可以重复，任务纠错能力要另行评价。[几何与语义核对](results/pilot_coverage.csv)

## 由实测票数得到选框分数

对一个固定输出槽 $i$，用它在 PCA 以前的原生框来比较探测到的框。记 $k_{ij}$ 为这两个轴对齐框的 3D IoU，$p_j$ 为原生匹配头在全部文字 token 上归一化后赋给主体词的概率，$T$ 为原 256 个查询，$R$ 为备用 768 个查询。局部平均值及对冻结槽分 $s_i$ 的改动为

$$
m_i(J)=\frac{\sum_{j\in J}k_{ij}p_j}{\sum_{j\in J}k_{ij}},\qquad
s'_i=s_i+\log\frac{m_i(T\cup R)}{m_i(T)}.
$$

若所有新增票在空间上都接触不到该槽，改变量为零。若新增票在该槽内与原票具有相同加权平均概率，增加点数本身也不改变得分。代码在可比较槽内恢复原有总概率质量，其他槽仍可赢。最终返回精简 v1 已经产生的七维框，包括原 PCA 朝向。上式定义的是模型读数的变化；把它当作定位证据，需要假设未被文字选中的 seed 仍有可迁移的主体语义。[读出实现](probes.py) · [独立概率空间复算](score_probes.py)

同预算对照让全部 1,024 个查询开放交互，仍取同一 768 个备用输出，同原始的 256 个实测输出组合。另有不经过六层的提议头、仅累计词概率票数、仅累计重叠质量、同帧置换备用词概率四组对照。两项积累量给出精确分解：词概率票数增长的对数，等于局部平均词概率变化的对数与重叠质量增长的对数之和。每个槽的此项等式均经过独立数值核验。[对照与公式](PROTOCOL.json)

## 与已有方法的关系

3D-SPS 在训练和推理中渐进筛选与语言相关的点；VoteNet 从 seed 预测指向物体的票并学习如何聚合。BRNet 从三维提议的位置回读邻域点来改善检测。Read-only Prompt Optimization 已使用单向掩码保护原特征。这里检验的具体操作是把**同一冻结模型按原句淘汰的物理 seed**逐个加入其真实解码上下文，估计固定候选的平均主体词证据如何随入选集合改变。单向掩码和点投票各有明确先例。实验未给这个新用法提供精确定位收益；它不构成替换精简 v1 的依据。[3D-SPS，CVPR 2022](https://openaccess.thecvf.com/content/CVPR2022/papers/Luo_3D-SPS_Single-Stage_3D_Visual_Grounding_via_Referred_Point_Progressive_Selection_CVPR_2022_paper.pdf) · [VoteNet，ICCV 2019](https://openaccess.thecvf.com/content_ICCV_2019/papers/Qi_Deep_Hough_Voting_for_3D_Object_Detection_in_Point_Clouds_ICCV_2019_paper.pdf) · [BRNet，CVPR 2021](https://openaccess.thecvf.com/content/CVPR2021/papers/Cheng_Back-Tracing_Representative_Points_for_Voting-Based_3D_Object_Detection_in_Point_Clouds_ICCV_2021_paper.pdf) · [Read-only Prompt Optimization，ICCV 2023](https://openaccess.thecvf.com/content/ICCV2023/papers/Lee_Read-only_Prompt_Optimization_for_Vision-Language_Few-shot_Learning_ICCV_2023_paper.pdf)
