# R175 源域双端监督与关系点支持反馈

**本配置未同时超过两项关键对照，关系点反馈的跨平台收益尚未建立。** 完整版本的六方向 Acc@25／Acc@50／mIoU 为 **24.055 / 9.660 / 12.905%**。相对单体几何反馈变化 **-0.290 / +0.040 / -0.120 pp**，相对仅配对打分变化 **-1.059 / -0.217 / -0.503 pp**。

## 1. 配方与边界

三个单平台 3EED epoch100 权重与已有同源 RGB 点投影特征均冻结。用原生语言匹配从 A256 初始化四个主体和四个参照槽，同样用原始点生成 PCA 朝向。R158 分数和候选选择只用于表中的内部对照。三个循环共享参数。所有学习版本保留预测框引导的单体几何反馈，完整版把配对条件概率加权的参照空间场加入下一轮点分数。参照角色使用反向关系。置信度、投影深度和可见性约束点场，未知关系走单体路径。输出框来自原生候选，连续回归只提供中间几何状态。

CORE-3DVG 通过目标与上下文对象的关系匹配辅助定位，EG-3DVG 通过几何掩码控制注意力，EDA 对语言成分与点云表示进行细粒度对齐。R175 的受检验差异是已监督参照实例的条件空间场是否在后续点注意力中提供超出同信息配对打分的帮助。 [CORE-3DVG](https://proceedings.neurips.cc/paper_files/paper/2023/file/9b91ee0da3bcd61905fcd89e770168fc-Paper-Conference.pdf) · [EG-3DVG](https://openaccess.thecvf.com/content/CVPR2026/html/Park_EG-3DVG_Expression_and_Geometry_Aware_Grounding_Decoder_for_3D_Visual_CVPR_2026_paper.html) · [EDA](https://openaccess.thecvf.com/content/CVPR2023/html/Wu_EDA_Explicit_Text-Decoupling_and_Dense_Alignment_for_3D_Visual_Grounding_CVPR_2023_paper.html)

## 4. 关系点反馈和真实实例绑定

**2570 条**记录解析出支持的关系，实际点反馈非零 **2570 条**。关系子集上的配对差异为相对单体几何反馈 +0.286 / +0.662 / +0.324 pp，相对配对打分 -0.733 / +0.230 / -0.385 pp，相对完整权重，关闭点反馈 +1.411 / +1.101 / +0.797 pp，相对完整权重，配对与点场错配 +0.348 / +0.145 / +0.161 pp。

同一 checkpoint 保留点场，相对关闭的全量增量为 +0.169 / +0.131 / +0.095 pp，相对配对与点场错配的增量为 +0.038 / +0.014 / +0.019 pp。关系证据能改变评分前的点注意力。参照身份的可靠性还需要几何与身份匹配的干预证据。

完整模型有 **4103／1301 条**已有达标主体候选却未选中。选择后框内支持比例和各关系子集见统计文件。

| 物理参照干预 | 可比／全部 | 正确参照的框内支持质量 | 错配的框内支持质量 | 正确参照相对错配的 IoU 改善／恶化 |
|---|---:|---:|---:|---:|
| 源域留出 | 114/336 | 49.183% | 47.611% | 3／5 |
| 目标已核验 | 1/50 | 76.414% | 78.441% | 0／0 |

干预只替换主体点反馈中读取的参照槽，保留文本、主体槽与同一权重。框内质量在同一个候选槽和同一批点上计算，表示框内点的注意力质量。身份含混、支持不足和候选缺失均保留原因和计数。这些条件性结果在主预测封存后获得，仅用于解释。

完整减单体几何反馈的 95% 录制重采样描述性区间为 Acc25 [-0.644, +0.622]，Acc50 [-0.119, +0.497]，mIoU [-0.292, +0.235] pp。

完整减完整权重，关闭点反馈的 95% 录制重采样描述性区间为 Acc25 [-0.011, +0.404]，Acc50 [-0.018, +0.252]，mIoU [-0.037, +0.224] pp。

按目标平台在录制内分组，两条源方向共享重采样。目标录制数为 Waymo 93、Drone 2、Quad 3。独立 CPU IoU 核验了 18,620 条，最大误差 3.94e-15，两个阈值零分歧。所有结果含全部正负变化。目标端参数更新次数和 FINAL 访问次数都为零。
