# R5 冻结 HiSpatial 原生 XYZ 通路干预

本轮使用 R4 的同一批 107 道 SpatialRGPT-Bench 钟面方向题。官方彩框、RGB、带参考系的题目和 MoGe 点图均复用封存输入。三种模型条件共用同一个冻结的 HiSpatial-3B，保持原解码。只在两个对象框的有效独占像素上，将 XYZ 替换为 R4 矩形读出的对象中心。对应组将两个中心放回各自对象，交换组将中心互换。两框重叠的像素、原来无效的像素及框外坐标保持原样，有效掩码逐值保持。 [锁定配置](NATIVE_XYZ_R5.json) · [R4 记录](OBJECT_PAIR_R4_ZH.md)

对象中心由与 R4 一致的采样点几何中位数复算，采用重力对齐后的右、下、前轴表示。干预只作用于上述像素，框外使用原相机 XYZ。同信息程序从实际写入的 FP32 中心直接读出钟点，交换时逐题检查相差 180°。107 题中有 94 道具备 R4 中心，其中 1 道无法为两个框都找到独占有效像素。实际干预 93 道，剩余 14 道的模型与同信息读出均回退本轮同格式原生回答。

每题从一次未干预的官方原生前向捕获 RGB 特征，之后两种编辑都复用该特征。更新后的 XYZ 经过原正弦位置编码、14×14 的不重叠深度卷积和冻结融合投影。原生视觉输入与缓存身份复核，以及原生与编辑分支的逐块比较，从像素层跟到融合后的视觉 token。 [HiSpatial 官方融合代码](https://github.com/microsoft/HiSpatial/blob/9b0a5718ed0fb3b8bd9d9e0b36b6192bd3e99be1/hispatial/model/hispatial_vlm.py#L279)

首次预检比较两次独立 RGB 前向，发现未改 XYZ 的融合结果也可能存在数值差异。该预检停在评分前。正式运行改用从同一次官方前向捕获的 RGB 特征，并对相同 RGB 与同一份原生 XYZ 做逐值回放。两次准备产生的 107 条输入清单字节一致。该修正用于隔离真实 XYZ 效应。

本轮原生复跑中，106/107 条的完整输出与封存 R4 逐字一致。唯一变化让本轮原生多对一题。相对本轮同格式原生，正确 XYZ 救回 0 题、误改 1 题，增量 −0.93 pp，按物理图像聚类的 95% 区间是 [−2.86, 0.00] pp。该题就是原生重放发生变化的那一道。按历史 R4 原生比较，107 道题的成功与失败标记与正确 XYZ 逐题相同。交换对应相对本轮原生为 +2.80 pp，配对区间 [−0.93, +6.93] pp。完整 PaliGemma 输出与钟面分数分别保存。 [配对结果](results/native_xyz_r5_20261122/PAIRED.csv)

R4 早先的直接读出为 93/107。本轮同信息物理读出严格复用模型干预的有效范围。那一道缺少独占像素的题回退原生，使全量直接读出成为 92/107。

## 反事实检查

93 道真正编辑的题，同信息计算从正确对应换到交换对应，**93/93 精确转向 180°**。模型在两组都给出可解析钟点的 91 道中，78 道仍报同一钟点，13 道改变。其中 9 道变化 90°、2 道变化 60°、1 道变化 30°、1 道变化 150°。**精确反转 180° 为 0/91，允许 ±30° 时为 1/91**。两次回答都与各自同信息读出相差至多一个小时的题为 0 道。正确对应和交换对应分别在 24/93、18/93 道与各自的同信息钟点相差不超过一个小时。 [逐条件汇总](results/native_xyz_r5_20261122/SUMMARY.json)

## 确认改动进入原生融合

目标像素触及的几何 token 每题中位 **149** 个，范围 16–865。全部 93 道题的正确对应、交换对应及两者差值，在目标范围内都改变了深度编码和融合结果。目标像素所触及的 patch 以外，深度和融合变化均为 **0**。8 道预检中，捕获原生 RGB 后重放原生 XYZ 可逐值复现官方前向。24/24 组批量与单图解码一致。独立复算了 93 道框内占用和中心反转。采用不同浮点乘除顺序时 1 道的边界像素归属有变化，该题的 patch 覆盖完全一致。 [独立复核](results/native_xyz_r5_20261122/VERIFICATION.json)

**裁决。** 这次中心覆盖干预已经到达 HiSpatial 的原生融合层。它没有提高钟面问答的成功率，模型对交换的响应也没有与几何定义一致。可见几何的直接读出仍保留为有效对照。这是给定区域、固定 107 道已曝光方向题和固定中心覆盖方式的诊断。中心广播将对象框内被选中的可见点压成单个位置，保留局部形状的 XYZ 干预尚未评估。

## 复现与产物

使用 R4 的封存图像、点图和方向条件。正式运行解码 107 条原生、93 条正确对应与 93 条交换对应，共 293 条，加上预检。RTX 5090 进程用时约 85.4 秒，峰值 CUDA 分配 16.22 GiB。参考答案在原生 XYZ 预测封存后读取，比较采用 R4 的 ±1 小时口径和图像聚类配对区间。本地 `outputs/hispatial_r5_native_xyz_20261122/` 保留完整输出、特征审计及评分，先前实验路径保持只读。

```bash
study=studies/hispatial_zero_shot_spatial_reasoning
assets=/path/to/model-cache
cpu_python=python
gpu_python=python
export PYTHONDONTWRITEBYTECODE=1 HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1

"$cpu_python" "$study/native_xyz_r5.py" prepare
"$gpu_python" "$study/native_xyz_r5.py" predict --model-cache "$assets"
"$cpu_python" "$study/native_xyz_r5_score.py"
```
