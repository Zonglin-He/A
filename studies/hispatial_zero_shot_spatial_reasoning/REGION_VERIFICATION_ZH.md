# HiSpatial 单区域语义核验与物理深度读出

EmbSpatial-Bench 的近／远题使用冻结 HiSpatial-3B 和已经封存的 MoGe-2 点图。这轮先用标注框检验完整物理区域库的深度读出潜力，然后在原来的 96 题上测试单区域 Yes/No 似然能否改进语言实体绑定。每个阶段复用原始图像、点图和冻结回答。[前一轮八区域实验](PHYSICAL_SELF_GROUNDING_ZH.md) · [EmbSpatial 论文 §2.1](https://aclanthology.org/2024.acl-short.33.pdf)

## 固定展示池的单区域核验

对问题中的每个具体对象和该图像上的每个原展示区域，保留原场景与对齐 XYZ。图像上只叠加该区域的半透明掩码和轮廓。无字母标记，每个区域使用相同颜色。核验分数采用冻结 HiSpatial 在第一解码位置的两种规范答案对数似然差
\[
s_{ij}=\log p_\theta(\mathrm{Yes}\mid I_j,X,o_i)-\log p_\theta(\mathrm{No}\mid I_j,X,o_i).
\]
每个对象可使用一个零分的拒绝位置。达到原掩码重叠阈值的区域归入同组，每组至多分配一次。组的边权是组内最高兼容分数。联合匹配求所有对象边权之和的最大值。语义干预保留同一图像和 XYZ，将题内具体物体名称轮换，另用问句的补命题检查分数符号和排序。离线用矩形 IoU 评价绑定，用低重叠区域作为错区对照。[锁定配置](SINGLE_REGION_VERIFICATION.json)

固定展示池上，单区域联合版比分组三选多正确绑定 25 个对象，救回 50 个、丢失 25 个（+6.60 pp，场景聚类 95% 区间 [+1.56, +11.24]）。加入联合分配后，完整且物理组互异的题数由独立拒绝版的 15 增至 34。对象命中从 112 降到 106，整题全部正确均为 1。96 道题中只有 3 题存在一套互异且全部达到 IoU 0.25 的展示候选，以这个池子衡量整题绑定的区分空间有限。离线穷举独立复核了每题四种联合分配的目标值与拒绝可行性。[绑定指标和负对照](results/region_verification_20261121/SINGLE_REGION_SUMMARY.json) · [配对结果](results/region_verification_20261121/SINGLE_REGION_PAIRED.csv)

- **名称有独立区分信号。** 正问中，达标区排在低重叠区之前的对象内平均 AUC 为 0.872。固定达标区域并将名称替换为另一个低重叠对象，正确名称的分数在 167 个配对中有 151 个更高。在 99 个交叉 IoU ≤ 0.05 的双对象配对中，95 个的正确对应总分更高。题内轮换名称后，联合绑定降至 19/379。
- **同预算的收益尚未复现。** 完整正问平均每个对象 7.99 次调用，分组和预算控制均为 3.86 次。预算控制仅访问几何排名前 3–4 个区域，仍与旧分组一样用 1,462 次模型输入，覆盖达标候选的对象由 209 降到 131。70/379 的成绩属于这一固定预算策略。
- **反问与拒绝存在代价。** 反问 2,929/3,028 次给 Yes 更高概率，合并正反问后正确绑定降至 64。主联合版的 273 个错误或拒绝中，170 个缺达标候选，75 个有达标候选但正问首名不达标，10 个达标首名被零分拒绝，18 个达标首名在联合分配时被改掉。掩码分组只合并了 1 张图上的重复区域，其余冲突来自多个对象竞争同一展示区域。

实际执行 3,028 次正问与 3,028 次反问，另有 64 次批量数值对照。两种提示各选 16 个单条／成批样本，似然差的最大差异为 3.82×10⁻⁶，符号全部一致。FP32 候选打分约 723 秒，峰值分配显存 19.94 GiB。结论对应规范 Yes/No 两个第一步 token 及本次固定提示。MoGe 点图直接复用。训练步数为零。

## 官方近／远问答

联合版通过了固定面板的物体绑定门，随后在同样 96 题上重放官方评分。只有所有具体对象都分配到互异物理组且深度极值唯一时，才用区域或同区矩形的平均深度回答。34 题采用几何读出，62 题使用原回答，其中原版答对 43 题。[逐条件汇总](results/region_verification_20261121/SINGLE_REGION_SUMMARY.json) · [问答分项及误改归因](results/region_verification_20261121/QA_READOUT_AUDIT.json)

| 96 题 | 答对 / 96 | 准确率 | 对原版救回 / 误改 |
| --- | ---: | ---: | ---: |
| 原始 HiSpatial | 65 | 67.71% | — |
| 八区绑定的物理深度 | 63 | 65.63% | 0 / 2 |
| 整图深度高亮 | 60 | 62.50% | 5 / 10 |
| 单区域核验＋联合绑定＋同区矩形深度 | 63 | 65.63% | 4 / 6 |
| 单区域核验＋联合绑定＋物理掩码深度 | 62 | 64.58% | 3 / 6 |

主读出相对原版 −3.13 pp，95% 场景聚类区间 [−8.54, +1.91]。下降来自 48 道远题中的 3 个净损失。34 道实际采用几何读出的题，原版答对 22 道，矩形与物理掩码分别答对 20 和 19 道。6 个误改题均缺至少一个达标端点，其中有 5 道的正确选项自身已经对上 IoU ≥ 0.25 的区域。因此答题表现还依赖其他候选对象的正确归属及可比的深度，单个目标框达标无法保证排序成立。

**本轮裁决。** 保留单区域正问能区分物体名称的结果。当前联合深度读出未能超过原始 HiSpatial，同调用预算下的绑定收益也未复现。停止于既有 EmbSpatial 近／远题的诊断范围，维持冻结官方推理作为 Spatial QA 参考配置。

## 复现

沿用原八区域实验及几何诊断已封存的输入与输出。以下命令从仓库根目录运行，使用 README 说明的 GPU 和离线评分环境。逐候选似然、逐对象绑定、逐题预测与错误记录写入两个新 `outputs/` 目录。

```bash
study=studies/hispatial_zero_shot_spatial_reasoning
assets=/path/to/model-cache
cpu_python=python
gpu_python=python

"$cpu_python" "$study/oracle_region_binding.py" prepare
"$cpu_python" "$study/oracle_region_binding.py" score --official-source "$assets/sources/HiSpatial"
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 \
  "$gpu_python" "$study/single_region_verification.py" --model-cache "$assets"
"$cpu_python" "$study/audit_region_verification.py" --official-source "$assets/sources/HiSpatial"
```
