# HiSpatial 多物体视角与远近题错因分析

本轮使用 3DSRBench 全部 175 个多物体视角原题组（1,372 条变体），以及 EmbSpatial-Bench 全部 1,206 道近／远题。保留所有正确与错误结果。原始 MoGe、仅 RGB、错配 XYZ 使用同一份冻结 HiSpatial-3B 权重、同一张图、同一题与同一批解码。官方评分在预测封存后重放。 [固定配置](GEOMETRY_DIAGNOSIS.json) · [HiSpatial 官方评测](https://github.com/microsoft/HiSpatial/tree/9b0a5718ed0fb3b8bd9d9e0b36b6192bd3e99be1/eval)

3DSRBench 的两种官方解析得到相同的原题组成绩。相对仅 RGB，正确配准的 XYZ 在 3DSRBench 增加 2.86 个百分点，按物理图像聚类重抽样的 95% 区间为 [−0.58, +6.59]，相对错配增加 9.14 个百分点 [3.59, 14.53]。EmbSpatial 远近合计相对仅 RGB 增加 8.87 个百分点 [5.85, 12.12]，相对错配增加 23.13 个百分点 [19.44, 26.79]。去掉 XYZ 使 208 道原本正确的远近题变错，也救回 101 道。分项表保留所有成对变化。 [配对分项 CSV](results/geometry_diagnosis_20261121/paired_metrics.csv)

仅 RGB 使用同一 RGB–XYZ 检查点，在融合投影输入中将几何通道置零。错配使用同一数据来源及镜像状态的另一场景的完整 MoGe 点图与掩码，按物理图像一对一互换。预检在本机观测到冻结 SigLIP 对相同像素张量重复前向时的特征差异，所以三条件共用每帧缓存的同一份 RGB 特征，原始 MoGe 随三条件重跑。仅 RGB 投影对两张点图的置换通过逐值等值检查。三种条件的单题／批量输出各匹配 48/48 个锚点。原始点图重跑与上一轮 3DSRBench 的 175 个组判分一致，EmbSpatial 有 3 道由错转对。 [运行与核验数据](results/geometry_diagnosis_20261121/SUMMARY.json)

## 3DSRBench 多物体视角

原题需要判断参照物相对主体的方向，并在主体自身朝向下归入前、后、左、右。补问只要求回答主体哪一侧朝向相机，使用相同图像与主体，探查模型是否把相机当成原题的参照。 [3DSRBench 官方论文](https://openaccess.thecvf.com/content/ICCV2025/papers/Ma_3DSRBench_A_Comprehensive_3D_Spatial_Reasoning_Benchmark_ICCV_2025_paper.pdf)

原始 MoGe 的 119 个错误组中，78 个在选项重排、已有镜像变体归一到原坐标约定后仍给出同一个错误侧向，31 个在同一画面重排选项时改变侧向，另有 10 个在各自画面内部稳定、跨镜像不一致。稳定错误里，有 77 组的相机探针回答与原题标注不同，其中 **64 组的原题预测正好复用了相机探针的侧向**。这一比例是错误模式统计。冻结模型自己的探针输出需要独立图像证据核对。

在封存预测前的 24 张图像盲核中，17 个组的原题最终答错。其中 9 张可核对相机所见的侧向，9 个补问答对，**7 个原题复用了已核对的相机侧向**。例如 V19 的猫及塑料容器都通过粗网格位置核对，原题答 `front`，补问所答的相机侧向也是 `front`，原题标注为 `left`。粗网格定位在正误两组都频繁偏离可辨位置，定位探针的结果不足以量化原题错误的定位归因。盲核来自一次读图，小样本和不确定的侧向保持分开。

## EmbSpatial 远近比较

作者用标注物体框内的平均深度形成远近标签。离线分析把同一张 MoGe 图聚合到标注框，比较以整个框与中心区域（长宽各取中间一半）计算的相机深度次序。位置真值仅用于这一离线诊断。 [EmbSpatial-Bench 论文 §2.1](https://aclanthology.org/2024.acl-short.33.pdf)

| 原始 MoGe 四选一结果 | 题数 | 具备全部选项物体框 | 整框深度给对极值 | 整框与中心区域均给对极值 |
|---|---:|---:|---:|---:|
| 答错 | 420 | 370 | 183（49.46%） | 130（35.14%） |
| 答对 | 786 | 687 | 576（83.84%） | 433（63.03%） |

百分比以具备全部选项物体框的题为分母。余下 149 题有无框的 `Unknown` 选项，仍参与全部官方对照。370 道有框的错题中，187 道按整框 MoGe 深度给错极值，183 道有框后可由同一份几何给对。其中 130 道对局部读出范围也一致。两种错误分别指向度量次序本身及把深度绑定到物体、比较和选择的接口。九格定位探针中，原始答对题也有 38/65 个正确选项的网格与标注框无交集，原始答错题为 21/31。网格结果衡量单独提问的粗定位能力。整序探针 0/96 取得可解析的完整排序，另用两选项正反顺序复问检查比较能力。

二选一在按数据来源和远近类型盲选的 96 道题上进行。四选一复跑及每对选项的两种呈现顺序共用同一帧特征。在四选一答错的 31 道中，原来选中的干扰物在与正确物体的对决中 **27 道两次都赢、3 道随选项顺序变化、1 道两次都输**。在 65 道四选一答对题中，62 道的正确物体能在正反顺序一致的两两比较中击败其他三个候选。错误已出现在两物体的局部比较阶段。两个错例的整框与中心深度均支持正确选项，两物体的粗定位也与标注框相容，模型仍在两种选项顺序中选错。粗定位只验证九格范围，局部点图读取、对象绑定和距离比较的贡献仍有重叠。

## 复现与产物

使用基线记录的两套模型版本和对应环境，从仓库根目录运行以下入口。官方答案与物体框在预测封存之后进入 CPU 分析。每种条件的原始回答、成对判分、各 3DSRBench 小组的失败类型、EmbSpatial 物体框深度与盲审记录同存于本地输出目录。

```bash
study=studies/hispatial_zero_shot_spatial_reasoning
assets=/path/to/model-cache
python "$study/geometry_cohort.py"
python "$study/geometry_controls.py" --model-cache "$assets"
python "$study/geometry_audit.py" --official-source "$assets/sources/HiSpatial"
python "$study/geometry_pair_probes.py" prepare
python "$study/geometry_pair_probes.py" predict --model-cache "$assets"
python "$study/geometry_pair_probes.py" analyze
```

代码及汇总文件位于本研究分支，逐题产物写入 `outputs/geometry_diagnosis_20261121/`。 [基线环境与配置](README.md) · [本轮数字与证据哈希](results/geometry_diagnosis_20261121/SUMMARY.json)
