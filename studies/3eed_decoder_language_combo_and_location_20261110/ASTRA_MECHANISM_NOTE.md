# R62 机制审阅

本记录仅审阅已注册设计、实际实现和已存汇总；未运行模型、未占用 GPU、未重新评分、未读取封存测试集或其他暂停项目。未使用外部文献。本记录不改变实验计划或实现。前半部分在语义对照结果提供前写成；最终结果与裁决见末尾追加部分。

## 当前可确认的结论

R62 固定 layer 5 的 1.5 倍语言分支，在暴露 DEV336 上相对 frozen ABC 提高 0.202187 个百分点；但低于 R59direct 0.106468 个百分点。重算编辑表示和 R59 targets 后，组合与 R59direct 的 mIoU 完全相同；两条最终候选索引改变均未改变 IoU。因此当前没有已测得的组合互补收益。相同总分不等于中间表示相同，也不证明两个机制完全相同。

六个位置的总分依次为 22.481100、22.392042、22.500017、22.301932、22.356781、22.504647。layer 5 按既定规则被选中，但只比 layer 2 高 0.004630 个百分点；不能解释为已识别稳定的最优语义位置。全部位置的主要收益集中于 drone 平台。所选 layer 5 在 drone 上相对 ABC 有四条改善、一条下降，共五条最终候选变化；quad 上只有一条候选变化且 IoU 不变。这是有限的候选重排现象，尚不是广泛修复语言 grounding 的证据。

## 干预实际改变什么

`compute62.py` 同时将所选 `cross_l.out_proj` 的 weight 和 bias 乘 1.5。设该分支原输出为 b，则正确干预为 1.5b。它不改变该次调用的 Q、K、V 或 attention 权重。尤其选择最后一层时，不存在之后的 decoder language-attention 层可借此重新分配注意力。因此“将现有语言分支输出加权得更重”是实现事实；“让注意力重新聚焦正确主体、属性或参照物”不是该干预本身的机制。

后续残差混合、归一化、前馈变换和固定匹配读出仍可能改变表示方向及候选排名。若分析显示最终描述类别上的差异，只能据此描述哪些类型对该输出增益敏感，不能反推 attention 分配被修正。

## 控制能区分的解释和剩余混淆

设 a 为固定 QK 后将有效 token 的 V 错配所得输出，再逐 query 缩放到与 b 相同的 L2 范数。当前 permutation 为确定的非零循环移位，保持有效 token 的多重集合、padding 位置和 QK 权重，破坏权重槽与 value 的对应。它不是删除全部语言信息：上下文化 value、特殊 token、重复词和相邻相关性仍可能保留信息；单个固定置换也不覆盖所有错配。

| 对照 | 能回答的问题 | 不能独自支持的主张 |
| --- | --- | --- |
| value1：a 对 b | 在同一分支范数下，原有权重与 value 对应是否比这次错配更有利于任务 | 1.5 倍新增量的收益机制；主体、属性或关系的独立因果作用 |
| value15：1.5a 对 1.5b | 放大后，正确对应是否优于同范数的错配方向 | 观察到整支损伤就宣称新增 0.5b 起到了语义修复作用 |
| increment_value | 保留 b 参与混合后，在最终总范数固定时，将新增分量方向换成错配方向是否破坏收益 | 严格固定原 source 分支的有效系数；排除所有非语义的方向几何因素 |
| increment_uniform | 当前 attention 加权的新增方向是否优于有效 value 均值方向 | 去除了所有语义；均值仍含上下文化词汇信息 |
| increment_joint | 同时置换 K/V 应保持 attention 汇总，结果是否近似正确 1.5 倍干预 | 任何语义损伤结论；这是实现与数值不变性正控 |

范数匹配控制的是所选 language 分支的逐 query 输出 L2 范数。它不匹配分支与视觉残差的夹角、各通道分布、残差和的范数、后续非线性结果或最终候选 margin。因此正确方向优于错配方向可以排除“只要把这个分支 L2 范数放大就等效”的解释，但仍不足以把方向敏感性唯一归因于人类定义的语义理解。

新增量实现还有一个必须保留的解释边界：最终输出实际为

`c * (b + 0.5a)`，其中 `c = 1.5 / sqrt(1.25 + cos(b,a))`，前提为非零且 `||a|| = ||b||`。

所以 c 在 1 至 3 之间，source 向量 b 的系数也随之改变。代码保留了 source 向量作为混合项，却没有严格固定它的最终贡献为 1。准确表述应为“保留原 source 向量参与混合、将总范数匹配为正确 1.5 倍输出的方向对照”。不能称为“只改新增量而原 source 贡献完全不变”。同样，输出投影 bias 也在被增益和归一的分支中，当前控制没有独立识别 value 内容与投影 bias 的贡献。

干预强度必须另行考虑。若 a 与 b 本来方向接近，错配未掉分不能推出 token 对应无关。对新增量控制，原始 alternative 的变化幅度也不足够：设 t 为 a 与 b 的 cosine，最终混合输出与 b 的 cosine 为 `(1+0.5t)/sqrt(1.25+t)`，最大偏转只有 30 度；当 t 为 1 或 -1 时，归一后的混合输出都恰为 1.5b。因此即使 a 与 b 完全反向，新增量控制也可能成为恒等干预。应区分“alternative 变化”与“最终混合分支变化”；现有代码保存的 alternative 中位 cosine 不是后者的直接测量，也不能将中位值经非单调函数变换当作最终混合角度的中位数。若既有产物不足以恢复最终扰动强度，应将无损失结论保持为未定，不为补充强度而自动扩大实验。

## 结果到达后的有限裁决规则

1. 先审查 source/native 重建一致性、joint 不变性、逐 query 分支范数误差和零向量回退。若正控或重建失败，停止机制解释，先按测量问题处理。不得用 aggregate mIoU 相等代替候选及分数一致性。
2. 若仅 value1/value15 明显下降，而 increment_value/uniform 保持 correct1.5 的效果，结论限于已有语言分支和对应关系对任务有用；新增 0.5 倍的特定选择性方向尚未证实必要。
3. 若 increment_value 与 increment_uniform 在同总范数下均低于 correct1.5，且 joint 保持不变，支持“所选位置的既有 attention/value 汇总方向，对这次增益后的候选重排有作用”，削弱纯分支范数解释；仍不证明 attention 被修正，也不区分词义、上下文化特征和残差几何。
4. 若错配新增量下降但 uniform 新增量保持收益，只能认为这次 value 错配有害；不能说细粒度 attention 选择性对增益必需。
5. 若错配或 uniform 新增量也保持甚至超过正确增益，不能选择性只报告整支损伤。若确认最终混合扰动有足够强度，可削弱“正确新增方向带来收益”的机制主张，保留数值混合、margin 敏感性和离散候选边界的竞争解释；若最终扰动很弱或未测得，结论保持未定，不能将未掉分等同于语义无关。
6. 均需同时报告相对 ABC 与 correct1.5 的总分、平台方向、改善/下降/不变和候选变化数量。新增量对照落到 ABC 以下意味着扰动有害，不能将整个损伤量直接记作原始 +0.202187 pp 的语义贡献。少数候选或场景驱动的变化须明确披露。

所选位置已经用本开发集 task labels 筛选；后续机制对照属于条件于该选择的开发诊断。即使结果符合方向性假设，也不自动产生独立泛化证据或提升 R59direct 的方法贡献。保持现有注册范围，不搜索新补丁、不新增动态门控、不追加层或倍率组合。

root 报告七臂预测的独立复算、评分和汇总审计通过。本审阅者随后直接回读 `research/round62/ANALYSIS_SEMANTICS.json` 及 `research/round62/semantics_audit_attempt001/FINAL_BRANCH_STRENGTH_PUBLIC_SAFE.json`，并仅对后者已保存的无 GT 分支统计作汇总复核，没有重新运行推理或任务评分。

正控保持全部最终候选和 IoU，分支相对向量变化仅为约 1.21e-7 的汇总中位值。所有臂最大分支范数相对误差低于 3.6e-7，alternative 零范数回退为零；本次回读的分支记录中 source 零范数计数也为零。现有结果不存在靠明显范数失配或近零分支回退解释主现象的迹象。

此前提出的“新增量错配可能实际接近恒等干预”已得到实际强度数据的检验。错配新增量与 uniform 新增量的最终分支相对变化汇总中位值分别为 0.347114、0.335808，cosine 分别为 0.939026、0.942269；最终分支相对变化超过 0.1 的比例分别为 99.927145%、100%。这里中位值的准确口径为 1008 个样本视角记录各自 query 中位值的中位值，比例为各记录 query 比例的均值；不能表述为直接汇集所有 query 后的全局中位值。两种控制均产生了广泛、非零的最终分支方向扰动，因此不能将收益保留简单归结为“控制实际上没有改动”。但约 0.94 的 cosine 也说明这些混合仍保留较强的原方向，不能外推到任意方向或更强损伤。

观察到的控制层次差异清楚：整支错配使结果低于 ABC，且把已错配整支从 1 倍提高到 1.5 倍只进一步变化 -0.003488 pp；而包含原 source 向量的两种混合对照均保留了 +0.186669 pp。相对正确 1.5 倍，它们各只有一条最终候选变化、零条 IoU 改善、一条 IoU 下降，下降全部来自 drone；quad 的任务成绩不变。相对 ABC，两者均是三条 IoU 改善、一条下降，仍保留全部三个 Acc25 救回且没有新增 Acc25 破坏。

据此，本轮支持的最强结论是：**所选最后一层原有语言汇总方向对完整分支的任务表现有用，但“新增 0.5 倍必须沿精确的 attention 选择性语义方向，才产生主要收益”这一强解释受到削弱。** 两种有实质方向扰动的混合对照保留了正确增益约 92.3% 的已测平均分提升，损失仅 0.015518 pp。92.3% 只是总分提升的保留比例，不能解释为已分解出“92.3% 数值作用、7.7% 语义作用”，也不能把整支错配的 -0.276210 pp 当成新增量的语义贡献。

这一结果与“保留已有语言方向后，固定分支增益主要改变残差/读出的相对平衡，并在少数候选边界上产生变化”的解释相容，但并未唯一证明它。原 source 向量仍含语义信息，uniform value 均值也非无语义；同时总范数匹配使 source 系数随方向变化。故本轮不能得出“语言无关”“模型只利用数值尺度”或“已经定位到主体/属性/关系理解修复”的结论。可以报告已有对应关系的作用与新增量精细选择性的有限必要性，不能把二者合并成语言理解改善。

最终资源与方法裁决：保留本轮作为已测得的开发机制诊断；不将 layer 5 增益或 R59+layer5 组合提升为优于 R59direct 的方法。当前组合没有任务增益，六位置搜索也未出现更强替代；本轮在已注册范围内结束，不提出新补丁、动态门控、额外倍率或新增实验臂。独立泛化与更广义的语义机制仍未建立。
