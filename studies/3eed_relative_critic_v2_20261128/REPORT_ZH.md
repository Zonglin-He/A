## 冻结迁移通过 665 条开发面板标准

| 面板 | N | Minimal-D mIoU / Acc@50 | 同池 AABB mIoU / Acc@50 | Verifier mIoU / Acc@50 | ΔmIoU 及配对 95% CI |

| 总体 | 665 | 34.31% / 35.19% | 32.50% / 29.92% | **37.84% / 39.55%** | **+3.53 pp [+2.38, +4.67]** |

| Quad | 192 | 26.40% / 12.50% | 25.31% / 10.42% | 28.82% / 13.54% | +2.42 pp [+0.43, +3.43] |

总体 Acc@50 提升 **+4.36 pp [+2.40, +6.47]**，救回 39 条，有 10 条原过线框跌破。后者占全量 1.50%，占基线过线查询的 4.27%。源域 1.0% 的跌破预算只用于源域标定。迁移后有 230 次实际候选替换，141 次提高 IoU、39 次降低、50 次相等。输出的 3D 预测先封存，再使用标签进行配对评分。

只用排序头时，总体为 38.02% mIoU / 39.55% Acc@50，救回 53 条、跌破 24 条。门控将跌破数减至 10，保留相同净过线数，mIoU 少 0.18 pp。Drone 上只用排序头的 Acc@50 为 25.00%，加门控后为 29.69%，原基线为 27.60%。Quad 的 Acc@50 配对区间为 [−4.76, +4.69] pp。Drone 与 Quad 仅覆盖 2 和 3 段录制，分平台区间需结合录制数解读。

相对 Minimal-D 的 mIoU 增益在 A、H、C_ray 路由分别为 +10.94、+2.64、+1.65 pp。A 路由约贡献总体增益的 56%。这些样本更常受益于替代物理解释，而完整双姿态路径已有更强的原始锚。四个开发平台的两项指标点估计均为正。该面板已在项目中多次使用。

## 独立录制 Mono3DRefer

从公开 val 的 299 帧中，按官方 KITTI Object 至 Raw 映射排除与历史 Mono Test 和 KITTI Tracking 相交的录制，剩下 35 段录制、148 帧。每帧用固定哈希取一条原始指代表达。RGB、Velodyne 和标定均对齐官方 KITTI Object 原始档案。沿用同一个已冻结 Verifier 和三阈值。预测封存后逐框核对 val 转存标注与 KITTI Object 官方标注。

| 方法 | mIoU | Acc@50 |
| --- | ---: | ---: |
| Minimal-D | 34.44% | 37.16% |
| 同池首次二维 AABB | 36.97% | 40.54% |

Verifier 相对 Minimal-D 提升 **+4.87 pp mIoU [＋2.04, ＋6.83]** 和 **+5.41 pp Acc@50 [0.00, +9.13]**。相对同池 AABB 提升 **+2.34 pp mIoU [+0.82, +3.86]**。Acc@50 点估计为正，配对区间下界触零。41 次替换中，26 次提高 IoU、8 次降低、7 次相等。跨过 Acc@50 的救回与跌破分别为 10 条和 2 条。最大录制组包含 32 帧。

## 复跑

使用 RTX 5090、Python 3.12.16、PyTorch 2.15.0+cu132、Transformers 4.57.1、NumPy 2.2.6 和 OpenCV 4.12.0。两次冻结 Qwen 读出共享模型和提示协议。源域 4,455 条解码用时约 62.4 分钟，退化特征可随解码缓存并行构建。665 面板的约 5.9 秒回放只计缓存读出后的候选、特征和选择，不代表端到端推理耗时。

从恢复后的仓库根目录运行。数据输入、冻结模型及历史预测路径见 [首轮协议](PROTOCOL_ZH.md) 和 [源域实施协议](SOURCE_PROTOCOL_ZH.md)。`results.json` 中提供聚合指标和校验摘要。

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 TOKENIZERS_PARALLELISM=false
py=../.venv/bin/python
study=studies/3eed_relative_critic_v2_20261128
"$py" "$study/compact_pool.py"
"$py" "$study/score_pool.py"
"$py" "$study/source.py" exclude
"$py" "$study/source.py" prepare

"$py" "$study/source_features.py"

```

源域入口检查第一阶段门槛，两个迁移入口检查第二阶段门槛。Verifier 引入了源域监督的小型排序器。新候选池、真实源域训练、交互特征和残差门控是整组变化，当前对照无法单独归因训练域或注意力结构的收益。
