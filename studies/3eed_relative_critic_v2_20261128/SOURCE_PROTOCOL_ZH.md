# 真实源域 Verifier 实施协议

阶段一报告达到既定 Oracle 线后，使用公开 Waymo Train 包中通过原始传感器与标注格式检查的全部 3,687 条查询。公开包覆盖 94 段 train 录制、2,701 帧。Waymo 官方 val 中剔除与冻结开发输入相同的 RGB 文件哈希，用录制内哈希排序和跨录制轮转抽样固定 768 条。train、val 录制不重叠。整个 Waymo 官方 val 录制都曾用于项目，因此后续开发面板的 Waymo 同属已曝光源域评测。Drone、Quad、KITTI、Mono 的样本及逐例分数均不进入源域管线。

## 输入与特征

- 使用固定 Qwen 版本、原图、原始提示和贪心生成。每查询离线缓存独立 2D 和 3D 两次读出，各物理视图共享原始读出。
- 每查询五个视图。一份原样，四份从高视角回波损失代理、低视角混叠代理、仅扫描/标定代理 30/30/40 抽样。对后二者描述的是回波退化模拟。相机姿态和 RGB 保持真实源域记录。
- 高低裁剪区域由首次二维窗和真实 LiDAR 中心深度带获得。高度阈值以该区原始观测的 Q10/Q90 计算，不使用目标真值框。高裁去低于阈值的点并随机丢弃 75%–95% 区域回波。低裁去高于阈值的点，屏蔽区域中心周围 30°–120° 扇区，并对后续地面估计加 ±0.15 m 截距扰动。所有退化视图先对原始点云按 0.25° 仰角代理分箱再抽掉 50%–85% 的非空分箱，加 0.02–0.08 m 坐标抖动，同时平移/缩放 Qwen 窗。随机种子由阶段和查询哈希确定。
- 同一退化视图的 Minimal-D 输出作为其第零项。46 节点通道只包含局部比例、残差、先验比值、池内相对特征、来源标志。规范化点统计在三个有效物理区域的并集上计算，必要时取既有 A 支持代理。射线描述基于缓存 Selection。14 边通道只包含框间重合、归一化局部相对位移、相对视径、尺度比及角度编码。源域真值仅生成 IoU 标签与离线验证。
- 评估沿用精确立框 3D IoU 和严格 IoU > 0.50。监督的非对称阈值事件按附件使用 IoU ≥ 0.50。相对增益 Huber 阈值为 .10，射线 Huber 阈值为归一化残差 1。区域缺失或只有基线时，推理保留基线。

## 学习与验收

固定随机种子 20261128，AdamW 学习率 0.0003、权重衰减 0.01、余弦退火到 0.00003，batch 96，12 个 epoch，梯度范数截断到 1。网络宽度 128，三层四头边偏置和边 Value 调制，前馈维 256，dropout .15，不使用位置嵌入。执行附件的低温 ListNet、非对称锚比较和双头残差目标。

每个 epoch 在同一固定 Waymo val 的 3,072 个退化视图上用预设网格选择三阈值，最多允许全部退化视图中的 1.0% 从 IoU>0.50 变为未过线。按 mIoU 增益选择模型与阈值，相同增益优先较少替换，保留不替换的对照。另报过线基线子集中的损失比例。录制聚类配对 95% 区间用于约定的阶段门槛。由于同一留出集用于选择和验收，这些区间只描述已选择源域策略。

阶段二须同时通过 mIoU 相对 Minimal-D 和同池首次二维 AABB 排序的两条正下界检验。阶段一的 Oracle 差异仅作为可达空间。源域通过后，跨平台应用同一 checkpoint 和门控，不再标定。

Mono3DRefer 的旧 Test 图像及与之同源的 KITTI Raw 录制全部排除，另排除历史用过的 Tracking 录制。先查作者公开 val，有符合条件的录制时按固定哈希每帧取一条原始表达。val 无可用录制时按同样规则查公开 train，该 split 只用于本研究外部评估。以冻结验证模型预测后才打开 3D 标注，并与 KITTI Object 官方框逐例核对。
