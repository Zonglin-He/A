# 固定 K16 候选时，排序损失怎样影响跨平台选框

**结论。** 在 18,620 条普通验证方向记录上，未按达标框数归一化的 PAL 得到 **26.2316% Acc@25、9.4770% Acc@50、14.0028% mIoU**。主指标比同候选冻结联合读出低 **1.1527 个百分点**，比仅优化达标集合总概率的 B 低 **0.7029 个百分点**。三个训练种子均增加了净误改。保留精简 v1 为主方法，结束本轮 PAL 替换。候选扩容改变旧排序项样本权重的现象已在真实特征上复现。

## 比较在什么条件下成立

每个方向复用 R180 的 16 个原候选及其既有 PCA 朝向、v1 原赢家、冻结 299 维特征和同一套 14,449 参数残差排序头。五个实验臂都在**冻结联合分＋可训练残差**上训练、选 checkpoint 和推理。原 R182 在主体独立分上训练、在联合分上选 checkpoint。三份历史排序头按原流程重训，选中轮数和权重均逐值复现。本轮 A 给出统一分数路径后、训练预算相同的旧损失对照。原种子下，只统一分数路径使 Acc@25 相对历史 R183 变化 −0.0626 个百分点。

Waymo、Drone、Quad 各自源域有 640 条拟合记录，沿用至少有一个 IoU>0.25 框的资格，实际分别训练 636、626、635 条。本源留出录制分别评 160、64、160 条，使用全部记录。三源的训练／留出录制数分别为 61/21、1/1、1/2。每个种子内五个头共享初始化、样本顺序、dropout 种子及优化预算，训练 20 个 epoch，在预设四个 checkpoint 中只看本源留出。共 45 个头。普通验证只在全体预测封存后评分。六方向复用 9,310 条描述，覆盖 93 个 Waymo、2 个 Drone、3 个 Quad 录制。该验证范围已在方法开发中曝光，FINAL 访问次数为零。 [固定协议](PROTOCOL.json) · [源域选出的各个模型](results/source_checkpoints.csv) · [运行说明](RUN.md)

## 无信息候选的机制验证

在三维盒反例上，用真实有向 IoU 和五个数值优化初值复现了结果。三个真候选单独被选时的成功概率为 0.6、0.5、0.5。仅用逐样本平均的成对排序损失时，K4 最优分配约为 (0.360, 0.320, 0.320)，K16 约为 (0.287, 0.357, 0.357)，加入永远失败的候选使胜者翻转。完整旧损失在 K4 和 K16 都选 B/C；K16 的最优分配约为 (0.209, 0.395, 0.395)。未归一化 PAL 给出 (0.375, 0.313, 0.313)，选中成功概率最高的 A。数值计算将无信息候选的 logit 固定为 −1000 来逼近边界下确界。 [反例与数值解](results/mechanism.json)

在 1,897 条有效源域训练记录上，将 16 或 48 个上述负候选追加到不变的 K16 分数。成对排序项在原候选上的梯度范数中位数分别缩至 **46.67%**、**22.58%**。若原有 m 个正例，缩放恰为 (16−m)/(16+d−m)，其中 d 为新增负例数。单独排序项的梯度方向维持一致，组合旧目标在增加 16 个负例时的方向余弦中位数仍为 **0.9991**。B、C、D 对原 16 个分数的梯度在两档干预下均逐值一致。真实梯度证实了候选数量带来的重加权，也显示了它在完整损失中的幅度。 [按正例数列出的梯度](results/source_gradient_by_count.csv)

在理想条件分布上，未归一化 PAL 的最优 softmax 概率正比于各候选的边际达标概率。该结论本身不保证有限的源域模型能估准目标域的边际达标概率。这次对照支持保留候选扩容的机制诊断；按照主方案需优于 B 的预设判断，停止将该 PAL 替换开发为主方法。PAL 已有公开理论来源。 [Menon 等，NeurIPS 2019](https://proceedings.neurips.cc/paper/2019/file/da647c549dde572c2c5edc4f5bef039c-Paper.pdf)

## 核验和成本

普通验证完整的 299 维输入此前未缓存，本轮在 RTX 5090 上重放冻结特征一次，三套源模型并行，最慢任务约 26.6 分钟。45 个小头的 CPU 拟合加三份历史头的精确重放合计约 32.5 秒。所有实验臂共享同一次特征提取，推理时使用同一结构的一份排序头。

18,620 条的 K16 坐标和旧版七个读出的赢家逐值复现，3 个历史基线的逐条 IoU 最大偏差为 0。两套几何实现核验 372,400 个框，最大 IoU 差为 约 8.88×10⁻¹⁶，两档阈值判定一致。独立核算复现了 864 个指标单元、2,432 个配对计数、72 个历史指标，并独立重放了 810 个排序头选择。所有零覆盖、选错与退化记录均计入。 [独立审计](results/audit.json) · [评分文件校验值](results/score_receipt.json)
