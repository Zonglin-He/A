# 外部盲测的录制隔离补充

为核对 Mono3DRefer 包的字段和描述分隔格式，准备阶段查看过数据查看器前三条例子，其 KITTI Object 帧号为 000001、000002、000004。这三帧来自两段原始录制。正式盲测在此前已排除历史 Tracking 录制的基础上，再排除这两段录制的全部帧。

在打开任何本次三维评分前封存两个固定范围。主外部结果为未打开样例、且与项目可审计历史录制分离的全部 118 帧，每帧一条预先哈希选定的官方描述，覆盖 18 段录制。171 帧范围报告为数据与运行完整性对照，标明其中 53 帧所属录制曾用于字段检查。所有方法、超参、提示、真实传感器、保留的查询和指标保持原协议。模型预训练的数据成员关系不可审计。
