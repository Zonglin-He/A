# 双姿态正式入口与外部复测协议

- 旧候选生成、四尺度、5 条回波门槛、地面、主视图转换、尺寸、姿态、固定底面的只缩顶部和全部回退遵循旧锁定。候选只有原 PCA 和 Qwen 双姿态，均执行原顶缩。用首次冻结 Qwen 二维框计算标定投影 AABB 的裁剪 IoU。覆盖分严格较大才替换旧射线赢家，失效或并列保留旧结果。无额外模型调用、训练或新搜索权重。射线等价保证相对于各候选自己的未缩框。
- 在原 702 条盲输入上核对旧入口与新入口的旧赢家、候选和改框决策，复用原 665 条封存评估。自然候选与四尺度实验的收益仍归入各自已有报告。
- 外部主验证使用 Mono3DRefer 官方 Test 的所有可取得且同历史 KITTI Tracking 录制分离的图像帧。每帧取一个作者已发布的原描述，以原始 frame ID、文本、作者实例编号的 SHA-256 最小值确定，选择不使用几何标注或得分。以此作为全帧的一条查询子集，分母包含解析失败等回退。对完整表达集用独立分母。本协议封存范围在外部模型运行前确定，作为外部泛化检验。无框、点云回退和缺失标注数单列。
- Mono3DRefer 公共数据转存件提供语言、相机及目标对应。核对 KITTI Object 左 RGB、原始 Velodyne、内外参的帧号与物理一致性，使用 KITTI 官方 devkit 将 Object ID 映射到 Raw 录制。把此前项目使用的 Tracking train 21 段全部视为已曝光，用两套 KITTI ZIP 中同大小同 CRC 的 LiDAR 回波索引匹配，再对每段匹配代表帧进行内容比较。任何命中的原始录制整体排除。结果称项目录制无曝光，模型预训练数据无法审计。
- 外部推理只读图像、点云、相机参数和原文字。正向封存原生 Qwen、原射线＋顶缩、首次二维框排序三组预测。外部标签只供离线指标与候选 Oracle。三组同时报告 mIoU、严格 IoU>0.5 的 Acc@50、录制聚类配对区间、回退与改框数。外部结果不参与模型选择、规则和参数调整。
