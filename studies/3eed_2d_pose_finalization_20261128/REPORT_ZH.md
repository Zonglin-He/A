# 首次二维框双姿态定型与外部录制隔离验证

新正式入口 `ray_equivalent_height_only_2d_rank` 复用首次 Qwen 二维框，在原双姿态范围内，以图像投影重叠选择经过顶缩的候选。它在 665 条历史配对查询上达到 **34.30% mIoU、35.04% Acc@50**。相对历史射线加顶缩分别提升 **1.21 pp [0.67, 1.81]** 和 **2.71 pp [1.52, 3.98]**。外部评测沿用冻结配置，单独报告。 [方法登记](../../QWEN_CURRENT_METHOD.json) · [实验协议](PROTOCOL_ZH.md) · [论文正文](MANUSCRIPT_ZH.md)

## 正式入口与严格对照

保留原四尺度选区、候选尺寸、PCA 与 Qwen 姿态、支持点和回退。每个候选独立执行原有顶缩，随后把八个角点投影成可见二维 AABB。如果其与首次 Qwen 窗的 IoU 严格改善，就替换原射线赢家。无效投影记零，替代框还须有有效投影才能换框。没有改进或并列时沿用历史赢家。原射线选择与三轴消融依然可通过旧入口重放。没有引入行人硬编码分支，也没有新增模型回答或训练。

665 条上共救回 **21** 条、误改 **3** 条。对 702 条盲输入，旧框及新候选赢家均与此前封存的严格双姿态对照逐框一致。新增顶缩及投影的 CPU 时间中位数约 **0.33 ms**，以进入 C_ray 的查询为分母。正常入口完成了 12 条三平台 inference/evaluation 烟测，旧封存仍可原样评分。此前 9,310 条和 1,536 条表仍属于旧入口。

34.68% mIoU、37.59% Acc@50 属于更宽的自然候选池，其中还包括稳健中心、局部表面等候选。Quad 在正式双姿态臂的 Acc@50 增量为 **1.04 pp**。在该平台的 14 次换框中，yaw 误差改善 **6** 条、变差 **8** 条，中心误差改善 **8** 条、变差 **6** 条。全平台 94 次换框中，yaw 改善 53 条，中心改善 58 条。排序改变了整个锚定框。Quad 的宽池收益不能归因于单独修正 yaw。 [原宽池对照](../3eed_2d_relocalization_20261128/REPORT_ZH.md)

## 观测等价与排序的边界

在同光心、直立框、固定活跃面的条件下，解析首交映射的局部秩至多 4。315 条实测查询的有效秩中位数 3，取决于观测和归一化阈值。此前七维搜索降低了同帧保留射线的 Audit 代价 0.121，完整框 mIoU 从 45.11% 降至 35.75%。这组结果给出全自由度优化可能偏离三维标注的受控证据。秩亏缺约束了可辨识性，优化效果还依赖目标、噪声和先验。

相机投影雅可比在射线弱方向的能量中位数约 72.7%。在自然池同时满足 Selection 和 Audit 首交等价的 275 个替代框上，与对应原框的二维投影 AABB IoU 中位数 **0.948**，其余 1,080 个替代框为 **0.798**。这 275 个严格等价替代全来自去顶缩臂，当前统计直接覆盖高度变化。严格等价组的重定位贡献仅 **+0.07 pp mIoU**，Acc@50 持平。正式方法的等价保证约束的是**每个候选自身的顶缩**，最终跨姿态排序可以改变首交观测。 [解析推导与几何保证](MANUSCRIPT_ZH.md)

归档的行人 GeoMedian 曾做过独立配对。185 条分离录制行人上的 +1.26 pp 是多候选二维排序结果，其中含 GeoMedian 和逐尺度后端。正式入口保持原回退，避免将这个混合池结果用作 GeoMedian 单臂的证据。R1、R2 线框、R3、R5 作为 Discussion 的负面控制，保留原报告。

## 外部冻结验证

采用 Mono3DRefer 官方 Test 的发布描述。与 KITTI Object Training 搭配只是因为其帧提供公开的 RGB、原始 Velodyne、标定与 GT，Mono3DRefer 的评估划分仍为作者 Test。对齐帧号和原始 RGB 像素，核对每帧的 P2、R0 与 Velodyne 外参。通过 KITTI 官方 devkit 把 Object 帧对应到原始录制，再对历史 Tracking 的全部 21 个序列作回波内容匹配。由同长度和 CRC 定位到的 3,098 帧支持录制映射，每个序列另取代表回波验证 ZIP 成员字节相同。

官方 Test 中有 262 帧、5,415 个不同描述。先排除与历史项目 Tracking 录制相同的 91 帧，剩 171 帧、20 段、3,185 个描述。每帧按事先固定的 SHA-256 顺序取一条作者原始描述。准备时为了确认数据字段查看过三条示例，评分前已将示例所属的两段录制整段隔离。严格外部主表覆盖余下的 **118 帧、18 段**。171 帧是更宽的运行完整性对照。审计覆盖可追溯的项目记录和本次人工查看，冻结基础模型的预训练成员关系无法核实。报告单位是帧查询，而非全 5,415 条描述。 [数据及方法补充](STRICT_TEST_ADDENDUM_ZH.md) · [Mono3DRefer 作者项目](https://github.com/ZhanYang-nwpu/Mono3DVG) · [KITTI Object](https://www.cvlibs.net/datasets/kitti/eval_object.php)

在严格外部面板上，旧射线加顶缩相对原生 Qwen 增加 **7.26 pp mIoU [+4.81, +13.13]** 和 **7.63 pp Acc@50 [+3.57, +11.77]**。新排序相对旧方法增加 **2.05 pp mIoU [0.00, +2.94]** 和 **5.08 pp Acc@50 [0.00, +7.20]**，救回 6 条、误改 0 条。12 次换框来自 4 段录制，其中 3 段有净 mIoU 改善并贡献 3／2／1 条 Acc@50 救回，其余录制的 mIoU 持平。全样本复现收益方向，排序增量的区间下界触及零。41 条已进入双姿态分支的条件分析覆盖 5 段录制，新排序增加 **5.90 pp mIoU [+1.09, +8.78]**。这组条件结果只用于解释触发覆盖和稀释效应。

严格面板共 116 条有效二维回答、85 条有效三维回答。41 条进入 C_ray，26 条走 H，18 条走 A，33 条无三维框。无框按零分处理。171 帧的 342 个标准模型回答由三种方法共用，RTX 5090 推理合计 191.66 秒。额外顶缩与排序在外部 C_ray 子集的 CPU 时间中位数为 0.29 ms。预测封存后，用官方 KITTI Object 标注核对了 171/171 个目标三维框的原相机系坐标。用独立分数汇总对照 mIoU 与阈值，复跑历史入口的外部框最大差为 0。无新 checkpoint、目标训练或参数改动。 [聚合、覆盖与封存哈希](results.json)

## 重放

配置与已有冻结 Qwen 运行环境相同。外部准备另用 PyArrow 26.0.1。以下命令面向尚未出现外部预测封存的工作区。脚本自动获取并校验固定数据包与 KITTI ZIP 成员。对已完成的本地结果，可直接从已封存输入和预测重跑 score。工作目录为仓库根目录。

```bash
study=studies/3eed_2d_pose_finalization_20261128
py=/home/administ/3eed/.venv/bin/python
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
"$py" "$study/prepare_mono.py"
"$py" "$study/strict_mono.py" seal
"$py" "$study/run_mono.py" predict
"$py" "$study/run_mono.py" score
"$py" "$study/strict_mono.py" score
```

3EED 的 702 条交叉复放由 replay_panel.py 在原研究缓存上验证，读取归档的历史注册哈希。新方法的开发面板只覆盖这 665 条评分查询。原 9,310 条普通 Validation 的历史数字继续报告给旧入口。外部结果只验证了可审计录制隔离的地面基准。
