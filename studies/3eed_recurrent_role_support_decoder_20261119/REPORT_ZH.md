# 3EED 语言—实例联合解码与连续三维框

完整联合版本与三项消融完成了三源训练以及普通 Validation 的六方向评价。

完整联合相对 R158＋PCA 的 Acc@25、Acc@50 和 mIoU 差值为 **-1.945 / -0.314 / -1.319 个百分点**。相同源监督与输入下，完整联合相对关闭反馈的差值为 **+0.773 / +0.646 / +0.393 个百分点**。

## 方法与比较条件

每个输入由现有冻结 3EED 和源平台的冻结图像编码器提供 1,024 个点 seed、绑定到可见 seed 的图像描述子及原文本 token。主体和参照各有四个槽，每轮读取全部 seed。同一组参数执行三轮，先更新点支持，再预测中心、尺寸和朝向。角色之间使用支持位置及成对 3D 几何与投影特征交换信息。预测框参与下一轮支持的几何读取，最终主体框由联合解码器直接产生。

新增解码器含 310,414 个参数。四个臂均使用相同源标注、三轮共享更新及固定 12 个训练轮次。自然表达监督主体框，参照作为潜变量。合成样本由源帧已标注的可见对象构造，保留同类干扰并要求根据投影水平轴可唯一判定。合成标签对已有标注库存有效。
固定候选臂和连续臂的训练权重逐张量相同，前者的最终读出是原候选中心、尺寸和既有 PCA 朝向。
关闭 RGB 臂保留相机标定和投影几何。关闭反馈臂同时移除角色间交换与框反馈。

## 数值审计与边界

全 18,620 条预测先封存，再读取真值。五个臂都由独立的传感器坐标三维凸体求交复核。最大 IoU 差为 5e-15，阈值判定分歧为 0。六方向重复出现同一目标物理帧，按录制报告差值方向。普通 Validation 具有历史开发曝光。目标域和源骨干参数更新次数均为 0。FINAL 未访问。

首版合成规则未在 Drone 和 Quad 产生有效双端例。源域改用分离的序位参照和唯一水平最近者后，关系训练覆盖三个来源。首个训练尝试在 Drone 的弧度输出处出现非有限梯度。复现后把弧度转换移到输出路径，双角向量继续提供朝向监督和关系特征。所有最终状态来自同一修正版。

历史 B 小头继续作为参照物排序对照。其 144 帧评测没有对应的六方向主体端点。本轮的同监督独立对照是关闭角色交换和几何反馈。 [历史 B 的固定面板](https://github.com/Zonglin-He/A/blob/da78a7e9dcb5ea8ba2de497e60f5f3944d2119ca/studies/3eed_verified_competitor_supervision_20261119/REPORT_ZH.md)

## 裁决

**保留 R158＋PCA 作为默认方法。保留闭环反馈的正向消融结果。** 完整联合的六方向 mIoU 都低于 R158＋PCA。其中 Waymo→Quad 与 Quad→Waymo 的 Acc@25 各下降约 4.5 个百分点。与同信息的关闭反馈版比较，Acc@50 在六个方向中有五个提高，Quad→Drone 下降 0.752 个百分点。直接左右关系子集的 Acc@50 增量为 1.090 个百分点。这组对照支持角色交换与框几何反馈的组合能够改善主体定位。

新增 RGB 在六方向等权的两项 Acc 上分别变化 −0.014 和 −0.051 个百分点。连续框相对同权重的固定候选＋PCA，在 Acc@25 上有 +0.178 个百分点，在 Acc@50 上有 −0.277 个百分点。两项改动均没有提供一致的主指标增量。固定候选对照包含候选分类读出和历史 PCA，因此这个差值衡量完整输出路径，无法单独归因于朝向、中心或尺寸。

13 个旧核验物理帧的双端身份仍缺乏正面证据。完整方法的主体框归属高于关闭反馈版，已核验参照正确从 3/14 降到 2/14，双端从 1/14 降到 0/14。该小面板刻意覆盖历史失败，适合说明反馈在错误参照下也可能改变主体，无法估计全量参照准确率。当前论文中可写的实证结论是，在同监督同输入条件下，共享解码中的反馈改善了该联合解码器的主体定位。正确双端绑定与相对系统强基线的优势仍需其他证据。
