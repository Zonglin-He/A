# 正式三轴主方法的逐公式删减

用正式 `ray_equivalent_extent_2d_rank` 的 873 条封存输入回放。3EED 576 和 KITTI Tracking 89 条构成开发评分面板，Mono3DRefer 171 条全部评分，其中此前录制过滤的 118 条是外部主对照。面板有历史项目曝光。冻结首次 Qwen 回复、LiDAR、标定、采样、GT 协议与其他模块。逐项改动保持真实路由，受该项影响的下游按同一规定重算。盲结果与射线审计封存后读取标注。方法测量无需模型调用、训练或阈值搜索。

- Object 检查地面前景门槛、四尺度简化为最细和最粗、区域中央支持门槛、用 $h_j$ 或 $h_j/e_j$ 代替 $h_j^2/e_j$、以及放宽预测机动车分支准入。Rays 所需的全局门槛在区域中央门槛消融中仍保留。
- Correction 检查近面锚定改点簇跨度中点、去地面底锚、去 PCA 长短轴补偿、只留 PCA 或只留 Qwen 候选。单姿态读出共享各自物理锚和三轴拟合。
- Fitting 检查关闭、只投影高度、只投影水平、去冻结尺寸先验、去实测点见证、去首交见证、去全部见证下界、去参考上界、固定中心、用原生第三尺寸代替竖轴选择、去见证余量。删除见证时保留开始拟合的原命中与光心条件，只有该项不再进入跨度下界。审计两姿态内的 Selection、原帧预留 Audit、实测点、首交点及嵌套约束。
- 候选排序分别去射线残差封顶、去未命中惩罚、去截断尺度的 0.1 m 下限、以 PCA 确定性默认替代射线默认、只用射线排序、2D 改交面积、2D 改中心距离、候选投影不裁剪、用 Dice 代替 IoU。备选 2D 分数沿用有效性与严格增分规则。Dice 是 IoU 的严格单调变换。
- H 回退单测去 Qwen 完成尺寸与只用 Qwen 尺寸，A 回退单测去前面至中心的深度补偿与去 LiDAR 深度替换。另测试一个预先固定的代数改写，将 H 补全写为 `max`、三轴界由两个见证集合各自的极值约束得到、2D 用 Dice。该臂检验等价改写，不从评估结果挑选组成项。

无框计零 IoU，Acc@50 取严格 IoU > 0.50。报告完整面板和正式 C_ray/H/A 条件子集，区间按录制配对抽样 2,000 次。没有预设等效界，差值小或区间跨零只提供描述性证据。多项探索的区间不作多重比较校正。正式默认入口独立于这些研究臂。
