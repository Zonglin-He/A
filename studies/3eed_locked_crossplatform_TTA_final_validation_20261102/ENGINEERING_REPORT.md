# R46 工程与协议报告

本轮将预先锁定的 **12 个主表输出和 12 个外部方法／控制输出**统一运行在 384 条保留观测上，全部九个阶段正常退出。预测控制器总耗时 **1020.2378222309053 秒（约 17.004 分钟）**，全部预测先封存，随后独立合同审计通过。源模型、方法、参数、读出、控制和最终主次假设未因最终结果而更换。任务指标、采纳裁决及匿名逐例结果由独立评分报告提供；本文不根据任务效果选择工程实现。

## 1. 模型、数据与读出边界

源模型为已登记的 Waymo-only 100-epoch checkpoint，SHA256 为 `0d8766abaf06c9f3e2500fcb187337982d391f9e4d46ca854f3b3bb70fd33bbd`。模型实际输入是每条固定抽样的 16,384 个 XYZ 点与完整文字，没有独立 RGB 输入分支。Drone 的 float32 高度偏移、原始文字 sentinel、归一化、温度和确定性设置均沿用既有实现。

所有主臂和外部方法使用同一项**有意设置的 GT-free 文字读出**：first-lexicon-noun，找不到时回退 all-content-tokens。它不是原论文依赖注释的 positive-map 读出。官方注释路径先读取 GT 对象类别，再按类别同义词匹配文字；source100 训练使用过官方训练 map，历史源验证也曾分别封存 official BBF/BBS 与 GT-free text-BBF/BBS。本轮没有把 GT class、GT span 或目标框标签接入推理、G、适应或选择，不能把最终表称作官方注释读出协议的完整复现。

R19 的主体属性修复已在 R20 独立测试，作用于 G，而非这项 GT-free mask；本轮不把这些已测试修复重新叙述为一直遗漏的实现细节。

384 条观测按已有输入哈希注册选定，Drone／Quad 各 192 条，来自一个已有 Drone 场景和三个已有 Quad 场景。内容保留不等于全新的独立场景；历史全验证集暴露、重复物理实例或相邻帧相关性需要保留披露，不能把 384 帧当作 384 个独立场景。最终注册阶段只获准对已有清单计算 opaque SHA，未解码清单；另获数据／模型授权后才首次打开行内容。

## 2. 主表：A 适应后冻结迁移

主假设在最终访问前固定为 **R30 beta-1**；次级候选固定为 **R24 query-MLP，原学习率 5e−4、16 步对应的既有状态**。每种候选分别使用平台对应的既有投影头，单个 query MLP 为 184,960 个参数。本轮最终观测上没有新增主模型优化器步骤，也没有重新训练源模型。

六个基础臂为 source、R24 固定头、R24 同 A 密集 G 记忆（alpha 1）、R30 固定头、R30 E-only 记忆，以及 R30 all-A／无反馈值为零的记忆。R24 和 R30 的状态来自既有 A208 适应；各自开发集选择历史和目标域开发标签使用已在原登记中说明。本最终确认没有重选层、学习率、步数、beta、记忆库、温度或主方法。

记忆使用原来的 source query × normalized noun 表示、逐 query L2 归一化、每个 A 观测内最近 query 后再取最近四个观测、CPU float32 指数余弦核和固定 0.1 温度。R24 值为旧 G 减 source 的原生分数增量；R30 值为原 22 条偏好对应的原生概率单位修正。概率修正没有加到 exact log-odds 上。真实近邻索引、分数、权重及完整修正向量均封存，独立审计验证合法最大值／Top-4 和并列边界，而不以另一套浮点实现的选择替换实际输出。

每个基础臂另有一个使用**相同当前旧 G**的成对臂，合计 12 臂。G 仅从同一冻结 source 候选池构造一次：原 Stanza 主体／参照解析、独立图像实例、点云几何与标定、GroundingDINO 参照物、冻结 Qwen2.5-VL-3B 的完整主体和灰图数值证据，以及原位置／参照计算。最终旧 G 保持 `F = s0 + 2*vision + 2*position + 2*relation`；没有替换成开发中未采纳的 7B、point、bbox 或新的关联接口。

source+G 保留 literal float64 F；其余五个臂给自己的原生分数加同一个冻结 `ΔG = F − s0`。因此必须同时比较 source+G、head+G 和对应 memory+G，不能把额外 RGB、预训练模型知识或 G 自身的收益全部归因于参数更新。主表所有框来自同一冻结 source 池，均未修改中心、尺寸或朝向，也没有加入 PCA。

## 3. 外部方法：独立的逐样本协议

外部表每条表达恢复 source 参数、缓冲、优化器与 RNG，在当前无标签输入上执行既定一步或合法跳过，再输出该输入。它与主表的 A→B 冻结迁移使用不同的信息历史，必须分别列示，不能把跨表数值当成相同预算下的算法胜负。

| 移植方法 | 固定更新配方 | 选择参数量 | 本轮实际逻辑更新步／跳过 |
|---|---|---:|---:|
| Tent grounding port | SGD 1e−3、momentum 0.9，一步；非文本 BN 仿射与批统计 | 42,816 | 384／0 |
| SAR LN-only grounding port | SAM，SGD 1e−3、momentum 0.9、rho 0.05；两次可靠性筛选，margin=0.4 ln256，恢复阈值 0.2；保持 source BN | 24,768 | 129／255 |
| MEMO Transformer-recipe grounding port | AdamW 1e−5、weight decay 0.01，一步；四个点云采样／轻噪声视图，BN prior 16；既有几何对应和覆盖门 | 144,527,419 | 291／93 |
| Reg-TTA3D-inspired | Adam 1e−3，一步学生更新；既有 NPG／CRR／CBU 代理与类别平衡 EMA | 1,734 | 382／2 |

合计 **1186 个逻辑更新步骤**，低于 1536 上限；SAR 的 SAM 一步内部包含扰动与第二梯度阶段，不能把逻辑步数当作全部前向次数。合法跳过仍保留输出并计入全部 384 条分母，没有删除输入。

官方 Tent 和 SAR 返回其更新前的首个前向；既有 grounding 移植额外执行干净的更新后前向。两种时机分别保存，不能把新增 post 前向冒充原返回时机。MEMO 同次保存 BN-prior-only、augmentation-only 与 clean-post；跨视图先几何去重／对应，不假设同 query 编号代表同实例。Reg 同次保存 teacher-pre、teacher-post、student-post 和 direct-pseudo。

Reg 只能称 **inspired port**：3EED 没有原检测器的 RoI／yaw／独立检测类别置信接口，本实现沿用已审计的位置尺寸扰动、文字类别代理、明确的稳定性替代与 6D 回归损失；它不是 Reg-TTA3D 的完整原论文复现。Tent、SAR、MEMO 也均是明确记录接口差异的 grounding 移植，不使用其原论文数字填本表。当前没有新加 CoTTA／MOS 或连续在线协议。

## 4. Fresh-frame 工程补齐与失败保留

输入池创建程序明确把这些新帧放在旧 501-mask/frame 缓存之外，旧 observations 不能直接按新 frame alias 查询旧缓存。本轮没有把缺缓存静默回退为 source，而是补齐**原 R12 同一个冻结 Mask R-CNN**的缺失输入预处理：同一 COCO 权重、FP32、resize 800／1333、最多 100 detections、score≥0.5、mask≥0.5、原顺序和原图像素坐标。相机字段继续通过原 ijson 顶层白名单读取，不 JSON-decode 整个 object annotation 作为输入。

最终访问前额外使用同一对旧 A 样本验证 fresh masks、相机、完整 scene 和完整 R17 prepare，与历史结果逐项／递归一致。工程扩展实际总共只做了两次 Mask R-CNN 前向：

1. 首个 standalone 尝试在模型导入前因输出父目录缺失退出，零模型调用；只修复父目录创建。
2. 第二次已完成首个 mask 前向并先保存原始 NPZ，随后 camera 白名单数值的 Decimal→JSON 序列化失败；没有进入第二次前向。
3. 第三次通过锁定原文件和图像哈希复用该 raw mask，只执行剩余一次前向。Decimal 转 float 与 CameraSpec 原本的 float64 转换一致。失败目录、旧锁、账本和 raw mask 均保留，没有为了修 I/O 重算首个模型答案。

没有重跑已通过的 24 次旧 A 数值 Qwen、8 次 DINO 或 8 次外部适应步骤。更早一次元数据准备的资产 receipt 路径错误也保留，模型调用为零。独立 fresh 比较器首次遇到 dataclass 内 NumPy 数组布尔比较歧义，原代码／日志保留，改为逐字段递归比较后通过；它没有更改任何模型输出。

这些是原流水线的输入 I/O 和测量修复，没有修改语义模型、阈值、prompt、候选选择或反馈接收规则。最终正式 384 条运行自身**没有阶段失败、重试或方法修复**。

## 6. 封存与独立审计界限

顶级预测封存 SHA256：`9970abdacaf45f6a3f0fa13a91ad31e3dc3b698f990f419d09a8762596f7c4cf`。实际计划 SHA256：`f0db1dba7b121d1e493b46da51b962fccfd25ca0ab2fe58661f3c8cd9b23834c`。预测控制器不包含任务 scorer；全部 24 输出封存并通过独立审计后，root 另行授权一次统一 GT 评分。评分完成后方法和模型工作已关闭。

独立合同审计耗时 **19.877910744398832 秒**，验证 384 个 fresh image／point／metadata／mask 绑定、768 个适应头输出、完整外部框池及显式 override；CPU64 头重放最大分数误差 9.865743643144853e−7，argmax 差异为零。对三种记忆独立重算 **5,473,566,720** 个 CPU32 相似度单元，保留 62 个 Top-4 边界并列记录，未替换实际输出。

审计证明算术、来源、输出、预算和冻结状态合同，而非实例语义正确性的金标准。位置／参照几何仍依赖已固定的实现和封存绑定；外部 backbone／optimizer 没有独立再跑一遍。旧 A2 工检和最终保留集均不是额外的独立场景金标。预测计数、重复控制和多方法比较也不增加独立样本数。

公开导出采用显式白名单，只含自有代码、匿名配置、工程计数、工程失败说明及后续独立评分方提供的匿名标量。私有清单、UID／alias、原描述、GT 容器、图像、点云、坐标、256 维分数、特征、权重、第三方源码和完整原始日志不进入工程导出。完整私有证据继续本地保存。
