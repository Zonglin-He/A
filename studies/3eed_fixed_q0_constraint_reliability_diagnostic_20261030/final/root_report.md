# R11：逐约束可靠性在真实跨域几何反馈中的检验

本轮完成真实 Waymo-only → Drone / Quad 实验。当前可靠性公式不采用，神经回归层 TTA 未进入执行阶段。逐约束加权相比无条件几何融合减轻了退化，但未在两个目标平台同时超过冻结源模型和统一权重对照；固定覆盖率的可靠性排序也未稳定优于保留源预测或低平面残差。这个结果否定本轮公式的进入条件，不否定可靠性研究原则或回归适应路线。

## 1. 实验对象与可解释边界

固定原模型目标选择 q0，使用已完成的 Waymo-only epoch100 权重，不重新训练 source、不使用教师或 EMA、不改选候选。源权重 SHA256 为 `0d8766abaf06c9f3e2500fcb187337982d391f9e4d46ca854f3b3bb70fd33bbd`。因此源模型训练平台与本轮目标平台不同；这不再是三平台混合训练权重的诊断。

本轮按输入哈希选择320个不同物理帧：Drone128、Quad192，每场景64帧，共2+3个场景。排除此前380个诊断或 smoke 帧，实际重叠为0。目标验证集及这些场景曾被之前轮次研究，所以是新帧机制诊断，不是独立新场景确认。帧和坐标不能当作独立场景证据。预锁评估包含按场景聚类的描述性区间，但仅2/3个簇不足以支持总体显著性结论。

R10 的可见表面几何、RGB约束、源形状先验和物理边界保持冻结。文字继续经原 grounding 模型影响 q0；本轮没有新增可独立确认文字目标的视觉语言分支。CLIP分数不作为实例真值。`association_supported` 仅表示源框先验下的几何兼容，不能翻译成“已确认同一目标”。

## 2. 实际实现与必要对照

去除替换采样造成的重复回波，相同XYZ归同组；按固定0.10m体素哈希将物理点拆为 A/B。两侧分别重建可见性、GrabCut种子/掩码和法向图，估计不混入另一侧点。它们仍共享RGB图像、q0、源ROI、骨干与形状先验，同一背景或错误先验可以在两侧稳定重现。

- 点面可靠性使用两侧平面偏移、法向一致和切向覆盖；任一侧不足3个面点时该面不可定义。
- RGB可靠性使用 A/B 掩码交并比、对称边界距离、跨侧点支持及点集歧义项。点多或当前残差小分别保留为独立控制。
- 对应状态分几何支持、冲突、未知。冲突作为有定义的拒绝零权重，未知保留NA并在实际加权中停用对应项；原始特征不抹除。
- 每个中心/尺寸约束分别可用或不可用。源尺寸先验和正则项保留，不能由可见点跨度直接替代完整尺寸。
- 实际加权目标是 `mean(r_face * face_loss) + r_RGB * RGB_loss + prior`，点面项保留原固定项数分母，不按权重和重新归一；不是事后把坐标位移乘小系数。原始全1/全0权重在26个真实改变例上分别逐bit恢复原G/源框。

统一权重对照使用每个平台无标签队列的有效已定义约束均值，点面与RGB分别计算，包含冲突定义零，并使用相同未知/对应门控。它有显式无标签队列信息，不能冒充逐例非传导方法；它用于检验“特定可靠性”是否胜过一般衰减。

原无条件G实际改变集合 C 为 Drone11、Quad15。额外可靠性计算限定在 C，外部保持源框且计入全部320例分母。六种固定半覆盖排序在同一 C 中各选K=6/8：可靠性、固定哈希随机、源一致性、低平面残差、点数、掩码稳定性。它们应用相同原G框，只改变接受集合。为了严格同K，可靠性排序可能接纳冲突零分；实际Drone接纳2个，未接纳NA。此排序实验不是实际加权求解器的遇未知即停用规则。25/75/100%覆盖曲线和1000次固定随机子集参考仅作描述，不从中选最优覆盖或种子。

同时封存6个单坐标替换框，评分时只替换源框的一个坐标。效用标签为真实IoU增量和坐标误差减少；这是坐标应用效应，不是删除某个损失项的因果效应。RGB增量单独比较全约束与去RGB坐标约束，点支持和门控一致。所有规则、队列均值、NA、预测和排序均在GT评分前封存。

逐约束加权减去冻结源模型为 **+0.019257 / −0.126626pp**；减去统一权重为 **+0.004890 / −0.025527pp**。相对无条件G恢复了部分损失，但不能据此证明可靠性有效。Quad上统一权重更好，低残差排序也超过当前可靠性排序。

平均中心L2误差 source→加权为8.447501→8.442780m、4.224585→4.222833m；中心误差减小可以与IoU下降并存，不能在结果出来后改换主指标。尺寸全部保持不变，尺寸误差分别0.251819/0.280579m；本轮没有检验出尺寸TTA能力不足。

## 4. 可靠性是否区分了有益与有害约束

| 固定同K排序 | Drone K=6：有益/有害/零 | Quad K=8：有益/有害/零 |
|---|---:|---:|
| 当前可靠性 | 1 / 1 / 4 | 0 / 5 / 3 |
| 固定哈希随机 | 1 / 3 / 2 | 1 / 3 / 4 |
| 源一致性 | 1 / 0 / 5 | 1 / 1 / 6 |
| 低平面残差 | 1 / 1 / 4 | 1 / 1 / 6 |
| 点数 | 1 / 2 / 3 | 0 / 4 / 4 |
| 掩码稳定性 | 1 / 2 / 3 | 1 / 3 / 4 |

Drone可靠性接纳的有害IoU总量为0.018733，源一致性为0；Quad可靠性为0.798089，固定随机为0.354242、源一致性0.094497、低残差0.029676。固定覆盖排除了“只因少改框”的解释，但没有提供当前可靠性优于简单规则的证据。

Drone主效用AUROC=1.0只来自**1个有效正例、1个有效负例**，还有4个有定义零效应、5个NA。它不能证明可靠性具有稳定区分能力。Quad有定义子集只有5个有害、5个零效应，唯一有益案例是NA，所以主AUROC/AP为**不可定义**，不能记成0、0.5或1。零效应不能充当有害类。

RGB匹配增量分别为+0.026896/+0.016234pp；候选中有益/有害/零效应为3/0/5、4/0/5。两平台都缺有害类，RGB可靠性主AUROC/AP同样不可识别。这保留RGB坐标约束的小正增量，但不证明其可靠性分数能识别坏监督。

原G改变集合共有26例/27个实际改变坐标；有效case分数16例有定义（包含4个定义零）、10例NA。其对应状态是14几何支持、4冲突、8未知。4个冲突全部由两分区mask零重叠触发，真实样本中**3D显著分量距离冲突规则触发0次**，不能声称已用3D歧义成功辨识邻物。52个分区掩码均可用，但8个活跃面约束因一侧点不足3而NA。另有2个几何支持案例case为NA，单独RGB约束仍可用并改变框，不能说所有改框例都有有效case可靠性。

## 6. 执行、审计与失败保留

实际source前向320例用时28.831817s；CPU几何与可靠性求解367.864692s；封存后CPU评分3.267233s。这些是分阶段整轮耗时，不是单臂完整部署延迟。全程未重新训练source，未用目标GT拟合阈值或可靠性。

26个真实例全1/全0桥通过。原G为25例收敛、1例有限非收敛；加权/统一各为12例纯先验原样返回、13例数值收敛、1例有限非收敛。所有有限非收敛在Quad，均保留，不删除负例。无无效数值输出。机制汇总第一次因哈希控制没有数值score而KeyError，未产生输出；原程序及失败收据保留，v2只兼容缺失哈希score，没有改变模型、可靠性或预测。

独立无标签审计复核320例源输入与预测契约；独立评分归约复核12094项，最大数值差1.776357e-15；机制与预锁门槛复核131项差0。审计区分NA和定义零、相同信息对照、匹配分母、负尾、固定覆盖和场景聚类。按场景区间及完整随机参考保留在标量汇总中；1000次随机参考不是p值，不可把320帧或5760条相关标量输出记录当成独立证据。

主要证据位于本目录 `scored320_attempt001/SCALAR_SUMMARY.json`、`PROGRESSION_GATE.json`、`DECISION.json`，独立复核在 `../evaluation/SCORING_INDEPENDENT_AUDIT.json` 和 `MECHANISM_GATE_INDEPENDENT_REVIEW.json`；无标签机制汇总在 `../mechanism/actual320_attempt002/SUMMARY.json`。完整图像只保留本地，不进入公开导出。

## 7. 本轮裁决

预先锁定的下一阶段资源门槛要求两平台均具备主效用两类、固定覆盖风险优于每个简单控制、加权在任务/坐标上优于source且任务上优于统一权重。本轮没有满足。它是控制继续投入的工程条件，不是总体统计检验。

因此不采用当前可靠性公式，不追加神经回归头更新，不把约束优化称作TTA收益；保留单模型、无教师的研究约束。两种有效机制事实仍成立：未知约束拒绝能避开一部分坏修正，少数RGB坐标约束有正增量。尚未成立的是“当前稳定性与源先验兼容分数能可靠判断目标约束有益”。下一次进入参数适应前，需要新的、能够独立检验目标前景或观测模型的证据，并检验对未被直接拟合的预测的收益。本轮没有安排后续GPU任务或阈值搜索。
