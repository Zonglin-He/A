R11 A/B seed support agreement is a proposed observable diagnostic, not an identity confirmation rule. No mask/G/model evaluation is executed by this document.

Keep the same original frozen q0, source dimensions, camera, RGB image, crop/initial probable labels, GrabCut settings and deterministic solver initialization. Split only point-backed hard foreground observations. Canonical raw-return IDs must be grouped before replacement: repeated model sample rows with the same raw ID belong to one physical observation. Verify that repeated raw IDs have identical canonical float32 XYZ. Conservatively union distinct raw IDs with exactly coincident canonical XYZ, including signed-zero normalization; this prevents identical positions from appearing in both roles, but also groups physically distinct coincident returns. A role is deterministic SHA256(`R11_seed_support_AB_v1|` + case ID + canonical group identity) parity. The exact serialization must be locked by the implementing agent before real extraction; use raw-ID groups when present, otherwise explicitly label the fallback unique-XYZ grouping. Do not force balance or duplicate a sparse role to reach a minimum.

Construct continuous-FOV/floor/nearest-depth visibility independently for A and B. Each mask can receive hard foreground seeds only from its own role. The other role must not enter seed counts, hard-foreground pixels, visibility selection or acceptance conditions. The same q0 supplies both tight ROI and probable foreground initialization, and the same outer ROI supplies background seeds. If either role has insufficient unique seed pixels, record a diagnostic unavailable condition; do not replace it with the whole-point mask or all foreground. The existing whole-observation mask remains a distinct reference.

Record A/B point and unique pixel seed counts, explicit segmentation statuses, retained seed fractions, foreground areas, mask intersection/union and IoU, symmetric disagreement, and agreement restricted to projected source ROI. Cross-role point support can be measured after both masks are frozen: evaluate B pixels against A mask and A pixels against B mask, with denominators and FOV counts, without using these measurements to rerun segmentation. Do not call these extra independent scenes, sensor views or independent RGB evidence. If the geometry pipeline is also compared under A/B, all geometry support/visibility/fitting for one proposal must consume only its registered role, keeping source priors and optimizer/caps identical. The shared frozen q0/backbone still consumed source observations, and RGB/camera remain shared.

Two masks can agree while both are wrong: q0 can select the wrong instance, a common probable-foreground ROI can segment the same background, neighboring objects with similar appearance can be merged, and occlusion can hide the same part in both masks. High agreement is therefore stability under disjoint seed interventions, not proof of semantic identity, full-object coverage or pseudo-target correctness. Low agreement can arise from a correct object under sparse support; it is not an automatic negative label.

First retain raw diagnostic values with no threshold selection. Any future reliability gate or weighting requires a separate finite protocol and matched no-optimization/direct-use control, and must be evaluated on sealed predictions with both gains and harms retained. Target labels cannot enter the splitter, seeds, mask generation, geometry target or per-case gate. An independent target-region association model would provide a different information channel; the current local CLIP crop similarity alone does not implement an independent referring-region detector. Single source grounder and no EMA remain unchanged.
