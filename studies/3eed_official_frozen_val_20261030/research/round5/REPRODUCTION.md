# Reproduction boundary

This is a frozen inference benchmark, not a source-model training recipe.

1. Obtain the official 3EED data and baseline checkpoint through the official repository/HuggingFace links. The full data archive SHA is 2ba7acd85b5240ec8acb6b9684a38deacafe873375fab4e3262183ef469fd809; checkpoint SHA is bfdedb97971fb31640c5a78790716dc9547953caa646489138f048375e645ec8. Do not substitute a Waymo-only interpretation for this union checkpoint.
2. Check out official worldbench/3EED commit 843a901f5367a6be5cc484b97c6ecad462961dfa in crossplatform/upstream. UPSTREAM_COMPATIBILITY.patch records the existing minimal import/model-construction changes. The deleted data/roberta_base entry is the author's absolute symlink, replaced locally by the authorized tokenizer/config assets; inspect the patch before applying it to a populated checkout. Model parameters, including the text encoder, are strict-loaded from all1,034 checkpoint state entries after config-only construction.
3. Match the recorded environment in baseline_engineering/ENVIRONMENT_AUDIT.json. This run uses PyTorch2.7.0+cu128 on RTX5090 and existing compiled PointNet/RoI operators; operator binaries are not distributed. Compile the official pointnet2/teed/roiaware sources for the installed Torch/CUDA/GPU ABI using the upstream setup.py entrypoints. A different build or batch may need a new numerical bridge. No installation or modification of the shared runtime occurred in this round.
4. Prepare a new input registration from the legally accessible local data. Run baseline_engineering/prepare.py, preserve the raw expression population and missing-scene ledger, and independently verify counts. It opens metadata containers to extract captions but does not select true class or target geometry. The public export excludes private input manifests and scoring indices; a reproduction must regenerate those local bindings.
5. Create a NEW immutable plan with new code/input/checkpoint hashes, absolute CLI paths and a new output directory. Keep B1, per-expression sampling and native Top10 tie order explicit. run_frozen.py changes its working directory to upstream; absolute plan/manifest/output paths avoid the retained first-attempt path failure.
6. Complete and hash-seal every full/noun candidate cache and unchanged model-state receipt before separately authorizing CPU scoring. score.py and the independent3D auditor have different geometry algorithms. The original float32 evaluator bridge is reported separately, not silently replaced. Qualitative image analysis requires the same completed source seal and scoring release; all real media stay local.

Public historical locks and hashes are evidence for the recorded run. They are not editable templates and cannot be made valid for a new machine by changing paths inside them. The exporter maps original to exported JSON hashes, with relative paths and hashed physical scene names. All raw prediction arrays, original captions, labels, images, point clouds and weights remain outside the public bundle.
