# Parent-controlled full diagnostic execution

`diagnose.py` is CPU-only and reads real target/class/other annotations only after verifying the parent's release, source seal, scored-result seal and manifest hashes. It changes no predictions. `render_cases.py` additionally requires an explicit media rendering flag before any real image pixels or pointcloud are loaded. Both scripts require new output directories and retain empty case strata.

The parent supplies a release JSON containing the existing scorer fields `all_predictions_sealed_before_numeric_GT: true`, `prediction_seal_sha256`, and `manifest_sha256`, plus `qualitative_and_GT_analysis_authorized: true`. Real figure rendering also needs `media_rendering_authorized: true`. These fields are authority/audit gates for this scientific workflow, not requests for new user permission. Existing user authorization permits the parent to issue them after the complete full-VAL source seal.

```
/absolute/workspace/avis/env_infer/bin/python /absolute/workspace/research/round5/qualitative/diagnose.py --mode full --cache FULL_SOURCE_DIRECTORY --manifest /absolute/workspace/crossplatform/round5/baseline_engineering/inputs/all.json --release PARENT_QUALITATIVE_RELEASE.json --scored FULL_SCORE_DIRECTORY --out NEW_DIAGNOSTIC_DIRECTORY
/absolute/workspace/avis/env_infer/bin/python /absolute/workspace/research/round5/qualitative/render_cases.py --mode full --cache FULL_SOURCE_DIRECTORY --manifest /absolute/workspace/crossplatform/round5/baseline_engineering/inputs/all.json --release PARENT_QUALITATIVE_RELEASE.json --scored FULL_SCORE_DIRECTORY --diagnoses NEW_DIAGNOSTIC_DIRECTORY --out NEW_LOCAL_PRIVATE_FIGURE_DIRECTORY
```

Primary selection is fixed to `official_full_last_bbf` on the original official eligible population. The text-only comparison uses `text_full_last_bbf` vs `text_noun_last_bbf` on both common official-eligible rows and all raw rows. The official-full vs noun image pair has unequal label information and is labeled accordingly. No GT class rescues a missing noun span or changes a model prediction.

Each row retains annotated-same-class-other overlap, nonexclusive ranking/coverage flags, the parent scorer's separate center/size/yaw field-injection oracles and rank-bounds for tied scores. A geometry-only Hungarian assignment between full/noun256-proposal pools supports a descriptive replay: use noun-selected matched index on the frozen full pool, then compare actual noun geometry. The two numerical components add exactly to noun-minus-full selected IoU, but correspondence is neither real identity nor a causal decomposition. All pool coverage and geometry-oracle values are GT-assisted offline diagnostics. Parent-level quantitative summaries preserve historical frame/scene exposure groups, including their caveats.

No new TTA or training is performed. No model is imported, no GPU acquired. PCA is not added to native yaw0 outputs. If a later parent requests a PCA diagnostic it must be a separate explicitly named output and cannot overwrite the current evaluation.

The original design and selection thresholds were drafted before reading round5 scores. Implementation then used only the already authorized48-expression smoke result to validate the schema/geometry contracts; those48 are exposed and part of the full9706 evaluation. The full target GT remains unopened by this agent until the full prediction seal/release. The source code was refined only for complete scalar aggregation and schema adaptation; stratum thresholds and hash selection did not change.

`smoke48_schema_audit*` contains private engineering outputs, no original RGB pixels or loaded pointclouds. `synthetic_fixture_v1` is a purely synthetic layout inspected visually. `ENGINEERING_FIXTURES.json` records independent synthetic camera sign/all5Waymo suffixes, Drone z undo, near-plane clipping, Hungarian permutation and exact stratum-boundary tests. Every real figure also regenerates source sample bytes and asserts both point/sample-index hashes against the sealed source, uses actual RGB dimensions, and records positive-depth/FOV fractions. Failed projection becomes an explicitly unavailable RGB overlay; BEV/3D remain available, with no guessed transform.
