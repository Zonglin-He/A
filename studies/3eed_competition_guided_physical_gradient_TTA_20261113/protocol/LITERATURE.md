# Primary sources and migration boundaries

[PCGrad NeurIPS2020 fullpaper](https://proceedings.neurips.cc/paper/2020/file/3fe78a8acf5fda99de95303940a2420c-Paper.pdf) and [official TensorFlow implementation](https://raw.githubusercontent.com/tianheyu927/PCGrad/master/PCGrad_tf.py), lines35–60, opened this round. They compute task gradients, remove opposing components when inner product<0, and aggregate projected gradients; original routine projects each task over the others. R93 is a deliberately asymmetric, norm-balanced migration protecting a weak grounding-task gradient while adjusting physical adaptation, not a PCGrad reproduction or evidence of its published results on3EED. Direct coefficients and original physical radius remove raw magnitude confounds; surgery itself cannot fix wrong task feedback.

[GEM NeurIPS2017 proceedings](https://proceedings.neurips.cc/paper/2017/hash/f87522788a2be2d171666752f97ddebb-Abstract.html) and [official implementation](https://github.com/facebookresearch/GradientEpisodicMemory/blob/master/model/gem.py) identify gradient-constraint projection against episodic supervised memories. R93 has no labelled task memory and does not implement GEM; it cannot inherit label-based no-forgetting guarantees. The transferable question is conflicting auxiliary/task directions, not trusting model preferences as GT.

The supervision is current-input R91 trained local/global competition predictions under physically tracked masking, not external experts, source training, or another model. R56/R58 tried broader distribution self-training; R93 instead constrains relative base-score differences on qualified spatial hypotheses, tests physically matched gradient interventions and a same-evidence least-squares direct readout. This mechanism difference is a finite hypothesis, not a novelty claim. Stable masked/local agreement is not correctness. No paper/official snapshot or weights included in public export.
