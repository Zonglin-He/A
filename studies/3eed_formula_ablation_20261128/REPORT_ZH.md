# 逐公式删减与简化

在同一批冻结推理输入上完成 **45 项**删减或简化。正式路径 23 项，中心路由 16 项，统一图割 6 项。地面准入和四尺度区域打分对精度最敏感。顶面约束中，实测点和首交见证主要维持几何一致性，删掉它们后 IoU 可能几乎不变。类别实验中的几何中位数可用坐标中位数近似。 [全部逐项分数](TABLES_ZH.md) · [冻结协议](PROTOCOL_ZH.md)

## 评估范围

正式方法和统一图割各复用 702 条缓存回复，评分 3EED 576 条和 KITTI 89 条。结构路由另复用并评分 288 条行人查询，其中 185 条的录制与直接机制面板不重合。各面板有历史曝光。每次只改当前项，下游根据原接口重算。所有候选先封存，GT 仅用于评分。Acc@50 为 IoU 严格大于 0.50，配对区间按平台内原录制重采样 2,000 次，未做多重比较校正。未调用新模型或训练 checkpoint。

## 正式路径

正式法在 3EED 主面板为 **34.77% mIoU / 33.85% Acc@50**，在 KITTI 为 **22.22% / 22.47%**。

| 单项改动 | 3EED ΔmIoU / ΔAcc@50 | KITTI ΔmIoU / ΔAcc@50 |
|---|---:|---:|
| 移除地面准入 | −9.58 / −11.81 pp | −10.41 / −13.48 pp |
| 区域打分中的重叠数从平方改一次方，保留曝光归一化 | −6.43 / −10.94 pp | −0.30 / 0.00 pp |
| 只用重叠数，去曝光归一化 | −2.63 / −2.43 pp | +0.33 / +1.12 pp |
| 四尺度只留最细和最粗 | −2.47 / −2.60 pp | +0.33 / +1.12 pp |
| 水平近面锚定改跨度中点 | −3.48 / −5.73 pp | −6.15 / −10.11 pp |
| 底部去地面下拉 | −3.78 / −5.21 pp | −1.85 / 0.00 pp |
| 补尺寸去 Qwen 下限 | −4.13 / −4.51 pp | −1.27 / −1.12 pp |
| 固定 PCA yaw | −2.53 / −4.86 pp | −4.45 / −7.87 pp |
| 固定 Qwen yaw | −2.97 / −5.03 pp | +1.36 / +3.37 pp |
| 关闭 C_ray | −3.26 / −5.73 pp | −3.91 / −5.62 pp |

区域分数的原式为重叠数平方除以曝光。三种读出分别比较了原式、保留曝光归一化的线性分数、无曝光因子的重叠数。3EED 中，线性归一化版本的 mIoU 差为 **−6.43 pp [−7.62, −5.25]**。区域中心最低票数单删使 3EED **+0.45 pp mIoU [0.07, 0.72]**，主要来自 Drone；KITTI **−1.36 pp**，因此将它视为遇到域变化时需要复核的门槛。

射线 yaw 选择的**无交罚项**比残差封顶更敏感。拿掉封顶只改 3EED 的 11 条框，mIoU 差 **−0.05 pp [−0.28, 0.21]**。无交罚项设零改 25 条框，mIoU 差 **−1.06 pp [−1.61, −0.54]**。固定 Qwen yaw 在 KITTI 有正点估计，区间 **[−1.80, 4.63] pp mIoU**。A 回退去半尺寸深度补偿在 3EED 得 **+0.43 pp mIoU**，在 KITTI 为 **−2.94 pp**。

## 顶缩的精度与物理合同

关闭顶缩后，3EED **−1.25 pp mIoU [−1.49, −1.04]**，Acc@50 **−1.74 pp**，净少 10 条成功。删 Qwen 高度下限使 mIoU **−1.24 pp**、Acc@50 **−2.60 pp**。

在 3EED 282 条启用 C_ray 的查询上，正式顶缩相对原未缩框保持 **40,898 条 Selection 射线的首交全部一致**。在 40,921 条独立 Audit 射线上仍有 21 条首交变化。两套射线使用不同观测组。

| 只改一项 | ΔmIoU | 改变的 Selection 射线 | 原拟合点被排除的查询 |
|---|---:|---:|---:|
| 正式顶缩 | 0.00 pp | 0 | 0 |
| 去首交见证 | −0.04 pp | 1,224 | 0 |
| 去实测点见证 | −0.05 pp | 0 | 20 |
| 只用 Qwen 高度 | −0.23 pp | 1,892 | 44 |
| 底面随高度移动，围绕旧中心缩高 | −1.37 pp | 286 | 50 |
| 去掉原高度上限 | 0.00 pp | 0 | 0 |

删原高度上限使 **8 条**输出高于未缩框，聚合分数和上述射线结果持平。它规定了变换只缩顶部的行为。首交见证与实测点见证分别保护相交几何与物理占据；是否可删必须同时看物理审计。 [高度上限补充协议](ROOF_CAP_ZH.md)

## 结构与类别读出

在 185 条行人录制子集上，去边界否决使 Structure 的 mIoU / Acc@50 从 **22.73% / 12.97%** 升到 **24.22% / 18.38%**。去协方差特征值比得到 **24.35% / 17.84%**。相同读出在 576 条混合类主面板中的 mIoU 增量分别为 **+0.36 pp [−0.65, 1.35]** 和 **+0.26 pp [−0.01, 0.55]**。去象限覆盖、去观察角项的框在这两组面板上逐值没有可测变化；去除边界的竖直复核几乎不触发。两项放宽各自救回部分行人框，剩余差距仍需其它证据解释。

固定 `α = 0.5` 使 185 条行人的 mIoU / Acc@50 达 **28.10% / 30.27%**，仍低于同支持的类别版本 **29.31% / 35.14%**。混合类主面板中，半权插值使 mIoU 降到 **31.89%**，相对原 Structure **−2.34 pp [−4.15, −0.81]**。

类别路由内，把几何中位数换为**坐标中位数**，3EED 四尺度支持的 mIoU 差 **+0.01 pp [−0.04, 0.07]**，185 条行人子集 **−0.10 pp [−0.29, 0.07]**，子集 Acc@50 持平。换成算术均值在 185 条行人子集为 **+0.32 pp mIoU**、**−1.08 pp Acc@50**。坐标中位数是本轮得分最接近的简化读出之一。
