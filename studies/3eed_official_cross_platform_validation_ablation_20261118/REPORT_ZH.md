# R165 · 3EED 六方向跨平台 Validation 与严格消融

完整单帧方法相对逐条配对的官方 Frozen，六方向等权 mIoU / Acc@25 / Acc@50 变化为 +2.711 / +4.790 / +4.005 pp。
覆盖 18,620 / 19,388 条官方方向记录。既有 FINAL384 对应 768 条方向记录未进入本轮。

**主要收益来自 PCA 朝向。** 只给官方 Frozen 加 PCA，Acc@50 从 6.16% 提高到 9.94%，贡献 +3.79 pp。完整方案相对同样带 PCA 的 Frozen 另增加 +0.22 pp，在六个方向中三升三降。

Waymo、Drone、Quad 各自使用已存在的单源 epoch100。每个目标表达分别由另外两个来源评估。
全部配置共用一帧目标观测、16,384 个相同采样点、同一描述和源模型的原始 A256。
官方 Frozen 使用发布代码的末层 BBF，类别跨度来自评测注释。R76 和 R91 使用同步 RGB，选框路径只读点云、RGB、标定及原句。
这批 Validation 此前用于开发及评估。R76／R91 是已有的源域准备状态，本轮进行了冻结推理。

## 2. 组件是否有净贡献

每行只改变列出的因素。`上升／下降方向` 以 Acc@50 计，`救回／损伤` 是逐条跨过同一阈值的数量。

| 改动 | ΔmIoU / ΔAcc@25 / ΔAcc@50（pp） | Acc@50 上升／下降方向 | Acc@50 救回／损伤 |
|---|---:|---:|---:|
| R76 源域准备，关闭 RGB | +0.556 / +0.429 / -0.132 | 2 / 4 | 189 / 219 |
| R76 的 RGB 路径，统一 PCA | -0.254 / -0.339 / -0.541 | 0 / 6 | 174 / 273 |
| R91 竞争接口，统一原选框和 PCA | +0.081 / +0.141 / +0.169 | 5 / 1 | 83 / 54 |
| R91 竞争接口，统一去重和 PCA | +0.057 / +0.089 / +0.215 | 3 / 1 | 84 / 49 |
| 重叠去重，冻结 R91 和 PCA | +0.642 / +1.269 / +1.021 | 5 / 1 | 408 / 224 |
| PCA，固定完整方法的候选、中心和尺寸 | +1.758 / +3.234 / +3.536 | 6 / 0 | 729 / 112 |
| PCA，直接加在官方 Frozen 上 | +1.765 / +2.962 / +3.786 | 6 / 0 | 745 / 96 |
| 完整方法相对同样带 PCA 的 Frozen | +0.946 / +1.828 / +0.219 | 3 / 3 | 554 / 514 |
| 完整方法相对原始 Frozen | +2.711 / +4.790 / +4.005 | 6 / 0 | 1020 / 331 |

PCA 与重叠去重有范围明确的任务证据。R91 目前仅支持小幅增量。R76 的 RGB 开关没有提供净收益，且 Acc@50 六方向均下降。
- PCA 路径以原始点云估计朝向，严格固定原候选、中心和尺寸。
- R76 的 RGB 消融在相同训练权重下关闭早期双向 RGB 读取和晚期图像残差。开关整体衡量同步 RGB 路径的增量。统一 PCA 后的 mIoU -0.254 pp（1 个方向提高，5 个方向下降）。
- R91 与 R76 共用原模型和同一套融合参数。对比时只启用竞争接口。固定去重和 PCA 后的 mIoU +0.057 pp（4 个方向提高，2 个方向下降）。
- R158 的重叠去重允许改选候选，PCA 仍在各自最终框上用同一规则。固定 R91 和 PCA 后的 mIoU +0.642 pp（5 个方向提高，1 个方向下降）。

## 4. 验证边界

- 作者表 7 列出 9,706 条原始描述。发布加载器按类别同义词筛除 12 条 Waymo 描述，留下 9,694 条可评描述。所有臂使用相同的最小框尺寸 `1e-6`。
- 使用严格 `IoU > 0.25 / 0.50`。为了让朝向消融共享一个稳定的 IoU 实现，独立传感器坐标凸包重复核验了 260,680 个输出。最大绝对 IoU 差 3.94e-15。
- 上游原生 FP32 几何保留了完整平行评分。官方 Frozen 的 Acc@25 / Acc@50 为 22.550 / 6.156%，两种实现合计出现 0 个逐臂阈值判定差异。[评分器更正记录](experiment/SCORER_ADDENDUM.json) · [原生 FP32 的全部指标](results/literal_upstream_geometry.csv)
- 每个录制场景独立出表。同一帧的多个描述与两条来源预测共享匿名标识。无人机和四足分别只有两个和三个录制，方向均值不能外推为跨新场景显著性。 [分场景指标](results/recordings.csv) · [逐条指标与负例](results/all_rows)
