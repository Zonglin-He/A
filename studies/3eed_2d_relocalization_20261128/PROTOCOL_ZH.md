# 原图二维重定位扩展与可辨识性复核

- 主要终点是固定 665 条开发面板上，原图重新定位对原 R2 自然候选池的 mIoU 提升。Waymo、Drone、Quad 和 KITTI 分开报告，同时给出 Acc@50（3D IoU 严格大于 0.50）、救回和损失。采用平台内按录制配对 bootstrap（2,000 次），其他池和子组用于机制分析，区间不作多重比较校正。
- 用现有 702 条盲输入生成全部候选和新二维读出，在封存后恢复既有 665 条带配对 GT 的评分清单。GT 只进入离线评分，以及单独标记的候选 Oracle。记录同一模型批量推理与历史逐条 pilot 的差异。
- 原图只送入 RGB 与原查询，使用同一冻结 Qwen3-VL-4B、相同原二维提示、贪心解码，无额外训练。二维读出只用于排序，不进入支持生成、深度、姿态或尺寸计算。原候选顺序和去重固定，标定校正后用投影包围矩形与二维框的可见区域 IoU 排序，同分优先首位正式框。无有效框或候选时退回正式方法。用首次二维缓存、同平台异查询框、截断首交残差、均匀随机期望和候选 GT Oracle 作对照。
- 自然候选保留 pilot 的已封存盒。C_ray 池仅使用正式框与同支持下的 PCA、Qwen 双方向替代。多尺度池从原四尺度逐次限制为单尺度，保留原 Object 选择规则、几何后端和输入，记录可用及去重后的候选；全量统计包含单例和回退。三池分别打印条件子集和共同候选覆盖。行人补充面板用其正式框、逐尺度和已有固定支持下的几何中位数；185 条录制与主面板不交叉，用作复测。
- 首交等价要求命中图案一致、至少一条正式框命中且深度差最大值不超过 1e-6 m。分别检查原 Selection 和同原支持下的 Audit，均使用全部已封存评价射线。经济性通过模型批内吞吐和候选/排序耗时报告。另保留原 R2 的单因素合成首交等价 pilot，明确标记与主面板的重叠。
- R4 只复核诊断。固定正式框，以原 R4 标度、稳定首交面与有限差分重算射线雅可比，报告相对阈值、绝对阈值与改用统一标度的敏感性。取稳定投影极值角点计算归一化 2D 矩形雅可比，测量其在射线弱方向上的能量、秩以及叠加前后的变化。该计算只检验观测模型，不使用真值框、Qwen 区域或物理原生射线。
- 采用公开发布与历史录制清单核查真正无曝光测试数据。主面板和补充录制均明确标注曝光级别。正式入口的晋升取决于全量配对、平台一致性和曝光外验证，保留原顶面收缩。R1、R3、R5、R2 线框，及 R4 多自由度优化保留实验历史并冻结。
