# R12 proposal · independent target evidence before adaptation

Status: proposal only. No new target labels, model/GPU calls, scoring, masks or temporal correspondences have been accessed or produced by this preparation. Root must verify the actual observation interface and freeze one branch before execution. This card does not authorize an extra model, a pose oracle or neural TTA.

The narrow question is whether independently generated image-instance evidence and, if it exists, verified real neighboring observations supply better fixed-query geometric supervision than the same source prior and generic attenuation. R11 showed shared RGB/source-ROI stability can remain high for harmful background; 26/320 proposals changed, only27 coordinates, sizes never moved. Drone's task AUROC1 used just1help/1harm, while Quad's only help was undefined. A new stability formula alone would not resolve that missing foreground/identity evidence.

Keep the Waymo-only epoch100 source checkpoint and strict-FP32/source preprocessing unchanged. Select at most160 new anchor inputs, preferably32 distinct pointpaths in each of5scenes, by input-only hash before any outcomes. Exclude R9/R10/R11 and smoke anchor IDs/physical pointpaths where available; shortfalls are reported without outcome-based replacement. Real neighbors are auxiliary observations, not extra novel test anchors. TargetVAL/scenes already have old research exposure; this is a new-anchor exploratory study with only2Drone/3Quad scene clusters.

Prerequisite branch decision must use verified files/schema, not filenames alone. Each temporal support needs an actual frame/timestamp relation, source and destination coordinate conventions, calibration/pose provenance, and a validated mapping into the anchor model frame. Same-frame camera extrinsics do not by themselves provide cross-frame ego motion. Static points can be compensated only when the transform is valid; moving cars/people need an independent motion/instance correspondence, otherwise their temporal contribution is rejected/NA. Recorded sensor/estimated poses and ground-truth-assisted trajectories are distinct protocols. Unknown pose provenance is not silently labelled deployment-valid. GT-assisted pose results, if separately authorized, remain oracle auxiliary and cannot satisfy the primary no-GT prerequisite.

First deliver the independent single-frame mask diagnostic. Full-frame mask generation must not use q0 box, q0 crop, q0 foreground seeds or q0-selected point labels. Image/text target association must retain multiple-object ambiguity; generic objectness or same-class overlap is not identity. A source box may remain a shape prior in G but cannot be relabelled as independent evidence. If the method reselects query/object identity, expose q_source and q_association and include association-only without geometry; do not attribute that gain to pseudo geometry. The preferred first branch keeps q0 fixed.

With usable temporal inputs, compare source; directG using independent single-frame evidence; directG using valid temporal independent evidence; and fixed wrong-frame/shuffled-correspondence controls. Preserve the same source/q0 and equivalent evidence-processing budget. Wrong controls must be deterministic, built before GT, and report their FOV/support/reject rates. Failure to pass a correspondence gate is an outcome, not proof that a useful temporal signal exists. Every directG arm is already the same-information no-update comparator for any future parameter adaptation. Do not create a duplicate named no-update arm and count it as an independent method.

Freeze a concrete generic-attenuation/prior comparator once G is specified, before predictions or labels. Use a uniform-constraint or one predeclared source-to-proposal shrink control; do not tune its coefficient on target metrics. Report its information/eligibility/coverage and compare common populations. A gain only over an intentionally corrupted control or a harmful unconditionalG does not meet the source-feedback prerequisite.

Score nativeyaw0 selected boxes, no PCA/GTyaw/GTclass or GT candidate choice. Show source/directG all-anchor mIoU, strict Acc25/50, center/size error; signed gains/harms/zeros, numerical failures, NA and unchanged counts. Also use the same presealed common-eligible/common-changed masks for all arms, and retain own-change statistics as descriptive only. Report per-coordinate geometry provenance, original source-prior assumptions and correction magnitudes. IoU overlaps are not exact instance-identity labels. Single-frame masks, valid/moving-reject temporal support, wrong-frame and pose-oracle cases must have separate denominators. Use scene-equal paired means and per-scene effects;2/3clusters cannot support a broad significance claim.

Progress only if independently measured direct feedback has nonzero supported applications, improves task and the relevant coordinate error over source in each target platform, and its gains exceed harms on the full preselected cohort while outperforming the prelocked same-information/simple attenuation comparison. A temporal claim additionally requires a positive temporal-minus-single-frame increment with plausible correspondence and rejection controls; generic source/mask changes alone do not establish temporal value. Report effect sizes, tails and defined counts; do not invent a universal AUC/sample-size/significance cutoff. If useful and harmful classes are absent, discrimination is unidentifiable rather than successful. If these conditions are not met, stop the current branch and retain the positive/negative/zero observations.

If temporal observations are absent or unusable, label the temporal branch missing-input/unexecutable and execute only a separately locked single-frame independent-mask feasibility branch. Do not fabricate neighbors by augmenting the same P/RGB, treat fixed filenames as motion tracks, or call a source-conditioned crop an independent target detector.

Any conditional TTA would need a new registration after the direct prerequisite: supervision from A must be evaluated on another verified, unused observation/input B, with correspondence/motion assumptions explicit. Same-input fitting to the same pseudo box is not extra task evidence. Preserve the direct pseudo/no-update readout and, for a frozen-feature linear last head, its exact feature-kernel transfer control. No such update is planned or executed by this proposal.
