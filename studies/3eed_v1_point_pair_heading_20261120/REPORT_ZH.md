# 同一个已选框里，两点能否被同一朝向收进来

固定精简 v1 选中的实例、中心和三个边长，对最后一次 PCA 的取点方式做干预。在 18,620 条普通 Validation 方向记录上，共同取点的 Acc@25 从 27.3740% 升到 28.2798%，Acc@50 从 10.1603% 降到 9.7815%。Acc@50 救回 194 条、误改 280 条，按录制配对的六方向等权差为 −0.3788 个百分点，95% 重采样区间为 [−0.7802, −0.0465]。保留精简 v1 的朝向估计。这批录制以前已用于研发。[实验锁定配置](PROTOCOL.json) · [逐方向配对](results/ordinary_paired.csv)

## 测量

v1 原先在水平轴对齐的预测框内取点，再用这些点的长轴估计朝向。如果取点边界左右了估计，就有理由在同一中心、同一尺寸下考察多种取点朝向。对当前传感器帧中每个唯一回波，记 $a_i(\theta)$ 为它是否落入绕中心转过 $\theta$ 的矩形。高度区间固定，角度在 $[0,\pi)$ 均匀取值。估计量为

$$
M=\sum_{i<j}\mathbb E_\theta[a_i(\theta)a_j(\theta)](x_i-x_j)(x_i-x_j)^\top .
$$

输出 $M$ 最大特征值对应的无向轴。用 $n,s,Q$ 表示一次取点的数量、坐标和、二阶矩和，展开点对可得 $M=\mathbb E[nQ-ss^\top]$。每点的进入和离开角把圆分成有限区间，排序这些角后积分，耗时 $O(n\log n)$，空间 $O(n)$。这种做法赋予能共同进入同一物理尺寸窗口的点对更高权重。相同窗口也可能同时包含路面和邻物，点对属于同一实例仍是待检验的假设。[实现](orientation.py) · [显式点对积分与旋转等变核验](results/geometry_audit.json)

所有臂读取 v1 同一帧同一份 16,384 点采样。原 PCA 的点数、长宽比和退化条件决定共同的适用范围。普通验证 13,768 条符合条件，4,852 条沿用原值。主方法对照包括逐点独立权重、外接圆全部点、两点间裁框方向相差 90°，以及沿原 PCA 方向再裁一次。源域留出、开发面板、普通验证三批的全部预测先共同封存，随后以原始描述对应的单目标七维 GT 评分。每条基线 IoU 均与历史封存值一致。两套有向交并比实现的全体最大差为 1.23e−15 以内。[预测程序](predict_yaw.py) · [评分](score_yaw.py) · [公开逐例独立复算](results/recount.json)

已有工作比较了分割点簇的 PCA 与可见 L 形侧面拟合，也有工作通过点对投票构造局部方向张量。这里单独检验的操作是用同一固定尺寸矩形的共同包含概率加权点对。显式逐对积分与事件扫描的最大归一差为 1.1e−15。计算正确性成立，数据给出的 Acc@50 更支持保留原取点方式。此实验未改变语言读出与主体选择，未使用新增训练标注。[Zhang 等的 L 形拟合](https://publications.ri.cmu.edu/storage/publications/2017/07/Xiao-2017-Efficient-L-Shape-Fitting.pdf) · [Wu 等的张量投票](https://arxiv.org/abs/1601.04888)
