# 四种单帧物理恢复范式

冻结论文方法 Minimal-D 为配对基线。本轮设置互相独立，实验均不改正式入口。仅范式一和三更新参数，分别训练几何 Flow 和 IoU Critic。两者只读取封存的 Waymo train 框尺寸，验证只使用 Waymo val 的尺寸及新仿真。Qwen3-VL 权重冻结，无外部感知模型，无目标域训练、域适配或域级校准。目标域 RGB、真实 LiDAR 和原查询只用于逐样本推理，评估标注在预测封存后打开。

| 范式 | 实现与预先固定的比较 |
| --- | --- |
| 1 · 射线规范 Flow Matching | 1,000,448 组按需采样的源域仿真视角，模拟多仰角、多高度、遮挡和 1%–100% 保留概率。点以实测质心为原点，将观察方向对齐到规范轴，保留相对重力。用高斯至框的条件流拟合中心、对数尺寸和轴向角；8 步 Euler、12 粒子。对照无投影 MBR 与每步投影 MBR。投影选择最近的固定参考 yaw，维持各自参考框的锚和保护跨度。无物理支持时观测约束为空，仍复用同一生成网络。 |
| 2 · 冻结 ViT 自提示 | 读取最后一层 ViT、merger 前的原网格。LiDAR 物理支持投影为正原型，原窗外环为负原型，余弦间隔经 sigmoid 输出概率。单测用凸包概率重叠替换 AABB 排序，再测同时对区域投票加权。另在同姿态参考框与拟合框间严格匹配 Selection 和 Audit 首交，比较 AABB 和剪影选框。旧回复缓存未存特征，本轮重跑纯视觉编码，语言生成次数为零。 |
| 3 · 3D IoU Critic | 共用源域仿真样本。用取受扰动直立框与 GT 的精确 3D IoU 训练，特征由尺寸归一化的六面距离分布、首交残差、相对朝向、尺寸比和可选剪影重叠组成。绝对世界高度、绝对距离与平台 ID 均不进入网络。在六种姿态与 16 个尺寸、分位数、中心偏移配置的格点上打分，附基线及原候选。对照同池 AABB、射线、纯几何 Critic 和加剪影 Critic。格点允许软锚定，Oracle 仅评估时计算。 |
| 4 · 清洁裁剪与 MBR | 固定哈希按录制和唯一图片分层，Waymo、Drone、Quad、KITTI Tracking、Mono3DRefer 各取 32 条。原图窗口裁两种尺度 1.3× 与 1.8×，每尺度采两个二维框和尺寸回复，再另读五类视角分布。用新窗口的 LiDAR 做 10% 分位数锚和候选内保护投影，按合并的端面/侧面概率剪枝，做加权期望三维 IoU 决策。比较第一有效样本、未剪枝 MBR、剪枝 MBR，以及用硬极值代替分位数。无有效原窗或裁剪回复时走 Minimal-D。 |

范式一至三在完整 873 条封存输入上预测，沿用已有 836 条带参考查询。其中 665 条开发查询含三平台 3EED 576 条和 KITTI Tracking 89 条，Mono3DRefer 171 条全报并额外列出历史录制过滤的 118 条。范式四报告固定 160 条的有标注子集与全部分平台样本量。队列包含无框和回退，严格 IoU > 0.50 为 Acc@50，配对区间按平台录制重采样 2,000 次。两套面板此前都被项目评估过。这是冻结配置迁移评估，历史曝光仍需区分。

仿真使用矩形及随机内缩表面、少量污染和距离噪声。源域没有冻结 Qwen 三维先验记录可用于本仿真，训练的尺寸条件由封存尺寸加固定扰动生成，测试使用实际 Qwen 先验。Flow 的精确约束相对于每粒子选定的参考框和有限 Selection 射线。共享支持提取复用原绑定或固定二维窗深度筛选。剪影训练代理是模拟射线覆盖，实际评分用视觉特征导出的概率场。裁剪的分位数参考框由新支持得到，其物理保持也相对于自身参考框。所有新方向的报告分别列出适用覆盖、候选 Oracle 和计算成本。
