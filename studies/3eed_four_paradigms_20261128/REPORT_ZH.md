# 四种单帧物理恢复范式的配对实验

四条分支分别实现并封存，使用正式 Minimal-D 作为配对基线。两个小网络均仅从 Waymo 源域仿真学习，Qwen 权重冻结，目标域只参加推理与离线评分。前三条在完整 873 条封存输入回放，对 836 条有参考查询评分。第四条固定抽取 160 条，按可用参考评分。两个评估面板均已有项目曝光。 [实验协议](PROTOCOL_ZH.md) · [完整机器可读结果](results.json)

开发面板上，仅换剪影排序最接近 Minimal-D，mIoU 下降 **0.22 pp**，配对 95% 区间 [−0.45, −0.05]。清洁裁剪、分位数锚和视角剪枝的组合在固定开发子集下降 **4.37 pp**，在 Mono 子集提高 **10.45 pp**。候选 Oracle 只用于计算上限。

## 范式一 · 源域仿真与 Flow

训练使用 256 条 Waymo train 框和 94 段录制产生 1,000,448 组虚拟观测，Waymo val 共 8,192 组不同仿真。Flow 有 110,055 个参数，Critic 有 22,913 个参数。192 个 Waymo 评估图像与源训练在录制和 RGB 哈希上均无重叠。
Flow 对 861 条生成候选，853 条有实测支持。10,236 个终步粒子上，Selection 首交变化为 0/744,720，独立 Audit 的变化为 1,266/744,744。投影是对各自参考 yaw 的有限射线保证。无额外 Qwen 解码。

用同一噪声样本比较两种 Flow 读出，逐步投影使开发 mIoU 进一步下降 **3.05 pp** [−4.25, −1.84]。在这套仿真与投影配置中，候选的参考首交保持并未带来整框准确率提升。

## 范式二 · 冻结 ViT 剪影

845 张图片得到 845 个有效剪影，缓存网格 845/845 一致。回放额外用了 106 批纯视觉编码，59.4 秒，语言解码 0 次。三平台各一例的普通二维生成中，捕获钩子与纯视觉重算的特征逐项均一致，原生生成 token 也保持相同。
在 333 条同姿态参考框与拟合框的严格 Selection 和 Audit 首交等价对照上，AABB / 剪影 mIoU 为 47.62% / 47.63%。剪影改变 60 条选择，mIoU 配对差 +0.01 pp [-0.08, +0.10]。该候选对和历史自然候选池各有自己的分母。

## 范式三 · IoU Critic

源域留出仿真上的 IoU MAE 为 7.06 pp，同批均值基线为 15.19 pp。真实开发数据的有效候选池均值大小为 96.9。几何 Critic 与剪影 Critic 的逐查询平均 Spearman 分别为 0.291 和 0.278。

同一开发候选池，剪影 Critic 比 AABB 排序低 **1.01 pp mIoU** [−2.35, +0.44]。在 Drone 上，剪影 Critic 比同池 AABB 多 **5.21 pp Acc@50**，仍比 Minimal-D 低 **2.60 pp**。候选 Oracle 相对 Minimal-D 的开发 mIoU 空间为 **7.94 pp**，Drone + Quad 的空间为 **9.17 pp**。KITTI Tracking 上，同池 AABB 提高 **6.29 pp mIoU** [＋3.30, ＋9.60]，高于该平台的两个 Critic 读出。

## 局限和复现

仿真由封存标注框与虚拟观测组成，形状、噪声和尺寸先验与真实传感器及 Qwen 输出存在差异。裁剪方案的样本量和额外推理预算单列。选框条件与 Audit 的几何约束各自报告。正式 Minimal-D 独立登记。

从已恢复的仓库根目录运行。历史输入、Waymo 封存源清单、目标离线标签、权重和传感器文件须可用。聚合结果已发布。

  python "$study/blind_experiments.py" "$mode"
