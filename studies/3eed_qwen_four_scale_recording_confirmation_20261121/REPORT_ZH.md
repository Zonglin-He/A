# Qwen 四尺度物理补框的录制隔离复核

**保留原 PCA 版本作为主研究候选，暂停 HiSpatial 的算法开发。** 固定配置在 288 个新物理帧上把 Acc@50 从 Qwen 窗口中位深度的 **14.93% 提到 29.51%**，相对同帧 v3 的 **17.88%** 提高 **11.63 pp**。只看与原选型录制隔离的 224 帧，Acc@50 相对 Qwen 提高 **10.59 pp**。分平台看，Drone 的增量在新帧和隔离录制都复现，Quad 隔离录制上则出现净退化。[锁定版本](METHOD_LOCK.json) · [完整任务指标](results/metrics.csv) · [所有配对变化](results/paired.csv)

## 固定方法与复核范围

方法重放原配置 `C_E_Qsize`。独立调用冻结 Qwen3-VL-4B-Instruct 得到二维窗和三维尺寸，通过原四尺度物理区域及投影匹配选区，以区域 PCA、可见面和底面补全 7D 框。方法推理只加载 Qwen 权重。训练和目标参数更新次数均为零。原开发面板仅用来核验实现，原中位深度、PCA、Qwen 朝向重锚定三组共 **288 个框记录**逐坐标复现，核验过程只读取旧封存预测。[原实验](https://github.com/Zonglin-He/A/blob/776c982aa54636907b9c2afd99b2fd97d6597dea/studies/3eed_qwen_four_scale_region_grounding_20261121/REPORT_ZH.md) · [逐坐标核验](results/locked_replay.json)

| 复核范围 | Waymo | Drone | Quad | 与原 96 帧的录制关系 |
|---|---:|---:|---:|---|
| 普通 Validation | 96 帧 / 61 段 | 96 帧 / 2 段 | 96 帧 / 3 段 | Waymo 录制隔离，Drone 和 Quad 同录制新帧 |
| Ordinary TRAIN 单列扩展 | — | 64 帧 / 2 段 | 64 帧 / 2 段 | 全部录制隔离，既有 R159 普通样本清单 |

所有 416 帧均与原方法选型面板的物理帧、LiDAR 内容和 RGB 内容分离。Waymo 同一记录时间的多相机视角归为同组。扩展跨录制针对 Qwen 选型面板的暴露定义，数据此前已用于其他项目实验。所有样本一并计入，320 帧得到可用完整区域，余下 96 帧走原回退或原生无有效框。全部只用普通数据，FINAL 未访问。按目标平台等权，v3 每帧分别运行两个外域源模型，每份源权重等权。Qwen 的相同原句两次独立询问共 832 条，v3 使用其原评测的文本规范。[数据清单封存](results/panel_seal.json) · [评价协议](PROTOCOL.json) · [模型封存](results/model_seal.json)

每个单元格为 Acc@25 / Acc@50 / mIoU，单位为 %。Acc 使用严格的有向 3D IoU 阈值。

| 普通 Validation · Waymo | 72.92 / 30.21 / 37.07 | 29.69 / 10.42 / 15.42 | 77.08 / 57.29 / 48.38 | +27.08 pp |

| **普通 Validation · 三平台等权** | **42.01 / 14.93 / 22.72** | **32.64 / 17.88 / 18.53** | **56.25 / 29.51 / 31.92** | **+14.58 pp** |
| 隔离录制扩展 · Drone | 35.94 / 12.50 / 20.48 | 38.28 / 21.09 / 21.59 | 53.13 / 20.31 / 24.97 | +7.81 pp |

| 隔离录制扩展 · 两平台等权 | 34.38 / 10.16 / 18.62 | 31.25 / 16.80 / 17.47 | 46.09 / 12.50 / 21.54 | +2.34 pp |

普通 Validation 对原 Qwen 在 Acc@25 救回 52 帧、误改 11 帧，在 Acc@50 救回 54 帧、误改 12 帧。Acc@50 录制级配对重抽样区间为 `[+7.76, +21.18] pp`。Drone 的普通 Validation 及隔离录制均比原 Qwen 改善，分别救回／误改 17／4 和 10／5。隔离录制 Quad 救回 3 帧、误改 5 帧。将 Waymo Validation 和 Drone/Quad 隔离扩展仅作描述性合计，224 帧、65 段录制上，Acc@50 从 16.84% 到 27.43%，比正式 v3 的 14.67% 高 12.76 pp。两个小平台各只有两段录制，整体优势受 Waymo 贡献较大。[配对计数](results/paired.csv) · [分方向 v3](results/v3_directions.csv) · [录制重抽样](results/score_receipt.json)

## 朝向变化和框补全的作用

`只换朝向`与 PCA 版固定同一个物理节点、同一组点、同一长宽高和同一框中心，仅换成长轴对齐后的 Qwen yaw。`换朝向并重锚定`则按新轴重新测量并锚定框面，允许补全后的中心和尺寸随之变化。缺支持帧沿用同一个回退。所有数值为 Acc@50（%）。

| 范围 | PCA 版 | 只换 Qwen 朝向 | 换 Qwen 朝向并重锚定 |
|---|---:|---:|---:|
| Validation 三平台等权 | 29.51 | 20.14 | 24.65 |
| Validation Waymo | 57.29 | 41.67 | 48.96 |
| Validation Drone | 20.83 | 9.38 | 13.54 |
| Validation Quad | 10.42 | 9.38 | 11.46 |
| 隔离录制 Drone | 20.31 | 6.25 | 10.94 |
| 隔离录制 Quad | 4.69 | 1.56 | 14.06 |

原 96 帧上观察到的 Drone 朝向偏好未在本轮复现。Quad 隔离录制中，换朝向并重锚定在两段录制分别把达标数从 1 到 6、2 到 3，单换朝向则分别为 0、1。在 46 帧选中区域的 Quad 样本上，PCA、Qwen 重锚定的中心误差中位数分别为 **1.33 和 0.51 米**，原 Qwen 窗口中位深度为 **0.61 米**。在 13 帧细长真框且区域点半数以上来自目标框的事后子集，PCA / Qwen 轴向误差分别为 **54.74° / 16.48°**，只换角度仍损失一条 Acc@50。这些对照支持把朝向与可见面锚定一起检查，尚未分开估计重锚定中中心和尺寸的各自贡献。[朝向配对](results/orientation.csv) · [逐帧几何误差](results/rows.csv)

横向协方差归一化特征值间隔与扰动后 PCA 的稳定度均有一定排序信息。比较同录制、IoU 优势相反的样本对，Validation 的 AUC 为 **0.607 / 0.565**，Drone/Quad 隔离扩展为 **0.637 / 0.664**。较大的方位覆盖分别为 0.430 / 0.408，方向与预设的单调假设不符。录制隔离的 Quad 内，间隔和稳定度只有 0.556 / 0.582，且实际任务收益依赖是否重锚定。这一轮保持固定 PCA，未从这些观测中选阈值或构造朝向选择器。[观测量排序审计](results/observability.csv)

## 物理区域覆盖与独立留出回波

固定同一个完整树节点和补全规则，只改变用于测量的点集。普通 Validation 共有 235 帧中央窗也足以拟合。该子集的三平台等权 Acc@50 为中央半窗 **22.29%**，完整二维窗 **32.79%**，整个物理区域 **34.46%**。同一批帧的点数中位数为 54、122、154。主要跨度出现在从中央窗扩到完整目标窗，窗外区域点的增量更小，隔离录制 Quad 的窗外点使这一口径下的 Acc@50 从 8.70% 降到 6.52%。这些是固定节点的覆盖对照，允许完整树在构建中读取全帧。[同节点点集覆盖](results/support_coverage.csv)

独立留出试验重新建拟合侧的树和地面，在原始索引上检查 **3,042,501 个留出抽样项，零个进入拟合树**。同一种补框规则的同点数对照以全体样本为分母，拟合失败时共同回退。普通 Validation 中，正确区域相对同窗同点数错配将 Acc@50 从 **11.46% 提到 19.10%**，mIoU 从 **18.49% 提到 26.48%**。隔离扩展分别为 **3.91% 到 5.47%**、**14.56% 到 17.54%**。普通 Validation 的 17,565 条两框共同击中、事后确认落在目标框范围的留出射线，首面光学深度 MAE 从 **0.928 米降至 0.264 米**。在全部窗内留出射线上重复计算，共同击中项的 MAE 从 1.105 降到 0.583 米。射线指标按回波汇总，Waymo 的回波数量占比高。各平台覆盖、漏击和共同射线数全部单列。[任务控制](results/paired.csv) · [逐平台留出首面](results/surface.csv) · [原始索引隔离核验](results/score_receipt.json)

## 决策与复现

主研究候选继续使用原 Qwen 选区、PCA 和可见面补全。Quad 新录制显示的首要具体问题是区域局部几何如何决定完整框的锚定，本轮的轴向可靠性指标不足以选择跨平台阈值。当前实验只评估语言指定的单对象 3D 框。后续与对象级空间状态和关系推理的联系仍待实测。[研究决策](DECISION.json)

完整本地复跑按顺序执行 `cohort.py`、`run_qwen.py <Qwen资产目录>`、`predict.py audit`、`predict.py run`、`replay.py`、`score_confirmation.py`。Qwen 使用原独立 MLLM 环境，3EED v3 和几何评分使用原项目环境。两套权重和关键代码哈希见锁。Qwen 的 832 条生成耗时 508.5 秒，v3 的 832 条方向推理耗时 138.9 秒，几何预测耗时 25.0 秒。所有预测封存后评分，修复了一处目标框尺寸切片的诊断代码，原预测哈希保持一致。v3 的 576 条 Validation 重跑与已封存 IoU 一一对齐，最大差 6.66×10⁻¹⁶。标准库入口 `python recount.py` 可在公开目录独立复算全体任务和配对结果，最大差 1.07×10⁻¹⁴ pp。[代码及权重锁](METHOD_LOCK.json) · [推理封存](results/prediction_seal.json) · [独立复算](results/recount.json)
