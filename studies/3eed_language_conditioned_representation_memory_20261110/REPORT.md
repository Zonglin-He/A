# R64：语言条件化表示修正记忆

**本轮不采纳该记忆配方。三种顺序未同时满足“超过 R59，并超过打乱键值对应”的预定条件；停止本配方，不扩大记忆或继续调系数挽救。**

## 实际执行

Waymo-only epoch100、历史已暴露 DEV336（Drone168＋Quad168）、ABC 采样、原始256个最终框、R57候选传输及UNKNOWN处理全部固定。三种顺序各自初始化，平台间清空。每条输入先输出，再写入；只检索过去输入，物理帧重复也排除。不访问 FINAL384、全量5912或原始媒体，不重训source，不运行新decoder/encoder推理。

记忆键是冻结source的64维候选方向和主体／上下文token均值；上下文排除人工追加的sentinel。值为同一候选的R59融合方向减source方向。它不是目标标签，不使用source第一名作为正例，不把其余query标负。只写三采样几何支持及方向相容的修正，以支持强度选最多16条；框重叠与特征共同去重仅压缩重复假设，不声明实例身份真值。

当前R59方向加上检索到的加权历史修正（alpha0.5），再走真实归一化、文字log-odds与固定ABC传输读出。1024条FIFO、top8、beta5和所有阈值在任务评分前锁定，未依据结果更改。每个输入的写入来自原始冻结source，不把已修改结果递归写回。

## 机制与结论边界

- original：记忆相对R59 +0.021810 pp；相对打乱值 -0.122319 pp；相对去显式文字条件 -0.004387 pp。
- hash20261110：记忆相对R59 +0.034164 pp；相对打乱值 +0.026106 pp；相对去显式文字条件 +0.003629 pp。
- hash20261111：记忆相对R59 +0.031191 pp；相对打乱值 +0.031191 pp；相对去显式文字条件 +0.003779 pp。

独立审计确认三顺序共993次输入实际获得历史修正，记忆与打乱控制最终query不同39次。因此必须由定位指标而不是缓存覆盖或程序可运行决定是否采用。检索相近和跨采样稳定不保证修正可跨物体／描述迁移；本轮测的是这个具体迁移假说，不能据此否定所有记忆TTA。

若当前修正没有超过同信息R59，不再用增大容量、寻找更好顺序或调alpha来保住算法名称。保留R59直接融合为内部表示参照；跨输入复用需要新的任务相关、可验证条件或训练准备，本轮没有建立该条件。没有访问FINAL来确认或挽救。

全部五个场景、三个顺序和所有方法见results/ALL_ORDER_SCENE_ROWS.csv；每输入过程计数见results/ALL_STREAM_PROCESS_SCALARS.csv。场景内观测相关，不把336帧当336个独立场景，不对只有两个Drone／三个Quad场景作稳健总体保证。

## 验证、成本和保留记录

冻结缓存R59桥接误差为0。独立程序未导入R64生产者，重建336条表示、文本键和支持门，复核3024个记忆读出及672个R58在线更新（包括Adam状态、教师状态、停止梯度目标和所有回溯尝试）；全部最终Top1一致。最大概率差0。11,088个表格任务值通过一次封存后的旧候选IoU查表，无新原始GT或几何评分调用；独立平台、场景、全体和负比较核算通过，保留12167条有向负比较。

CPU缓存准备27.64s，完整三顺序正式执行（含新顺序R58对照）198.16s，独立复核200.12s，峰值缓存CPU进程1.225GiB。主记忆没有反向传播、权重编辑或新增模型；不能把缓存耗时冒充完整3EED端到端推理成本。

封存前工程修正仅涉及trace集合构造、统计名称和方法排序；正式预测未重跑。正式初版12条R58 source状态标志有误，已按原状态或权重哈希修正为第二版，所有预测与过程文件字节不变、第一版保留。补充历史向量审计最初误要求旧ABC概率逐位相同；检查发现最大差4.49e-7，但全部336条Top1和任务值相同。改为如实报告历史ABC浮点漂移并要求Top1一致；source与R59仍逐位一致，R64自身独立重放差为0。该失败代码与记录保留，没有改预测或R64数值审计容差。任务GT只参与最后查表和开发结果评估，没有用于检索、写入、顺序、停止或参数选择。

## 文献关系与可复现入口

自有实现见own_code/research/round64/，其中memory64.py定义检索与写入，run64.py定义顺序与读出，audit64.py提供独立复核。依赖的历史自有R59/62读出与R58对照代码分别保存在原study；私有表示、原始文字／ID／媒体／坐标和权重均不发布。协议参数见protocol/FIXED_CONFIGURATION.json；所有匿名逐条任务值和有向负比较完整保留。
