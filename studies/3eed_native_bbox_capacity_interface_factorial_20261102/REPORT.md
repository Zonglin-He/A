# R45：固定 3B/7B × point/bbox 接口诊断

本轮裁决：停止当前固定 7B bbox 主配置，不接 TTA、不扩大确认集。主指标为预登记的 bbox-center；其平衡 mIoU 为 20.551200%，低于旧 G 的 24.727373%。预登记的 rectIoU 次配置也低于旧 G，结果全部保留。资源停止针对本固定配置，不能解释为所有 7B 或原生定位接口无效。

## 协议与比较边界

使用已暴露的 A208（Drone/Quad 各104），复用 R42 同一已校验官方 7B 模型、全场景图像、完整文字与原图缩放/处理器设置。只把固定输出接口由 point 换成 bbox：208 次新的单次贪心生成，预检两条复用正式输出；无新训练、优化器或目标标签反馈。17个旧控制逐位保留，加4个新 bbox 读出，共21臂。3D候选框和候选代表规则冻结，bbox只提供二维实例关联，不直接预测或改写三维框。

主读出以 bbox 中心查询原实例 mask；次读出以原 bbox 与全部 detector rectangles 的标准矩形 IoU 做唯一正最大匹配。均先匹配二维实例，再检查原三维组，不能跳过空组去找第二名。分别保留 full mapping 与旧 subset 对照。没有把主配置的资源停止改成整个接口家族的科学否定，也没有按结果把次配置换成主配置。

point/ bbox 使用不同的固定 prompt、schema 和下游关联，因子解释是整个固定接口流水线的差异；不能当成只改变一个模型内部能力。3B/7B 是独立预训练权重，不能将容量差解释为纯参数数量因果。

## 覆盖、格式与所有负例

严格解析结果为56 parsed、115 invalid_box、20显式 null、17 parse_failure。invalid_box 原样拒绝，不裁剪、不交换坐标、不换单位，不按 GT 修改输出；null 和格式错误均保留并回到 frozen source。bbox-center fullmap 映射46条（Drone18/Quad28），rectIoU fullmap53条（20/33）；旧 subset 分别21和24条。覆盖恢复不等于语义正确。最大 IoU mask 对应空三维组的3次事件也保留，未以第二名救回。

完整4368个任务 IoU 与7770条有序负比较公开导出，3536个旧控制任务值精确复现。负比较是同一批208观测在不同臂/参照之间的重复比较，不能当作7770个独立样本。所有 unknown、invalid、null、格式失败、恶化和原 source 误差均保留。
