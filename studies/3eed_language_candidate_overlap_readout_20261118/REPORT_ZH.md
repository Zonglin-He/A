# R158　重做文字驱动的 A256 第一名选择

**工作版本采用完整描述下的候选分布，再选择与高概率候选总体重叠最大的原始框。** 在六个迁移方向的 1,798 条普通开发记录上，相同 A/B 信息、相同 PCA 朝向下，mIoU 从 16.0149% 升至 16.3212%，Acc@50 从 9.2349% 升至 10.2734%。该规则随后固定，在点云和图像内容均与本批 A、B 不重叠的另外 5,942 条记录上，单独供给主帧 A，mIoU 从 12.5299% 升至 12.9710%。两批分别计分。历史上目标域完整验证范围已有曝光。

## 改动与前向路径

旧程序用完整句子条件化 3EED，再以词表识别的第一个名词为基础读出，并利用已训练的主体、参照物和局部竞争残差打分。单个分数最高的 query 决定输出。R158 的第一版让独立编码的主体短语和参照物短语在相同 256 个物理锚点上重放六层 decoder。完整句子的字面主体跨度、主帧相机中明确的方位区间、所有候选上的参照物边缘化和 B 的逐框支持率都参与比较。未解析、无相机方位、无有效关联分别有中性处理。这个设计借鉴按实体与关系分步执行的思想，沿用仓库的文字解析、冻结特征和标定。[NS3D 原文](https://openaccess.thecvf.com/content/CVPR2023/papers/Hsu_NS3D_Neuro-Symbolic_Grounding_of_3D_Objects_and_Relations_CVPR_2023_paper.pdf) · [NS3D 官方实现](https://github.com/joyhsu0504/NS3D)

第一版退化后，只做了一次已登记的修订，取消独立短语投票，合并完整句子在主体跨度上的匹配与原有学习式竞争输出。修订仍未达到同信息简单读出。工作入口取两个主要实验都比较过的简单规则，沿用有判别作用的完整句子分数。这个选择发生在开发数据上，附加 A-only 范围的选择和方法则在附加评分前固定。[原始设计](config/DESIGN_LOCK.json) · [修订登记](config/REVISION_LOCK.json) · [工作版本与扩展协议](config/TRANSFER_CHECK_LOCK.json)

令 p 为冻结全句竞争模块在 A256 上的分布，K 为这些轴对齐候选两两之间的三维 IoU，K 对角线为一。每个候选的重复程度 d 为对应一行 K 平方之和。将 p 除以 d 并重新归一化得到 q，选择使 Kq 最大的原始候选。q 是推断权重，其真实性和校准度未单独验证。减轻重复框堆积带来的多次投票后，相近候选的证据可以支持一个共同代表框。最后对这个已选候选沿用同一份主帧采样点做 PCA。单帧用 A 的完整句子分布，双帧用配准后的完整句子分布，两者执行相同的决定。因此缺 B 时同样可以改选。工作读出新增一个 256 × 256 的几何矩阵及一次矩阵向量乘法，额外神经网络前向为零；原始三个源模型和全部框参数保持为同一次实验的输入。对照研究中的独立短语重编码才需要额外前向。全 1,798 条真实前向接口逐条与封存选择相符，原竞争概率的最大重放误差为零。[工作入口](own_code/research/round158/grounding158.py) · [审计](results/working_AUDIT.json)

## 错误定位与机制边界

- 第一版能抽取主体的有 1,678 条，可执行带明确方向的参照关系有 620 条，捕捉到明确画面方位的有 302 条。移除独立主体短语票提高了 0.9586 pp。单独短语能表达类别或属性，却常丢失原句区分邻近候选所需的条件。这里测得的是该投票设计的后果。
- 第一版正确参照路径 15.3470%，置换候选与参照证据后 15.4777%；这一比较不足以支持新参照路径。第二版完整版 16.2771%，其 B 错配控制 16.3401%。两项均保留在结果中。第二版中仅在完整竞争证据上加画面位置比工作规则多 0.0362 pp；未为这个开发消融再选权重或单独启用上线。
- 工作版本改变了 1,116 个 query。新旧框部分重叠且 IoU 小于 0.5 的 242 条贡献 +0.2811 pp，框间 IoU 至少 0.5 的 727 条贡献 +0.1212 pp，框完全不相交的 147 条贡献 −0.0960 pp。后者 41 条改善、43 条恶化，其余真实 IoU 相同。框间重叠只说明空间位置接近，无法替代实例身份核验。当前证据支持改善附近竞争框的选择；语言在相互分离的物体间辨认正确实例，仍有明显空间。正负最大记录均按匿名序号和原样本权重保留。[贡献核对](results/SCALAR_AUDIT.json)

## 另外 5,942 条的固定规则复核

**采纳决定。** 采用重叠读出作为新的无更新研究基线。冻结分布与直接重排作为后续 TTA 必须超过的同信息对照。两个完整的新语义方案保留作负结果，分离物体之间的身份纠错仍未得到稳定证明。
