# 候选验证与物理锚定实验

五项实验。模型仅冻结推理。使用原 576 条面板的已封存候选、正式框和尺寸对照。固定规则在本轮评分前执行，验证标签只在输出封存后开启。

1. Object 对至少有两个冻结候选的查询做两种各一次的 Qwen3-VL-4B-Instruct 核验。相同输入画布尺寸、视觉 token 限额、解码上限、batch，将直接重复定位投影回同一候选池，比较编号裁剪＋原图位置＋真实 LiDAR 回波的对比式验证。直接定位结果单列。标识随机但可复现。解析失败、无匹配、其余单候选均保留原正式选择。报告全样本、可比较子集、原明确错指子集和最终救回/误改。
2. Correction 使用原先已封存的 2×3 候选池。对实际替换做配对收益/退化、录制、中心／朝向、Ray/Coverage/Projection 和独立留出的射线诊断。评估才读标注。
3. Conservative Correction 默认正式框。以原 Selection 射线评估实际回波深度的明显违背，并对候选作不退化检查。仅当另外两个不相交 Audit 回波子集独立重复支持时接受。三组各须至少 8 条，原框每组至少 3 条强冲突，冲突率至少 25%。候选每组修复至少 2 条、下降至少 0.10，新增冲突不超过每组 1 条。真实回波与相机射线代理的首交误差超过 0.25 m（行人、骑行者）或 0.45 m（车辆）计强冲突，几何缺失无修改。不得根据验证结果调门槛。
4. Fitting 操纵物理锚定质量。同一批有正式锚、正确残差和打乱对照的查询，用完全相同的刚体变换扰动已封存的两个尺寸输出。横向/纵向平移四方向、朝向正反号均匀平均。平移幅度固定为 0、0.3、0.6、1.2 m，yaw 固定为 0、15、30 度。另用离线真实锚质量分层；对两臂共同应用扰动不重选尺寸或姿态。物理约束只对原预测成立。主比较为未扰动与预设 0.6 m / 15 度条件的配对交互。
5. 独立确认优先获取可公开取得、此前未参与本项目的 RGB/LiDAR/标定/三维标签数据。冻结已有公式和两条正式几何规则。如独立数据缺乏自然指代或原平台分布，必须据实报告测试的范围。任何旧录制的哈希留出只能作为录制分离复测，不能称未曝光确认。

数据与预测账本、各条读出成本、按录制配对区间以及失败样本均保留。
