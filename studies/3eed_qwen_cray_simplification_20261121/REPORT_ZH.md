# C_ray 正式推理简化与机动车两尺度对照

**精简四尺度版已通过全量复核，三平台等权 Acc@50 为 34.4089%。** 相对原双标签 C_ray 救回一条、误改零条。只给机动车分支保留细、粗两个尺度后，Acc@50 为 32.5869%，相对精简四尺度下降 1.8220 个百分点。行人和骑行者的成功集合在三组间完全相同。[全量指标](results/metrics.csv) · [配对计数](results/paired.csv)

## 正式推理入口

正式入口只读取已有 Qwen 2D 回答的类别。道路机动车且具备至少 5 条独立选择回波时，用 PCA 和 Qwen 两种朝向分别重锚定成框，并选择射线误差较小者。其余情况走四尺度 H。H 无法出框时沿用原 A 回退。Qwen 3D 回答提供框尺寸和朝向先验。[正式实现](cray_simple.py) · [方法锁](METHOD_LOCK.json)

1. **选区只比较 $h_i^2/e_i$。** $h_i$ 和 $e_i$ 分别是区域归属的窗内回波数与全图回波数。约去所有候选共享的窗内总数。中心半窗支持阈值仍为 5。
2. **H 和双姿态共用一条锚定式。** 在朝向对应的局部轴上，令 $m$ 为观测区间中点，$s$ 为跨度，$D$ 为输出尺寸，$f$ 为由观察原点所在一侧确定的符号。水平中心为 $m+f(D-s)/2$，竖直中心为下边界加半高。H 用尺寸先验和实测跨度的较大值。两个姿态框使用相同 Qwen 尺寸，各自按新轴重新估计中心。
3. **射线比较直接使用截断误差之和。** 在同一组选择回波上求 $\sum_p\min(|z_{\rm near}(B,p)-z(p)|,\delta)$。未击中代价为 $\delta$。将原归一化比较容差按回波数和截断尺度换算到米，并列时优先 PCA。
4. **正式入口按实际路由计算。** 2D 类别不满足时跳过隔离拟合。双姿态成功时直接返回该框。L7、固定 PCA 对照读出和错配深度等对照不在正式入口内执行。

两尺度实验只把机动车隔离拟合侧的尺度索引由 $(0,2,5,7)$ 改为 $(0,7)$，使用原八分位网格上的最细和最粗阈值。H 两组均使用四尺度。同一份 Qwen 回答、点云采样、回波划分、尺寸先验、锚定和射线评分用于比较。[协议](PROTOCOL.json)

## 回放与复现

- 9,310 条精简四尺度输出全部与按 2D 类别重新组合的历史 C_ray／H 框核对一致。5,510 条逐坐标相等，最大坐标差为 $1.42\times10^{-14}$。两个 IoU 阈值的通过集合逐行验证。新增启用双姿态的 3 条均来自 2D 类别简化。
- 对应清单覆盖 7,221 个物理时刻与 98 段录制。2,436 条 2D 类别门控未通过的描述在两尺度臂复用同一个正式回退输出，全部计入分母。所有预测封存后使用两套原有 IoU 计算交叉评分，再从匿名行独立重算指标和配对计数。
- 既有普通 Validation 已用于项目开发。运行复用锁定 Qwen 回答，无新增调用、训练或 FINAL 访问。所有负例和回退均保留。[预测封存](results/prediction_seal.json) · [独立复算](results/verification.json) · [Waymo 匿名逐条](results/rows_waymo.csv.gz) · [Drone 匿名逐条](results/rows_drone.csv.gz) · [Quad 匿名逐条](results/rows_quad.csv.gz)

正式推理使用 <code>cray_simple.predict(frame, replies)</code> 的默认配置。拥有原始普通数据和历史封存的工作区可用 <code>evaluate.py predict</code> 成框、<code>evaluate.py score</code> 评分。公开匿名结果可运行 <code>python3 verify.py</code> 复算。**登记精简四尺度为主方法，细粗两尺度作为测量对照。** [决策](DECISION.json)
