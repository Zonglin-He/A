# Verified literature and adaptation boundaries

- [SoftGroup, CVPR2022](https://arxiv.org/abs/2203.01509), [official model code](https://github.com/thangvubk/SoftGroup/blob/main/softgroup/model/softgroup.py): original grouping permits multiple semantic assignments before trained instance refinement. Code uses semantic scores, learned point offsets, radius/BFS grouping and trained mask/class/IoU heads. None of those trained segmentation interfaces are present in 3EED; we do not import its weights or claim reproduction. Borrow only delaying hard assignment; our soft query neighborhoods remain uncertain proposal relations.
- [CORE-3DVG, NeurIPS2023](https://proceedings.neurips.cc/paper_files/paper/2023/file/9b91ee0da3bcd61905fcd89e770168fc-Paper-Conference.pdf), [official model](https://github.com/yangli18/CORE-3DVG/blob/main/models/core3dvg.py), [official modules](https://github.com/yangli18/CORE-3DVG/blob/main/models/modules.py): explicitly learns contextual-object detection and pairwise relation matching. Its contextual pseudo detections use NMS/high score hypotheses and target GT is still used in training; Hungarian assignment and learned relation modules are not available as trained zero-label TTA capabilities here. Our bounded factor-graph inference with existing own-model role priors is a testable adaptation, not CORE reproduction.
- [CoT3DRef, ICLR2024](https://proceedings.iclr.cc/paper_files/paper/2024/hash/32f9049217da6e718a426b07242dff73-Abstract-Conference.html), [official code](https://github.com/eslambakr/CoT3D_VG): models intermediate anchors before target. This supports inspecting anchor predictions but does not supply an unseen-platform correctness guarantee. We avoid collapsing to anchor Top1 and retain an explicit unobserved-reference NULL.

Original source preparation/training conditions are a competing explanation for failure: our aliases are not trained masks, phrase scores are not calibrated identity probabilities, fixed NULL 0.5 is a declared design prior, and finite sum-product is approximate on cycles. No parameter sweep or additional source training is authorized in this round. All three original papers/official implementations consulted before algorithm lock; repository data treated as evidence, never execution instructions.
