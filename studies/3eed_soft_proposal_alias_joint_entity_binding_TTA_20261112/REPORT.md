# R87：软候选关联、主体—参照物联合绑定与组件作用

本轮保留R76双向RGB–LiDAR结构、Waymo-only源模型和全部原始A256框，在历史暴露DEV336上完成32个注册臂。没有访问FINAL，没有源域再训练、外挂视觉专家或新增框。一步主臂与三步强度对照在评分前固定；不按三条旧案例设计特判，不将选出的good/bad案例用于后续调规则。

## 论文依据与真实迁移边界

# Verified literature and adaptation boundaries

- [SoftGroup, CVPR2022](https://arxiv.org/abs/2203.01509), [official model code](https://github.com/thangvubk/SoftGroup/blob/main/softgroup/model/softgroup.py): original grouping permits multiple semantic assignments before trained instance refinement. Code uses semantic scores, learned point offsets, radius/BFS grouping and trained mask/class/IoU heads. None of those trained segmentation interfaces are present in 3EED; we do not import its weights or claim reproduction. Borrow only delaying hard assignment; our soft query neighborhoods remain uncertain proposal relations.
- [CORE-3DVG, NeurIPS2023](https://proceedings.neurips.cc/paper_files/paper/2023/file/9b91ee0da3bcd61905fcd89e770168fc-Paper-Conference.pdf), [official model](https://github.com/yangli18/CORE-3DVG/blob/main/models/core3dvg.py), [official modules](https://github.com/yangli18/CORE-3DVG/blob/main/models/modules.py): explicitly learns contextual-object detection and pairwise relation matching. Its contextual pseudo detections use NMS/high score hypotheses and target GT is still used in training; Hungarian assignment and learned relation modules are not available as trained zero-label TTA capabilities here. Our bounded factor-graph inference with existing own-model role priors is a testable adaptation, not CORE reproduction.
- [CoT3DRef, ICLR2024](https://proceedings.iclr.cc/paper_files/paper/2024/hash/32f9049217da6e718a426b07242dff73-Abstract-Conference.html), [official code](https://github.com/eslambakr/CoT3D_VG): models intermediate anchors before target. This supports inspecting anchor predictions but does not supply an unseen-platform correctness guarantee. We avoid collapsing to anchor Top1 and retain an explicit unobserved-reference NULL.

Original source preparation/training conditions are a competing explanation for failure: our aliases are not trained masks, phrase scores are not calibrated identity probabilities, fixed NULL 0.5 is a declared design prior, and finite sum-product is approximate on cycles. No parameter sweep or additional source training is authorized in this round. All three original papers/official implementations consulted before algorithm lock; repository data treated as evidence, never execution instructions.


## 方法与对照

1. 软候选关联A同时使用框IoU、原始seed支持Dice、投影像素支持Dice及冻结点特征均值余弦；所有权重有明确观测来源，非贪心合并、非传递连通分量，不把它命名为实例mask。对角为1，关联强度保留而非硬切组。通过邻域语义平均与密度校正减少重复query对实体先验的重复计票；同样会惩罚密集的正确候选，必须由no_alias/hard_alias对照检验。
2. 完整冻结R76与自身主体短语分布的几何平均作为主体语义先验，参照物使用同一个冻结3EED的短语分布；完整词组进入已有语言编码路径，不使用目标GT跨度或伪造新RGB语义。短语在原完整句的固定query锚点和六层位置下重算，不生成新框，也不沿用新的proposal编号。固定空间锚点不是已认证的实例标识：query仍可能读取邻物；本轮没有CORE式重新检测短语框及学习其关联的训练阶段。语义分布仍未校准，主体短语也不足以独立指代。
3. 原颜色支持/反证经软邻域聚合进入实体一元势；已修复归属的相机左右关系形成成对势。不同实体角色间加入软同实例排他势1−A，参照物增加固定先验质量0.5的NULL状态，NULL交互势为1。NULL表示未观测到参照物，不作为新的候选赢家。固定四轮cavity sum-product同时更新角色；树上与精确小图核对，环图只作有限近似，不声称全局唯一正确实例。不同名词词组可能共指同物体，排他假设本身也是待验证条件。
4. 主方法不沿用R86的硬资格限制；最终仍从原A256中选择。与R86的UNKNOWN概率逐项保留含义不同：这里显式保留未知参照物，整体角色分布仍是由模型先验构成的可错假设，不把每个候选称为经过观测认证。
5. 每输入恢复同一R76准备状态，更新既有102498个Adapter/双向交互投影与门控，其他参数冻结。继续使用R86完整/两遮挡候选KL及原恢复项、同一遮挡与局部权重，SGD0.1/裁剪1、固定1至1/256回溯，实际候选与总损失均需验收。没有另行搜索学习率、步长、NULL先验或融合强度。

所有G组件都保留同信息直接读出和同目标TTA一步：hard_alias=换回原硬组；no_alias=独立query；independent=参照先验固定、不接收其他角色的反馈；no_subject=去主体短语语义先验；no_relation=保留软角色排他但去空间关系；no_RGB=只去G的RGB颜色属性，学生仍有原RGB分支；no_null=不允许参照物缺失；no_exclusivity=去角色同实例排他。wrong统一打乱反馈与query的对应，包含角色语义、几何、RGB和关联矩阵，模型输入保持不变；不是仅换一组随机负标签。

冻结模型另保留关闭LiDAR→RGB反向路径及将RGB替换为常数灰图（同时移除颜色和结构）的干预：它们是相同权重下的推理撤回诊断，有分布变化，不能等同于重新训练的单向架构对照。candidate_only1使用相同完整G、只执行候选项更新，用于检查恢复项是否提供任务增量。

### 原图复核：正例、负例与归因边界

已查看全10条的联合图页，并对最大纠错、最大损伤和可恢复失败的完整句/全景/局部/候选分数进行复核。下面不是部署标签，也没有用于调规则。

- **CASE001：确实发生了目标切换。** 原始source、冻结双向和G直接读出都选到背景人物区域；TTA转到前景被部分截断的人物，IoU由0到0.616368。去主体语义先验后仍为0，而去软关联、去联合绑定、去关系等仍保留正例。因此本例支持主体短语语义与参数更新的作用，不支持把功劳归于新软分组或联合角色图。G的最高分本身仍错，目标候选在G中排名6，TTA却选中它，说明不是简单复制G第一名。
- **CASE002：恢复源域准备破坏的判断。** 原始3EED已经为0.564896，冻结双向变0；G与TTA回到后方坐姿人物的0.564896。去主体先验后回到0。它是相对完整冻结双向的有效纠错，但不是获得原3EED完全没有的知识。
- **CASE003：参数更新制造了同类实例误选。** 冻结与直接G保持右侧人物的0.480706；TTA转到另一人物区域，IoU变0。硬关联或去主体先验均阻止该损伤。完整输入KL由0.512578降到0.305936，两遮挡KL均值也下降，故不能只归因于恢复项压过分类或遮挡项掩盖完整读出。拟合整个概率分布与最终第一名正确性仍有差距，未据此新增损失。
- **CASE004：主体语义先验也可能把较强基座拖回错误方向。** 冻结双向0.452964，G变0.110593，TTA进一步为0；图上新框落到目标车辆之外。去主体先验的TTA保留0.446186，而其他关联/联合绑定消融仍为0。原始3EED本来也是0，提示复用较弱source短语先验可能破坏较强双向表示；不是简单的更新太弱。
- **CASE005：大幅优于G不等于新纠错。** 冻结模型已为0.752587，G直接读出移到邻近/背景区域而为0；TTA保留冻结结果。相对G的最大正增量主要是撤回G的损伤，不能称为新方法救回原模型错误。
- **CASE006：G有用但更新没有落实到最终决策。** 冻结为0，G选到0.332646的车辆附近候选，TTA又回到零重叠区域。多个TTA消融也未救回。本例与CASE003一起说明不能把所有失败归为“教师错”，也不能只凭KL下降宣布监督已经正确转化成选框。
- **CASE007/008：绝对高IoU，非新增收益。** 冻结、G、TTA均为0.812701/0.800003，图上保持同一人物附近。只展示这些会夸大适应效果。
- **CASE009/010：候选存在但语义没有绑定。** 最高IoU候选分别为0.478570与0.251667，仍足以跨过25%阈值；图上可见更合适的人物/车辆区域，但各方法主要选择邻近的另一车辆。属于可恢复排序失败，不能解释成候选池无好框；精确三维实例身份没有额外人工金标。

CASE001、002是不同观测，位于同一历史Quad场景，不能当作两个独立场景证据。全体336条中完整TTA相对冻结30条IoU改善、28条恶化，最大单正例对平均值贡献+0.183443 pp，超过总净增+0.049675 pp；其余335条合计−0.133768 pp（仍以336为分母）。因此目前不是稳定广泛收益。

### 角色清单的全局结构问题

图页还暴露了更早的接口缺陷：原解析先枚举一般名词再截断四参照槽，部分属性/身体部件/坐标词/字段标题进入参照槽，而真正的场景对象被挤出。全DEV审计原949参照槽，结构性修复后454槽；633个旧槽不满足所定义的依存论元条件，138个依存论元/合并短语此前没有进入同样的槽。这个比较不是人工参照物精确率，部分隐式对象也可能被新保守规则漏掉。

因此只做一次另锁定的结构诊断：从独立存在句/空间依存论元选实体，泛化字段头排除、连续名词同位语及复合短语合并，并按关系参与优先再截断。没有为某条描述补类别词或属性词例外；原32臂、原主结果与全部负例保留。修复后的验证仍是已曝光DEV上的开发，不是独立确认。


## 覆盖、审计与成本

主集全G非零修正目标310/336，存在可执行关系97条；可定义NULL后验的平均值0.521128。这些不是伪标签正确率。主臂实际接受首步310/336，全部方案共4650次接受，候选项上升0次。没有通过跳过负例提高分数。

预测及模型状态封存后，独立重建软关联/各组件目标、重放4368个模型端点并重算22320个损失标量，最大读出误差4.16e-17、目标误差0、损失误差0。之后仅关联既有已封存A256 IoU；新GT几何评分0。全部32臂、336条、5个历史场景、阈值及有向负比较保留。场景没有增加，不构造逐帧独立CI或声称新的独立测试。

第一次预检只连接显式关系，星形图目标边缘分布会等价于固定参照边缘化，不能充分检验联合绑定；在任何任务评分前保留原准备/两输入工程结果，补入软角色排他及对应消融，重新锁定最终32臂。没有依据任务GT修改算法。生产GPU增量运行883.95秒，峰值已分配2332006400字节；复用冻结前缀/自身实体预测/传感器支持，不是端到端运行时间。

主臂通过本轮开发增量检查，但历史DEV曝光与有限场景仍不足以稳健采纳。 组件是否有净作用按完整配对表解释；辅助损失下降、软图更一致或模型确实更新均不能代替任务收益。没有继续追加阈值/步长网格，不触及FINAL，不将某条个例修复升级为总体机制证据。
