# R13：分开验证完整文字关联与局部正观测几何反馈

本轮已完成真实Waymo-only→Drone/Quad九臂实验。**完整文字读出能救回部分源候选选择；撤去可见面等式后，Quad的几何直接修框出现一致的正增量。当前G仍未在两平台同时满足监督效用条件，因此不采用当前完整管线，未组合A+B，未执行神经回归层TTA。** 不能把这些直接输出收益称为参数适应收益。

必须明确：R7/R8已经对全部5912条目标VAL记录运行过模型并完成任务评分。这里的“new_content108”仅指与注册的近期914组内容不重合，**不是从未见过的输入、标签或场景，也不是独立保留集确认**。本轮完整预测先封存再当前评分，保障当前配置的探索性配对测量；不消除历史研究暴露。Drone仅一个场景不能提供场景层不确定性，Quad三场景也不能支持总体泛化结论。没有把目录前后顺序、发布pose或timestamp当认证连续时序。

## 2. A：只改变完整文字关联，不修框

使用本地冻结Qwen2.5-VL-3B-Instruct，全部11个运行文件含两份safetensors加载前实际重哈希，local-only、safe tensors、严格加载、BF16/SDPA、eval/inference，无远程代码。模型输入是原图及同图编号候选框，不看到3D query、q0、源分数或COCO类别置信度。候选由冻结整图mask前端生成，保留全部实例，不按源预测裁剪或截取有利候选。

同一图使用哈希编号及反序编号。完整原文、首个既有词表名词、固定同场景不同描述各两次调用。模型只可返回候选ID或UNKNOWN，最多8个新token，不修复回答、不截断文字。主读出要求两编号指向同一物理mask；不同描述不保证指向不同目标，错配描述不是自动负标签。

3D对应独立于VLM回答：原256框按原文本分数稳定排序，以AABB IoU≥.5贪心去重；代表仍为原query框，不融合。mask映射要求投影IoU≥.1、至少3个最近相机深度可见点同时位于mask和3D框内，多组时最高与次高差≥.05。不能唯一映射就退回q0。主完整文字、无共识的order0、名词共识和错配文字共识分别保存，**所有A输出均逐bit等于原池中某个候选**。

因此A任务增量说明新的关联/候选读出有价值，但不单独证明文字身份正确：更换原候选也可能更换同一物体的几何假设，2D选择与2D→3D映射仍需区分。两个编号同mask也不是身份真值。

## 3. B：固定q0，不再把可见面设为完整边界

B不使用A结果，保持原q0，按R12的类别族/投影/源ROI唯一兼容规则提取独立mask支持，保留原raw行号，通过相同float32转换与去重映射。Drone的+1.8m仅做一次。多解、无有效支持和无效源框均明确回退。

新G只使用两类单侧不等式：前景点应被框包含；mask前景应被投影框包含。**没有局部平面=框外表面等式、点极值/均值直接替代完整框、PCA、轮廓等式或不具来源的自由空间项。** AABB内部不假定实心占用。

采用固定源先验与有界最小改动，中心位移不超过min(.25源尺寸,.5m)，尺寸只能保持或扩至源值1.2倍。局部正观测没有缩尺寸或完整尺寸上界的依据；这也意味着本版本不能修复所有过大尺寸错误。source满足不等式时精确保留source。六维active只是搜索域，不表示六个几何量均被独立识别。

full/noRGB共用点、mask门控、搜索域、先验与边界，只关闭RGB坐标项；half为精确float32半位移。旧R12等式方法保留为legacy对照，使用同source/mask/raw输入，但旧面门控、有效支持和搜索域也不同，不能解释为单个损失项的严格因果消融。旧8例的legacy输出与原R12单帧输出全部bitexact。

### 5.1 评分后的关联与映射诊断

以下为看完封存正负例后新增的描述性分析，不是原主指标，也未用于修改G、提示词、筛选规则、阈值或采用裁决。新增计划、结构核验、v2实际字段适配及单独计算release均保留。真实数据每容器只有1条ground_info目标记录，目标框为raw9D；其他已标注几何实际位于同一记录的others[].bbox_3d_other，共425条raw7D，others_num全部与长度一致。没有显式实例ID，也不保证完整场景对象清单。不能假造多个顶层ground_info对象或统一9D字段。

目标沿用冻结R5变换；其他raw7D显式按Drone z+1.8/Quad不变后转float32，不补造尾字段。变换后逐元素exact相等去重，在IoU计算前完成，不用IoU聚类GT。固定q0、fullA、nounA三个已有候选，记录其目标IoU、其他标注几何最大IoU及带符号margin=target−other。targetIoU>.25且target−other>.10标目标几何占优；othermaxIoU>.25且other−target>.10标其他已标注几何占优；其余为未确认或NA，不等于错误。诊断的目标IoU与原主评分最大差0，没有按GT另选query。

这些是标注相对的几何代理，不是文字身份正确率。new_00067的source/fullA对目标IoU为.548004/.212028，对其他已标注几何最大IoU均为0；A/B选中同一mask。因此该负例与“同一2D观测映射到更差3D假设”相容，不能说已证改选另一个标注对象，也不能反向证明mask一定是文字真目标。

另外记录冻结COCO预测类别与输入首名词类别族的兼容性，仅作无GT类别addendum。Quad完整文字的44个两编号共识mask中有5个类别预测不兼容；regression_00006的A所选mask预测类别41（滑板），B支持mask预测类别1（人），与图册中关系物/目标主体混淆的观察相符。类别预测可能错误，首名词也不总能正确解析目标主体，因此这不是GT仲裁，也没有据此新增过滤器或重算主成绩。

这些结果提示至少两类待核解释：文字目标与关系物混淆，以及2D选择正确性未知时的3D候选映射/框质量。不能把全部A负增量统一归因于文字理解，也不能把空间占优变化当成完整身份验证。

## 7. 裁决

按预锁规则，A因Quad等场景source比较为负而未通过；B因Drone任务及坐标反馈为负而未通过。当前G不作为两平台统一监督采用，未组合A+B，**未执行回归层TTA**，没有按平台挑最佳臂后拼成绩，也没有评分后调整提示词、阈值、点选择或几何权重。

本轮不是全阴性结果。Quad上“局部观测提供单侧包含约束”比旧表面等式更有依据，并获得39正/2负、三个场景均正及强对照增量；完整文字也救回部分原池候选。这些是值得保留的机制信号。尚未成立的是稳定语义身份/2D→3D关联、Drone反馈效用以及正确完整尺寸识别。不能仅凭当前同输入直接框增益宣称参数更新有额外价值。后续若满足监督前提，仍需用未参与拟合的另一观测及同信息直接迁移对照验证回归头TTA；本轮没有自动排队新的训练或调参。
