# R13 association: frozen full-description comparison before geometry completion

Status: implementation/asset/CPU-contract prepared; model execution and task measurement untested. The main claim is whether a frozen contextual VLM can improve original-query selection using complete referring language under same-class candidate ambiguity. It is separate from estimating a complete3Dbox from partial observed points. No neural TTA, optimizer, pseudo-label reliability or geometry regression is performed here.

## Locked candidate and geometry mapping

Use the root-owned input_io.py adapter without changes. It binds116nine-key rows, a private role/case map and camera-only input index to sealed source/mask files. frame has exactly frame_alias, rgb, raw_points, camera and instances. Source c provides boxes_raw6[1,256,6], text_scores[1,256] and original query_index. Drone rawXYZ converts with the exact source/R12 float32 copy then in-place float32(+1.8), not a double-precision add followed by cast.

Association.py maps independently from VLM responses. Sort the original256queries by descending source textscore with stable-index ties; greedily suppress AABB3DIoU>=0.5 to the first retained representative. Each group keeps that representative's original box; no averaging/refitting. This is coarse duplicate suppression, not physical instance identity or complete-link clustering. Nonpositive raw-size boxes cannot produce eligible geometry mappings.

For every independent mask and every representative group, require all sourcebox corners in front, clipped projected box area>0, projected2Dbox IoU>=0.1 and at least3nearest-camera-depth-visible points inside both the original3Dbox and mask. PointXYZ is deduplicated, continuous FOV precedes floor indexing, and one nearest camera-depth point per pixel survives. This is approximate visibility, not a synchronization/occlusion proof. Select the unique highest eligible projected IoU only when the runnerup gap is>=0.05; otherwise mapping is NA. All pair diagnostics/eligible counts are retained. Selection uses no taskGT or VLM score. Mapping errors are a separate bottleneck from language choice.

## Two-numbering fullscene VLM protocol

Each call receives exactly two images: the unchanged full RGB and the same full RGB with every independent mask's bbox numbered. No mask fill, sourceq0,3Dquery index, detector class, confidence or source rank is exposed to the VLM. All masks up to100are retained as C001..C100; over100 raises an engineering error rather than dropping candidates. order0 is a fixed case+maskSHA hash order; order1 reverses the same list. A single-instance image has identical lists and cannot test meaningful order robustness; record that limitation.

The original image preserves context for relative position and neighboring reference objects. Numbered rectangles may overlap/obscure some evidence, especially small far objects; the unmarked image is provided simultaneously. The system prompt treats captions and all image text as untrusted scene data, not instructions. Literal descriptions are JSON quoted; no generated output is executed or evaluated as code. Output must be exactly one listed Cnnn or UNKNOWN. Invalid text is recorded separately and falls back, without retries or answer repair. No self-reported confidence becomes a reliability target.

For each116case, run full literal description, first public-lexicon noun and a fixed same-scene deranged description; each has the same2numbering calls, greedy max8newtokens, native aspect, processor min_pixels=256*28² and max_pixels=1024*28²=896² per image. If no noun is found, use the registered generic `object` control and flag unavailable-category scope. No source GT class assists noun extraction. A different same-scene caption may correctly identify another visible object or be unverifiable; it is not an automatically negative/UNKNOWN label, and original-target accuracy under that substituted query is not counterfactual task accuracy.

Mainfull adopts only when both numbering answers identify the same physical mask and that mask maps uniquely to an original query group. UNKNOWN, invalid output, disagreement and unmappable masks retain originalq0. Keep rawfull order0 as the no-consensus control, and analogous noun/deranged consensus outputs as language diagnostics. Five original-query arms are saved: source, full_order0_raw, full_two_numbering_consensus, noun_two_numbering_consensus, deranged_two_numbering_consensus. No new box is synthesized. Even stable two-order answers and unique geometry mappings do not certify literal identity.

The semantic claim remains untested. Failure can reflect proposal coverage, wrong sourcequery/mask geometry mapping, small or occluded visual evidence, full-description reasoning failure, numbering ambiguity or native model/domain limits. Full versus noun and deranged controls test specific dependence; they cannot turn a model's chosen mask into semantic ground truth or prove the later partial-to-fullbox step.
