# Evidence acquisition and its limits

[Latte, ECCV 2024](https://arxiv.org/html/2403.06461v2) uses estimated poses and spatial-temporal voxels to retrieve corresponding observations, then evaluates prediction reliability before cross-modal adaptation. It studies semantic segmentation with compatible per-point/per-pixel class predictions and pre-existing modality networks. These conditions do not imply that grounding query IDs or entity identities are shared across frames.

The [official correspondence implementation](https://github.com/AronCao49/Latte/blob/master/latte/models/hr_module.py) explicitly uses scene/scan metadata and relative transforms before voxelizing in a fixed origin. It aggregates class probabilities within corresponding voxels. The inspected code has both mean point entropy and entropy-of-mean alternatives, with the former active in that file; we do not claim an exact implementation transfer or substitute a new entropy objective here. Its pretrained visual networks are not imported.

R106 changes only the observed point evidence. Each additional cloud is registered into canonical A coordinates, encoded with the SAME frozen source PointNet, and its pre-language features are interpolated onto the SAME A seed positions. The radius limit is taken from the actual source model's second abstraction scale, not target labels. Known exact self-correspondences do not need neighboring-point extrapolation. Original RGB, its bidirectional interactions, text roles and A256 remain unchanged. The sampling control reruns the same A cloud with equal16384-point/forward budgets, so mere repeated inference cannot establish the value of actual neighbors.

This is an offline multi-observation prototype, not Latte reproduction or certified causal online TTA. Static near-surface support and low registration residual are not object identity. New voxels can reflect sampling or alignment noise. All task conclusions require the complete fixed cohort and same-information frozen direct controls; fitting or interpolation success alone is insufficient.
