# One plain expert-only spatial interpolator

`pure.py:interpolate(anchor_times, anchor_xyxy, frame_ids)` is the complete estimator: eight raw expert pixel-corner boxes, physical anchor times, and output video frame IDs. Ordinary coordinatewise linear interpolation, nearest endpoint hold, exact eight observed boxes. It imports only NumPy. No Source prediction, shared E correction, feature/mask, prototype, prior/posterior, box transport, candidate selection, DP, log-size interpolation or query language enters it.

The data adapter reads original expert boxes and timestamps by immutable payload/receipt SHA, and generates every physical frame of the original input segment. HC uses [0, frame_count); Vid uses official [start_frame,end_frame). No GT/interval/Source boxes or Full result is read during prediction. Source native interval and Full interval are read only AFTER whole-domain trajectory seal, by the separate scorer. Two evaluation protocols share the exact same pure trajectory: (1) independent Source+expert baseline with original Source interval, (2) explicitly controlled spatial comparison with Full's interval. Protocol2 is not independent expert temporal inference. No new method or optimizer/Source/expert/GPU calls.

Confirmed old boundary coupling: PureLinearFixed generated only on Source's native sample IDs, then the official evaluator densified strictly between the first/last native ID, without extrapolation. Thus nearest-expert tails did not cover the entire input segment. Four metadata-only preflight examples reproduce uncovered final video frames. Also HC negative-coordinate clipping after sparse interpolation and before evaluator densification can differ from evaluating the true piecewise-linear trajectory at every video frame. The new estimator produces the full video trajectory before benchmark clipping. Impact on measured vIoU is measured, not presumed: missing video frames outside a predicted interval do not contribute to that vIoU and may leave it unchanged.

Separate issue: previous PureLinearFixed scores use Full's refined interval by design of the spatial control; these must not be presented as the independent Source+expert baseline.
