# R70: two independent RGB evidence branches

Frozen Waymo-only epoch100, fixed 256 original boxes, historically exposed DEV336 (168 each platform; five scene clusters). No FINAL access, source training, new detector, raw target annotation use, or hyperparameter search.

A uses only frozen pinned CLIP ViT-B/32 plus the existing grounder. Literal subject prefix and complete sentence are separate fixed readouts. All valid projected candidate groups are encoded, with sparse LiDAR visibility/point-support reliability and an explicit projection-only control. Mapped evidence is centered before propagation; unknown candidates receive no visual evidence, rather than a synthetic negative label. Tight/context crop information is identical between direct joint use and the residual score adapter. The adapter learns a stopped tight-crop distribution and evaluates context features; this tests transfer between crop observations, not a new independent scene.

B loads no CLIP or cached external visual output. A tiny random CNN maps real calibrated 16x16 RGB patches to frozen pre-cross-encoder point feature directions. Fit and held seed indices are disjoint. Only held seed features are modified, with 0.2 relative norm cap, then the full frozen encoder/decoder is replayed with original query anchors and positional boxes. Per-input source and adapter reset; no online history. Point targets are nonnegative, so predictor output uses ReLU before normalization (decided before labels). Learned-point alignment cannot create semantic knowledge missing from point targets. Random, mismatched-RGB, point-mean and RGB-neighbor interpolation controls test that competing explanation.

Bounded A 3/16-step and B 3/32-step probes are fixed before any task scoring. No GT-dependent pseudo-label acceptance or per-case selection. Task predictions are sealed and independently audited before joining saved candidate IoUs. All arms and all negative comparisons retained. Adoption depends on full task results against matched direct-use controls, never alignment loss or nonzero gradients alone.
