# 3EED 第四轮：语言条件的目标选择与形状先验保护适应

2026-10-30，Asia/Shanghai。本轮仅3EED，没有重训源模型或恢复已取消的100epoch任务。已完成新研究场景上的错误分解、有限query适应与中心潜变量适应、同信息直接对照、确认、独立评分和固定正负案例。

**判断。** 候选池确实包含一部分被语言读出漏选的目标，且存在明确同类非目标贴合案例。该缺陷构成一个可研究的问题，但本轮没有建立有效TTA方法：512参数Query3的选框与TTAug/直接位置教师完全相同；保持尺寸的3变量中心优化仍损害性能。保留语言条件实例选择为候选研究切入点，不采用当前Q3或G3，不把单个接口阴性上升为所有query/decoder TTA失败。

先锁源/PCA并评分DEV，看到rank-headroom后才锁一套Q/G机制；确认方法和代码固定后才运行确认源前向。确认source/BBS、13适应与6读出文件及诊断/code共981项全部封存并核hash，随后才进行确认数值GT评分。重复source/control不是独立实验。适应器只读独立XYZ/text/calibration/源缓存，不接触GT、全候选IoU或others标注。

## 实验1：是否存在候选已覆盖、首选却错的缺陷

| 主Waymo／固定PCA／IoU>.5 | DEV24 | CONFIRM48 |
|---|---:|---:|
| Top1 recall | 19/24 | 43/48 |
| Top5 recall | 22/24 | 47/48 |
| Top10 recall | 22/24 | 47/48 |
| Top32 recall | 23/24 | 47/48 |
| Top256 recall | 23/24 | 47/48 |

开发与确认都是5个Top1失败中4个在固定候选池可救；确认4个全部在Top5内，只有1例Top256仍未达到>.5。按IoU>.25，确认Top1为45/48，Top5/256为48/48。确认fixed-PCA best256几何oracle均值69.8936%，Frozen60.9030%；该差也包含同一实例不同框假设的质量差，不能全叫语言身份错误或无标签可达增益。

DEV四个可救例中，三个q0对目标IoU0却对已标注同类非目标框>.5；确认四例中有两个这种非目标贴合（.6718/.5615），目标IoU0。完整标注没有稳定instance/track ID且others未证明完备，因此是已标注distractor几何关联，不是全场景exact-ID认证。源候选通常已经能定位物体，错误子集中实例排序有具体空间；但确认仅4/48具有>.5排名可救空间，不能称所有样本主要都选错实例。

固定q0只注入GT中心/尺寸/朝向，是封存后非互斥诊断，均不可进入适应；GT yaw不是固定错误尺寸中心下的最大IoU。DEV的GTcenter增益11.6853pp，其中8.2389pp来自三个错误实例框被搬到目标位置；剩余21例均值仅+3.9387pp。确认GTcenter/size/yaw分别68.2511/64.4450/68.0897%，不能把center oracle高解释成纯回归缺陷。没有执行GT监督的适应器优化。

## 实验2：语言区域约束的Query适应

来源可核验的相机变换是必要前提。Waymo E定义camera→vehicle，正确投影为A·inverse(E)·inverse(front_rotation)·source，A把x前/y左/z上改为OpenCV轴。直接使用原E时锁定点云FOV约.0113%；按[Waymo官方定义](https://github.com/waymo-research/waymo-open-dataset/blob/master/src/waymo_open_dataset/dataset.proto)预先推导后，72Waymo采样的raw视野检查为100%，独立刚体逆代数误差≤8.88e-16。选择未使用GT或caption位置；针孔/库投影数值一致不等于真实观测重投影精度。此修复仅用于新教师，不改旧模型/PCA/评分。

严格取第一目标的全局横向位置子句，左/右半幅或center中间1/3；不预测颜色，不用图像像素特征，不研究一般behind/left-of-object关系。把参考候选中心投到图像，区域内零惩罚，区间外平方距离/.25²，与三full-view IoU加权p_aug结合：.9 normalize(p_aug exp(-E))+.1p_aug。不可投影项E0但全局归一化可间接改其质量，已锁为局限。位置满足性不是正确实例证据。

新增64维查询投影上的rank4残差头，共512参数，正交A/零B，原模型全部冻结；native logits/span数值锚保持零步精确。用teacher logratio监督source-relative logposterior变化的Huber目标+.1embedding trust，Adam.01、1/3步，梯度clip1，每步embedding≤.05、总≤.1，无标签目标回溯。Q0/无空间控制严格等于p_aug对应的TTAug，不是singleFrozen。直接教师具有完全相同信息而不更新任何参数。

## 实验3：保留尺寸的可观测面中心区间

在view0完整采样点云（去重后）上建kNN16法向图，固定1.25倍PCA框crop仅选择查询节点；按校准camera原点决定近侧，camera在某轴slab外且点在近半侧才允许该轴观测。normalalignment≥.9、planarity≥.3、support≥8、两切向覆盖≥.2、MAD≤.05m。逐axis面偏移−signed source半尺寸形成center区间，半宽max(.03,1.4826MAD)；未观测轴精确保留源，尺寸/PCA角不变。近侧可见性是启发式，不是点级实例/遮挡GT。

G只优化3个中心潜变量，是输出优化，不称网络特征适应。目标为等权米制区间距离平方+.25源中心锚；Adam初始.05m、1/3步、最多10次无标签回溯、总位移cap.15m。direct对照用最近区间端点/1.25后施同一球约束的解析最优。独立凸数值/KKT合成检查通过。该构造避免可见点紧包络缩小尺寸，但仍假设观测局部面能对应完整包围框外侧面。

## 原论文条件、运行事实和范围

原官方BBS分类头也作为无更新强对照复现：42状态项strict，576,838参数冻结，nativeGPU头重放的所有center/size与source位等，首例与两次完整原模型BBS logits位等。CPU/cuDNN数值差和一次device修复留档；主BBS未放宽桥阈值。统一纯文本first-noun条件下BBS41.2344%低于BBF60.9030%，未发现换原评分头就能解决缺陷。此处不冒充原GT-class-assisted BBS全benchmark。

源token softmax保留所有真实special/sentinel分母，proj_tokens来自point-conditioned crossencoder，不能当独立文本teacher。模型实际XYZ输入没有RGB颜色/服装证据。全文/noun-only会影响query seeds和框，冻结几何对应不等于实例真值；它们的差异不能全归为纯语言排序因果效应。所有参数/缓冲区冻结、零步、无信息控制、episodic reset、真实梯度和物理cap均有实际记录。独立评分没有保存/重新拟合每个最终参数张量；更新证据来自锁定源码与封存运行轨迹，不把数值复算当独立实验复现。

## 定性与研究决定

根代理实际查看了三张本地私图：一个已标注同类干扰物案例中，目标与错误候选都满足同一横向区域，教师和Q3仍错，候选池却有高IoU框；最坏几何例的源尺寸误差仅3.3%、源中心已接近GT，局部面约束仍把中心推离；最好几何例真实改善但direct更好。固定规则的A选例曾有class大小写漏选，修复只影响离线图/索引并保留旧图，不改任何实验。图像、GT坐标和原描述不公开。完整亲看记录在QUALITATIVE_REVIEW.md。

决策：保留语言条件的实例选择作为待研究问题，优先级高于当前可见面中心优化。已有候选/已标注distractor证明缺陷存在，却没有证明当前无标签反馈能纠正它；在确认48中仅4例有>.5排序可救空间，不夸大普遍性。下一项必要证据应是能区分同侧同类/前后遮挡干扰物的实例级可观测反馈，再谈参数更新；单纯增加loss或步数不能生成这种信息。它尚未执行，不计为本轮成果。当前Q3/G3均不采用，原模型/部署方法不变，所有模型工作已结束，不排队继续训练、网格或确认后调参。
