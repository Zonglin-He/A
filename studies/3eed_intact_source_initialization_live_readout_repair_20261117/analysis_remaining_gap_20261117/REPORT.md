# R135 剩余损失归因：候选框上限、目标排序与监督—读出错位

本轮是**已曝光1798条上的缓存诊断**。R135原实验、预测、参数、配置与裁决保持不变；没有新GPU/full-model前向、参数更新、源域训练、原图/原始标注读取或FINAL访问。三种固定的末端读出消融从已有h/u/late和冻结匹配权重重放，先封存再与已有候选IoU比较；这些是事后诊断，不能当成新方法或独立验证成绩。

## 核心判断

当前微小TTA增量有一个明确的结构原因：R134用A/B共同支持、但F融合反转的顺序构造偏好；R135主项改为A输出后，这些偏好**不可能直接反对A原来的全局第一名**。部分标签又保留了全部546个受支持的A第一名。因此，更新主要在维持/放大既有候选偏好，缺少允许推翻错误第一名的身份监督。

这不是完整pipeline的唯一瓶颈。Acc25下主要有可恢复目标的排序失败、B覆盖不足和少量S/C损失；Acc50下固定A256框的几何上限严重。RGB–LiDAR物理绑定存在可测风险，但本轮没有独立实例掩码/人工图像核验，不能将总损失定性为标定或物理错绑。

## 4. 已确认的监督—读出错位

R134的成对证据要求A和B都支持i>j，而初始F支持j>i。设g_A是A的group-max最高分组，则不存在A(g_i)>A(g_A)，所以g_A不可能成为这些偏好的负端。这是构造规则的数学性质，而非阈值偶然过严。

1798条中：3619条边，478条输入有边；A第一名被偏好反对0条，F第一名被反对仅2条。A第一名进入S的546条全部也进入C，没有一次被部分标签排除；其余1252条第一名位于未知/无支持部分。不能用“没有显式要求保住第一名”推断监督具有纠错方向。

B有实际互补：A失败时，B Top1在47条达到Acc25；但A原本正确时B也会在41条失效，因此不能直接改成相信B。另有79条可恢复错误，B将C里的某个好组排在A错误第一名之上，因A不支持这个反转，它们无法进入AB一致偏好。当前构造主动放弃了这类有益分歧，同时也避免了其中可能有害的分歧；缺的是可靠区分两者的任务证据。

3619条边按初始F组代表框的IoU衡量：427条方向更好、353条更差，2839条两端IoU均为0；只有131条赢家达到Acc25。它们大多不直接区分目标与当前主要竞争者。该统计是框质量代理，不是实例身份标注，也不是独立边样本。

我在R135优先保证了完整Frozen-A初始化，却沿用了针对F反转构造的监督。这个迁移缺口需要明确纠正：A路径的正增量不代表它已经获得了能够推翻错误A第一名的监督。保留初始化修复有依据，继续把该偏好当作充分的A纠错信号没有依据。

## 5. 更新方向比“有没有动”更成问题

749条任务中：A仅522条产生非零参数更新。153条只有成对任务，A本来就满足这些偏好，任务值近乎0，所以没有有效方向；74条部分标签任务有非零梯度，但三步每次9个回溯提案全部被拒绝；15条有B无任务，1034条无B。

74条拒绝全部含A初始间隔上的紧约束；三步重复相同梯度与初始目标，总计1998次拒绝。梯度范数中位数约.25015，初始目标中位数约.07431，最小步幅仍使目标中位数增加约3.42e-5。不能把它们描述成“梯度没有接通”。紧hinge边界与部分标签方向冲突是优先解释，但本轮没有重新跑全模型方向导数，不能把非光滑数值原因宣布为已证明的唯一原因。

在294条“Frozen-A错误、A256有好框、实际更新”的输入中，比较初始最有竞争力的好框与旧第一名：92条缩小差距，202条扩大差距；初始差距中位数1.15582，更新后差距变化中位数-.07496。即使限制为C中有好框的208条，85条缩小、123条扩大；只有11条最终达到Acc25。全体A-TTA在Acc25有12次救回、5次破坏。

部分标签目标L=logZ_S-logZ_C对保留组g的导数是exp(z_g)*(1/Z_S-1/Z_C)<0。若错误组在C中本来更高，在直接logit负梯度下它会得到更大的提升；该目标没有提供让弱势正确组反超的额外信息。真实共享参数更新不等价于直接改logit，但实际margin方向统计支持“错误顺序被放大”的竞争解释。因而优先加大学习幅度很可能同时放大误改。

## 6. 对齐与读出：存在风险，但尚不能作为已证实主因

当前1678条有解析主体的输入，native token mask与解析主体均有重叠，未发现选中参照物token的情况。120条没有该解析角色。这只能排除大范围显式token索引错位；解析角色本身不是GT，不能证明完整属性/参照关系得到正确使用。

物理绑定另有具体风险：Late RGB按原始query seed anchor取图像特征，并非按最终预测框重新取区域。1437条A256有Acc25好框的输入中，GT最佳候选的anchor有403条位于其预测框之外，114条没有RGB映射；280条Acc50可恢复输入中，仍有45条anchor在框外。这里使用预测框近似目标范围，不能据此认定anchor属于错误物体；图像投影重叠、遮挡与上下文都可能影响解释。可见性也是已有深度缓冲启发式，不是真实实例可见性标注。

固定h/u的读出消融显示：去竞争接口13.341768%，完整A13.394463%；去Late但保持原竞争残差13.330524%；去Late且去竞争13.376914%。它们没有释放出接近TopK/候选oracle的大幅收益，Late和竞争还存在交互，不能简单相加。尤其不能把最后Late项的+.063940pp当作“整个RGB模态贡献”：早期RGB–LiDAR融合已经保留在h/u中。

是否有语义错绑、视觉区域混入邻物，仍需有独立实例依据的物理/语义对应核查。当前最强的已确认结论是任务监督不覆盖错误领头候选、已有表示目标排序弱；不能仅凭低mIoU宣布相机标定或三模态物理对齐坏了。

## 明确处置

保留R135初始化、完整读出和无B回退修复。当前重点转为**错误第一名与竞争好候选的监督资格及集合内判别**，先验证信号能否允许并正确指导反转，再讨论更新幅度与新层位。不要把B分歧直接当正确标签；47救回/41破坏已经表明需要独立可靠性依据。若需要进一步区分Up接口能力与监督不足，下一项应是明确标为GT辅助诊断的同接口正控，而不是再调一次无标签步长。

几何/回归应作为另一个独立问题：若目标是明显提高Acc50，固定原A256本身限制了结果，单靠匹配参数没有实现路径；在身份判断仍不可靠时不能自动把伪目标框当回归真值。

本轮没有提出并执行新的部署配方，没有使用GT逐例选择输出，没有访问FINAL或重启旧paused项目。所有范围、负例、GT-only上限、代理指标和未确认解释均保留。
