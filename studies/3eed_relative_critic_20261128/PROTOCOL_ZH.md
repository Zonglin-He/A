# 竞争式物理原型与真实源域相对评分

正式 Minimal-D、冻结 Qwen3-VL checkpoint 和原 96 格点候选生成器固定。仅四个小型评分器使用真实 Waymo 源域监督。源域输入来自既有 256 条 train 和 64 条独立录制 val 封存，train 的冻结二维输出复用，源域其余读取按原 prompt 生成。候选特征按真实预测、原 LiDAR、原图 ViT 及同一格点算法计算；源域标签给候选评分。阈值只在 Waymo val 选择，训练进程拒绝目标域数据和非源运行目录。目标 RGB、LiDAR 和冻结回复只用于逐条推理，目标标签在全部预测封存后进入评分。

| 实验 | 受控改动 |
| --- | --- |
| 2A · 窗内竞争负原型 | 使用原固定双姿态候选，以原支持为正原型，在相同 1.15× 支持范围比较只含窗外背景与加入最多三个窗内物理对手后的剪影。另做区域与目标框归属的离线分离审计。 |
| 2B · Bind | 在原四尺度候选中，以竞争概率对原物理投票加权，仍要求原中央支持条件。沿用正式姿态排序。 |
| 2C · 固定候选 | 原 96 格点候选、原姿态候选和 Minimal-D 框逐项复用。并列 AABB、历史单原型、同范围竞争剪影与 1.50× 竞争剪影。 |
| 3A · 真实源域 IoU | 复制旧仿真 Critic 的 48 通道和网络宽度，使用真实 Waymo 及同协议候选训练绝对 IoU 回归。比较原仿真 Critic 及同池 AABB。 |
| 3B · Pairwise | 同真实候选及同 48 通道网络。随机同查询配对并包含与参考框的配对，以至少 0.01 IoU 差训练逻辑排序。输出全池最高分框。 |
| 3C · 相对参考 | 同来源与同 48 通道，学习相对于 Minimal-D 的 IoU 差。网络自减保证参考得分为零，比较正增益直接替换和源验证阈值替换。 |
| 2+3 · 联合 | 保持相对评分器训练和选择规则，额外加入主竞争剪影与最强竞争者的凸包重叠两个通道。比较各自零阈值及各自在源验证选门槛的版本。 |

物理对手来自原区域目录，先以现有 $h^2/e$ 排序，排除与已选区域重叠超过较小区域一半的候选。原赢家始终作为主原型，窗外背景是额外原型。使用温度 $1/8$ 的余弦 softmax。2B 把合格候选的强度乘以 $(0.25+0.75\bar M_j)^2$，$\bar M_j$ 来自该区域在窗口内的 Fit 投票。非合格区域仅可竞争，不可作为 Bind 输出。剪影采用冻结 ViT 最后一层、merger 前网格。分离审计只使用离线标注辨认候选中的目标和同类对手，未能可靠映射同类的案例单列为物理竞争代理。

全部评分器固定训练 36 轮，AdamW 学习率 .001，按查询分批，不对目标调参。3A 与 3B 共用初始化。3C 与 2+3 共用容量和初始化，3C 的两个新增视觉通道恒为零。两者使用 $[a,b,a-b,|a-b|]$ 网络预测相对增益，在 $\{0,.02,.04,.06,.10,.16,.24\}$ 中按冻结 Waymo val mIoU 选阈值，持平时保留替换较少的门槛。参考框缺失时相对评分维持原读出。

使用上一轮的 873 条盲输入和 836 条参考，主报开发 665、Drone + Quad 384 以及已曝光的 Mono3DRefer 历史录制过滤 118 条。严格 IoU >0.50 为 Acc@50，按录制成对自助采样，汇报候选 Oracle、Spearman、有效竞争覆盖、替换率及收益/伤害。两套面板均有历史项目曝光。策略若触发替换而最终 IoU 无明显变化，单独计为持平。 [上一轮候选与配对结果](../3eed_four_paradigms_20261128/REPORT_ZH.md) · [RankNet 原论文](https://www.microsoft.com/en-us/research/publication/learning-to-rank-using-gradient-descent/)
