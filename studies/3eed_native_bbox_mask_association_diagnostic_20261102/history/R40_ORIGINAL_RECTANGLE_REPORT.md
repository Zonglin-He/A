# R40：同一 native bbox 的标准二维矩形关联对照

## 结论

固定 R39 模型回答、bbox 原值和源三维框，将 bbox 中心查询 mask 改为标准矩形 IoU 唯一最大匹配后，A208 两平台平均 mIoU 从 **20.7337%** 提高到 **21.0381%（+0.3044 pp）**。它仍低于 compatible point 的 **22.7403%** 和旧 G 的 **24.7274%**。当前关联修正补充了部分有效信息，但不足以建立可靠监督或支持接入 TTA；不替换当前精度默认方案。

本轮只有缓存 CPU 运算，**新增 VLM 调用、GPU 推理、源训练和学生更新均为 0**。A208 已暴露，结果属于开发诊断。FINAL、T、U 未读取。

## 唯一改动

`PLAN_LOCK.json` 先锁定方法，再实现并固定 `IMPLEMENTATION_LOCK.json`，随后才执行 CPU 检查和新预测。

- 只对 R39 已通过原安全解析和输入边界检查的 bbox 做关联，不修复原 4 条坏 JSON 或 2 条越界框。
- bbox xyxy 原数值精确保留，按原 `image_grid_thw×14` 逐轴反变换到原图；不剪裁、交换、切坐标单位或改原回答。
- 对**全部原独立 mask 的 detector box** 计算标准二维 rectangle IoU，复用 R17 使用的 `association.rect_iou`。原 R37 缓存的 `mask_boxes` 来自原 `instances.boxes_xyxy`；逐 mask 与原候选矩形一致性断言通过，无需新检测或重建。
- 只有最大 IoU 严格大于 0 且最大值唯一时提名该 mask。全零、精确并列、缺失或无效 detector-box 库均 UNKNOWN。不引入可调阈值、间隔门、类别、最近距离或融合分数。
- **无三维组的 mask 也参与最大值选择**。若它胜出，直接 UNKNOWN/source fallback，不改选第二名。
- 被提名的 mask 仍查原完整组或原 R29 AB-only subset，使用组内固定原 source 分数最高 query；不生成、融合或修正三维框。

原 R39 的 13 个臂全部逐 query、逐原框精确保持，新增 `bbox_IoU_fullmap` 与 `bbox_IoU_oldsubset`，共 15 臂。本项是标准几何关联强对照，不是新算法。

## 机制子集仅作解释

预先定义的子集不使用 GT，预测封存后才评分，不用于选择规则或排除反馈。两个子集可能重叠，不能把它们当独立样本或相加收益。

|---|---|---|
| 原中心 UNKNOWN | 28 条；2 改善、1 恶化；子集均值 +0.4901 pp | 16 条；任务 IoU 全不变 |

该表支持“中心压缩有时丢失有用 extent 信息”，但不支持“它是总体性能不足的主要原因”。同一框提供的范围信息能修部分关联，仍无法替代可靠的完整描述主体判断。

完整映射中，Drone 有 19 条胜出 mask 无三维组、2 条继承原越界框；Quad 有 7 条胜出 mask 无三维组、4 条继承坏 JSON。本数据未触发零 IoU 或精确并列 UNKNOWN，但 CPU 合成合同已验证这些分支。所有 mask 都参与最大值选择，未通过跳过无组 mask 伪造覆盖。

## 测量与边界

CPU 正控覆盖标准 IoU 数值、各轴逆变换、唯一正最大值、精确并列、全零、缺失库、原无效输出保留，以及“无三维组赢家不能换次优”。208 条新预测、每个 mask 的完整 IoU 向量、最大值和间隔、未知原因、原 bbox 和全部 15 臂原框向量先封存，再完整重放审计，最后读取任务 GT。

封存 SHA：`7843e817f654f84ffa07f3f09656b875567d688ba4b21caa922b445461bdc41f`。原 13 臂、原 bbox 位置值和源三维框精确不变。没有重生成 R39 回答，原 209 次实际生成及其中 1 次技术 raw 丢失记录沿原研究保留，本轮成本另报 0 次新模型调用。

同一预封 24 条身份注释可以在新 seal 后对照中心与矩形 IoU 的提名，注释不修改，不按身份结果挑样本或选门。它仍是声明历史暴露的 assistant provisional review，不是专家 gold。

## 证据入口

- `PLAN_LOCK.json`、`IMPLEMENTATION_LOCK.json`：语义方案先于代码，代码先于执行。
- `CPU_TECH_CHECKS.json`、`CPU_AUDIT.json`：软件合同和封后完整重放。
- `TASK_SUMMARY.json`、`FACTOR_CONTRASTS.json`、`COVERAGE_UNKNOWN.json`、`SCENE_ROWS.json`：总体指标、15 臂强对照、未知和逐场景结果。
- `MECHANISM_SUBGROUPS.json`：原中心 UNKNOWN 与不同 mask 子集，均为封后机制描述。
- `ALL_ROWS_PRIVATE.json`、`ALL_NEGATIVES.json`：完整逐条结果和全部负例；公共导出需脱敏。
- `DECISION.json`、`COSTS.json`：不采纳 TTA 的裁决及零新增推理成本。

有限结论是：当前 bbox 的范围信息比仅取中心有小幅总体收益，然而剩余误关联和主体判断仍使它低于 point 与旧 G。停止该固定读出配置的 TTA 接入，不据几个负例继续追加门槛。
