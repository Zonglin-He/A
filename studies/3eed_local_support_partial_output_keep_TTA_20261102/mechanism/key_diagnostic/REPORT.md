# R34：语义投影 key 与投影前隐表示的无标签区分度诊断

状态：CPU 诊断 completed，测量 valid；没有评估新方法的任务收益。本轮使用 A208 / DEV64 / T128 的 source 特征和原22条偏好的 endpoint 索引，没有访问 GT、U128、FINAL384，没有模型前向、训练、预测或 GPU 操作。

当前判断：**有依据单独测试 h288 隐表示检索，但没有依据称其已解决同类实例对应或提高 TTA。** 原64维投影存在较强的方向聚集和较小近邻间隔；h288 的间隔明显较大、数值检索较稳定。其门覆盖反而稍低，不能预期自动扩大有效传播。

## 执行与数据合同

`diagnose_keys34.py` 对400个观测全部256个候选比较三种 L2 归一化 key：

1. 原 R32 key：source query64 与 source noun-token 均值的归一化向量逐元素相乘，再归一化。
2. query64 单独归一化：区分投影本身和 noun 乘积的影响。
3. h288：source decoder 最终 query、进入 contrastive_align_projection_image 之前的隐向量，直接归一化。

每个平台只检索本平台104条 A 观测；每个 A 观测贡献最近的一个候选，再排序不同 A 行，A 查询排除自身整行。比较 NumPy float32/float64，描述 nearest-A 行间隔、所选 A 行内部候选间隔，以及接受偏好的 endpoint 门是否改变。原22条反馈只用于描述 endpoint 门，没有读反馈正确性的 GT。跨 A 余弦分布固定取每观测索引0,32,…,224，排除同观测对；不是按得分或任务结果挑子集。

h 的来源已核对 capture24.py / capture25.py / capture32.py 的 projection-image forward-pre-hook。h 已经是文字和点云条件化的 decoder 隐表示，并非新引入一种观测。其低层距离是否适合跨场景实例检索仍待任务验证。

输入合同、1200个观测×key记录、跨观测样本、邻居记录与汇总已封存于 attempt001/SEALED.json。CPU_AUDIT.json 独立读取封存产物核对 SHA、样本数、间隔范围和所有精度差异计数，通过。诊断约61秒。第一次审计在封存完成前执行而未找到 SEALED.json；原诊断继续完成后再次审计通过，未重跑或替换结果。

## 区分三个结论

**方向聚集存在，但“完全 collapse”不成立。** T128 原 key 的候选对余弦约0.96–0.98，候选仍有可测差异；h 的候选对差别大得多，但 centered participation rank 也只约2.42（Drone）/2.06（Quad），仍集中在少数变化方向。维数288不代表288个有效自由度。

**noun 乘积同时有语义条件作用。** 固定跨 A 样本中，原 key 的 Drone 中位 cosine约0.171，裸query64约0.946；Quad约0.811/0.969。不能仅凭投影前区分度大就判定删除 noun 条件更好。原 key 跨描述差异较大、观测内实例差异小，是合理竞争解释；需要实际输出对照确认。

**数值稳定改善不等于标签可靠性改善。** h 的最近行和候选间隔约扩大一个数量级，CPU精度检索变化减少。但 T128 原/h 的 endpoint 门都没有因CPU32/64改变；因此本诊断不能把之前 legacy memory 的6个 Drone 最终 query 差异归因于此处 endpoint 门，也没有重现 GPU 与 CPU 的 legacy weighted-correction 算术。旧 legacy 差异仍应保留为已报告的单独边界。

重复 queries 可能对应同一个物体，小的候选间隔本身不必然有害。最近候选是否越过了接受组边界比索引变化更重要，本次 endpoint 门统计正是为避免把所有索引差异解释成身份错配。

## 最小后续与停止规则

可将 R32 原 noun×query64 key 唯一替换为 normalized h288，固定 R30 b1 匹配头、原反馈、endpoint支持定义、q0锚定、ell_eps读出、QP margin0.1和 k=1 主设定。保持同 h-key/同门 QP无参数记忆、同门均值及实际修正范数匹配的全局缩步对照；不要同时改适配头和反馈 G。若先做 k4，仅作提前登记的次要敏感性项，不能根据新留出标签选择。

[GRACE](https://papers.neurips.cc/paper_files/paper/2023/hash/95b6e2ff961580e03c0a662a63a71812-Abstract-Conference.html)把冻结网络的中间激活用作局部编辑记忆的 key，可作为“隐表示支撑传播范围”的参考。它有已知正确的编辑标签、学习的值和半径维护；本地换 h-key 没有这些前提，因此只能称借鉴 hidden-activation locality，不能称复现 GRACE。

需要的任务证据仍是：固定方案后在未用于选择的新观测上，总体 mIoU/Acc、纠错/误改、作用覆盖，以及与同信息不更新记忆的差异。如果 h 只改善数值而总体指标无收益，就停止这一 key 分支；不通过事后黑名单提高数字。若两个 key 门都几乎不触发，优先判为支撑覆盖不足，不能将低覆盖下的“安全”当作有效跨观测适应。
