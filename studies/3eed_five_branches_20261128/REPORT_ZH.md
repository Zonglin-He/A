# 五条机制分支实验报告

五条分支均已完成首轮冻结预测和独立离线评分。**Drone 与 Quad 的原生逐束射线能从上游数据恢复。** 在本候选池上，它们尚未提供超过相机代理或打乱对照的稳定收益。七维优化给出了另一个机制结果：即使独立 Audit 的观测代价更低，真实 3D IoU 仍下降。

R1 和 R4 在主面板封存 702 条输入，其中 3EED 576 条、KITTI 89 条可评分。R2、R3、R5 共用另行哈希锁定的 48 条主面板子集，每平台 12 条，KITTI 一条无对应评估标签，最终 47 条可评分。R1 原生对照的 24 条 Drone 与 Quad 查询均通过同帧回波匹配。全部面板有历史曝光，结果用于机制研究。五条分支使用同一冻结 Qwen3-VL-4B-Instruct，各自读出，没有训练。正式入口仍为 `ray_equivalent_height_only`。 [总协议](PROTOCOL_ZH.md)

| 分支 | 核心结果 | 结论 |
|---|---|---|
| R1 负空间 | 原生自由空间使正支持 **28.89% → 29.19% mIoU**，地面项 **29.63%**，打乱对照 **29.65%** | 真实射线可恢复，当前排序与打乱对照难以区分 |
| R2 渲染核验 | 自然候选下，正式框 **35.76%**，同色 RGB 核验 **28.12%**，随机期望 **32.52%**，重做二维定位 **39.07%** | 线框核验对面板位置敏感。重定位有初步信号 |
| R3 内部注意力 | 全层注意力 AUROC **0.952**，二维框 **0.922**。AUPRC 分别为 **0.216** 和 **0.474** | 粗排序信号尚不能稳定转成实例支持 |
| R4 七维投影 | C_ray 315 条，模式搜索降低 Audit 代价 **0.121**，mIoU **45.11% → 35.75%** | 独立观测拟合与完整框精度仍有差距 |
| R5 虚拟相机 | 原图 **6.88%**，Roll **6.70%**，平视 RGB **5.93%**，同位点渲染 **1.83%**，三视融合 **1.93%** | 纯旋转未稳定提升。同位稀疏渲染已造成较大损失 |

## R1 · Native Negative Space

3EED 元数据的 `timestamp` 对应本次匹配的 M3ED 原始 sweep 索引，目录编号存在错位。经两个独立点子集核验，24 条查询均通过。利用 SDK 标定查找表重建 **13,014 条**实测 ROI 回波的逐束发射原点和方向。正支持、加自由空间、地面项、联合四种规则在同回波条件下，原生路径与相机代理 24 条的候选选择均相同。原生联合相对正支持为 **+0.30 pp mIoU [−1.36, +1.76]**。包内零距离值单独审计，后方空间仍按未知处理。原生比较在导出 sweep 的传感器坐标中执行，未另行估计运动中的每束世界位姿。Waymo 原始 TFRecord 匿名请求返回 403，保留相机代理。KITTI 用点坐标系名义 Velodyne 原点。 [详细结果](../R1_negative_space/REPORT_ZH.md) · [M3ED 原始数据结构](https://m3ed.io/data_overview/datafiles/) · [Waymo 数据权限](https://waymo.com/open/terms/)

## R2 · Render-and-Verify

自然候选的主同色 RGB 版本比正式候选低 **7.65 pp mIoU [−13.77, −1.58]**，交换顺序后同一候选的一致率 **31.9%**。47 条中有 22 条严格首交等价候选可评分，其中 12 条存在至少 0.01 的最佳候选 IoU 差。该组主 RGB 选择正确 **5/12**，射线和正式候选 **10/12**，顺序一致率 **18.2%**。等价组主要比较顶端变化。重做原图 2D 定位后使用投影重叠选择自然候选，12 条改善、6 条退化，提升 **3.31 pp [−0.02, +7.71]**。实际给定候选已包含物理几何，RGB 核验与原生坐标输出的分差还包含候选池的贡献。 [详细结果](../R2_render_verify/REPORT_ZH.md)

## R3 · Attention-to-3D

全层注意力相对固定二维框的点 AUROC 平均配对差 **+0.076 [0.025, 0.117]**，AUPRC 差 **−0.219 [−0.296, −0.152]**。有同类竞争点的 29 条里，二维框的竞争 AUC 中位数 **0.932**，全层注意力 **0.770**，类别反事实 **0.821**。8 条初始二维 IoU 小于 0.20 的查询里，所有替代读出的 0.50 IoU 召回均为零。峰值连通热区替代原窗后，最好的几何闭环 mIoU **6.61%**，原窗 **35.76%**。在当前读出中，前景排序收益仍不足以提取可用的目标区域。 [详细结果](../R3_attention_to_3d/REPORT_ZH.md)

## R4 · 7-DoF Projection

315 条可评分 C_ray 查询使用经真实回波的 Selection 相机代理射线，尺度归一化局部秩中位数为 **3**。GT 框落在实测可行域 **115/315**，只看正确指代的 221 条时为 **106/221**。首交等价候选去重后，采样 Selection 留 2,459 个，全量 Selection 留 2,455 个，加独立 Audit 留 2,286 个。7D Sobol mIoU **37.56%**，模式搜索后 **35.75%**。加弱空间尺寸与 yaw 先验比同池纯物理高 **1.94 pp**，比正式顶缩低 **2.76 pp [−3.98, −1.81]**。有限候选 F 内 Oracle **49.21%**。观测兼容性和有限候选内的排序均有剩余误差。 [详细结果](../R4_unified_projection/REPORT_ZH.md)

## R5 · Virtual Camera

接同一正式几何后，原图、Roll、重力平视 RGB 分别为 **35.76%、35.88%、35.77% mIoU**。原生深度误差的单臂中位数下降，逐例配对的 Roll 和平视 RGB 深度误差变化中位数只有 **−0.11 m** 和 **−0.07 m**，平均差区间均跨零。原位点渲染非空像素中位数 **4.6%**，相机位姿保持时已使接正式几何的 mIoU 降至 **8.40%**。三视角融合 **1.93%**，等调用次数的原图融合 **6.88%**。同位控制表明，稀疏渲染输入本身已造成明显损失。 [详细结果](../R5_virtual_canonicalization/REPORT_ZH.md)

在 RTX 5090 上，R2 使用 1,290 次候选 logits 读出和 48 次二维解码，逐例累计 132.1 秒。R3 用 144 次不生成坐标的 attention forward，累计 30.5 秒。R5 用 864 次二维或三维解码请求，累计 427.9 秒。R1 原生配对按 HTTP Range 拉取 144 MiB 数据，含解码和网络的逐例累计 316.3 秒。以上为累计工作量。各分支的盲预测、哈希和正负案例索引保存在本地，图像与逐例标注未进入公开产物。

复算时分别运行 R1 的 negative.py、native_experiment.py，R4 的 project.py、full_rays.py，以及共用 gpu.py R3 R2 R5。所有封存齐备后运行 score_branches.py，随后用 paired_details.py、export_reports.py 和 verify_branches.py 生成并复核结果。 [各平台聚合、配对区间和传感器审计](results.json)
