# Minimal-D 冻结后的评估协议

冻结点由主方法登记及其源码哈希定义。在线运行保持冻结 Qwen 的两次独立读出、L0/L2/L5/L7、PCA/Qwen 双姿态、参考框轴投影和历史证据不足回退。标签在预测、清单、模型及代码绑定后进入评分。方法更新与新 checkpoint 实验使用独立分支。 [主方法锁](PAPER_METHOD_LOCK.json) · [推理与评分命令](../../tools/3eed_recovery/README.md)

## 3EED 全量

已核对公开 Ordinary Validation 的 9,310 条输入与公开 UID 账本逐平台一致。Waymo 3,782、Drone 2,792、Quad 2,736，均有现成 RGB、LiDAR 和相机字段清单。用冻结运行器生成当前方法与同批对照，报告每平台 Acc@25、Acc@50 和 mIoU，再报告三平台等权汇总。阈值沿用严格大于，解析失败计零。配对比较以录制为重采样单位。过往的 9,310 条是历史方法结果，Minimal-D 的全量表需以冻结后运行填入。 [历史账本与指标](../3eed_qwen_extent_height_only_20261122/REPORT_ZH.md)

## 同协议基线

| 比较 | 输入与统计口径 |
| --- | --- |
| 冻结 Qwen 原生框及既有 `C_ray_simple` | 同一 RGB/描述与冻结前端，原生框按相同传感器坐标约定评分，`C_ray_simple` 复用同一份回复和实测点云 |
| 历史三轴、只缩顶部及高度加二维 | 同一帧、相同回复与回退定义，用于归因轴投影和二维排序 |
| 已发布 3EED 学习式基线 | 使用公开 checkpoint 与对应官方拆分，记录训练域和评估 UID，单列报告其监督条件。核对样本覆盖后才与同分母结果对比 |

统计中区分重构等价、方法对照及学习式对照的证据。

## 独立泛化

目前已评分的 665 条开发面板、Mono3DRefer 171 条及其 118 条录制子集、Talk2Car–mini 113 条均有项目接触记录。3EED 公开包可见的 199 段普通录制也有历史接触记录。外部独立验证在具备真实 RGB、同步 LiDAR、标定与原始指代表达时，先做原始录制及派生资产交叉核对，整段排除已接触录制，再封存分母。沿用冻结 Method 和超参数，报告各平台或数据集结果及解析失败。项目曝光与预训练数据来源分别陈述。 [既有曝光审计](../3eed_2d_relocalization_20261128/REPORT_ZH.md) · [Mono3DRefer 协议](../3eed_2d_pose_finalization_20261128/PROTOCOL_ZH.md)
