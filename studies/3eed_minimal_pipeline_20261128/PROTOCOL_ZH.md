# Bind–Project–Select 最小流水线消融

以登记的 `ray_equivalent_extent_2d_rank` 为 Full。在相同的 873 条封存输入上做标签隔离回放，沿用前一轮 836 条评分定义、665 条开发查询和 118 条按录制过滤的 Mono3DRefer 主对照。它们均有历史项目曝光。保留两次冻结 Qwen 读出，使用现有回复、点云、标定、采样和类别准入。标签在所有预测、审计和计时输入决定结束后读取。全程没有训练、模型推理或目标域适配。

| 版本 | 固定干预 |
| --- | --- |
| Full | 原登记的四尺度完整入口 |
| Minimal-A | 仅把 C_ray 与 H 使用的候选尺度换为历史单尺度 L7，沿用 Full 的其余计算 |
| Minimal-B | 仅把 C_ray 与 H 使用的候选尺度换为 L0/L7，沿用 Full 的其余计算 |
| Minimal-C | 四尺度、新统一轴恢复、二维优先及平局射线回退，复用视图绑定中间量 |
| Minimal-D | C 叠加通过判据的最少尺度绑定，若尺度减少均未通过则取 C |

在读取本轮标签前固定筛选判据。尺度替换需要在两个主面板上，mIoU 下降各不超过 0.5 pp，Acc@50 下降各不超过 1.0 pp，且各自参考框的 Selection 首交保持率为 100%。这些是本轮工程筛选容限，配对区间另行报告。C 要求逐框与 Full 的绝对差不超过 $10^{-12}$、姿态和所有输出字段一致，且保持相同物理绑定和审计。若两个减尺度方案均不过，D 采用 C 的等价重构。两种低尺度与重构组合均在盲阶段运行，用于核验重构与尺度干预可组合。

报告 mIoU、严格 3D IoU $>0.50$ 的 Acc@50、以录制为单位的 2,000 次配对自助区间、C_ray/H/A 路由、首交和证据保持、有效模型解码次数与本次新增调用。首交保持比较每个候选自身的参考框和输出框。分母跨两个姿态累计，前后差 $>10^{-8}$ 米或击中状态改变均视为首交变化。另报告相对 Full 仍纳入的 Selection/Audit 射线，避免证据较少的版本仍显示高保持率。

计算复杂度用匹配入口的自有函数数、Python 非空/非注释/非文档串代码行与结构化控制节点，以及原方法与重构中射线排序调用数对照。尺度数单独列出，其余冻结门槛不搜索。延迟用单 Python 进程、OpenCV/BLAS 一线程、固定 80 条查询，按平台和 Full 是否进入双姿态分层，独立预热并交替顺序计 3 次，以查询配对。仅测真实 RGB/LiDAR 后端读取至返回预测的 CPU 时间，模型回复来自缓存。
