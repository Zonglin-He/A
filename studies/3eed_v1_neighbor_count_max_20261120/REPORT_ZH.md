## 实验设计

每份 checkpoint 只读取自己的源平台数据。源拟合清单与本次诊断清单按录制和点云内容核对，两者交集均为零。384 条中有 192 条参加过早期 K16 诊断，单列其余 192 条。本文的留出专指相对于本次源标定清单的录制划分。[预设方案](PROTOCOL.json)

第一层有两个球形邻域。实验只干预半径 0.2 米、最多 16 个邻居的 32 个通道，另一半径的原生特征原样进入聚合层。采样、球查询与中心索引均来自真实 CUDA 前向。用每个张量槽对应的原始 LiDAR 行号计数。补齐空位所产生的重复点不能增加最大值，截满时中心也可能落在前 16 个返回结果之外。按物理 ID 去重再取最大值、额外复制一个已有激活再取最大值，均须逐值复现原生答复。[官方骨干](https://github.com/worldbench/3EED/blob/843a901f5367a6be5cc484b97c6ecad462961dfa/models/point_backbone_module_v2.py) · [原生分组与池化](https://github.com/worldbench/3EED/blob/843a901f5367a6be5cc484b97c6ecad462961dfa/ops/teed_pointnet/pointnet2_batch/pointnet2_modules.py) · [测量实现](native_pool.py)

在包含中心且恰有 16 个不同原始回波的邻域，保留中心，从另外 15 点中抽取 3 个或 7 个。两个固定随机掩码分别执行。结构化对照保留中心及距传感器最近的三个非中心回波。每个邻域的所有通道共用同一批保留点。原输入的 256 个 query 对应、六层 decoder 位置、K16 原框和 PCA 朝向固定。最终分数等于冻结 K16 的联合分数加上干预引起的原生主体词 log-odds 变化。逐条重放无干预路径后才比较改变的分数。该实验隔离现有候选之间的语义竞争。精简 v1 自身的赢家也随同记录。[诊断入口](probe.py) · [事后评分](score_probe.py)

设按升序排列的 15 个非中心激活中的最大保留项排名为 $r$。保留中心在内的 $n$ 点时，其概率为 $\binom{r-1}{n-2}/\binom{15}{n-1}$。在固定通道、点数和观测响应箱内，平均缺失响应是平方损失最小的加性补偿。独立脚本用带相等值的邻域穷举子集并检验条件均值的经验风险恒等式。该推导只涉及删点重建风险。最大池化与随机删除的次序统计已有前例，当前需要验证的是冻结选框对实际回波缺失的依赖。[数学与计数复核](verify.py) · [Wu 和 Gu 的最大池化分析](https://arxiv.org/pdf/1512.00242) · [PointNet++ 的点密度处理](https://proceedings.neurips.cc/paper/2017/file/d8bf84be3800d12f74d8b05e9b89836f-Paper.pdf)

## 执行与结论范围

RTX 5090 上封存预测约耗时 175 秒。三份骨干的状态指纹在运行前后相同。384 条无干预重放的候选分数逐值相同，2,688 行公开结果已独立复算。逐行按物理 ID 消除重复槽以及在池化输入中复制一个已有值的检查均通过。源域原主体标签只用于封存之后的诊断。此次源域研究对目标平台数据和 FINAL 的访问均为零。[核验回执](results/verification.json)

本次执行覆盖原生、两种随机掩码的两档删点和结构化删点。条件表、点数均值、仿射和打乱查表的自然稀疏比较，以及允许原生提议重新变化后的候选覆盖评估，均未进入执行阶段。现有证据支持停止固定 K16 上的这项补偿方案，无法推断其他尺度上的提议生成是否对真实传感器稀疏敏感。
