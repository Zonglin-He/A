# Query-only headers for good and failure figures

The user's 2026-10-27 display request removes every case title, dataset tag,
top-level metric delta and explanatory notice above the good/failure figures,
leaving only the original Query. The three good and four failure cases are
unchanged. This is a presentation edit, with no inference, selection or scoring.

`edit_pdf.py` reads the seven previously published PDFs from the pinned
pre-edit commit `c9e023426916fd5f41043745a97d2831f4467a9f`, modifies only their
header text operators and renders matching PNGs. Encoded image streams, every
other PDF operator and all rendered pixels below the header are checked for
exact equality. Original frozen renderers, plans, selections, predictions and
private figures remain unchanged. The original publications retain the prior
display and its signed results, limitations and post-hoc selection records.

The public PNG/PDF paths in the two original figure folders are updated after
all seven actual images are inspected. Publication is restricted to these
already authorized seven figures and their presentation code/receipts. This
does not authorize other media, captions, annotations, masks or raw features.

Rendering and publication wait for the separately running matched-pipeline
timing GPU measurement to exit. The timing and later temporal-alignment
experiment are separate scopes and are not completed by this display change.
