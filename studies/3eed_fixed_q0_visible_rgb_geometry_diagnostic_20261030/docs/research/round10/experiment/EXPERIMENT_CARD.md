# R10 geometric-increment experiment

Claim: calibrated RGB foreground support and observed point-cloud surfaces can constrain a more accurate fixed-q0 center/size than the original source output. Language acts through the original frozen grounding query; this is not a new semantic localizer. G never averages candidate centers, reselects a query, or receives labels.

Finite sample: 160 input-only hash-selected distinct frames,32per each of five scenes, excluding earlier60smoke and R9's160frames. TargetVAL has previous research exposure; this is exploratory, scene-balanced, not a new independent confirmation set. Source is unchanged Waymo-only epoch100; Drone64 andQuad96.

Mechanism: originalq0 point-backed RGB foreground mask; real local point-surface plane constraints with declared sensor/camera convention; source complete-shape prior and bounded correction. A single visible surface is not a complete-object centroid or extent. Size may change only with sufficient independent opposing-face evidence; otherwise retain exact source sizes and disclose zero size feedback. RGB adds calibrated one-sided containment of observed foreground, not equality of a partial silhouette to a full projected box.

Primary direct-output comparison: source, full_RGB_geometry, no_RGB_coordinate_constraint. Last two use identical sourceq0, exact same RGB-selected point support, per-axis acceptance and globalgate. Only RGBcoordinate residual is removed. Separate RGBpointmask_ablated control uses raw geometric support, with its information difference declared; retain common gate. Save raw fit, final fit, prior, plane evidence, bounds, support hashes and per-coordinate provenance. No greater-displacement objective, forcednonzero update or quality-threshold tuning on target labels.

Measurements after all predictions seal: allsample center/size error,IoU,Acc25/50; shared union-of-changed mask comparison; own-changed subsets descriptive; positive/negative/zero counts and signed contributions. Scene means and2/3cluster uncertainty descriptive, not160independent scenes. Preserve invalidsource, nomask, sparsegeometry, numericallyinvalidfit and zerochange cases as sourcefallback, never discard. A finite bounded solver result at its fixed iteration limit may be delivered, explicitly marked nonconverged with its objective, rather than falsely reported as success. Unexpected implementation errors stop the run and retain lineage.

Decision/resource gate: Only if fullG has positive paired task gain and lower center orsize error in bothplatforms, and positive average matched gain versus noRGBcoordinate, release an exploratory unused-observation adaptation check. This is an engineering resource gate, not a significance claim or method adoption. A failure means preserve the measured G limitation and stop current branch, not reject regression TTA in general. No hyperparameter sweep or source retraining.

Conditional TTA purpose: supervise using one raw-index-disjoint subset A, evaluate a fresh forward on B without B points entering segmentation seeds, point support, planes or pseudo fitting. RGB and scene are shared, so this is point-sampling transfer within a frame, not multi-view/temporal or population generalization. Compare frozenB, directG(B), and A-updated model on B with B's frozen originalq0 held fixed; include same-information no-parameter transfer. Register exact algorithm and gates before any conditional predictions; no sameinputexactfit-as-contribution. If initial G fails, this stage is not executed.

Budget: at most30GPUminutes/45CPUminutes, sequential shared GPU lease; no new paidservice/download required. Root executes; G/input/evaluation agents own disjoint new files. All older plans and predictions frozen. Publish only code/protocol/anonymous scalars and retained failures with independent privacy and remote-byte verification.
