R10 reconstructs a fixed-q0 direct geometry diagnostic on a newly hash-selected subset of historically studied Drone/Quad VAL. It does not train or adapt neural parameters. Source weights were trained on Waymo only. The source checkpoint hash, exact source forward program, strict FP32 flags, manifest hash and source state fingerprint must be supplied by the final sealed records. Target VAL has historical research exposure; this is not a fresh confirmation cohort.

Use a checkout with the original 3EED model/dataset assets and the bundled source-environment dependencies. Assets are private/local and excluded from this export. The public code preserves the source factory and fixed R7/R9 compatibility interfaces, not a recursive copy of all old experiments. Any `__WORKSPACE_ROOT__` string is a path-only export projection to configure in the local checkout. Source/export SHA pairs are in EXPORT_PROVENANCE; path projection does not change algorithms. OpenCV 4.11.0, NumPy 1.26.4 and SciPy from the isolated existing environment were used. No shared environment was modified for RGB support.

The private input selection program reads input-only prior manifests. Each of five platform-scenes contributes 32 unique pointpaths, sorted by SHA256(`R10_rgb_support_geometry_v1|` plus private input ID), excluding the prior R9 160, R8 40 and R7 20 input IDs/frames. It does not filter color, score or GT. Actual count is 160 (Drone64/Quad96). Original IDs, scene/frame names, paths and captions are excluded from the public export; public rows use ordinal aliases. Reproducing exact raw sample membership requires access to the local input manifest, whose SHA remains public.

The ordered execution is source capture → source/observation seal and independent binding audit → CPU geometry with calibrated camera and q0-conditioned RGB mask → all four arms sealed → explicit root CPU scoring release → independent score/geometry reduction audits → root report/decision/review → finite export. Source capture uses fresh source forwards, fixed native yaw0 and the pure text readout; no PCA, teacher, semantic image encoder, source query reselection or extra heading is introduced. Model point sampling can repeat observations. The CPU runner deduplicates exact XYZ and passes the first raw index; support counts do not count replacement rows as independent points. Distinct raw returns sharing exact XYZ are conservatively combined. The optional hash-parity observation split is saved only as future scaffolding and is not used as heldout evidence in this whole-observation stage.

RGB support uses OpenCV GrabCut with fixed five iterations, supplied q0 projected box, expanded context ROI and point-backed seeds. No color/category hard rule or semantic localizer is used. Unsupported source corners, ROI, seeds or foreground component produce explicit invalid masks, with no fake all-foreground fallback. The private fixed-hash10 gallery makes segmentation failures, wrong-instance priors, adjacent-object contamination and partial observations visible. A supported mask is not proof of object identity or completeness. The main calibrated RGB term is one-sided containment; it is not equality to the visible mask bounding rectangle or to a mask center under occlusion.

The four arms are source, full_rgb, no_rgb_coordinate, and rgb_gated_pointmask_ablation. Full/no-RGB-coordinate share the exact RGB-filtered point support and eligibility mask; only the RGB coordinate term differs. The pointmask ablation retains RGB-derived eligibility and is not an RGB-free deployment baseline. Geometric acceptance gates are observation conditions, not correctness classifiers. Native invalid dimensions are retained and clamped only for IoU evaluation. All arms keep the source q0. Whole-population and matched changed/eligible subsets, zero changes, fallback and negative tails must all remain in the final report. A geometric fit or decreased unlabeled objective cannot substitute for target IoU.

Source/prediction manifests contain only inputs until postseal score release. GT is used solely by the offline scorer after complete prediction sealing. Coordinate errors in public tables are scalar magnitudes; raw boxes, GT coordinates, masks, features and cache arrays are excluded. ARM_SCALARS.csv.gz is deterministic gzip (mtime=0), 640 correlated arm rows from 160 cases, not 640 independent samples. Boolean coordinate roles are encoded as bitmasks. The main two/three scene clusters give descriptive uncertainty only. No selected gallery figure is a population performance estimate, and images/captions remain private.
