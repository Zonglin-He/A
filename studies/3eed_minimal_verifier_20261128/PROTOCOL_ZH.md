# Minimal Verifier 预先固定的消融

冻结 Minimal-D 第零项、Qwen 两次读出、真实 Waymo 训练及 val 的相同查询和五视图。S0 加载原 Verifier v2 封存参数和门控。训练及选择进程只读 Waymo 源域资产。与历史严格匹配使用 IoU > 0.50。

| 版本 | 相对 S0 改动 |
| --- | --- |
| S1 | 去掉 Quantile，最多 17 框 |
| S1-13 | 在 S1 中再删四个未投影的 Top-1 姿态参考，保留对应投影、候选区域和尺寸松弛，最多 13 框 |
| S2 | 单次共享成对 MLP 和均值聚合，保留 v2 三输出、三损失与门控 |
| S3 | 保留边注意力，改用单输出、风险效用 KL 和一个阈值 |
| S4 | 只将节点与边分别减少至 14 与 8 维 |
| S5-full17/13 | 预先固定的完整简化，相同单效用 MLP，分别使用 17/13 框 |
| S5 | 源域决定的组合，优先选择达到门槛的完整简化，若未达标则组合通过验证的单项并测试 |

候选根据全部来源标签过滤，多个来源生成同一几何框时只要保留一个生成来源就保留该框。先将 v2 源域缓存的逐例候选分数、持有掩码、顺序和路由与重放校验一致。缩减池的 v2 相对统计按实际池重算。14 节点为框内占比、壳占比、两个水平跨度、射线命中率、Huber、穿透率、二维 IoU、对数面积比、凸包填充率、三轴对数先验尺寸比、轴向朝向余弦。8 边为 3D IoU、局部归一化中心差 3 维、对数尺度比 3 维、轴向角差余弦。均值聚合掩蔽 padding。两组 MLP 宽 32。

单效用固定风险代价 0.10 与温度 0.05。参考框效用恒为零。单项 KL 仅在有效候选上计算，保留所有查询。阈值在退化 Waymo val 上从所有非负实际分数分界比较，严格大于阈值才换框。v2 三门槛变体保留原网格。两种门控都先限制相对 Minimal-D 的原正确框损坏数至全部退化视图的 1%。对所有变体同样用 12 轮 AdamW、batch 96、学习率 0.0003、权重衰减 0.01、余弦退火至 0.00003、同随机种子与梯度裁剪。每臂先在安全预算内选 mIoU 最大的 epoch 和阈值，平局选替换少者。

源域保留规则为退化 val 的 mIoU 与 Acc@50 均比 S0 至多低 1.00 个百分点并满足损坏预算。单项通过情况和固定两种完整配方全部报告。完整配方通过时优先选候选上限更小的。如果完整配方都未通过，合并通过的单项后按同一源域标准验证。组合无法保留时采用通过的单项中源域 mIoU 最高者。公开全部结果。源域选择与训练封存后，全部对照一批冻结转移，665 开发与 148 Mono 均视为历史曝光的复测。论文采用建议要求源域选中的完整简化达到 665 条 mIoU ≥36.8%，相对 S0 两项指标均至多低 1.00 pp。目标域用于核对固定验收线。
