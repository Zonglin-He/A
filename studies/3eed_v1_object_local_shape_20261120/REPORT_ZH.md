# 冻结 3EED 能从单个物体的原始回波中获得可迁移的实例证据吗

在 18,620 条普通验证方向记录上，同一批候选、同一套框几何下，加入物体局部点云读数让 Acc@50 从 **11.1191% 降至 11.1037%**，救回 19 条，误改 21 条。将相同的真实读数与同帧其他物体错配后，成绩再低 0.0490 个百分点。正确放置点云证据有可测影响，现有整帧证据仍然更强。保留精简 v1 为正式方法。[全量六方向](results/metrics.csv) · [配对结果与录制重抽样区间](results/paired.csv)

## 为什么检验物体本身

精简 v1 四个主体槽之间，有参照时的纠错上限是 2.5 个 log-score，无参照时是 1.5。重新逐条以初始分最高的达标槽为准，18,620 条中该上限锁死的 Acc@25 / Acc@50 错误是 83 / 36。四槽已经有达标框但仍在可翻盘范围内的错误有 3,190 / 1,216 条。对 Acc@50 的这 1,216 条，初始分最高的达标框的第二轮主体残差在 1,159 条中低于误选框。多数此类错误应先检验新证据能否给正确候选更高分。[原生分数重建与误差归因](../3eed_v1_subject_margin_attribution_20261120/REPORT_ZH.md)

为辨别模型利用的是局部三维形状还是位置、大小等因素，本轮把分出的物理区域放在冻结点骨干之前重新读取。每个真实物体都有一个匹配计算预算的对照。在该物体水平主轴坐标系内，分别置换点的短轴坐标和高度，保留各轴所有边际值、点数、中心和范围，破坏三维坐标的联合结构。每次读取 2,048 个输入点。点数不足时真实和置换分支采用相同重复规则，超过时使用相同子集。该操作还会改变表面连续性和局部密度，真实减置换分数无法单独识别这两种影响。[点云读取实现](local_reader.py)

每条描述按原联合分布为主体和参照物各提名最多八个物理区域。所有物理区域始终有资格获选，同帧两句话各自独立提名。设整帧对区域的类别分布为 $p_0(c)$，真实和置换读取的名词 logit 分别为 $h_c$ 和 $h_c^\perp$。本轮在提名区域使用下式，其他区域使用 $p_0$。

$$
p(c)=\frac{p_0(c)\exp(h_c-h_c^\perp)}{\sum_d p_0(d)\exp(h_d-h_d^\perp)}.
$$

整帧与局部均使用同一源平台的冻结模型。点云只读当前单帧，主方法输入不含 RGB 外观。局部读数取两种固定名词顺序，聚合 256 个 query，相同锚点的总权重相同。[提名实现](nominate.py) · [联合选择和几何实现](method_local.py) · [预设协议](PROTOCOL.json)

独立编码物体点云在 SAT 中有先例。对比真实和降质输入的 logits 也有视觉对比解码的先例。本轮单独检验保留三个坐标边际的同物体干预，以及它对冻结 3D grounding 输出的影响。现有结果不足以据此提出新的可靠实例绑定算法。[SAT](https://arxiv.org/abs/2105.11450) · [Visual Contrastive Decoding](https://arxiv.org/abs/2311.16922)

## 换参照名词是否能换对真实主体

自然描述中独立核验双端的 42 条，加入形状前后，按唯一框重叠归属，两端都正确均为 0/42；按种子归属均为 2/42。在 32 个 Waymo 物理帧的两句试验中，每对文字只换参照名词，要求换到另一个主体。两个源模型共 64 对，两句都选对主体及四个端点都正确均为 0/64。额外排除此前小面板全部点文件及相同内容后，共找到 9 个符合相同构造条件的新物理帧，来自两段已有录制，两个源共 18 对。新面板两句主体都对和四端都对均为 0/18。新面板同几何形状读出与原读出相比，Acc@50 救回和误改均为零。这两批人工构造的同名词竞争条件适用于 Waymo 目标，不能当成六方向独立确认。[原面板配对身份](results/pair_identity.csv) · [额外清单](results/fresh_panel.json) · [全部新帧结果](results/fresh_pair_counts.csv)

受控变词面板 128 条描述中，有可按唯一重叠归属到正确主体的可见区域 60 条，其中正确主体进入任一角色局部读取名单 34 条。对应参照物为 72 条覆盖、53 条进入读取名单。对有可归属干扰物的 56 条参照比较，加入局部读数前后正确参照压过最强干扰物均为 27 条。空间分组覆盖和已有候选之间的竞争均有损失。[逐角色覆盖与比较](results/ranking.csv)

## 给出真实物体区域后，类名是否对应到正确物体

以下是封存实际预测后进行的诊断。仅把真实三维框用于提取物体点云，去掉多个标注框共用的点。读取器看不到类别和句子的目标编号。对同一帧两件真实参照物及两个名词，比较正确和交换命名的概率乘积。此二选一以正确参照都已给出为条件。随后恢复整张场景的竞争，检验两句话是否各选对两端。[诊断实现](oracle_local.py)

| 身份证据 | 两件真实参照物的名词分配正确 | 全场景两句都选对参照 | 全场景四端均正确 |
|---|---:|---:|---:|
| 原有整帧类别与尺寸证据 | 51/64 | 9/64 | 7/64 |
| 叠加真实减置换点云读数 | 49/64 | 11/64 | 6/64 |
| 将形状差分放到同帧其他物体 | 38/64 | 10/64 | 6/64 |
| 只用真实物体局部 logits | 46/64 | 7/64 | 4/64 |
| 只用置换物体局部 logits | 42/64 | 6/64 | 3/64 |
| 提供真实类别的构造正控 | 64/64 | 64/64 | 64/64 |

在 424 个源模型—物体观测中，整帧与形状读出的类别 micro 正确率为 36.79% 与 45.52%，五个有样本类别等权为 32.88% 与 26.61%。直接用实际和置换局部输入，两者都命中所有 car，其他四个出现过的类别均无 Top-1 命中。每个物体上局部读数有非平凡差异，类别不平衡让总体识别和困难名词竞争得出不同结论。[类别分解逐例](results/oracle_class_rows.csv.gz) · [名词分配](results/oracle_assignment.csv)

同一批真实框的事后干预中，仅将参照限制为那两件真实参照物，形状读出四端正确从 6/64 升到 12/64；同时将主体也限制为两句涉及的两件真主体，达到 19/64；逐句直接指定真参照为 32/64。GT 支持的是分析整帧干扰物、主体区分和参照所有权的相对作用。生产流程的分数和名单均在此之前锁定。49/64 对 51/64 的名词比较中，形状读出救回 5 对、误改 7 对；对同帧错配则救回 14 对、误改 3 对。源方向共享同一画面，两方向一起按 11 段录制重抽样。[限制竞争集的对照](results/oracle_competition.csv) · [逐对与区间](results/oracle_paired.csv)

## 同一物体上的几何收益和损伤

沿用选中物理区域的主轴和实测表面，尝试用局部真实与置换读出的类别条件尺寸比修正原补全尺寸，保留所测范围。在相同选中节点上，Acc@50 **救回 5 条、误改 58 条**，六方向差值 −0.2712 pp，录制区间 [−0.3609, −0.1420] pp。两种归属口径均在修改前后指向标注主体的有 5 条救回、46 条误改。5 条救回中有 3 条超过同一描述的全部原始 A256（逐框同时检查原基准零朝向及 PCA 朝向）。三个例子均未同时证明局部形状证据纠正了原区域联合读出的主体实例。[完整几何损益](results/geometry.csv)

Quad → Drone 的匿名例 3796bfb647fd79d46e5b29，原补全 IoU 0.4736，形状修框后 0.5732，原 A256 最佳 0.4298。独立和错配参照读出可归属于另一物体，原物理联合已选对这个主体。反向例 Drone → Waymo 的 c69639e7a5ea418a5fe8ea，IoU 从 0.8211 降至 0.1260。所有同阈值的正负变化均有逐例记录。[Quad 逐例](results/quad_geometry_rows.csv.gz) · [Drone 逐例](results/drone_geometry_rows.csv.gz)

## 复现

运行需要此前研究归档、注册源权重和原始观测。每次调用 source 使用该次迁移对应的单一冻结 checkpoint。下列命令在研究工作区根目录执行，环境变量 PUBLIC_HISTORY_CHECKOUT 指向已有公开历史的本地 Git 检出。新面板构造需要源数据中的框与类别来形成可检验的语句，单独的推理程序只读取产出的描述和观测。真实物体区域诊断及统一评分在普通预测封存后执行。

```bash
study=studies/3eed_v1_object_local_shape_20261120
py=crossplatform/env/bin/python
"$py" "$study/nominate.py"
for src in waymo drone quad
do
  "$py" "$study/observe_local.py" "$src"
  "$py" "$study/predict_local.py" "$src"
done
"$py" "$study/predict_local.py" seal
"$py" "$study/fresh_panel.py"
for src in waymo drone quad
do
  "$py" "$study/fresh_inference.py" "$src"
done
"$py" "$study/fresh_inference.py" seal
for src in waymo drone quad
do
  "$py" "$study/score_local.py" "$src" --archive "$PUBLIC_HISTORY_CHECKOUT"
done
"$py" "$study/fresh_score.py"
"$py" "$study/oracle_local.py" prepare
for src in waymo drone quad
do
  "$py" "$study/oracle_local.py" "$src"
done
"$py" "$study/oracle_local.py" score
"$py" "$study/oracle_competition.py"
"$py" "$study/summarize_local.py"
"$py" "$study/verify_local.py"
```

本轮主观测读取 1,622 个源模型—帧组合的 22,631 个不同物理区域。每个区域读取真实与置换版本，两种固定名词顺序，三份模型在单卡上的局部读取合计约 487 秒，另计旧特征缓存及新面板和诊断的成本。重算的普通成绩与旧读出最大差值小于 $3\times10^{-14}$ 个百分点，两套有向 IoU 的最大差值小于 $3\times10^{-15}$。源训练、目标参数更新和 FINAL 访问均为零。[运行成本](results/runtime.csv) · [独立核验](results/audit.json)
