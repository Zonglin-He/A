# R49：当前 G 的实际接口与可识别边界

本轮是用户新增授权的手动 P1，使用此前已暴露的 336 条开发观测。旧夜间任务已经结束，定时任务已关闭。没有新增模型前向、源训练、TTA、损失或框修正；本轮不访问 FINAL384。

## 同一份源预测

Waymo-only 源模型从 XYZ 和完整描述产生 256 个候选，保存原始 6D 框与主体 token 匹配分数。所有实验保持这些数组及候选顺序一致。源分数是原有主体 token 的概率质量，不是校准后的实例正确率。6D 框按共同 yaw=0 协议评分，不能把低 IoU 全部解释为实例选错。

## 图像证据之前还有候选池筛选

旧 G 先按粗类别、点云支持、投影质量与源分数筛选图像实例，代码设有六个候选上限，再补源第一名和旧比较对的实例。当前 ALL336 的实际池最大只有三个，六个上限在本批没有构成数量限制；不能预设扩大 top-k 就能修复覆盖。它没有给完整实例集合中的每个目标调用视觉模型。

因此，全文目标存在于完整 detector inventory 却不在 G 池中，是证据覆盖损失；该目标没有旧 e 分数，不能将缺失分数补零后宣称视觉模型判断失败。完整 inventory 的 detector mask 也不等于已验证的真实实例 ID。

## 三种不同的证据

旧视觉项 V 的实际输入是缓存中的主体与属性短语；其两种裁剪的 full-minus-gray log-odds 取均值，得到每个 mask 的 e。它并未收到完整描述中的所有关系。P 使用已解析的全局图像位置关系；R 使用已解析的参照实体及相机图像坐标关系。不可执行的坐标系、缺失检测或裁剪边界等条件可能使 P/R 为零。

因此，一个与主体短语兼容、却不是全文所指目标的视觉赢家，不能直接称为图像认错。需要分别封存全文身份与实际主体短语的兼容集合。已有 joint 控制收到完整描述、主体裁剪与场景，属于不同的缓存证据路径；只有固定相同 W、读出及辅助项，才能检查更换证据本身的效果。

## 图像实例到三维 query 的传播

W 来自点云支持与投影质量，并按 query 归一化；一个 mask 可以向多个重复或重叠的 query 广播相同分数。W 的非零支持不是独立的三维实例真值。最高 cue 并列时，本轮按预先固定的源分数、再低 query 索引选择，不能按 IoU 选择代表。

本轮另外保存原始点云经既有可见性处理后的互斥 mask 归属，并统计每个固定框内的目标、其他前景、未分配与歧义点。可见表面仅作为身份支持代理，不作为完整物体的中心或边界。该代理仍共享 mask 和标定，不能认证标定正确或提供独立 world ID。

## 最终读出

当前旧 G 使用 F=s+2V+2P+2R。V 为传播后的视觉 cue 相对源第一名或中位数锚点的差，除以二并截断；P/R 也相对锚点。无映射 query 的额外项为零。

当源第一名有映射时，其三个增量均为零；未映射 query 的分数不超过源第一名。因此，不能把旧 joint 原始分数读出里的“未映射零分逃逸”默认套用到当前已锚定的 G。本轮保留 mapped-only、去视觉截断、去灰图及同算子 joint 替换控制，依据实际选框与总体任务指标裁决。

16 组固定读出已先封存，独立审计精确复现 336 条的旧 V/P/R、旧 G 选框和 joint cue。身份核查封存后才统一进行任务评分。总体任务对照、条件身份核查和点支持代理回答不同问题，不能相加成互斥的总体错误占比。

## 成本与使用范围

本轮零新增实验模型前向，表示复用已保存的 Qwen／源模型输出，不表示原 G 没有外部模型成本。缓存计算时间不能当作部署时的端到端延迟。两名助理按预定分工查看 48 条 RGB、完整描述及全部实例裁剪，随后核查实际主体短语；这些暂定视觉标签只用于封存后的机制诊断，不作为新增训练监督或自动部署组件。所有观测都来自已暴露开发数据，不能将最好的消融结果作为新的独立验证。
