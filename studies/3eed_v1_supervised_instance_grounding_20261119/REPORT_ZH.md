# v1 的实例候选、双端监督与保留原框

保留源域选定的主体决策、直接输出该候选的原始几何后，Acc@25、Acc@50、mIoU 分别为 **29.720%、14.714%、16.425%**。相对当前 v1 分别提高 **0.684、0.358、0.371 个百分点**。净收益主要来自车载→无人机，车载→四足的 Acc@50 和 mIoU 下降。保留原框作为可运行的研究候选，默认入口沿用当前 v1。

## 六处机制的检验

### 候选生成和几何输出

每条输入在 A256 之外增加 64 个源域训练的点投票框。原始候选与投票候选都产生有限幅度的中心、尺寸和航向修正。以下覆盖率使用真值只判断该池中是否存在达标框。

| 候选阶段 | Acc@25 达标数 / 覆盖率 | Acc@50 达标数 / 覆盖率 |
|---|---:|---:|
| v1 主体四槽 | 1,435 / 46.712% | 689 / 22.428% |
| 原始 A256 | 2,471 / 80.436% | 1,372 / 44.661% |
| A256 加 64 个真实新框 | 2,492 / 81.120% | 1,419 / 46.191% |
| 原框和连续修框全部保留 | 2,550 / 83.008% | **1,581 / 51.465%** |
| 质量头为每个候选保留一种几何 | 1,931 / 62.858% | 1,157 / 37.663% |

保留原框和连续候选合计多覆盖 209 条严格门槛可恢复记录。硬选几何丢掉了 A256 已达标的 361 条，新增达标 146 条，净损失 215 条。固定原先选中的主体后启用同一修框，也使 mIoU 从 16.054% 降到 14.604%。这两项结果定位到跨域质量头误选几何，固定主体的对照隔离了更换实例的影响。 [候选覆盖](results/coverage.csv) · [失败及救回分解](results/coverage_attribution.csv)

### 四槽检索和主体排序

Acc@25 有 **1,036 条**在 A256 已有达标框，主体四槽漏了它。另有 543 条在四槽已有达标框，最终主体仍未达标。全池原型取消四槽硬裁剪，在联合版本中救回四槽原先漏掉的 38 条，同时造成更多其他输入退化。保留原框只能部分回收全池得分，当前全池排序不足以普遍替换四槽读出。

### 实例点支持

在源域留出集中，使用有混入点且具备合格候选的局部区域，按三维标注框给点赋归属计算支持纯度。Waymo 为 87.03%→90.65%，Drone 为 78.39%→82.17%，Quad 为 89.14%→92.48%，分别有 58、56、113 个可比较区域。重叠归属点在训练中保留未知。目标域去掉学习式点权重，完整联合反而提高 0.044 mIoU 点，属于源域支持纯度改善、跨域定位收益待验证。该纯度以已有框推导点归属。

### 语言角色与参照可信度

1,150 条方向记录产生参照短语，246 条具备可执行的明确空间项。联合对同池主体单体评分提高 0.029 mIoU 点，对错配参照提高 0.038 点，后一个比较有 6 条 IoU 改善和 6 条恶化。数字衡量整体主体定位。

另做 12 条物理帧盲核，先从原句和原图读参考物体，模型预测在判断时隐藏。4 帧有可清楚关联到数据集框的唯一参照，另 8 帧保留 UNKNOWN。4 帧对应 8 条方向记录，原 A256 均存在达标参照，质量头选后的池仅在 4 条保留达标参照。新版在其中两条抽取参照短语，可执行关系为零。当前 v1 和完整联合的双端达标都为 0/8，保留原框沿用原型的参照决策。该盲核只有一位读者且可判定帧偏少，四足的 4 帧均保留 UNKNOWN。 [盲核结果](results/reference_audit.json) · [同池及错配比较](results/summary.json)

### 源域双端监督

冻结全部三份 3EED 骨干及当前 v1 解码器，每个源平台只拟合一个 71,110 参数的实例头。用原句目标框监督主体，用标注库存、可见性、名词与关系只在唯一条件下给自然原句匹配参照。可用多对象框另构造带同类干扰的合成左右关系。来源和规模按录制划分如下。

| 平台 | 自然拟合 | 自动唯一配对 | 合成拟合 | 自然留出 / 唯一配对 | 合成留出 |
|---|---:|---:|---:|---:|---:|
| Waymo | 640 | 7 | 256 | 160 / 4 | 64 |
| Drone | 640 | 3 | 29 | 64 / 0 | 13 |
| Quad | 640 | 50 | 256 | 160 / 5 | 30 |

自然配对是基于已有标注库存推断的监督。107 条合成留出中，A256 的两端独立覆盖为 80 条，完整联合双端达标为 23 条，当前 v1 为 3 条。9 条自动匹配参照的自然留出中，完整联合双端达标为 4 条，当前 v1 为 0 条。Drone 和 Quad 的拟合各来自一个源录制。目标物理帧及重复点云已经排除于新增实例头拟合与选型之外。 [源域监督及留出](results/source_summary.json)

## 运行、限制和裁决

点投票参考 VoteNet 的中心提议思路，主体和参照的配对比较基于显式几何及冻结文本表示。参照质量不足时允许 UNKNOWN。图像路径用于图幅尺寸和相机几何，推理使用 LiDAR 与语言特征。 [VoteNet](https://openaccess.thecvf.com/content_ICCV_2019/papers/Qi_Deep_Hough_Voting_ICCV_2019_paper.pdf) · [CORE-3DVG](https://proceedings.neurips.cc/paper_files/paper/2023/hash/9b91ee0da3bcd61905fcd89e770168fc-Abstract-Conference.html)

在独立 CPU 有向 IoU 实现上对照了 24,576 个终端结果及 21,504 项覆盖检查，两种 Acc 的阈值判定完全一致。保留原框的实际入口在六方向各测两条，12 个主体框与回放逐值一致。原型从独立源录制选择 checkpoint 和读出，保留原框属于看到覆盖损失后的诊断修复。测试面板为已曝光普通数据，无目标域更新。早期源清单曾低估重复点云造成的样本不足，在提取和正式训练前修正，失败记录保留。 [协议](protocol.json) · [核验](results/audit.json) · [尝试登记](results/attempts.json) · [运行方式](RUN.md)
