# Fixed fair runtime protocol

`worker.py` is byte-identical to the source that produced the published timing data. It is staged to `outputs/maintenance/simplepath_fair_cost_20261023/run.py` so its original project-root discovery and frozen-plan checks remain unchanged. In a clean reproduction checkout with the already sealed official full results, model assets and private official metadata available, run `python -B studies/fair_cost_v1/prepare.py`, then the staged worker once. Preparation refuses an existing timing plan; never overwrite completed measurements or duplicate a live worker. No annotations are read by timing.

The 32 selected inputs are fixed by `selection_hashes.json`, resolved against local official manifests; no caption, video path, GT coordinates, features, masks or weights are exported. Each domain has16distinct parents, one query each. Source and Full share samples, decode, original Source precision/grid/seed, resident models/processes and original CPU/GPU offload. Three repeats alternate Source/Full order; warmup and model loading are reported separately. Cross-query RGB, visual, expert-result and prediction caches are disabled. The same ReferDINO observes the same eight positions:96timed expert-query calls plus2warmups, no additional expert model or observation position. Every timed Source/Full output matches its corresponding sealed prediction bitwise. Component durations can nest and must not be summed.

Protocol and all192 measurements are under `results/simplepath_full_v2/cost_protocol.json` and `cost_measurements.json`. These are uncached matched deployment-path timings, separate from full acquisition cache-hit records. Only two directions of TA-STVG were measured.
