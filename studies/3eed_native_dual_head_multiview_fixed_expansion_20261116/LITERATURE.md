# Frozen complementary evidence and why it is not yet TTA

R109 keeps the exact R106 source-PointNet canonical interpolation and R108 frozen-head policies; there is no new algorithm/source training/temperature/BN adaptation. These are existing source-supervised heads, not external experts.

[3EED official evaluator](https://github.com/worldbench/3EED/blob/main/src/grounding_evaluator.py) separately evaluates soft-token BBS and contrastive BBF. The official BBS uses annotated positive_map; R109 explicitly uses the same existing inference-only text mask for both and never reads that annotation. CE is computed over all256positions including last no-object255; eval BN and dropoutoff preserved, checkpoint14keys exact.

[MDETR original supplemental](https://openaccess.thecvf.com/content/ICCV2021/supplemental/Kamath_MDETR_-_Modulated_ICCV_2021_supplemental.pdf) studies the distinct roles of soft-token classification and contrastive alignment, including a binary object/no-object alternative. It does not prove that averaging the two classifiers improves this 3D domain shift or that either is a reliable TTA teacher. [BUTD-DETR official project](https://butd-detr.github.io/) and [official implementation](https://github.com/nickgkan/butd_detr) are the task-family source, not additional pretrained models used here.

The mathematical decomposition `log P(subject tokens) = log P(nonnull) + log P(subject tokens | nonnull)` is exact for the frozen CE head. A postseal R108 attribution records these margins on existing BBF/pool candidate switches without creating a new readout or choosing methods. Both components contribute to helpful AND harmful changes; non-null mass is learned source-unmatched-query probability, not verified foreground or correct target identity. Hence a tempting "just use objectness" shortcut is not justified.

R4's older BBS negative comparison is retained; R108's positive observation is limited complementarity in the current three-source/R91/actual-point setting. R109 expands outside currentDEV anchor paths with fixed coefficients before fitting its outputs. Entire VAL has historical exposure, and the same small Drone/Quad scene count remains, so expansion is not pristine independent confirmation. Sensor registration evidence is classical geometry only and does not certify dynamic-object identity.

## Original-paper implementation conditions rechecked

The full author paper [MDETR, arXiv2104.12763](https://arxiv.org/abs/2104.12763) was downloaded to a temporary local file and text-inspected after the CVF supplement returned403 and the web PDF parser rejected the23.7MB file. Relevant original sections:2.2.2 separates positional soft-token supervision from embedding contrastive alignment; B.4.1 reports that removing either source training objective damages modulated detection in its CLEVR ablation. This supports preserving both objectives' existing information, not the claim that frozen score ensembling or TTA must help 3EED. Referring-expression no-object readout in its task-specific training setting is not automatically equivalent to the current3EED intermediate-detection/no-mentioned-token semantics. No code or training recipe from a different task was silently imposed here.
