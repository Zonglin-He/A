## 结果

负点积能量占比定义为 sum(max(-g_a·g_b,0))/sum(abs(g_a·g_b))；所有观测仍保留，极小梯度的阈值只用于描述，不筛训练反馈。加权 cosine 用 norm_a*norm_b 加权。

每个平台均只有 7 个精确非零反馈观测梯度，其他已满足的 softplus 项因饱和变成精确零。以最大 norm 的 1e-6 为描述阈值，每状态均剩 4 个活动观测：Drone b1 的 6 对没有负 cosine，最小 +0.240054；Quad b1 的最小 cosine 为 −0.014162，仍仅占约 0.013592% 的负点积能量。

source Drone 的 norm 主要来自 V_drone_006 / W_drone_012 / A_drone_047，占 norm 之和约 45.80% / 28.03% / 26.16%；第四项约 0.0057%。source Quad 主要为 A_quad_028 / Z_quad_023 / W_quad_010，占约 40.27% / 35.39% / 24.34%；第四项约 0.0022%。因此“超过一半负角度”不能直接解释为重要反馈互相抵消，许多负角来自几乎不贡献目标函数的一项。

## 判断与下一动作

1. 当前两个状态不触发优先运行 PCGrad 的证据门。PCGrad 的归一化投影方向可能让极小但负角的任务显著旋转大任务，改变目标函数的实际贡献比例；不能为使用某篇论文而运行。
2. R30 末态 pref 与 keep 为负夹角，是纠错与保持源输出之间的可测权衡。该现象不等同于偏好任务互相冲突，也不证明它是异常机制。source keep 梯度精确为零，其 cosine 未定义，不能当作“兼容”。
3. 本诊断只观察 source 与已封存末态，未测 16 步中间路径，不排除中途出现冲突。若未来出现中途明显损失振荡等新证据，可再做路径诊断；本轮无需额外训练。
4. 后续优先做原预算下 query/text 匹配接口对照。文本侧接口能否改善局部反馈传播，需要独立新观测验证；梯度角度不能替代总体任务指标。
