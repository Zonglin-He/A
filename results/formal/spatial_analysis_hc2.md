# HC2 空间 OPD 离线机制分析

对已完整封存并评分的 TA-STVG Vid→HC2 官方 1,902 条查询／227 个父来源进行 Full − WithoutOPD 分析。两组使用同一 Strong 区间；只比较空间 OPD 相对 ReferDINO 初始化的净变化。全部样本保留，当前开发曝光规则沿用正式报告，不能称全部独立确认。VidSTG 尚在正式推理，本轮没有读取其标签或计算部分成绩。

本次没有模型或专家前向、没有参数选择，没有修改正式运行源码、配置或计划。分析使用 CPU 单线程与低进程优先级。脚本位于 scripts/，不在正式计划的冻结代码扫描目录中；已核验正式计划及预测封存未改变。

## 定义与统计

- 主汇总先在 query 内平均，再等权查询；95% 区间按父来源聚类重采样 10,000 次，seed 20261021。这里的 bootstrap seed 是离线统计种子，不改变推理 seed41。新旧报告同一均值的区间会因 bootstrap 随机数不同有小幅 Monte Carlo 差异。
- 实际节点：原 Source 真实特征帧且有 GT 的位置。观测节点：八个专家位置中有 GT 的帧；未观测实际节点不含它们。密集帧包含按原规则插值的 GT 帧，不能把这些帧描述为独立视觉监督。
- Recovery：初始 IoU<0.3 的帧中，最终 IoU≥0.5 的比例。Damage：初始 IoU≥0.5 的帧中，最终 IoU<0.3 的比例。主率是存在相应分母的 query 的宏平均；另报告合并帧数的比例。两个率的分母不同，不可相减。阈值来自用户任务书，没有按结果修改。
- GT 对齐使用官方 HC 下界裁剪后的 cx,cy,logw,logh；中心以初始框宽高归一化，log尺寸不缩放。两向量长度均>1e−12 才计算 cosine。有效框上的正内积且平方误差增加定义为过冲；这是该坐标图表中的描述，不是 IoU 退化的因果证明。
- 78 个密集 GT 帧在采样支持外，按官方规则以 IoU=0 保留在任务指标与 Recovery 分母中，仅从坐标方向分析剔除。非正框尺寸也仅从几何分析剔除；实际节点共有49个此类帧，其中未观测节点45个。几何分析有效 query 为1,901。

## 时间重叠的加权限制

逐query核验 ΔvIoU = tIoU × Δs_intersection；s_intersection仅在预测与GT时间交集内计算。全体GT帧sIoU不是该量，不能将平均tIoU乘平均sIoU解释完整vIoU。1810条非零时间重叠query的交集空间净增量为 0.5247 [0.3055, 0.7484] pp。

| Strong tIoU分层 | 查询数 | 未观测节点 ΔsIoU pp [95% CI] | 完整 ΔvIoU pp [95% CI] |
|---|---:|---:|---:|
| tIoU=0 | 92 | 1.3110 [0.3569, 2.3827] | 0.0000 [0.0000, 0.0000] |
| 0<tIoU<0.3 | 324 | 0.4446 [-0.0304, 0.9347] | 0.1041 [-0.0042, 0.2133] |
| 0.3<=tIoU<0.5 | 500 | 0.5404 [0.1943, 0.9179] | 0.3022 [0.1402, 0.4786] |
| tIoU>=0.5 | 986 | 0.4179 [0.1627, 0.6848] | 0.3326 [0.1275, 0.5494] |

这验证时间支持会使已有空间修正无法计入vIoU，但不证明时间是全部小收益的主因。92条零重叠query的空间变化不会改变完整vIoU。

## 教师拟合与缺失的过程数据

八帧的原定位代价 5L1+2(1−GIoU) 从 3.145710 降至 2.850970；净变化 -0.2947 [-0.3138, -0.2763]。99.1588% 的query代价下降。代价下降不等于GT质量提高。

正式NPZ仅包含Source、E_Ref、Live_raw、Live、frame_ids、positions8及两组时间区间。内存中的path和rounds未序列化，无法恢复真实的逐轮loss、ESS、候选覆盖曲线。没有重新推理来补这些数据，也不以起终点伪造曲线。Direct、Fixed、FitNets、Soft KD同条件正式结果目前不存在，不能把本次分析写成OPD胜过传统KD。

## 复现与核验

```bash
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  .conda/tubedetr/bin/python -B scripts/analyze_spatial_offline.py --dataset hc2
```

分析入口只接受已scored且完整封存的方向；在读取GT前验证所有预测及清单，结束后再次验证原封存、评分和标签哈希。正式计划、运行源码、推理seed和输出均未改变。原指标重算最大绝对误差 1.3322676295501878e-15；时间乘积分解误差 3.279711571768651e-16。独立合成例检查Recovery/Damage不同分母、无预测支持IoU为零和坐标方向；现有70项CPU工程检查通过。

完整聚合和输入哈希见 [spatial_analysis_hc2.json](spatial_analysis_hc2.json)，复现脚本见 [analyze_spatial_offline.py](../../scripts/analyze_spatial_offline.py)。逐query分析保存在私有outputs/analysis/，不公开原视频ID、文本、标注、教师缓存或逐帧框。
