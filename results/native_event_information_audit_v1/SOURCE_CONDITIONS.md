# Original word-head supervision conditions

A fixed original-code/data check found a real scope mismatch, then measured whether it matters. The original public HC2 recipe configures60motion classes, but the author's released HC2 source-training annotations have9586records and positive word labels only on axes0–19. Source data SHA9ca11ef8 matches the pre-existing local source-training file. We read only these source-training payloads from the author's linked archive by bounded HTTP ranges; the6.6GB archive was not fully downloaded. A16MB Vid source-training prefix provides1153complete records, observedaxes0–31 outof34; that prefix cannot prove the remaining axes never receive positive supervision. No target-test annotation payload is parsed and no teacher/model run is added.

The head-size difference is **not a sufficient explanation for failure**. On sealed fixed Vid32 TargetContext feedback, the40HC axes without released positive labels have median probability6.37e-6. Their combined LLR standard deviation has median9.81e-5 versus.18164 for the20source-positive axes. The complete original second-round LLR is recovered by summing the decomposition, error<1e-12. No class count, evidence gain or dropping-coordinate experiment is justified by those tiny contributions. The released recipe/data does not independently prove the private checkpoint's full training history.

Original source code supervises the word head after averaging per-frame logits, using video-level verb labels. It doesnot supervise these outputs as framewise event labels. The original native query initializer uses the ASA attention map; word logits and `verb_index_list` are returned for classification loss and do not select a new temporal interval in the native forward. Thus the loader's explicit empty runtime label placeholders are not missing event inputs or a newly found forward bug. Current source native predictions remain exactly preserved.

The official code tree does not supply an explicit word-to-head-axis vocabulary. Pure lexical co-occurrence can suggest many axis names, but some are ambiguous and the Vid prefix is incomplete; these candidates are not a verified semantic dictionary. Duplicate indices in annotation lists must first collapse to sets, exactly as source BCE one-hot assignment does. No inferred label meaning, target-GT class index or assumed same-dimensional alignment is admitted to inference. This audit doesnot establish a new event teacher or justify another query/weight/class-count scan.
