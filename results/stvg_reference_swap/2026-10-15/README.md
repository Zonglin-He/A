# E1 anonymous outputs

These files report the sealed, fixed 32-source same-frame reference-geometry comparison. The roster was previously exposed development data, not an untouched confirmation set. Source-level metrics retain unknowns as null; aggregate summaries and paired contrasts use the locked domains, eight arms and five metrics.

`E1_REFERENCE_QUALITY.json` is the separate observed-anchor box-IoU diagnostic. It is not full-tube vIoU or an oracle fit. `E1_EXECUTION_COST.json` distinguishes retained results from completed prefix work and failed partial attempts. `E1_OPTIMIZER_MATH_READBACK.json` contains the anonymous CPU arithmetic receipt and its limits. `REPORT_RECEIPT.json` binds report inputs and generated outputs.

The export contains no query text, raw teacher responses, source paths, frame coordinates, private images, annotations, model weights or raw caches. No commit or push is performed by report generation.
