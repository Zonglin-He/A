## Existing published TTA baselines

- **Tent**, ICLR 2021: https://arxiv.org/abs/2006.10726 ; original repository https://github.com/DequanWang/tent at e9e926a668d85244c66a6d5c006efbd2b82e83e8.
- **SAR**, ICLR 2023: https://arxiv.org/abs/2302.12400 ; official repository https://github.com/mr-eggplant/SAR at 20f6e24b17525f34503510afccedc0629b67b7c4. This repository supplies the official LN/GN-compatible Tent comparator, SAR and SAM used here. The downloaded files are SHA-bound in `reference_audit.json` and imported verbatim.

This is an explicitly disclosed **STVG task adapter of existing optimizer algorithms**, not an unchanged reproduction of their classification benchmarks or a claim of full-network STVG TTA. On the primary TA-STVG backbone, only native final temporal-decoder normalization affine parameters update. Actual seven-argument final-pass contexts and original Source boxes remain fixed; no expert is used. Four start/end categorical rows (two native offsets) form the entropy batch; different lengths are padded with the finite dtype minimum. Padding preserves the mathematical distribution with float32 entropy roundoff below 1e-6 in the CPU fixture (not a bitwise claim). Grounder dropout stays in its original eval mode; LayerNorm train/eval arithmetic is identical. Official configure/collect/core rules are retained, including SAR's final-layer exclusions. Episodic query resets are exact, and evaluation uses the after-update native hull posterior and original MBR. This differs from continual online before-update reporting.

Tent: SGD momentum .9, LR 1e-4/1e-3/1e-2 ×1/5 steps (6 trials). SAR: same LR/steps × entropy margin .4/.8 log(N) (12 trials), original SAM rho .05/adaptiveFalse and EMA recovery .2. All18 configurations share the previous64 development parents/domain. Complete development predictions seal before labels; parameters are selected per method/direction then frozen for128 disjoint fixed confirmation parents/domain. Both cohorts were historically exposed to TA-STVG evaluation. Numerical failures and empty reliability sets remain explicit; no sample is dropped or threshold forced to create updates. Budgets are up to9472 optimizer iterations across development and confirmation, 0 extra Source or expert forwards. Official CPU class execution/reset checks have passed; real native replay/reset checks run per query.

The earlier Adam entropy / PhotoConsistency experiments remain custom controls. **PseudoBox is a self-designed box-residual control, not an existing published TTA baseline**, and is not used as a substitute here. VLOD's released YOLO-World proposal/class interface does not directly match CG's single referred-tube output; we do not invent a VLOD reproduction or change the expert/backbone to force one.
