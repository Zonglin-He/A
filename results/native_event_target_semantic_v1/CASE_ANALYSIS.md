# Strong HC64 improvement still fails fixed transfer

Target-only ASA word semantic reading leaves original fused feature values, fullcaption, time decoder, native time prior and final spatial algorithm untouched. Allkeys/no-op and original semantic arrays restore bitwise. The new source projection produces larger HC64 task gains and fewer severe harms than global semantic prototypes, but correct-position specificity is not established on fixed panels: HC32 reflected/random controls score higher; Vid32 true and reflected time means are nearly equal and harmed queries outnumber improved queries. Reflected supports overlap the predicted target by about40%; they are placement controls, not certified false objects.

Independent postseal frame-event AUC and matched candidate-pair ranking remain stronger on HC64 than Vid32. Target framing does not uniformly improve these diagnostics over global framing. This prevents interpreting the HC64 positive mean as a universal spatial-to-temporal mechanism. All signed positive, negative and severe cases remain available.

The same fixed ten-step query optimizer fits the new target-semantic posterior with every query retained. Loss falls on128/128 queries, but median posterior movement is only.031/.029/.055 onHC64/HC32/Vid32 versus direct-teacher.227/.274/.318. HC64 learnedquery time is3.910pp below direct teacher, with negative paired interval. This is a failure to realize that feedback's gains under the tested interface/budget; it is not proof of universal query incapacity or evidence that more steps would solve the problem. No query-step/radius/lr scan follows.

An exploratory boundary-transition candidate-score diagnostic used same-offset outside neighbors, both inclusive interval ends, sign contrast, and an uninformative baseline subtraction. Ranking is51.4%/51.5%/49.4%, versus69.0%/64.0%/58.0% for the original interval-sum semantic feedback. No new final predictions were generated for that diagnostic; it does not justify another boundary-rule experiment.
