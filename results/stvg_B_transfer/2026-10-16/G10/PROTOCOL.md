# B identity-to-Student transfer: extent x guarded step-size control

User-authorized two-domain diagnosis of incomplete reference extent versus
rejected updates. All sixteen prior exposed development sources are retained,
eight parent/query pairs per domain. This is not a new confirmation cohort.

Keep the complete B identity decisions, admitted anchor positions, visibility
admission, weights, frozen Source checkpoints, corrected Temporal intervals,

## Locked factorial

* B00: exact sealed original B, original reference, lite_fullstep. Strict reuse.
* G10: same reference center and ID; width/height x1.25, capped symmetrically
  by image boundaries; original lite_fullstep and original acceptance.
* R01: exact original B reference; original released lite_backtrack recipe
  [1,.5,.25,.125], keeping the same finite-box and mean-reference-IoU gate,
  tolerance1e-7, Adam rollback and early stop when every proposed scale fails.
* GR11: same G10 references with the same R01 guarded backtracking.

The expansion factor is a single prelocked diagnostic intervention, not a
GT-selected radius. It does not certify a complete object, add object evidence,
change WHO, or repair an incorrectly identified object. Clipped expansion is
reported; centers must remain identical. Smaller accepted steps are never
forced through the gate. The comparison tests step reachability under the
existing gate, not the causal effect of eliminating acceptance.

All original loss/reward/response-direction, lr/sigma/tau/steps and random
sampling rules remain fixed. New recipes are selected explicitly; original
fitter and independent audit already implement both recipes. No source edits
to those scientific modules are permitted.

## Readouts and causal limits

Before new fitting: independently read original B saved states using explicit
scalar whitelists only. Count no-information, rejected first full proposals,
accepted steps, later skips and nonzero final states. Preserve invalid/unknown
and existing negative sources. No raw state/gradient/Query output is published.

After each complete new sixteen-source prediction/root seal: official and
independent full Student five metrics, same prospective four-position support,
actual adopted-gradient support separately, all paired source signs against
Frozen, Temporal and B00. Separate observed-anchor geometry IoU, target-area
coverage and reference precision using exact annotated times; missing GT stays
unknown. GT is never used to construct expanded references or choose steps.

For R01 versus B00, independently compare common-prefix rollout/noise, initial
state, full proposal and acceptance. Record the original rejected full proposal,
whether a smaller scale passes the same criterion, and the resulting complete
Student prediction. Later trajectory changes are consequences of this recipe;
they are not identical fixed directions at every later optimization step.

Factor effects are G10-B00 (extent, original updates), R01-B00 (guarded step
reachability, same reference), GR11-G10 (reachability with expanded extent),
GR11-R01 (extent with backtracking), and their difference in differences. None
is selected per Query using GT. More acceptance alone is not an improvement.
