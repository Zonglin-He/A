# Bounded full-input global-context evidence study

This is the latest direct-human-authorized follow-up, after six core256 groups.
The latest budget is global512, superseding the proposed1024. The two ordered
WHO groups are deferred, not folded into this experiment. No extent expansion,
new teacher, new proposals, two-candidate Temporal, joint-window output or
direct-preference OPD is introduced.

## Hypothesis and matched intervention

More full-input event context may improve referent identity and event-role
selection among the same existing local candidates. The alternative is that
geometry availability, irrelevant context or downstream optimization still
blocks Student gains. Teacher selection is not itself the endpoint.

Control is the exact matching A output from core256. New global video samples
32 distinct legal input frames at rounded linspace positions, including both
endpoints, without using QA/GT event boundaries. Raw Source canonical decoding,
unmarked full-scene letterboxing448 and model are identical. Physical timestamps
remain in the prompt; mean-gap fractional uniform mRoPE clock is retained and
its approximation to irregular sampling is disclosed. No frame outside the
legal request frame_map is allowed. Fewer than32 input frames yields unavailable
Spatial evidence and the original Temporal fallback, without replacing sources.

Qwen merger output is4096 global plus768 local visual tokens before pruning.
New selection keeps512 global and the exact prior A local96 indices, yielding608
per call versus A160. This is3.8x visual sequence, not3.8x wall time. The original
global A algorithm/constants are unchanged; its16 merged time groups naturally
receive the original12.5% budget. Local features, candidate IDs and geometry,
five-frame videos, semantic instruction wording, original four per-window WHO
calls, JSON ID output, greedy96/repetition1.05 remain unchanged. Only the global
timestamp list in the original prompt changes with the video.

Global encoding is once per qualified unique global input/model/processor/clock
binding. Main local features are reused bit-exactly from the already encoded
core A inputs. Four LM prefills still occur; LM KV-prefix reuse is not claimed.
Extra global and local encoding for qualification is explicitly counted.

## Engineering qualification and gates

Legacy bridge and assertions remain intact. A separate strict bridge accepts
only video grids[[16,32,32],[3,32,32]] and4864 visual embeddings. All nonvisual
tokens and original fractional mRoPE positions survive pruning. It preserves
the original pruned KV cache/generation position protocol.

CPU contracts compare pure-A selection against the old A branch at T2/T3/T16,
including quotas/roles/exact indices and64/96/512 counts; match count/schema,
missing/null and complete-source aggregation. These are not GPU qualification.

After all six core256 ROOT/prediction/CPU barriers, test the first eligible
input per domain: isolated global features equal the joint encoder global
block; existing core local features equal the new joint local block; unpruned
first8 generation tokens match original model.generate; compressed cache agrees
with at least two independent uncached next-token checks. Any discrepancy
fails closed. No assertion deletion or tolerance loosening is authorized.

## Evaluation, costs and decision scope

All32 WHO references/updates/full Student decodes and independent saved-math
ROOT/readout must finish and seal before new GT evaluation. Retain every parent,
including unavailable/no-reference/rejected cases, and all positive/negative/
neutral/unknown metrics. Report Frozen, Temporal, A, newG32 and Spatial-only
controls, official and independent vIoU/tIoU/dense/sparse sIoU, matched pairs,
anchor geometry, accepted/nonzero updates and negative sources. Common E1 support
and actually adopted support are different readouts.

Use prelocked all32 parents slots0/3 for arm-blind candidate identity, role and
extent review before exposing selected IDs or Student/GT outcomes to that review.
Missing windows stay unknown. This project-exposed review is not an independent
human benchmark and cannot reveal latent reasoning. No semantic labels enter
online selection or adaptation.

Record actual global encoder/selection, processor, LM prefill and generation,
Student fit/full readout and memory costs; reused controls/preprocessing are not
free or new independent inference. A positive result initially supports this
joint global range/density/budget design only, not an isolated compression claim.
Better WHO without Student improvement does not resolve the downstream bottleneck.
No automatic expansion or new budget sweep follows a result.

Each complete group is independently read back, anonymized, visually inspected
and published to Zonglin-He/A with code/configs/all signs/unknowns/costs/limits.
No media, annotations/GT coordinates, raw tensors/weights, real query/caption
prompts, raw Teacher text, personal conversation or credentials are public.
