# Referent-conditioned evidence: bounded prerequisite study

This is a new development study, not a promotion of the previously closed
Source-seeded foreground recipe. The preceding 32-development/64-confirmation
study reduced old spatial harm but did not establish additional Spatial benefit.

## Question and fixed conditions

Can query/caption agreement, disagreement and reciprocal temporal feature
correspondence distinguish useful evidence under the original R1 input?
Separately, did Source-conditioned foreground help primarily by re-admitting
Source-like geometry? Original cross-domain TA-STVG Source checkpoints, frozen
STVG-R1-7B, corrected fractional time, candidate intervals, eight448 marked RGB,
Temporal-Lite512 and episodic Spatial1792 are unchanged. No LR/prompt/model search,
Bootstrap, CURRENT modification or official fullset. No cross-query LN carry.

## Source-box reference control

All original development32 sources, same E1 adopted anchor positions, weights,
presence and admission decisions. Replace only reference coordinates with the
original frozen Source coordinates at those positions. Run the original final
M2 Lite fullstep/full-grid configuration and real full-model Student decoding.
The original E0/E1/E2 and Frozen/Temporal predictions remain immutable. This
control is deliberately self-reference; it is not new geometric evidence, a
GT intervention or an alternative deployment recipe. Compare Source-control
against E1 and Temporal on the same support/full Tube. Optimizer state resets
per Query and final Source restoration must pass.

## Native response diagnostic

Select eight sources per domain from the original development32, sorted by
parent/query SHA among cases with original candidate inputs. No score/GT-based
selection. All sixteen have prior project exposure. Reuse only exact saved
corrected-clock captions; compute fresh native frozen visual encoder+merger
tokens on those exact saved videos. At most64 visual passes, zero new decoder
generation. Query and caption use the same native input embedding space and
top-two normalized cosine reduction from the released Qwen2.5 SemVID approach.
Within each merged temporal cell, percentile-rank Q and C, U=min(Q,C),
D=abs(Q-C). All six token selections use the same ceil(.125*P) per-cell budget:
query, caption, consensus, disagreement, connection, cyclic within-domain
wrong-query control. Ties are stable; no GT enters selection.

Connection selection retains half consensus anchors and fills remaining slots
using reciprocal adjacent-cell feature matches within .25 normalized spatial
distance, weighted by cosine and proximity. Global mean cosine below .5 breaks
the connection. Keep uncertain or unmatched positions unconnected; do not force
instances to merge. This is a feature proxy, **not attention CS**, verified
identity, motion segmentation or new object proposals. No response-derived box.

Preserve native temporal merge: one visual token corresponds to a spatial cell
and a pair of actual physical frames. Account for448 letterboxing and the
processor grid. Spatial overlap cannot certify actor/patient/recipient identity.
Do not compare or multiply TA-STVG attention with R1 attention. Student-internal
response is excluded from this first diagnostic; Source box/interval only.

## Readback and evaluation

Seal selections/features/inputs and independently reproduce selections before
loading GT for offline diagnostics. Report per-source macro and domain means,
known and unknown positions, selected-area target occupancy/target coverage,
Source-prior overlap, query-swap specificity and matched adjacent-pair target
support. Geometry overlap is not semantic correctness. Review fixed first two
SHA sources/domain, without cherry-picking results; publish only aggregate or
anonymous scalar outputs, never media, actual queries/captions or token arrays.

This phase produces no new evidence-conditioned Teacher decision or Student
update, so association with prior correction does not establish a causal gain.
The Source-box control does execute a real matched Student intervention.

## Conditional A/B/C

Proceed only if both domains show positive source-macro consensus minus the
better single-text selected-area occupancy AND positive connection-minus-query
adjacent supported-pair coverage, with at least four known sources per domain.
Do not tune this gate after reading results. It is an exploratory development
resource rule, not a statistical significance or universal feasibility test.
If not met, publish all positive/negative/unknown diagnostics and stop this
specific expansion. If met, first qualify native sequence/position/cache pruning;
then A=official SemVID, B=dual-text instance/state constraints, C=B+connection,
matching actual per-frame quotas, tokens, calls and unchanged OPD. RGB masking
does not qualify as token pruning. No compression/LR sweep in this study.
