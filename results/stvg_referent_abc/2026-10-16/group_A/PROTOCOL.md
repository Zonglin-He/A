## Native intervention and common safeguards

Operate on R1's own visual encoder+merger vectors after normal preprocessing.
Exclude token cell centers outside the known resized physical-image support.
For candidate contact sheets, derive thumbnail placement from the unchanged
crop renderer, accounting for individual tile padding and missing boxes.
Use intersection support across each native temporal pair; odd local frame5
is duplicated according to the processor's normal temporal padding. Preserve
every cell intersecting the numeric ID glyph as actual task content. This
excludes padding tokens from the LLM sequence; already contextualized encoder
features are not claimed free of every padding influence.

Keep all text/special tokens and original selected mRoPE coordinates. Compress
only KV cache sequence indexes and adjust rope delta so subsequent generated
text starts at the original absolute final coordinate. Isolated original
fractional-time correction remains active; do not stretch FPS. The original
generation repetition penalty1.05 is preserved, alongside cap96 and greedy
decoding. Do not silently replace generation with a shorter ID-only protocol.

Qualify both domains with actual native no-prune generation token identity,
then A/B/C cached versus uncached next-token checks. A failed interface may be
repaired in an isolated version, retaining failure/code/output evidence. It is
not a scientific failure and cannot authorize changing feedback mathematics.

## Fixed A/B/C

Each video keeps ceil(.125 * original visual tokens). SemVID-style relevance
and transition weighting allocate A's per-frame budget; common ID/context
floors prevent deleting instance labels. B/C use exactly those same frame and
role quotas. The same context/ID protection applies in A, B and C.

Capacity clarification, revision002: if a merged local frame has no candidate
pixels and only numeric IDs, its floor is min(ID-count+2, actual valid capacity).
No padding tokens are introduced to satisfy an impossible extra-evidence floor;
the original total video budget is redistributed to other valid frames. Numeric
glyphs remain protected but are excluded from C's feature-connection edges.
All64 actual input geometries and budgets pass the CPU preflight, including the
all-absent final frame. Originally observed first11 A outputs (final exact audit:12) are reused only after exact A
selection/input/model/clock/prompt/embedding equality; old C had no outputs.

* A: SemVID-style query/object-MMR, transition and context selection, based on
  paper equations and released .7 frame mix/.8 object ratio/.5 MMR/.5 motion
  constants. Common valid-area/ID safeguards and this local implementation
  mean it is an STVG adaptation, not a bitwise upstream benchmark reproduction.
* B: dual query/caption consensus and disagreement, candidate-coverage object
  slots, and query/caption-conditioned state-transition selection. No dedicated
  connection selection. These are proposed constraints, not proven role labels.
* C: exactly B's ID, context, object indices and role budgets. Only transition
  slots change to incorporate reciprocal feature correspondence restricted by
  local candidate ID and spatial proximity. No global cross-window ID claim.

The same sealed Source-marked caption is selected by largest interval overlap
with the fixed Temporal output, without GT. It can inherit Source mistakes;
caption acquisition is common information/cost, not independent truth. A uses
query selection; B/C use the already acquired caption. Teacher generation
prompts and query text remain identical for all arms. Full native projected
features can be reused across B/C only when exact input/prompt/clock/model
hashes match; each arm performs its own new R1 generation.
