# Layout reward development trial

This directory archives the HC128 trial with Geometry OPD, Layout OPD and same-layout Direct. It is separate from the registered geometric method and paused formal evaluation. Only machine-specific root paths are replaced with the required `STVG_PROJECT_ROOT` environment variable; source hashes are recorded in `results/layout_reward/source_export.json`.

Private assets are required: the development manifest and labels, sealed matched reference predictions, Source weights, ReferDINO weights, video data and the existing runtime. They are not distributed here. Labels must remain unavailable to inference.

To reconstruct the isolated workspace, copy the project `stvg/` into `outputs/layout_reward_dev/workspace/stvg/`, then copy `layout_reward.py`, `layout_fit.py` and `layout_teacher_worker.py` from this directory into that package. Place `run_trial.py` and `score_hc2.py` in the workspace, copy `results/layout_reward/config.json` to the trial root, and link the existing private runtime/checkpoint/configuration assets as in the project setup. Set `STVG_PROJECT_ROOT` to the project directory. Do not overwrite an existing trial.

The executed inference program retains the original 256-query manifest for exact reference verification. The user reduced execution to the first HC128 direction while it was running. The external `finish_hc2.py` verifies the owned controller PID/startticks, stops it at the completed HC128 query boundary, verifies all prediction hashes and writes a separate HC-only seal before CPU scoring. Its scope/controller files are private runtime state and must be created for the actual process; never reuse another run's PID. A fresh HC-only reproduction may use the unchanged inference entry with `--limit 128` and then independently verify/seal all HC128 outputs before running `score_hc2.py`. Do not resume the original program without a HC-only limit: the original planning manifest also contains Vid128.

Scoring uses the preserved development label version, not the corrected formal split labels. All reported results are exposed development results. `report.py` produces aggregate and anonymous per-query results only after successful complete sealed scoring. No GT is used for reward, selection or per-query stopping. The original Source label in the scorer means Source spatial boxes with Strong time; it is not the unmodified Source temporal baseline.
