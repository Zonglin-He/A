# 通用轨迹OPD：TubeDETR版本

用户最新指令将主线改为通用证据传播、参数接口、真实轨迹和统一奖励；ASA、TTS、专用target-query残差及offset内部传播不作为方法前提。原冻结方法与结果保留，本原型全部隔离。尚未跨骨干验证，不能称输入输出黑盒或所有STVG已兼容。

## 通用核心和TubeDETR适配器

core.py只读取空间视觉向量、归一化图像网格、真实秒时间戳、八处教师区域质量和实际轨迹。它不包含任何模型类或目标query规则。adapter读取原生224的ResNet layer3（最后stride<=16的普通视觉层，文本融合前），完整时间fast分支的实际采样帧；按stride16有效图像网格对齐原八帧ReferDINO软mask面积积分。坐标是离散feature raster的覆盖格，不声称精确像素感受野边界。只实现TubeDETR；其他骨干需证明特征质量与参数接口，不只改模型名字。

所有decoder nn.LayerNorm的仿射参数作为统一参数类型，functional_call临时传入替换值，持久权重均冻结且每query hash复核。每处原生教师框的中心/对数尺寸平方监督分别对同一参数向量求梯度，八列保留观察来源、负梯度归一化后限制RMS0.01且单坐标最大0.05。这个几何监督**只构造U**，不进入全轨迹奖励，不声称完全无几何信息。source空间保持原生、零参数替换逐位复原；不使用旧E_Ref坐标修正或query residual。

## 传播与统一奖励

固定cosine温度0.07，在相邻实际采样帧的空间cell建立双向Markov对应，目标cell面积作为先验。八处证据分别传播成八套完整视频分布，不先平均成一个身份。置信启发式由偏离面积先验的TV、往返保持和一倍中位锚点秒间隔的时间衰减构成；它不是可见性概率或身份真值。

全轨迹奖励为目标支持（候选覆盖的证据质量减其图像面积）+0.5×双向跨帧关联超额支持−0.25×低证据位置相对Source的有界中心/尺寸改动。各锚点解释分别计分，再以tau0.1 log-mean-exp汇总；目标支持仍可能偏局部区域，固定系数与置信都未验证。Direct得到相同连续cell交叠、关联和Source保护梯度，不人为detach或硬化。时间固定旧Strong，SourceStrong与所有候选一致，收益来源只在空间。

## 有界真实执行与对照

固定沿用原输入哈希16条，不能根据新结果更换。U的8个正方向/8个反方向/零/正负均值/前后半组合，共21个实际参数候选（零复用）；全部重新执行学生decoder并评价整条轨迹。八个分量各在[零,+e_a,−e_a]内按tau0.1重权求参数状态均值，再分别实际执行八个新中心，不跨分量平均轨迹。它是一次奖励加权参数策略搜索，不能仅因softmax就宣称新蒸馏，分量也不自动等于不同目标身份。

Direct从相同八个正方向起点，在同一U和L1系数约束内优化同一全轨迹奖励，Adam系数lr0.1各2步；保留初始21候选直接重排序作为强制对照。Direct多反传、前向预算不同，仅接口/机制初试未公平调参，不据此宣称最终优劣。每query至多54次decoder执行（含原生/共同basis），24次适应反传；总864/384，0新专家，无参数搜索或新全量。

完整16预测seal后独立CPU读取GT，报告SourceStrong、候选重排序、策略中心和多起点Direct；候选oracle仅诊断不可部署。检查子空间Gram数值rank、平均轨迹IoU与0.9阈值聚类（非身份GT）、全轨迹奖励排序、未观测证据强度、Direct非零梯度、实际成本。若候选差异/证据传播或奖励不成立，先报告问题，不自动扩大样本或训练。只有资格与公平后续证据支持才讨论128及全量。
