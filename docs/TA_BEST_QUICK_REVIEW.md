# 最佳配置：快速 Frozen/Ours 对照与 GT pipeline 诊断

两组 8,808 次预测全部封存后，在 CPU 完成 GT 评分、逐步诊断和 root 独立核验。VidSTG 使用旧 P1 固定的 670 来源、每源一 query、两序、六条件，共 8,040 到达；HC-STVG-v2 使用旧 P5 的 128 来源、一 query、一序、六条件，共 768。

同一官方同域 checkpoint、224px、原 Paper48 采样；条件为 clean 与 frame drop / freeze / blur / occlusion / exposure 五类 5% 物理帧 transient burst，注入独立于 query 和 GT。专家可用率 25%，在线更新 1,792 参数。Vid 使用封存 v3 的 lr=.033761698432507946、teacher temperature=.34902548789596055、K=1；HC 使用 lr=.006097133675874025、teacher temperature=1、K=8；rho=.05、student temperature=1、D=4 固定。

所有来源都有历史项目曝光，outside-tuning 只表示排除本轮 Optuna/v2/v3 调参来源，不能称 fresh。本轮不是官方全 query 评估；每源多 query 的在线历史可能改变结果。没有重选参数或晋升生产方法。

## 正确候选漏选

“正确”严格指 joint dense vIoU > 阈值，分母仅为有专家的 corruption 到达。时间候选使用当时学生空间框，因此无正确 joint 支持不能单独定位为时间 proposal 不够。

| 数据集 / 阈值 | 专家到达 | 存在正确候选 | 其中漏选 | 漏选率 | 无正确候选 | 原正确被 rerank 破坏 | 被纠正 |
|---|---:|---:|---:|---:|---:|---:|---:|
| Vid / .3 | 1,680 | 698 | 159 | 22.78% | 982 | 57 | 65 |
| Vid / .5 | 1,680 | 403 | 104 | 25.81% | 1,277 | 33 | 41 |

| HC / .5 | 160 | 35 | 14 | 40.00% | 125 | 8 | 6 |

空间第一步中，Vid 空证据 211/1680、平坦奖励 109/1680；HC 空证据 20/160、平坦奖励 5/160。空间正确支持却专家 top 集合全部不正确的 .3 计数分别为 3/547、0/70；.5 为 6/299、0/25。不能从这些阈值计数认定整个空间排序无误：top 集合包含正确候选不等于完整偏好正确，也不等于一次梯度能达到该候选。

## 核验、计算和后续边界

全部旧 P1/P5 Frozen 指标逐条匹配本轮，最大误差 0；36 次 full reinsertion 通过，独立 CPU dense 评分误差 0。root 复核全部状态链、5,567,744 个参数更新标量、149,832 项指标标量检查，以及额外 29,256 项诊断/净效用检查。
