# Finite night study: global_B

32 fixed parents, 16 per domain, one query per parent. Complete all-arm Student roots and prediction seals preceded GT access. All positive/negative/neutral and unknown cases are retained. Development global groups are exact core256 subsets; confirmation128 excludes all core256 parents and prioritizes no registered past selection, but is not claimed globally unseen.

Original acceptance, rejection, rollback, precision, step counts, per-domain parameters and final full-frame Student readout remain. Global B changes full-range32 global512 plus original local B96 and separately qualifies actual physical elapsed mRoPE. The original global A group retains its uniform-average-gap clock. Comparing those two global groups is not a pure selector experiment. Local B is the matching frozen core updater.

The engineering rule is prelocked: promote global only if domain-mean vIoU gain exceeds0.10pp with neither domain below -0.20pp, or an independently established >=15% end-to-end saving within -0.05pp. Reused vision costs are not treated as free deployment savings. A negative global result returns core B without a new frame/budget/prompt search. Semantic identity, role and full-extent pixel review remains pending and is not inferred from IoU or accepted updates.
