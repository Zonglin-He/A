# From a negative attenuation oracle to a native actuation control

The completed six-arm oracle tested **post-reader attenuation of the existing
B1 residual**. It did not establish preferential use of correct support over
matched wrong support. That is a narrow result, not a rejection of shared THW,
task-conditioned readers or conditional privileged-policy distillation.

For each branch, the pre-cast change is `g W ((w-1) z)`; the output bias cancels.
All weights w are in[.25,1]. Evidence enters after pooling,FiLM,reader,LN andSiLU.
This is amplitude editing after evidence reading. However the mask itself
carries positional information: saying it injects *no information* would be
incorrect. Nor does similarity of two noisy outcomes identify a single cause.

Actual saved B1 gates are event.002495449 and spatial.002515606, not merely the
initial sigmoid(-6). These are small and earlier cast/discrete-readout evidence
is relevant, but gate scale alone does not prove failure causality. Correct
output support is also not guaranteed to contain all relational/boundary cues.

## Existing-evidence readback

All16 source cases are retained, with complete GT-class margins from saved
native endpoint/coordinate logits, target size, sampled center displacement,
event duration and lexical relation flags. No model rerun is needed for those
fields. Positive/negative S cases have mean box areas.2021/.1468 and relation
word flags2/3 versus6/7. These tiny exposed groups are descriptive, not a
predictive test. Distractor counts, occlusion, and causal context dependence
are not annotated by the selected-referent records and remain unknown.

Three actual source contact sheets were inspected locally. The largest spatial
gain example itself contains multiple similarly dressed people and a relational
query, opposing a blanket appearance-only interpretation of successes. No
video,caption,GT,contact sheet or raw tensor is published here.

## Minimal sequential experiment

First optimize one free merger delta for each of two deliberately selected
source failures, with all model parameters frozen. Only the actual current
native endpoint or coordinate distribution is supervised, never a forcedGT
semantic/time prefix. Fresh native rollouts and differentiable replay must
agree at each state; keep the original BF16 program. Fixed30steps, no best-step
selection. All gradients, actual Adam changes/counters and native outputs stay
in the private evidence archive.

If both fixed endpoints improve, restrict the same diagnostic to the column
span of the frozen branch out-projection. Use an explicit QR parameterization
in token units to avoid confusing a tiny gate with a zero reachable span. It
is equivalent to a potentially large latent delta under the unchanged gate;
it does not establish that a reader can learn it efficiently. Finite Adam
failure is not proof of mathematical non-controllability.

The old multiplicative condition is reused. A successful supervised control
and failed no-update mask show an available interface plus an ineffective
operator in this setting; they do not alone isolate supervision versus the
operator. Earlier evidence conditioning and context-preserving evidence need
separate matched protocols after this first gate. No OPD or target expansion.

## Primary-source checks

[TA-STVG, Figure2 and AppendixA](https://arxiv.org/html/2502.11168v1) describes
GT-box RoI pooling to generate decoder object queries, and reports36.4→49.9
m_vIoU on HCSTVG-v1. This is a different architecture and oracle intervention,
not a matched reference for frozen PTD residual masking.
[CG-STVG](https://arxiv.org/abs/2401.01578) describes appearance/motion instance
context generation and refinement; its abstract supports context relevance,
not a causal explanation for these particular PTD failures.
[Collaborative static/dynamic streams](https://openaccess.thecvf.com/content/CVPR2023/papers/Lin_Collaborative_Static_and_Dynamic_Vision-Language_Streams_for_Spatio-Temporal_Video_Grounding_CVPR_2023_paper.pdf)
is relevant background for complementary cues. None of these papers guarantees
that moving this same scalar mask before the reader will improve PTD.

## Completed source controls and a specific objective gap

The fixed30-step free-merger controls are completed and independently audited.
The temporal source improved native tIoU29.1667→68.0556%, sIoU37.3443→50.6994%
and vIoU18.6722→50.6994%; both endpoint targets are the final native argmax.
Reference tokens are unchanged. This establishes source-case temporal actuation,
not generalization or a useful learned adapter.

The spatial source's1001-class coordinate CE fell4.709064→.663528, but native
format failed at steps24..30. One coordinate slot emitted a non-coordinate token;
its temporal decisions and the11 native anchors remained exactly unchanged.
All three official tube metrics are zero on these format failures. That is the
existing whole-output validity policy, not a measured temporal-branch change.
The original spatial baseline was t/s/v20.1342/59.6550/19.8850%.

The first worker stopped because it confused parsed successful positions with
actual probe support. A separate recovery derived anchors from the real native
probe, kept malformed predictions, and reconstructed24 saved-gradient CUDA Adam
updates with exact before/after parameter hashes, actual deltas and counters.
Only the missing6 model-gradient steps were executed. The completed temporal
trial was hash-reused. Original failure and partial files are preserved.

The scientific issue is separate: official generation takes full-vocabulary
argmax, but1001-class CE excludes non-coordinate competitors. A new registered
single-factor control uses full-vocabulary CE at the same four coordinate
positions, same source/B1/free tensor/LR/fixed30steps. No structure loss, token
repair, prefix forcing, dtype change or best-step selection is introduced.
Its real GPU result is pending. A finite failure cannot prove interface or span
impossibility. The original both-branch gate for the span experiment is not yet
satisfied; no OPD or target experiment is qualified.

The three-source layer readback reproduced the old oracle's merger hashes.
