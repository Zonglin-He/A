# 弱证据尺度与保守回退

统一原型的支持/关联项各按置信度总和归一化，而保护项按时间长度归一化，可能消去整体证据强弱。只做一次事前冻结的CPU修正：用固定Strong时间上的八假设平均置信乘旧无保护奖励，保留原0.25保护项，全部新分数seal后离线读取GT。没有搜索系数，没有执行新轨迹或训练新OPD。

16条结果：9条选择零状态Source，m_vIoU17.19465仍低于SourceStrong18.40157；pair准确率0.46850、Spearman−0.12837。修正减轻原重排序损伤，但不是有效改进或OPD优势；置信启发式也不是概率。旧严重损伤并非仅靠置信权重即可解决。

只读幅度解释（scale_interpretation.json，来源两个预测seal）：所有策略分量中心系数L1平均0.15899，按奖励选出的策略中心平均0.32083；选中策略框相对Source的均值位移0.02085，而全起点Direct为0.05984（归一化cxcywh向量距离）。策略中心较保守，可能解释它相对Direct较少损伤；这是非因果的幅度诊断，不能归因于保留身份模式或探索能力。

## 当前结论和下一有界问题

接口和真实参数候选已验证，只有TubeDETR，不自动推广其他骨干。传播在GT矩形中有部分正向质量富集（观察/未观察置信加权约0.316/0.232），不能称完全没传播；但支持/关联轨迹排序均约44%，未达到有效候选评价。置信低、不同项尺度不齐、普通视觉特征的身份辨别能力未验证，均需要在奖励层处理，不能回到ASA/query模块或仅扩大OPD探索。

下一轮只做普通学生特征的前景/背景辨别资格：同16、同八教师区域、同21已执行轨迹，零新教师/学生适应。对比至多两个固定信号：原始视频特征的前景减背景原型余弦，以及按整个视频有效cell面积/真实时间加权去均值后的相同余弦。原型只由教师区域与其补区域构造，留一观察交叉检查避免自身模板匹配，不把补区域或GT矩形中的点冒充真实像素身份。无新学习网络、无温度/正则搜索。先冻结具体实现/预算/父seal，完整支持与候选分数封存后独立CPU评价；实际Source特征若需重建，最多同16原生Source调用并缓存以复用，不能新增专家或改样本。

资格必须在同21实际候选的定位排序和oracle regret上改善原全轨迹奖励，且按新信号选择不低于SourceStrong；否则不进行新策略/Direct训练。若仅增加保守回退，也不能称方法有效。该下一阶段尚未实现/冻结/运行，不自动执行全量或恢复旧HC/空间调参。Direct后续必须同证据、同参数子空间、包含全部候选起点及充分相同调参机会；不以当前未调参两步的差值宣称优势。
