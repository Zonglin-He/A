## 奖励实现边界

同一帧特征图F上，对学生框和教师框分别取3×3有序网格，每行L2归一化，再平均九个对应位置的余弦。特征和教师模板冻结；OPD的候选与目标停止梯度，仅候选概率更新学生；Direct保留学生框到采样坐标的梯度。

实现前先依据官方源码固定一处特征层/尺度、原图到有效特征区域的坐标变换、padding、边界外候选与近零特征的处理，并写入独立试验配置；不依据GT结果选择层或候选有效性。保留既有越界候选规则，不用零填充值制造高奖励。

旧几何温度与余弦奖励量纲不同，不能将旧数值称为已适配的新配置。初轮应预登记一个明确的布局温度；如做温度校准，只使用上述开发集与预登记有限集合，所有结果保留，不使用正式划分选择。学习率/步数先以各数据集现有配置作为起点，未授权无限参数搜索。

现有正式缓存不含教师F及完整学生decoder输入。先盘点已保存开发缓存，完整匹配的视觉输入和证据可复用；缺失部分才补导出。特征导出仍用同一模型、同一八帧，分别计入实际Source和ReferDINO成本，不把它描述成零专家计算。
