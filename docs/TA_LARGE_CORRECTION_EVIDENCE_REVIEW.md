# 大幅 temporal correction：边界证据审计

已有缓存信号含部分大幅修改的排序信息，但未建立可安全替换A8的共同证据。冻结native在Vid拒绝全部有益大幅修改；UVTG边界密度与两视图稳健性仍大量接受有害修改，HC全流负收益区间低于零。

固定前一轮 A8 / Expanded32、A 空间轨迹、Uniform 持久更新和专家到达位置。两集各32开发＋16确认来源，一query/source、两序、clean＋五类5% corruption、25%专家；1,152到达、288专家（240corrupt、48clean），864非专家仍是原A。来源全部历史曝光，本轮是机制开发诊断，不是fresh test或新方法全量评估。

## 实际信号与证据边界

- **N：冻结 TA 原生起止先验。** 同输入的source-checkpoint两offset各自softmax后等质量交织，候选分数为起止log概率之和。在线日志没有完整A-current logits；N不能冒充它。cross-offset边界配对也不是TA原生envelope的联合概率。
- **U：UVTG proposal边界密度。** 全proposal等质量Gaussian起止边界密度，固定带宽0.5秒；无confidence、无interval-IoU配对、无PE语义曲线。边缘分布仍可能组合不兼容的两端。
- **S：两视图边界密度稳健性。** 用已缓存phase0/.25秒真实采样，取同一A8相对总分增量的两视图最小值。它是同模型的稳健性诊断，不是独立专家或定位正确保证；旧T使用confidence×IoU，此处只使用边界密度。

所有分数、几何分组和选择先seal，才关联已公开的逐候选dense GT指标；没有新增GT标注读取、模型调用、专家调用、backbone或decoder replay。确认结果不参与选择规则。

冻结源native与A的pre-Fast native一致 288/288，与最终A8一致 11/288；真实采样位置发生变化 288/288。

三类信号在相同支持上用同一预锁读出：只有唯一最高分且严格优于原A8才替换；任何top tie或无增量都保留A8。不按GT调阈值、带宽或组合权重。

## 决策与限制

N在Vid确认全流为+0.1715pp [-0.0567,0.4528]，没有稳定增益；开发为-1.2218pp。其大幅修改TP=0、FP=11，实际没有选择大幅修改，不能补主要新增容量。此结论限定冻结source起止边缘先验，不替代A-current/joint span检验。
HC的N大幅候选接受为9个TP/0个FP，全部来自source47；条件precision=1不能外推安全性。32候选最终选择只采用2次有益大幅修改，同时21次小幅修改受损；全流-0.3887pp区间跨零。
U在Vid确认large benefit/harm AUC=.7092 [.5772,.8347]，S=.7157 [.5823,.8366]，但有益precision仅10.31%/10.75%；候选内排序与相对anchor的正值认证不是同一能力。四组的候选/类别构成相同，AUC不存在跨支持pair population混淆，但仍是有条件的探索性统计。
U/S在HC确认全流分别-2.7536pp [-5.7064,-0.4106] / -2.2134pp [-4.2095,-0.5847]。两视图降低部分有害候选接受率，没有消除共享误判；large top1均6次改善、32次损害。
Vid large trim-start的U/S条件AUC=1，但只在5个有双类别到达上定义；有益precision仅3.90%/5.88%。HC large trim-start没有任何有益候选，AUC未定义，不能据此证明该类修正不可行。
保留A，暂不接入本次N/U/S读出、不启动小半径refiner、PE变体、额外expert或旧队列。现有UVTG proposal边缘密度和同专家双视图不足以授权大胆改边界；这不否定完整joint temporal evidence、A-current概率或另一独立专家的未来验证。

本轮三信号是预锁的探索性机制测试，未作多重比较校正；来源少、共享专家错误、候选重复、缺少current-state logits和边缘密度可能配出不存在的span，均限制外推。相关性或某个均值正向不等于一个已验证的安全selector。本轮不晋升A、不启动额外expert/局部refiner/历史队列。

独立公开审计通过：339492标量检查、1728选择、9216候选几何；最大数值差 3.55e-15。7个CPU边界测试通过。
