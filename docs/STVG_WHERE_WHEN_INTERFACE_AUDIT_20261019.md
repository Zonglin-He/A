# ReferDINO WHERE → WHEN 接口审计与有限验证方案

日期：2026-10-19。状态：只读代码、缓存及原文核对完成；以下能力实验尚未实施。

## 本轮范围与结论

问题是已有空间轨迹能否帮助同一对象的事件判断，进而改善时间区间。保持冻结空间配置、现有 ReferDINO 权重及八个物理位置；不追加专家、训练网络、修改空间参数或宣称完成时间 OPD。本轮没有模型前向、状态更新、新 GT 读取或新评分。

当前可确认存在逐帧逐 token 的语义读出位置，但旧缓存不含这些信息。还需区分两个接口：学生轨迹帮助从已有教师对象中选择对象，与学生区域改变教师实际读取的视觉语义。前者可以利用原生全部对象输出实现；后者不是原生输出自动提供的能力，也不应自动恢复已经失败的 reference 条件化路线。

空间版本保持封存。最新 RF32 Live−E 完整 vIoU −0.867175 pp、八观察外实际节点 sIoU −0.909300 pp，两个区间跨零；不能称适应后轨迹已稳定改善。Source→E、E→Live 是不同空间干预，必须分别报告。旧 finalMBR 继续作为固定对照，不确认为最终通用时间方法。

## 核验到的源码事实

- `external/ReferDINO/models/GroundingDINO/groundingdino.py:655–684`：对象先按 memory/Hungarian 关联，再经 `temporal_decoder[nl]` 跨帧融合；随后 `class_embed[nl](hs, text_dict)` 仍返回逐对象、逐 token 匹配，下一句取 token 最大值。
- `models/GroundingDINO/utils.py:238–276`：上述匹配是对象与增强文本特征的点积，按文本有效 mask 填负无穷，再补齐至 256 token。不是动作分类器、事件概率或经过校准的置信度。
- `models/GroundingDINO/temporal_modules.py`：时间 self-attention、文本代理 cross-attention 和残差保留各帧输出；不是把单个全局分数复制到八帧。不过，全上下文融合后的某帧响应不等于该帧独立的因果事件证据。
- `groundingdino.py:539–607` 与现有 wrapper：caption 先 lower/合并空白，再补句号，BERT tokenization 与截断。词组 span 必须映射到这份实际输入的子词；不能直接用原始字符偏移。padding、CLS/SEP、标点与事件词应明确区分，原生置信度对照仍保持原公式。
- `methods/stvg_referdino_opd_v1/experts.py:37–39`：保存选中对象八帧框、八帧单类分数、各对象时间平均分数及 mask 汇总；没有保存对象／文本内容张量或 token logits。
- `vg_tta/stvg_referdino_condition_hc128_v1.py` 另存全部对象框、归约后 logits、关联 lineage 与内容哈希。哈希不能还原内容特征。

缓存审计见 [逐文件收据与源代码 pins](../artifacts/stvg_where_when_readonly_v1/CACHE_INTERFACE_AUDIT.json)：128 份 RC teacher0 及 32 份 RF 原生输入，共 160 文件 SHA256 与相邻收据一致；全部 native selected_frame_scores 为 `[8,1]`，RC 全对象 logits 为 `[8,15,1]`。检查范围限这些缓存和对应保存代码，不声称扫描了全项目所有历史文件。未加载权重、媒体或标签，CUDA 未初始化。

## 原文依据与任务边界

[ReferDINO 原文](https://arxiv.org/html/2501.14607v2) 的时间增强模块和推理规则支持上述实现读法：使用时变文本表示与跨帧对象特征，按时间平均分类分数选对象序列。它证明该表征用于 RVOS 有效，没有证明动作 token 可以直接定位事件边界。

[Temporal Grounding as a Learning Signal for Referring Video Object Segmentation](https://arxiv.org/abs/2508.11955) 指出可见目标监督与描述实际相关时段之间存在语义错配，并引入人工时间标注及训练框架。这里只引用任务差异，不引入其标注、训练或新模型。

## 对 WHERE → WHEN 的可识别性修正

设同一视频、原文和八帧的原生教师输出为对象轨迹 `B_j` 与逐 token 分数 `L[t,j,l]`。如果两份学生轨迹都关联到同一个固定 `j`，且不重新读取区域，那么 `L[:,j,:]` 完全相同。动作词读出与候选集合也固定时，其时间结果必须相同；不得把这种设计当成已经检验了区域条件语义读取。

若 `j(B_before) != j(B_after)`，反馈可能改善，但机制首先是对象选择改善。它仍可成为空间帮助时间的有效路径；必须报告对象切换、对应关系及误配损伤，不能写成同一对象的语义响应被学生更新增强。固定一个全视频 track index，禁止逐帧任意换 query 再拼出人为事件曲线。固定 track index 也不保证物理身份绝对正确，原生关联仍可能换人。

第一阶段只检验这个较窄、可实现的轨迹关联读出接口。若原生对象选择不变且无输入依赖，记录为该接口没有可用的 WHERE 变化；不将其扩大为所有空间帮助时间机制失败，不自动再加 reference 注入、裁剪或新模块。

## 一次能力验证应包含的对照和输出

以下为提案，未启动、无新的资源授权或正式名单锁：

1. 以完整 RC128 暴露开发父视频为候选集合，沿用原八帧、原文本、原生固定 teacher、当前空间配置。使用既有 E 和实际保存的冻结 Live 三种子轨迹，不能按 GT 留下改善样本。RC128 不是确认集；RH32/RF32 也已有方法开发／评价曝光，不重新标为独立确认。
2. 仅为补存语义中间量，计划在每个视频相同八帧运行一次冻结 ReferDINO；同时保存所有 tracked query 的框、pre-max logits、文本有效 mask、实际 token IDs／字符对应、physical timestamps、最终 query index 与关联 lineage。适应前后两种轨迹共用同一份语义缓存，不各重编码一次。补存属于真实新增专家计算，须计成本；不新增观察位置或权重。此步骤尚未执行。
3. 补存必须核对 `max(premax, token)` 精确恢复原生 logits；同输入的原生选中框与分数保持原数值行为。所有 layers 的共享 class_embed 可能多次调用，须确认捕获的是最后空间层、时间融合后那次，不能仅依靠模块名。
4. 动作／关系词组以已有依存解析和固定规则提取，包含必要介词、否定、助词与状态描述，不只取孤立动词。无明确事件词、分词截断或关系角色歧义要标记为 unknown，全部父视频保留。不得看 GT 后挑词；不额外调用语言模型。具体词组聚合／区间评分规则须在评分前固定，当前不把尚未选择的公式冒充已冻结配置。
5. 三个主对照：原生选中 track 的原生置信度；事件词读出＋E 关联 track；相同事件词读出＋冻结 Live 关联 track。对象关联使用同一无 GT 的全轨迹规则，例如八位置平均框 IoU 最大且 query index 打破平局；记录匹配质量、切换及低支持，不用 GT 回退。另将 native track 上的事件词读出作为可复用的归因列，区分改读出和改对象。
6. 区间候选共同覆盖整个物理视频，包含初始 MBR；不能只围绕 MBR 微调，以免没有大边界修正能力。稀疏区间如果在八位置证据上不可区分，显式报告分辨率限制，不插值伪造独立语义观测。候选、聚合、读出和无支持返回初始区间规则须在新评分前封存。
7. 先封存全部响应、关联、排序与区间，再进行离线 GT 检查：父视频内事件内外排序、共同候选的区间质量排序、tIoU、完整 vIoU、负尾和成本。事件内／外至少各有一个真实观察位置才可定义其区分统计；不足时记 unknown，完整主评价仍保留全部父视频。不因空间退化、无事件词、零时间交集或低教师分数删除父视频。
8. 将“目标可见、事件不成立”单独列为关键负例，但没有事件外框标注时不能从缺失 GT 框推断目标不可见，也不能用 teacher 高分循环定义其确实可见。可用既存且明确标注的样本；若不存在，披露这一真值缺口，不新增人工标注并冒充已有标签。
9. 时间归因使用相同固定空间轨迹比较新旧区间的 tIoU／完整 vIoU；联合效果另外用适应后空间轨迹评估。否则 `v(B_after,I_after)−v(B_before,I_before)` 混合空间与时间两项，无法证明 WHERE → WHEN。全部三种子先父内汇总，再按父视频配对，不把种子或八帧当独立父视频。

这是一项能力检查，不以直接选区间失败宣称 OPD 失败。若候选排序有可重复信息、但直接读出无增量，应记录反馈质量与读出限制；不能只凭直接读出决定所有分布蒸馏不成立。相反，只有目标置信度变化、没有正确事件偏好，也不支持启动时间 OPD。

## 后续路线和退出边界

- 新读出对事件排序无可复现信息：停止该 token 反馈配置，不用温度／局部参数扫描维持它；结论限此配置和稀疏支持。
- 事件词读出有效、E 与 Live 相同：是新的时间反馈证据，不是空间适应促进时间的证据。是否继续需单独衡量其容量，不能凭“teacher 可以评价区间”声称 on-policy 必需。
- Live 关联的事件偏好与时间结果更好，且不是损伤／覆盖筛选：支持轨迹关联路径的 WHERE → WHEN；仍需未参与选择的父视频确认，不预先宣称 2–3 pp。
- 只有锚点／区分 AUC 改善而时间或完整 tube 没有收益：报告可用信号与尚未兑现的传播／读出问题，不晋升方法。
- 进入时间 OPD 时采用 `(V,Q,timestamped_boxes,initial_interval) -> interval` 插件输入输出。区间 policy 可为逐视频临时状态；Live 每轮当前候选与 Fixed 同预算反馈比较，另保留相同信息的直接读出。不把相同固定曲线在不同区间求和包装成教师重新观察，不把 ordinary KL 仅改名为 OPD。

当前 spatial content 状态仍依赖 TA-STVG decoder；时间插件可解耦其 offset／query 结构，但本轮没有建立整套方法跨 backbone 无需修改的结论。研究／生产登记和冻结 predictor/config 均不修改；本审计不是新模型实验或新部署成绩。
