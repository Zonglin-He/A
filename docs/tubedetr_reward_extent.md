# 目标范围失配：离线原因分解与下一有限阶段

独立CPU诊断固定原Vid128/同32候选，完整奖励seal后才读GT；Geometry/Layout3/MaskDice/MaskContrast/TransportDice的regret逐位聚合回归误差小于1e-12。完整结果见../results/tubedetr_reward_extent/report.md。102条至少有一个可评价观测，另26条八位置无GT事件，不能评价观测框收益。

全102条：几何与MaskDice选框的GT矩形覆盖率为61.23%/57.89%，框内精度56.93%/58.68%。61条教师比Source更好时，MaskDice面积小于GT框的比例53.59%（几何32.71%），覆盖65.37%（71.99%），IoU50.33%（54.92%）。41条教师不更好时MaskDice和Transport反而比几何略好；不能说全部失败都来自坏教师。分组仅诊断，不用于GT门控或样本选择。

数学反例：STVG评价外接矩形，mask支持只覆盖可见前景。即使mask完美，两块相距较远、合计面积0.2的可见区域，其GT外接矩形面积1，整个框的mask Dice=0.4/1.2=0.333；仅框住面积0.1的一块可得到0.2/0.3=0.667，而矩形IoU=0.1。因此mask Dice最大化不保证矩形范围准确。此反例证明目标并非等价，不证明本面板所有损伤均由此导致。

跨帧报告的80.85%是GT矩形包含关系，不是像素级身份GT；背景也可在矩形内，必须避免过度解释。平均观测间隔108.8原始帧、62/1024支持为空提示稀疏证据限制，尚没有间隔与损伤的因果证明。

## 已授权下一有限研究的决策

下一轮只检验“用内容分布约束四条边的目标范围，比区域Dice更适配矩形定位”这个具体假设，先资格、后适应，不无界换奖励。拟检查至多两个同功能信号：原生软mask和已封存跨帧支持各自的边界CDF奖励。对左右上下四边计算一维边际质量CDF，与固定2.5%/97.5%质量位置比较；不取GT框、不混入L1/GIoU、不对候选硬化或detach，保留连续CDF框梯度给Direct。固定分位值是未验证的鲁棒范围假设，不能称最优，也不能因结果不好而任意搜索。

它检验完整范围而非局部纯度，但仍可能被错误mask、背景质量和事件漏观测破坏，也仍可能不如Direct。实现后必须先加有效图像padding、边界积分、Direct有限差分、全零支持与越界行为检查，再冻结代码hash/完整预算/父seal。只复用同Vid128/同32候选，0新教师、0适应和参数搜索；报告几何/布局/区域Dice/CDF的排序与regret，以及本离线分解的覆盖/范围指标。事前门槛仍是排序和regret均不劣几何且至少一项改善。未通过不执行适应，不凭novelty要求晋升。

通过后才单独冻结有限的同奖励OPD/Direct验证：同初始化、同临时状态、同证据、同预算和相同合理调参机会；Direct不能被人为硬化、删梯度或限制到劣势配置。采样是否在真实有限步、自然弱梯度区域有优势，要由输出与梯度诊断和公平比较决定，不是由“奖励复杂”推导。不得自动新全量，不恢复旧HC/空间数值调参。

本文件是下一轮可执行研究决策，不是已实现/已冻结CDF代码或已经获得新奖励结果；执行时必须先绑定实现及计划，保留全部正负结果。
