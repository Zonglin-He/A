# 历史时间适应审计：失败机制、可复用证据与当前接口

日期：2026-10-22。范围：TA-STVG 历史时间适应与当前 BoxFixed＋Global6。
本轮为只读研究审计，不是新实验。没有模型/头部前向、反向、优化器步骤、新专家调用、RGB解码或新GT评分；没有改运行队列、参数、缓存格式或冻结源码。

## 判断与证据等级

**旧时间适应并非全部无效。** 已有结果分别涉及：更换解码器损失原生起点、伪标签不可靠、把排序分数当成校准分布、参数更新没有充分实现直接读出收益、小开发集结论不扩展，以及旧协议无法直接迁移。它们不能归为同一原因。

- **A：本轮重核**——实际读取 Git 保存的源码/逐条公开标量，重新核对聚合或核查当前缓存结构。标量重算不是原模型反传重演，也不是重新证明原评分器正确。
- **B：保留报告/总档案**——原报告或历史审计记录可读，但原私有张量、完整receipt目录当前不在工作目录；仅保留当时报告的结论，不能声称本轮重放了原实验。
- **C：假设或下一项验证**——尚无匹配当前设置的因果证据。

本轮从17个历史Git对象保存了私有证据副本，对256条四臂记录、128父来源Raw反馈记录、768条T2/T4记录重算1118个标量恒等式，最大误差2.22e-16。
见[聚合重核](../results/temporal_adaptation_audit_v1/SAVED_SCALAR_AUDIT.json)、[来源与范围](../results/temporal_adaptation_audit_v1/PROVENANCE.json)、[独立重算入口](../results/temporal_adaptation_audit_v1/recompute_saved_scalars.py)。不重复生成GT指标或bootstrap区间。

## 2. 原生信号诊断：事件相关性不等于可校准教师

**证据等级B（早期诊断），A（后续Raw反馈公开标量）。** 早期native-evidence用严格合法双offset和原物理时间恢复了48/48原生区间；一些帧级AUROC提升没有超过uniform合法区间产生的位置先验。Vid native-envelope AUROC .6917，uniform .7263；target−random擦除AUROC差区间跨零。不能以 pooled AUROC 或固定.5工作点证明可靠事件语义。

后续HC128 Raw前景信息诊断确实有视频特异排序信号：Action AUROC .8091，同节点长度候选正确率 .7571；但转换成指数区间教师后：

|---|---:|---:|
| Native | 27.9285 | 0 |
| TeacherDirect | 24.4934 | −3.4351 |
| DirectJoint | 25.4749 | −2.4536 |
| DirectConditional | 25.5874 | −2.3411 |
| Fixed | 24.1965 | −3.7319 |
| Live | 25.3406 | −2.5878 |

本轮从128父记录重算均值、配对seed平均及尾部：Live41正/74负/13平，34父完整v下降超过5pp。原独立候选质量审计还记录教师期望v较原分布下降2.8297pp。**连直接使用教师和候选期望都更差，故主要证据首先指向反馈构造，不是优化器能力不足或只有hard解码出了问题。** Live比Fixed减损1.1441pp，不能改写成相对Native的正效用。

一个可复用的代数解释：Bernoulli区间内外对数能量中，`log sigmoid(z)−log sigmoid(−z)=z`；统一偏置会添加与区间覆盖长度相关的项。帧排序保持不变，不意味着跨长度区间分布、校准或最终MBR保持不变。**排序信息、概率质量和最终决策必须分别验证。** 这不是“所有前景证据不可靠”的定理。

用户已明确不要把actionness作为新通用算法的依据。本段审计历史信号，不授权恢复它作为当前教师，也不更名规避这一约束。

## 3. 66,306参数结构化时间头：有过正效用，不能说路线已失败

**源码A，旧全量与Current/NLL统计B。** `TemporalReplay`复制原`temp_embed`，固定decoder hidden，逐查询fresh AdamW；头部为256→256→2两层MLP，总参数66306，eval关闭dropout。旧方法使用原生内部前景投影出合法目标区间，NLL＋margin拟合，最后将实际参数位移乘.25后重新通过头读出。空间框固定，时间更新不自动改变空间decoder。

旧全量使用HC1的1159可用查询/58父、Vid10303/732，父等权；报告temporal-only相对Frozen完整v约+1.670/+0.393pp，t约+3.251/+1.206pp。它说明该固定旧设置存在正收益，不是当前HC2协议下的复现，也不能把其参数直接套入现有方法。

更有约束力的历史规模验证：NLL-only相对NLL＋hinge，在旧32开发来源有+2.2776pp完整v，但排除该32后的主700为−.0030pp，95%CI[−.3506,+.3423]；t为+.1216pp且区间跨零。202正/207负/291平，正负大例相抵。它支持“这次简化的开发优势未规模复现”，**不支持“所有时间头适应无用”或“hinge普遍保护原生正确预测”。** 两臂伪标签相同，这个试验也不能证明伪标签本身可靠。

可复用：真实参数回插/no-op、最后状态与best状态区分、参数与optimizer重置、原尺度与收缩后尺度分别记账、Native-good保持和严重尾损、大面板验证。不能直接迁移：旧内部前景监督、域特定center/LR、HC1成员/父等权结果、不同原生MAP/envelope读出。

原已公开匿名例保留了相反机制机会：Q14/frame_drop10的Frozen/Rerank/OPD完整v为0/29.022/0%，有效直接纠正没有经一步更新兑现；Q09/frame_drop5为5.175/4.616/18.039%，OPD反而超过教师直接选择；Q10/frame_drop10的Rerank将28.014降至16.892%，OPD为28.421%。这些是固定旧运行的事后案例，不用于挑选当前参数，也不作为新的独立样本。

该支使用UniversalVTG/PE等旧外部时间教师、更新motion hidden；既不同于当前66k头，也不是当前只用一个ReferDINO的允许信息源。复用实验逻辑和成功/损伤案例，不能把旧教师预测当作当前合法免费反馈。

## 5. Caption/Query Temporal-Lite：保留正结果，先扣除投影收益

**A级重算768行，B级保留八例/role报告。** 同128父/域曝光开发，固定空间时T4相对Frozen：HC完整v+4.6420pp、t+9.4957pp；Vid完整v+.4851pp、t+1.2283pp。T2与T4均值接近，但既定−.2pp非劣下界条件未通过，不能说二者已等价。

关键实现事实：T2构造候选时已调用旧前景`project`，512参数L-BFGS共享候选KL＋全网格trust的无反馈回退也是`Projection_interval`。**零参数更新起点不是当前Native/Global6。** 所以T−Frozen并不全是Caption监督或蒸馏的贡献。八例报告中，直接Projection已占相当收益：HC v22.210→27.851，T31.286；Vid14.490→22.016，T22.442。小面板正值不替代全量或未曝光验证。

角色对齐另一轮将共同有效18个问题的候选排序从56.94%提高到65.28%，但完整28问题v相对旧prompt−.0622pp。改善条件排序不保证完整输出收益；候选支持、未知反馈、原生起点、有限拟合与时间区间内空间质量仍需区分。

复用：物理时间映射、缺失反馈回退、共同机会集、Projection-only/no-update、完整网格保护、反事实query控制；不复用旧R1 caption服务、8×448视图成本或前景project伪装成新监督。没有将该轮不同B空间确认失败扩大为“Temporal-Lite整体没有正收益”。

## 6. DSE-VTG / T3AL：需要保留的配套条件

未找到本地同名完整复现的运行收据；不能把相似关键词等同于复现。两篇原文的接口还存在区别：

- [DSE-VTG原文3.3–3.6](https://arxiv.org/html/2609.08850v1)在对齐VLM语义空间中，用逐帧/片段特征和query embedding构造相似度，只适应query offset；保留原始与适应query共同生成候选。多粒度、归一化、正负伪标签、保留原query和结构化读出都是条件，不是只抄一个query delta。原文有min-max分数作为logits的特殊约定，不能静默改成任意温度cosine后宣称同实现。
- [T3AL原文4节](https://arxiv.org/html/2404.05426v1)及[官方仓库](https://github.com/benedettaliberatori/T3AL)依赖预训练VLM的视觉/语言投影、视频级动作伪标签、自监督细化和caption区域抑制，并按视频重置。它的动作分类设定并不等于任意STVG指代表述。

**当前TA的RoBERTa、融合hidden、空间ROI特征与原生时间query均为256维，不证明它们处于可直接cosine比较的共享语义空间。** 在现有向量上加delta并最大化余弦，会新增未经验证的反馈假设；仅凭形状兼容不构成合法迁移。原文的其他VLM或caption也不能自动加入当前单ReferDINO约束。

## 7. 实际缓存与当前分支能否接入

本轮对4个缓存族各一个按文件名确定的已完成样本进行CPU/meta结构检查；未执行其中网络。结合保存器源码确认字段，详见[CACHE_INTERFACE](../results/temporal_adaptation_audit_v1/CACHE_INTERFACE.json)。这不是对所有历史缓存逐文件兼容的证明。

| 接口 | 当前保存状态 | 可复用程度 |
|---|---|---|
| 全量paper compact capture | Source/E、物理记录、六层两offset logits、完整传播几何；**无hidden/前景头输入** | 能分析后验、候选、支持与路径；不能从logits反演66k头输入 |
| v4等时间开发compact cache | 六层logits与简化几何 | 输出层读出分析；不是时间头适应缓存 |
| 旧HC64 native replay cache | 两offset真实decoder kwargs、六层hidden[6,1,33/32,256]、native logits、来源 | 有限面板具备未来头部验证的必要输入；尚未在本轮新执行任何头 |
| TTS适应所需pre-MLP特征 | 所检查当前缓存未存 | 不能用geometry.features[T,3,256]替换；后者是空间候选汇聚特征 |
| DSE/T3AL对齐帧/clip/text特征 | 当前缓存未证明具有该语义/接口 | 不具备直接复制原损失的依据 |

同一个66k`temp_embed`在结构上仍存在，这是**接口可接**；伪标签来自哪里、Native零状态是否精确、预处理/权重/网格/采样是否相同是**科学可接**，两者不同。当前Global6会应用同一个头到六层hidden；若仅按末层训练后仍读六层，其他层会被共同改变。只保存末层拟合/检查不足以证明Global6兼容。原物理MBR与旧per-offset MAP→envelope也须区分。

当前时间→空间作用位于`geometry.for_interval`和DP：区间控制可采用的传播位置、单帧项计数及事件内连边；不改变已生成的候选几何。时间后验改善不能自动推断未观测空间改善，须在同固定评价支持上检查Full−NativeTemporal。HC现有该差为未观测s+.0495pp，CI[−.0310,+.1316]，完整v−.0550pp，CI跨0；不能为了新故事包装成已验证促进传播。

## 8. 按严重程度排列的障碍与最小下一步

| 优先级 | 障碍 | 本轮证据 | 处理 |
|---|---|---|---|
| 1 | 没有经证明可靠、且满足当前通用性约束的纠错监督 | Raw直接/期望均负；TTS门控与confidence同输出；现有支持表示目标存在不等于事件 | 不先移植优化器；先审计候选反馈是否提供可执行纠错信息 |
| 2 | 更换原生起点/读出引入伪适应增量 | TTS冻结新decoder更差；Temporal-Lite空反馈从Projection起跑 | 必须精确no-op；Native/Projection/直接反馈/真实适应分列 |
| 3 | 信息收益未通过更新兑现 | 四臂Rerank明显强于Hard/OPD，loss全下降 | 不能把增加步数当原因结论；同信息直接使用是必要参照 |
| 4 | 当前缓存和更新位置不匹配 | 全量compact无hidden，旧HC64保留hidden但无TTS pre-head | 仅用旧64面板做后续接入资格，不为审计重跑全量 |
| 5 | 共享六层头/物理读出/参数尺度迁移 | 旧只读末层、5步AdamW和.25收缩；现有六层＋MBR | 当前输出与全六层影响须一起验证，不直接搬LR |
| 6 | 开发效应与协议不等价 | NLL旧32优势主700消失；HC1/父宏/旧专家不同 | 不拼旧汇总进新主表，不将旧曝光改称独立确认 |

**本轮决定：不直接接回TTS/内部前景投影、旧R1/UniversalVTG或Raw指数OPD，也不复制未对齐的query-cosine损失。** 可复用的是原生保护、明确的中间监督检验、直接读出与适应分离、真实参数回插合同，以及旧HC64的有限hidden缓存。

一项最小后续验证的设计（**本轮未运行，也不自动排队**）：在现有HC64完整hidden缓存上，先做固定原生头的全六层零态恢复与候选反馈审计；反馈必须来自同一允许证据、在接入前证明有别于原预测复制，且不能用GT选择。若没有这种反馈，停止在接口层，不继续调学习率；若存在，再单独锁定直接使用同反馈/同预算66k头/原生不更新三臂，并固定空间支持。不要同时更换解码器、反馈和更新位置。原样本已曝光，结果只能称开发。

在当前约束下，**已经有可以复用的工程接口与反例，但还没有被现有缓存证明可靠的新通用时间教师**。不能承诺接上旧适应就能弥补HC时间缺口。本轮只完成审计，主全量继续原指纹、原代码、原参数；不改变论文主线或生产注册。
