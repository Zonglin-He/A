# Archive and single-method policy

Maintained root: stvg-native2d. Only Native2D is registered and runnable through the project main entry. Upstream original TA-STVG/ReferDINO dependencies are retained because the frozen Source/evidence require them; their architecture is not a project alternative method.

All prior method code, original experiments, signed positive/negative results and frozen full receipts remain in Git ancestors and [archive/research-pre-native2d-20261023](https://github.com/Zonglin-He/A/tree/archive/research-pre-native2d-20261023). The native2d calibration source is reproducible from that archived tree under studies/native2d_risk_v1. Current main retains its exact protocol, source hashes and all calibration outcomes. Earlier archive refs pre-general, pre-k16 and pre-mainline are also preserved. No history rewrite.

Locally stvg-general/fusedHC401, stvg-k16/HC320, stvg-mainline/paperHC1902Vid1373 remain paused immutable evidence, and stvg-opd original full remains complete_published. Never resume them automatically or alter bound files. New full owns its own Native2D fingerprint and compatible reuse index. Fused pooled features are incompatible; only same-input Source/E/eight observations/geometry may be reused. Native2D pooled features are reused only with exact input/model/hash binding.

Run tools/archive.py check, then snapshot after intentional source changes, then check. Independent public commits use freshCAS main+research and verify every remote file byte/SHA, full tree and archive ancestors. Whole-domain seal precedes independent CPU official labels. Keep all severe harms and historical exposure; resource decisions do not retroactively pass failed scientific criteria.
