## 固定视图和读出

1. 使用不受预测事件区间截断的原全时间轴辅助BoxFixed轨迹。其完整框的外包范围按中心宽高各扩张1.5倍，取一个全视频固定的整数像素窗口。先向外取整，再在图像边界内平移保持可容纳尺寸，超过图像尺寸时截到全图。对所有外观/运动输入帧使用同一个窗口，不逐帧跟随。非法轨迹/非恒定图像尺寸必须记录并停止核查，不能跳query。
2. 从原始RGB裁剪，沿用原224预处理的固定高度224、宽度上限1.4倍高度、插值和归一化规则，不把已有224图像放大；核代码后纠正原“短边224”表述，“局部224”并非强制224×224，也不能假设任意比例保持。保存实际输入宽高、像素数、裁剪面积和目标有效尺度。若窗口接近全画面也保留，不能用GT选择或删除这类样本。
3. 偏移对照保持相同整数窗口宽高和跨帧稳定性。在同尺寸窗口的四个合法图像角落位置中，固定选择距真实窗口中心最远的位置，平局按固定坐标字典序。只用预测几何，不能用GT找“最错误”位置；若全图/对称导致相同窗口，如实记录。报告与真实窗口及预测目标的重叠，不能默认偏移窗口不含目标。
4. 局部视图仅offset0，保持原物理时间范围、帧号、采样、文本、权重和精度。重算原生完整流程，沿用必要的两遍时间解码，不插入ROI query或新头，不读actionness作为奖励/门控。offset0是事前选择，不依据448补采结果改选offset。
5. 局部末层区间后验映射到与Global6相同的原物理轴；固定0.5/0.5融合、原MBR，再执行一次原interval BoxFixed。空间最终输出取原空间候选，不用裁剪分支的框替换。只有这一轮反馈，不迭代裁剪。
