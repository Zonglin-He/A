# 负证据保留分布：当前写入、单次迁移与残差生命周期

本轮已完成两个数据集的288个同A更新前专家位置、288个下一非专家位置隔离迁移，以及独立1,152到达的reset-query-residual在线对照。全部预测和收据封存之后才读取GT。结论是：**固定λ=1的这版负证据目标没有建立相对原Rank的双数据集收益；清零query residual也没有建立稳定确认收益。保留原A，不晋升本轮配置。**

新目标有一个可验证的数学性质：没有相对反驳证据的候选，在teacher构造中保留原有相对odds。但这不保证候选GT正确、不保证共享参数更新后odds不变，也不保证未观察帧没有损害。本轮数值审计通过，任务结果仍不支持接入。

## 实际配置与比较口径

每数据集32个开发来源、16个来源互斥确认来源，每源一条query、两个顺序、clean和五种5% corruption；合计96条query、1,152到达。确认来源有历史曝光，不能称为fresh test。25%的位置调用既有专家缓存；当前专家corrupt确认子集分别只有Vid 8个和HC 7个独立来源、各40个cell。

TA-STVG官方同域EMA checkpoint、原Paper48像素和采样、原Uniform Sa2VA证据、固定source半径ρ=.05、四方向九probe与1,792空间参数不变。Vid参数包为lr=.033761698432507946、teacher temperature=.34902548789596055、K1；HC为lr=.006097133675874025、temperature=1、K8。学生温度1。每K步刷新学生候选，专家证据缓存复用。

四个同前态臂：原Rank；仅互换lr/temperature/K整包的Rank；fullclip几何分布上的负证据目标；同观察帧几何分布上的负证据目标。交叉参数包仍使用本数据集的L1/GIoU系数，不隔离单个超参数因果。

逐有效观察帧定义e=max(IoU(center,expert)−IoU(candidate,expert),0)。global先逐帧取正部再平均；local逐观察帧构造q∝p0 exp(−e)，λ=1固定。target、anchor与候选在每步detach；空证据/全零证据显式no-op。没有按结果改变λ、来源、步数或方法。

当前专家位置只比较更新后空间反事实，时间区间固定为原A。原A正式输出在write之前封存，所以这些当前反事实增减不能当作新的prequential全流方法收益。下一非专家位置只继承当前这一次write，结束后丢弃；它也不是新的负证据长期轨迹。另一个reset-u实验才实际执行完整在线流，使用原Rank，不与负证据loss捆绑。

## 确认结果

以下均为corruption，source宏平均、10,000次来源配对bootstrap，seed=20261004，单位vIoU百分点。

| 对照 | Vid确认 ΔvIoU [95% CI] | HC确认 ΔvIoU [95% CI] |
|---|---:|---:|
| 当前负证据global − 原Rank | −1.3049 [−2.5143, −0.1681] | −0.6810 [−2.3008, +0.5480] |
| 当前负证据local − 原Rank | −1.3044 [−2.5137, −0.1677] | −0.6418 [−2.2986, +0.6509] |
| 当前local − global | +0.0004 [+0.0001, +0.0008] | +0.0392 [−0.0003, +0.1167] |
| 当前互换参数包Rank − 原Rank | −0.6734 [−1.3253, −0.0585] | −0.4249 [−1.3292, +0.5024] |
| 下一query单次迁移local − 原Rank | +0.4810 [−0.5077, +1.4103] | +0.1310 [+0.0022, +0.2678] |
| 真正在线reset-u − 原A | +0.0426 [−0.0299, +0.1580] | +0.0772 [−0.0127, +0.2290] |

Vid当前两个负证据臂都显著丢失原Rank的收益。HC均值也下降，区间跨零。local相对global的差异很小，没有形成一个可接入的双数据集改进。互换参数包在HC开发上有+0.4924 pp，但两个确认均值都为负；不能用开发正例宣称参数包解释了数据集差异。

clean确认也没有救回当前对照：Vid global/local−Rank分别−1.4147/−1.4158 pp，区间均低于零；HC分别−0.5608/−0.5536 pp，区间跨零。两个顺序的完整区间、gross gain/loss和全部负尾保存在SUMMARY。

## 主要损失发生在有效更新强度，而非一次巨大错误步长

本轮新目标几乎停留在更新前。Vid确认的原Rank当前增益为+1.3053 pp，而local只有+0.0009 pp；HC对应+0.6555与+0.0137 pp。后者不是与Rank等强度竞争后得到的改善。

| 确认参数位移：每arrival净L2均值 | 原Rank | negative local | 原Rank/local |
|---|---:|---:|---:|
| Vid K1 | 0.244759 | 0.000139618 | 约1,753倍 |
| HC K8 | 0.147606 | 0.000943794 | 约156倍 |

λ=1作用于原始IoU差，teacher接近当前p0；Rank teacher的名次和温度则产生强得多的偏好。保持同一个lr并没有保持梯度或实际更新量。因而本轮只能判断这个完整固定配置的结果；不能把较少损害唯一归因于“保留未决支持”，也不能把收益流失唯一归因于负证据思想本身。没有运行幅度匹配臂，未自动扫描λ。

## 负证据本身仍会误罚

在GT事件内且有标注的实际观察帧，比较候选与center的GT框IoU。负证据local中，专家认为更差、但GT框IoU更好的条目为：

- Vid确认：46/212，21.70%；占可判定负证据权重14.38%。
- HC确认：872/2,034，42.87%；占可判定负证据权重34.52%。

这是candidate×观察帧×step的条目诊断；HC多步会重复计入同一来源，不能把它当成独立样本错误率或整个tube correctness。事件外/无标注的观察保留为unknown，不补成错误标签。不同arm的后续状态和候选支持会分叉。center的e恒为0，所以该构造也可能保护错误center。

local的未观察帧直接输出梯度确实为零，算术与日志核验通过。但共享参数仍改变未观察帧框：Vid/HC确认local的未观察输出位移范数每步均值分别0.000122/0.002015。因此“只在观察帧定义loss”不是“更新只影响观察帧”的保证；其变化更小也受整体更新量变小影响。

## 未来迁移的正例主要是少写，不能写成学到了更好知识

HC确认local相对原Rank的下一query迁移为+0.1310 pp，CI高于零。但相对共同A更新前状态的no-write对照，local只有+0.0007 pp [−0.00005, +0.00190]；原Rank为−0.1304 pp [−0.2672, −0.0021]。因此这项增量更接近避免原write损害，未证明负证据学到了可迁移的新增收益。

Vid确认local相对no-write为−0.0003 pp [−0.0012, +0.0004]，也接近零。主bootstrap按write来源配对，另保留future target来源敏感性；两种单向配对仍不等价于完全的双向依赖建模。

一对确认反例能直接看出取舍：Vid source38/occlusion/order1，Rank从0.453%降至0.043%，local保留约0.452%；但source41/occlusion/order1，Rank从17.069%提高至22.503%，local仍为17.070%。HC source44/occlusion/order2，Rank从21.599%降至18.572%，local约21.614%；source41/exposure/order2，Rank从63.807%提高至69.540%，local仅63.838%。避免坏write与丢失好write都保留，不能只展示前者。

## query residual生命周期删除没有通过

reset-u完整1,152到达实验的两个确认均值很小、区间跨零。开发集分别−0.6061 pp [−2.2580,+0.4215]与−0.8237 pp [−4.0170,+1.2936]；>20 pp损害到达分别6与10，均未删除。确认无>5 pp损害不等于已建立收益；clean确认也跨零。

四个block-only反事实保留query/norm1/norm3/norm4的有限输出效应，它们不是可加Jacobian分解，也不能仅按参数名称认定某块负责当前或跨query信息。现有结果不支持直接把query residual改成每query重置。

## 核验、资源与结论边界

原Rank在全部local内步强制逐值复现旧A状态/梯度/输出。根审计复算目标、证据、输出空间导数、SGD坐标、继承链和官方dense指标，共46,118,535项；公开匿名包另复算256,847项，报告/CSV/图manifest也通过。根审计没有重新加载模型，不能独立重建完整神经Jacobian或执行block输出；这些边界记录在ROOT_AUDIT。

四段GPU worker wall合计78.66分钟，含加载和I/O，不是纯GPU kernel时间。CPU评分约34.88秒；独立审计、开发、报告和公开同步另计。新backbone与专家调用均为零。三张图及对应单页PDF已经目检，保留当前/未来/生命周期差值、来源集中和更新量。

**本轮的有限结论是：这版固定λ=1负证据目标和reset-u删除控制都不接入A。数学合同成立，任务收益没有成立；正确负证据、有效更新量、共享参数作用范围仍是不同问题。** 没有重开DTA、旧P1、全query或其他暂停队列，没有GT线上门控、生产晋升或新超参数搜索。全部匿名结果、负例、协议和实现随本报告公开。
