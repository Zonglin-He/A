# 候选覆盖、前景背景评分与教师内校准：固定128续验证

2026-10-22用户要求：查明为什么大部分候选没有带来收益，只小改评分和准入；使用原Vid128与HC128独立父来源面板，时间不动、不跑全量。本轮没有恢复任何旧GPU/全量队列。原学生、单ReferDINO八观察、输入、候选坐标、对应与时间输出均不改。**结果没有达到更明显、更稳定的空间提升目标，新增配置不晋升生产。**

## 诊断与第一项有限修改

前一轮HC只在已通过cycle .7的候选上重评分，导致后续cycle .1实际上不能恢复更早被mask掉的坐标。本轮不重新生成框，只允许原side_available已经保存的几何候选重新参与准入。资格计划先冻结，缓存封存后才离线诊断，再冻结最多16配置/域的试验计划。

固定Global6区间内有GT的未观察物理节点上，HC6695个候选槽只有574通过旧mask；1383个比同初始化ERef高至少.01 IoU的槽中，1207被旧mask排除。84个来源存在这样的好节点，原准入只覆盖11个。Vid相应为64与38个来源。**有好候选不等于评分能找出好候选。**HC全部几何槽的平均IoU差为−14.63pp，交叉评分为正的槽仍平均−11.37pp；这两个统计按候选槽加权，不能冒充等query完整指标。

按预设顺序验证：旧控制；cycle .1/.25/.4，分别保留或取消unary里的第二次cycle权重；用同冻结Source特征、教师框2倍外环背景构造前景减背景余弦优势，混合权重.5/1；最后只对最佳可行扩展配置检查保护系数.1/.4/1。背景原型与前景原型先各自归一化，不归一化微小差向量；空外环退回有效图框外，仍为空则拒绝。观测位置保留ERef，连接和原DP不变。

实际Vid16、HC13配置。选择要求整体dense/未观察dense/m_vIoU均不低于旧控制和Temporal，最大化两项空间增量的较小者；预登记实用目标为两项均≥.25pp、同ERef至少10来源获益，并补父bootstrap与逐父留一审计。达到实用目标与否不能由单一正均值代替。

## 第二项有限修改：教师内四系数评分校准

第一项扩大准入和背景对比未得到实用收益后，单独冻结第二计划。每条query最多56个有序跨观察对，按原WLS传播生成校准样例；四输入为前景优势、前景减背景优势、相对中心距离、log尺寸距离；伪响应为相对Source的教师框IoU差。固定ridge1、无截距、RMS下限.01，四临时系数按query重置。不是STVG神经网络训练，也不是直接读取数据集GT。

交叉验证留出第k个观察时，同时排除训练集中source=k与target=k的行。教师内CV必须优于零预测；真实候选相对ERef的预测差减去固定噪声缓冲后大于0才准入。检查噪声系数0/.25/.5×原连接倍数0/1，恰好六组合，加旧控制各域7配置。不搜ridge、特征、教师或时间。CV噪声缓冲不是有覆盖率保证的置信界，教师同次联合推理仍会产生相关性。

工程v1只从target角色留出，同一观察仍可能作为训练source；发现后在晋升前停止并完整归档，不用于选择。v2同时从两角色排除，保持六组合不变并重新执行；不是数据集GT在线泄漏。见calibration_recovery.json。目标框/掩码不进入其留出样本的预测输入；目标教师框只构造伪响应。

v2仍失败：Vid77/128、HC98/128通过教师内CV，但固定首个校准组合在通过组相对ERef的dense均值分别−1.8254pp、−2.7686pp。通过教师一致性检查不代表真实定位更好。所有六配置都保留，不能把这项失败解释成只差阈值。

## 完整性与结论

43个域配置×128=5504条预测与receipt全部封存、另进程离线评分并逐条hash核验；Source/帧ID/八位置/两时间区间逐位不变，所有输出框都来自原bank，旧控制数组逐位回归。没有新重网络/教师调用，没有全量。原两域128已多轮曝光，所有区间仅开发描述，未校正选参。

两项研究的原final_seal保持不可变；completion_seal另外绑定完整报告、配对分析、工程恢复和审计。完整结果见[报告](../results/tubedetr_selection_coverage/report.md)。本轮不晋升新配置、不自动续跑。现有证据支持“旧准入漏掉部分好框，但现有特征/教师代理不足以可靠识别这些好框”，不证明所有可行评分都不可能成功，也不证明TA与TubeDETR相反表现由单一网络结构导致。
