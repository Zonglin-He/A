# TubeDETR 八帧观测约束与实际状态更新

前两轮结果没有显示新奖励或局部候选搜索的可靠优势。本轮检验更窄的网络假设：八帧32个框坐标对2048维临时状态的一阶约束，是否使Adam更新包含改变未观测帧的分量。维数差本身不能证明损伤，更不能证明OPD有优势。

固定沿用原输入哈希选出的16条，不增加或删除样本。每条从零临时状态开始，以相同Layout3奖励分别计算Direct与seed41 OPD梯度及原Adam第一步。实际观测输出使用中心归一化、对数尺寸坐标，D在该状态detach；求32×2048 Jacobian，double SVD相对奇异值阈值1e-5。把真实Adam步投影到Jacobian行空间和其正交补，各自真实解码完整轨迹，原完整步须与已封存单步输出逐位相等。保存奇异值、数值rank、正交补能量和线性观测残差。

预算为16条各32次Jacobian反传、2次原梯度反传、6个分量执行；无新教师、无新参数搜索、无60步训练、无GT分量选择或自动全量。共享GPU锁、冻结权重、每query重置。完整响应封存后独立CPU读GT，只汇报初始单步局部机制、各分量实际观测/未观测位移和定位变化；不据此声称多步投影有效。全部正负结果保留。

完整16条结果：Jacobian数值rank均32；Adam步正交补能量Direct52.02%、OPD53.31%，线性观测残差约5e-15。正交补实际观测中心位移约2.3/2.6e-7，未观测约1.07/1.24e-5；dense单步变化−0.000637/−0.000040pp，均很小。证明局部不可见更新与跨帧传播存在，不足以解释60步严重尾损，不证明投影多步收益或OPD优势。
