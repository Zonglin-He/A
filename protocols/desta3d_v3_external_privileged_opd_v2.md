## Physical time and local evidence

Original PTD RGB pixels, frame IDs, FPS, clip start/end, caption and source identity are fixed. For100 teacher slots, define physical times `linspace(clip_start, clip_end, 100)`. For each time choose the nearest existing observation, breaking ties toward the earlier frame (including roundoff within8*float64 epsilon*max(1, absolute support/time)). The full16 metadata check exposed two linspace midpoint roundoff cases before any GPU inference; the original CPU failure and pre-repair code/preflight are retained. No additional pixels are decoded. A normalized teacher time u maps to `clip_start + u*(clip_end-clip_start)`, independently of the repeated pixel IDs. On `[10,11,90]`, midpoint time is50, not11. The complete requested-slot/nearest-observation mapping is saved. This is a matched-observation approximation of the official100-frame path, not its original100-unique-frame benchmark.

Save raw tokens/text, including malformed and truncated output, before parsing or assertions. Preserve every recognized time-box entry and its raw substring, validity, continuous physical time and nearest observation. Many-to-one mappings are expected: aggregate valid boxes at each observation by coordinate-wise median. Save all duplicate counts, pairwise IoUs, per-coordinate ranges/std and invalid entries. Duplicates are not format errors. No disagreement threshold is introduced in this version. Format validity and evidence usability are separate.

A local invalid-only observation stays unchanged and is an interpolation barrier; it does not invalidate other valid observations. Valid and invalid entries at one observation retain both records and use the median of its valid boxes. Interpolate linearly in physical time between valid aggregate anchors only, never extrapolate. Save valid-anchor/raw support counts, coverage fraction, all support kinds and maximum raw/anchor/used interpolation gaps. No new gap cutoff or outcome-selected threshold. Missing evidence returns original pixels locally. These rules apply identically in all episodes, without retries based on quality.
