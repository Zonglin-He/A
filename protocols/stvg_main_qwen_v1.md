# Frozen Query–Caption Temporal and Direct Spatial OPD execution

Authorized on 2026-10-17, including official full evaluation, engineering
cleanup, exact acceleration and publication. Figure 1 and manuscript editing
are outside this execution. This registration supersedes neither historical
results nor the deployed CURRENT registration.

The unique Teacher is Qwen3.5-9B revision
c202236235762e1c871ad0ccb60c8ee5ba337b9a, native non-thinking BF16 with its
architecture's FP32 exceptions retained. No quantization, attention backend
replacement, new Prompt search or per-domain model selection is authorized.

Temporal keeps Native I1 and the highest merged-interval-probability I2 whose
actual sampled video frames differ. Caption generation is the existing marked
8-frame 448 interface with its 160-token cap. Both captions are compared jointly
in both display orders with the unchanged A/B/C/D task. Identity-remapped
posteriors are averaged; C/D carry no directional reward. Original 512-parameter
merged-interval-prior/target KL adaptation, full-grid trust and L-BFGS/Armijo
settings are retained exactly. Final decoding is merged physical-interval
marginal MAP. No external Actionness projection is computed or used.

Spatial uses the same frozen Qwen, original Direct coordinate protocol and
lossless unique-bbox parser. Four planned anchor positions and four unmarked
context frames are acquired from the actual final Temporal interval. The
original 1792 Query/last-LN Gaussian OPD, complete response solver, original
per-domain settings, reference acceptance, full-step rollback and rejection
early stop are retained. Source parameters and Adam state reset per Query.
No cross-query state inheritance and no DINO. Teacher and Student models run
serially. Every final trajectory is obtained by the actual full Decoder.

Source-only and Spatial-only use the same Source marginal decoder. A true
Spatial-only run obtains its own Native/MAP-clock evidence and never borrows
Temporal-adapted observations. Full's final time equals Temporal-only exactly;
Spatial-only's time equals Source-only exactly. Keep the original Source
decoder and same-reference parameter-free propagation as attribution controls.
Formal display rows may be compact; all controls and negative outcomes remain
in the saved research record.

The fixed old development HC16/Vid16 is engineering integration, not new
confirmation or a performance selection gate. Pin the full recipe before this
run. Correct only implementation/engineering errors; do not tune from its GT.
After its actual interface/output qualification and publication, use the locked
official 3,482 HC2 validation queries/237 videos and 10,303 VidSTG test queries/
732 videos. Record historical development exposure. No query is removed because
of missing captions, abstention, unavailable anchors or rejected updates.

Before new GT evaluation, every prediction in the declared population/arm must
be sealed and independently verified. Report query-macro mvIoU/mtIoU/msIoU and
strict >.3/>.5 success, plus source-cluster paired diagnostics. Baseline reuse
requires exact checkpoint/cohort/input/evaluator identity; historical online
Tent/SAR results cannot silently be called new episodic results. In-domain
supervised checkpoints remain a separate upper-reference evaluation.

Robustness retains the original deterministic physical-time burst operators:
frame drop/freeze/motion blur/occlusion/exposure, at 2.5%, 5%, and 10% coverage.
Source and Teacher must see the same corrupted pixels. Clean, each 5% family,
and means across five families at each severity are reported. Sparse propagation
separates observed/non-observed native frames from benchmark interpolation
positions. The budget analysis fixes K=1/2/4/8 before runs and changes only
planned geometry observations, retaining context and Student settings.

Engineering optimizations require actual exact qualification. Unchanged files
may be hash-verified once per worker with stat invalidation and complete
rehashing at seal. CPU snapshots may use a bounded asynchronous writer. Native
pre-LN Source views may be reused only by full input/checkpoint/query identity;
adapted state never enters a cache key for another Query. All RNG/gradient/
Adam/solver/acceptance paths and complete readouts remain unchanged. Last-token
text-logit projection is eligible only after actual raw-logit and probability
equality; otherwise retain the original full-output path.

Use one GPU lease, host headroom >=6GiB, GPU headroom >=4GiB, disk floor30GiB.
Do not signal or modify unrelated active services. Preserve old evidence,
negative results and original source bytes. Clean the new active/public code
tree using a hash-manifested recoverable source snapshot. Never publish weights,

Publish and remotely verify the cleanup before new model execution; publish
