## Annealed OPD

Three stages, 32 antithetic samples per reward anchor per stage. Constant sigma is sigma0*sqrt(7/12); descending uses sigma0, sigma0/sqrt(2), sigma0/2; ascending reverses the same set. Descending and ascending use identical standard-noise tensors per case/scale slot, and constant uses the same three slots. Sampling and Gaussian likelihood use the same stage sigma. Actions and normalized reward weights are detached. Every stage starts from actual Student decoder output. All three arms roll back both parameters and Adam state on rejection, then proceed to the next fixed stage. Original sparse reference acceptance, M2 response filter, fullstep update, 1792 episodic parameters and protection scope stay fixed. No external weighted box replacement.

Actual original HC settings: sigma0=.025, tau=.1, Adam lr=.0045, writeback=.0625. Vid: sigma0=.4, tau=.5, lr=.027, writeback=.125. Original response solver/settings are reused and recorded per actual fit. Historical original OPD has HC5/Vid3 steps and early stop, so is a historical baseline, not the matched three-arm primary control. Primary contrasts are descending-minus-ascending and descending-minus-constant. No result-triggered schedule change or expansion.

## Tube P0

P0_F is Source spatial with fixed T4; P0_O is exact existing sparse OPD; P0_R is an external deterministic completion diagnostic; P0_R_to_S is a new actual Student fit using the completed reference. In logit-cxcywh coordinates, completion solves mean sparse residual error plus lambda0=1 mean residual magnitude plus lambda_time=1 second mean Brownian increment penalty, using actual physical frame gaps. No clamping: missing references or noninvertible chart cause exact whole-query Source no-op, kept in denominator. One hash-selected leave-one-reference diagnostic is retained when at least two references exist, and measures pseudo-reference agreement, not GT.

Dense reward targets cover the original native grid. Protection positions and reference acceptance remain bound to the original sparse Teacher support; dense rewards must not empty the original protection set or replace sparse acceptance with self-generated dense targets. P0_R_to_S uses original fixed-sigma Gaussian OPD/Adam/M2/fullstep and HC5/Vid3 early stop. Dense reward costs can exceed sparse costs and are reported separately. No annealing in this family, no new Jacobian target optimizer, no denoiser training.
