# Original P5: separately pinned numerical recorder for the fixed budget suite

This is an engineering namespace for the already authorized P5 design. It changes
no source weights, query/source roster, frames, objective, action, reward, sampling,
gradient, Adam, active parameters, reset/writeback rule, Native WHEN or readout.
The preceding P4 must actually finish its phase root/view/public/archive closing
before any P5 qualification or formal GPU process starts.

The original eight cross-domain clean stages use K=1/2/4/8, 128 parent sources per
target, one fixed query per parent and both saved orders. Their selected HC2 and
VidSTG configurations remain unchanged. Two original pre-GT unified-configuration
appendix stages remain separate: lr=.03, sigma=.1, tau=.25, 10 rounds, writeback
1/16, M=32, K=4; they do not replace the main method. There are 2,560 logical
arrivals: 2,048 new formal fits and 512 exact original K4 complete-stream aliases.
Reused payloads and receipts are never rewritten or spliced into another stream.

The new recorder is copied from actually qualified P4 numeric engineering,
preserving its CPU32 matched reduction, independent CPU64 formula/gamma48,
same-original-GPU-action reward readback, chart/softmax and allocator bridges.
Only the namespace and dispatch revision differ. Existing science and runtimes
remain immutable. Historical absolute-guard failures are not relabelled as passes.

All ten stages' first two fixed order1 arrivals must receive two real complete
GPU fits: the already qualified P4 recorder and the new P5 recorder. Qualification
never uses historical aliases. All 20 arrival pairs (40 GPU fits) must be
scientifically bitwise identical, with actual source/expert process hashes and
native-head-output VJP checks. Actual DINO capture calls are counted from receipts.
No qualification fit is accepted as a formal result; qualification reads no GT.
The root independently reads complete dictionaries/1792 state, query/Adam reset,
LN inheritance/writeback, input binding and the paired saved previous controls.

New streams' first two order1 formal fits must match qualification before saving.
K4 aliases require exact complete source/input/configuration/order/history binding
to their original fully sealed streams and retain original measured cost.
All deployment budgets/directions/orders and the unified appendix must globally
seal before GT/scoring. Root population/math/state/dense/10000 paired-parent
bootstrap/negative tail/cost/observed-unobserved/signal/case/actual view/anonymous
publication/remote byte verification/archive/P5_ROOT_CLOSING remains necessary.

No retuning or new expert/algorithm/scorer/gate/memory is authorized. No independent
entire decoder Jacobian, CUDA transcendental proof or future numerical/OOM safety
is claimed. Single GPU execution remains serial. EATA and historical paused queues
remain paused. Only actual P1–P6 closing and final evidence complete the paper suite.
