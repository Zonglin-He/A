# Per-video discriminative dense feedback32

Question: do existing frozen TA-STVG features support target-versus-background discrimination in this video, beyond old cosine region propagation? This is a new teacher interface, not a trained DiMP/ATOM reproduction or a replacement encoder. Existing failures of correspondence, shared-memory adaptation and QR remain preserved.

Same current exposed NH16/NV16 parent/query32; same opposite-source checkpoints, final-MBR, E beta1/16, four planned frames, original DINO candidate cache and E associations/rejections. Pretrained weights frozen. No new DINO, Qwen, critic, historical Before or cohort. Raw input-projection appearance maps BEFORE text fusion are required; if absent, at most one frozen Source capture/query. Both offsets interleave on exact original IDs, Source output/logits verified exactly. Full fused memory is not substituted for these maps.

One ridge classifier per E-selected anchor. Positive: selected DINO ROI. Negatives: row-major9x9 grid of boxes with the same width/height, fully inside image and zero intersection with ALL retained DINO candidates in that frame, at most64. Other candidates remain unknown. Fractional-cell pooling on valid feature cells, L2-normalized appearance plus constant bias. Target label+1, background-1, total positive/negative weights exactly0.5 each. Ridge0.01 penalizes all coordinates including bias. An anchor without valid positive/background is unusable and recorded; no GT filtering or fallback teacher.

Keep per-anchor classifiers and probabilities separate; combine probabilities by fixed equal mean. Candidate ROIs are evaluated on EACH target frame's own frozen map. The feature-shuffle control cyclically deranges only unobserved frames and keeps anchor frames fixed. Old correspondence is reproduced using ALL E-selected anchor boxes (including anchors without trainable background), original cosine row-softmax0.07, soft-IoU and the SAME candidates, prior and feedback temperature0.1. An additional matched-usable-anchor cosine control isolates anchor coverage; it does not replace the all-E primary comparator. These are same-candidate comparisons, not reuse of old cohort scores.

Only centers change; widths/heights remain exactly E. Per-frame Gaussian position policy has fixed sigma=0.25*(E width,E height). Each round17 candidates: center plus8 antithetic pairs, deterministic alias-hash RNG; two rounds34 teacher position queries/frame. No coordinate clipping or GT-directed candidates. ROI support is restricted to nonempty visible feature cells; all-invisible rows have no feedback. Teacher probabilities are a tilt of the sampling Gaussian prior by exp(classifier score/0.1), then mixed across anchors. This explicit proximity prior is reported, not mistaken for discriminative information. Constant/no teacher feedback leaves the initial state exactly unchanged.

Phase1: seal all32 feature files, teachers,34 initial-distribution candidate scores/probabilities and E/teacher-argmax readout BEFORE any new GT. Direct readout changes only unobserved actual decoder nodes, picks an actual candidate (center first for exact ties), does not average coordinates. Score candidate expected true IoU relative BOTH uniform and Gaussian-prior weights. Primary scientific gate, locked before GT: in BOTH domains query/parent-mean unobserved ridge-minus-prior>0, ridge-minus-old-cosine>0 and ridge-minus-feature-shuffle>0. Report paired10000 bootstrap seed20261018, signed rows/negative tails/unknowns; a positive point gate is only development continuation, not a significance or confirmation claim. If gate fails, STOP this teacher, no updates or optimizer sweep.

Phase2 only if Phase1 gate passes: two-step external center-state KL adaptation, per-query reset, no network backward. Same E initialization, frozen teacher, widths/heights and MBR; all four planned DINO positions excluded from updates. Fixed arm pre-samples both17-candidate batches around E. On-policy arm uses identical noise identifiers but round2 centers follow its updated prediction. First round exactly matched. Each branch gets34 ROI scoring queries/frame. Teacher tilt and Gaussian student finite-support probabilities are recomputed on the visited support, all teacher feedback detached. Independent per-frame KL gradients are E_student[d]-E_teacher[d] in standardized E coordinates; fixed step0.5, two rounds/readstep2. This is equivalent to block SGD for independent per-frame KLs, avoids a video-length-dependent effective step. No Adam, scanning, gate changes, best-step selection, or extra sparse loss.

Phase1 labels are exposed offline for the GLOBAL continuation decision only. Phase2 online process cannot read labels or strata; parameters and implementation are already pinned. Seal all32 Phase2 predictions before their GT evaluation; do NOT claim Phase2 predictions predate the Phase1 GT exposure.

Reports: rank delta on unobserved actual nodes, far nodes(>=25% physical-span distance to a planned anchor), observed; complete official vIoU, fixed-time tIoU, observed/unobserved actual sIoU, interpolation contributions, severe losses and small/large/slow/fast groups using previously fixed full-cohort common bins ONLY offline. No reference/no-op/unknown samples retained. A smooth/classifiable response is not identity or calibrated localization probability.
