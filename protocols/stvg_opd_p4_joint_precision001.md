# Original P4 robustness: separately pinned joint numerical audit

This protocol implements the already authorized fixed P4 after P3 actual root,
real visual review, anonymous remote publication and archive closure. It does
not change the original `LATER_DESIGN_LOCK`/component science or production method.

P4 is same-domain TA-STVG: HC-STVG2 source to HC2 validation, VidSTG source to
VidSTG test. The original Table2 units are 237 HC2 parent movies (one selected
clip/query per movie) and 732 VidSTG parent videos (one query each), 969 in total.
The original single order, clean plus five physical burst families at 2.5/5/10%,
produce 15,504 formal joint fits. Source resets independently for all 16 conditions.
Query residual and Adam reset per query; LN inherits the configured writeback.
Native WHEN, original pixels/frame count, Uniform4/admitted Top1 frozen DINO,
M32 antithetic on-policy Gaussian likelihood, detached IoU reward and final
configured-round readout remain unchanged. HC2 .01/.025/.05/40/1/16 and
VidSTG .03/.1/.25/10/1/8 are the locked lr/sigma/tau/rounds/writeback.

The separate P4 recorder/auditor preserves the qualified P3 matched CPU32
2e-5/CPU64/gamma48 gradient arithmetic, actual-original-action reward 3e-6,
softmax/chart and expandable-segments allocator bridges. Only audit namespace
bindings change. Old source/runtime/receipts/prediction bytes remain immutable.
No clamp, skipped query, reduced frame/step count, parameter change, new expert,
training, model promotion or scientific algorithm is introduced.

The original first two fixed arrivals in every condition/source are qualified:
64 actual arrivals, 128 complete GPU fits. Each new P4 fit is paired with a real
fit using the already qualified P3 numerical hook on the same source/input and
initial state; every scientific tensor/scalar must be bitwise identical.
This previous numerical control is explicitly not a claim that old historical
absolute precision assertions all pass. The qualified P3 hook preserves the
original scientific computation and retains old audit failures as evidence.
Both numerical dictionaries are checked on CPU, source/expert process hashes
must remain unchanged, and real native-head-output VJP is checked. An independent
full decoder Jacobian or CUDA transcendental proof is not claimed.

CPU contracts cover valid and malformed update scopes, hook installation/restore,
AST assertion-only substitution and four immutable historical joint fits with
altered-action rejection. They are not GPU qualification or formal predictions.
Qualification accepts zero formal outputs and reads no GT. DINO capture may be
needed for original new condition/query inputs; actual calls are recorded, not
assumed zero. Every stored 1,792-coordinate state, scoped Adam/reset, initial
source/LN inheritance, committed writeback, input and complete math dictionary
must pass actual root qualification before formal execution.

The first two formal fits per condition must equal their full actual qualification
before acceptance. A bounded accepted HC2 clean prefix gets independent no-GT
root math/state/input/Native and SHA readback; this closes only qualification and
resumption. All 15,504 deployment outputs across both sources and all conditions
must globally seal before GT/CPU scoring. P4 full root statistics, state/dense,
bootstrap, negative tails, observed/unobserved costs, real cases/plot views,
anonymous full negative publication with remote bytes/hash/tree verification,
archive and actual `P4_ROOT_CLOSING_RECEIPT` precede P5.

Use one finite controller and the original single GPU lease, no parallel GPU.
Preserve every true failure before any necessary bounded engineering repair.
No future numerical/OOM safety guarantee is made. EATA and all historical paused
queues stay paused. Monitoring remains ACTIVE through actual P1–P6 suite closure.
