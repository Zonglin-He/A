# P0: Spatially guided temporal expert input audit

Question: does a target-centric input constructed from the sealed persistent spatial A trajectory improve the frozen UniversalVTG teacher's temporal localization? This is a three-arm expert-input audit, with zero TA-STVG inference, backward, SGD, temporal persistence, new expert, purification or DTA. It does not promote A or change CURRENT_METHOD.

Reuse the exact R2 cohort: each dataset 32 search +16 source-disjoint-in-this-batch confirmation sources, one query/source, two orders, clean plus five existing 5% transient corruptions. All sources have historical exposure. Only the scheduled 25% expert positions have expert inputs: 288 cells (240 corrupt,48 clean), Vid16/8 and HC14/7 distinct expert sources. Do not call these 288 independent videos or report teacher gain as full-flow STVG gain. Source macro and paired 10000-source bootstrap seed20261004; clean, order, positive/negative cases and severe tails are mandatory.

Full reuses the exact saved raw UniversalVTG proposals and first confidence argmax from R2. A-ROI uses `slow.boxes`, normalized cxcywh from the complete pre-current-update A trajectory, not post-update predictions, GT or candidate winner. GT-ROI is diagnostic-only and may never supply a deployable teacher or tuning decision. No scalar spatial plausibility score. Full/A-ROI are sealed under a GT/metric file-access guard before GT-ROI construction. All new predictions and confidence-top1 choices are sealed before temporal GT scoring. Preliminary spatial-annotation-support inspection is disclosed; no labels enter the Full/A-ROI workers.

One fixed crop convention, not a searched hyperparameter: each sampled box defines a centred square with side `ceil(1.5*max(box_width,box_height))`, minimum2 pixels; preserve the centre by edge-replicating border pixels. Invalid A boxes fall back to the full frame and are retained/countable. Do not smooth boxes or crop temporally. The same stock PE-Core-L14-336 image transform, FP16 visual encoding batch16 and existing cached caption features are used for all expert calls. The original nearest-original-observation 2Hz feature grid and entire clip duration/origin are identical across arms. Corruption is applied to the original full pixels before cropping and must reproduce the prior pixel hash. Cropping changes object scale, context and apparent motion as well as identity focus; a gain does not uniquely prove identity disambiguation.

**GT limitation prelocked before new predictions:** labels contain spatial boxes only inside the annotated event for nearly all cells (Vid138/144, HC144/144). To avoid a direct black-frame, missing-frame or event-window timing leak, interpolate GT spatial coordinates at original sampled frames and use the nearest annotated spatial box outside their support. Never drop/mask frames according to the GT event, never pass the GT temporal `span` to the crop routine. This is a GT-box-extension diagnostic, not perfect full-video GT tracking; outside-support boxes are not invented evaluation labels. Availability of spatial annotations is itself GT-derived, and this oracle cannot establish unlabeled deployment. Do not interpret a negative GT-ROI result as disproving all WHERE-to-WHEN methods.

Frozen assets: original UniversalVTG checkpoint/opt and installed PE visual encoder; query unifier disabled. No downloads. Cache only private crop geometry, hashes, features and proposals, not crop videos. At most288 A-ROI +288 GT-ROI observation requests, deduplicate only exact feature-input hashes. Two predetermined Full pixel-reencoding smoke controls (one/dataset) plus cached-head replay are engineering checks, not science arms. Reencoding must match saved Full features and confidence choice to FP16 precision; record max errors before accepting. One GPU serial, >8GiB disk floor, no total deadline. Do not touch desktop processes or old queues.

Primary: first-confidence-top1 continuous physical-frame tIoU, A-ROI−Full and GT-ROI−Full, separately four corrupt panels. Report >.5 success, zero-overlap errors, >5/>20pp harms, gains/losses and proposal-support oracle as a post-seal secondary diagnostic. All four paired lower95CI>0 is the strict cross-panel teacher-evidence GO rule; mixed/uncertain means no automatic DTA. Do not resample cohorts, tune crop ratios or select different rules by dataset. Even a GO needs separate authorization before any DTA experiment.
