# Real-Forward complete-task validation, fixed historical panel

Authority: the human authorized a bounded complete-task experiment after reviewing the distinction between exploration and final method evidence. The old eight-query screen remains closed at its original 50% resource criterion: 4/9 positive-proposal boundaries per domain (44.4%) did not pass. This new protocol does not retrospectively lower that threshold or reopen high-dimensional P/F projection. It tests a different question: what happens after committing selected updates and recomputing all subsequent proposals?

Exactly64 previous-P6 historical queries,32 per target, original Inherited-order1 LN state, zero query residual, Omega0 observations, source checkpoint, pixels/frames, cached admitted highest-score expert boxes, Native temporal interval, OPD Gaussian likelihood, lr/sigma/tau/K and antithetic32 noise are retained. Every query/arm starts with fresh Adam; no cross-query writeback. This is an episodic receiving-state experiment, not a long online stream. New noise draws use the original query/round seed; candidate arms share noise, not sampled actions after their means diverge.

Four complete trajectories: A original OPD, SEL real-forward selection, HALF fixed half proposal, LN fixed LN proposal with QR displacement masked. At each arm's actually committed current state, the original OPD forward/rollout/gradient/Adam are recomputed. All1792 proposal moments advance normally. HALF/LN/SEL only select the applied proposal state; moments are neither scaled, deleted nor reset. A copies the actual float32 Adam state directly. LN copies the proposed LN and keeps current QR; Query keeps current LN and copies proposed QR; Half uses current+.5*(proposed-current) in float32. These proposal masks differ from removing a block from the optimizer.

SEL evaluates exactly A/LN/Query/Half with the complete native decoder. G is mean admitted-observed expert-IoU improvement versus the current state. D is squared box drift per unvisited frame versus this query's entering boxes; no GT, generated query text, future state or oracle step enters selection. For positive G(A) and nonempty U, choose minimum D with G>=.9G(A); fixed tie order A,LN,Query,Half. Nonpositive G(A), empty observed evidence or empty U uses A. Empty/no-information updates remain exact noops and retain every round. No extra radius/GT tuning, candidate expansion, new teacher or regularizer.

Technical qualification: fixed indices0,1,32,36 (including the original empty query), four complete arms, two independent frozen captures each =32 actual GPU fits/800 saved rounds/8 captures. Require original A complete reproduction, whole-trajectory repeat equality, independent likelihood/action/gradient/Adam/state-selection readback, no early GT and restored source states. Synthetic CPU fixtures are not this qualification. No >=50% non-A-coverage or task-effect gate applies to launching the bounded formal test.

Formal:64 A control replays plus192 new SEL/HALF/LN complete fits =256 complete fits/6400 rounds/64 fresh frozen captures. All256 predictions seal before GT scoring. No new DINO; cached experts do not imply zero end-to-end expert deployment cost. Actual instrumented fit/candidate times are retained separately from past capture/expert cost.

Primary task contrast: SEL minus A full mvIoU, separately for each target, equal-weight32 independent parent videos with10000 paired bootstrap, fixed seed20261013. Secondary contrasts versus HALF and LN, full msIoU/mtIoU, actual observed learning, genuinely unvisited real event-frame IoU, initially correct event-frame retention (entering IoU>=.5), initially wrong event-frame correction (<.5), .5 threshold crossings, parent harms>5/20pp and all signs/unknowns. GT defines these offline masks only after the seal; it never selects an update. The common entering state defines identical masks across arms. Interpolation-only dense scores and actual annotated sampled-frame diagnostics are distinct. Each parent's valid-frame average precedes parent aggregation; undefined masks remain unknown. These historical-panel intervals are conditional on fixed histories, exploratory and unadjusted across secondary contrasts.

Decision: report task gains, protection/correction tradeoffs, simpler-control explanations and uncertainty. Protecting already correct HC frames while freezing correction on Vid is not evidence of a broadly useful mechanism. Similarity to HALF/LN is descriptive unless an independent equivalence margin is specified; a CI crossing zero is not equivalence. No requirement to beat Capped Direct before the first task test. A supported candidate would still need a separate independent replication and main protocol. This finite test does not automatically authorize more parents, order2, online writeback, production promotion, CURRENT changes or a paper. High-dimensional projection, Q0/P9 gates, negative evidence and ordinary R remain separate questions. The explicitly closed Luna automation stays deleted.
