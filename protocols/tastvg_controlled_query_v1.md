## Query intake, independent of GT metrics

Only real existing dataset queries are donors. No generated captions. Vid same-source natural captions/questions are obtained through an annotation-bearing metadata whitelist: video ID, used input segment, descriptions, query form and target object ID. GT temporal fields, relations/boxes and trajectories are not used or saved for pairing. That metadata intake is annotation-assisted referent matching and must be disclosed; it is not a claim of no annotation-file access. HC2 captions use the existing full-cohort metadata plan; multiple YouTube clips sharing a source are not the same exact video. Same-video means identical media SHA256; same segment is a separate tier. Different source or different lexical verbs is not GT certification of a false event.

Queries are parsed on CPU with the existing offline Stanza1.14.0 EWT assets. Root/main-action signatures use lemmatized root and coordinated VERBs. The strong subject-swap action signature additionally holds all lexical verb lemmas, direct/indirect-object head classes, particles and active/passive voice fixed (person nouns/pronouns share one class). This distinguishes take steps from take a cup and includes xcomp or parser-misattached verbs. These are text signatures, not a learned semantic embedding or complete event equivalence. Disjoint-action event pairs additionally require no shared lexical VERB, including modifiers. Native subject selection exactly follows existing QuerySubjectParser. Matching uses the nominal subject modifier signature or noun class; questions with unknown what retain the native empty subject. Query form must match (question/declarative), captions must differ after whitespace/case normalization. All linguistic labels are operational definitions, not verified equivalence of complex events or cross-video identities.

For each original48-source panel row, choose at most one event and one subject donor, with the following frozen hierarchy:

* Event: same exact media/same target ID/disjoint actions, same input segment first; otherwise a different-video donor with the same exact nominal modifier signature; otherwise the same native subject noun class. No same-media identity-ambiguous fallback.
* Subject: same exact media/different target ID/exact main-action signature, same segment first; otherwise different-video/different native subject noun class with exact main-action signature; otherwise same root action. No same-media action-ambiguous fallback.
* Within each tier minimize absolute word-count difference, then deterministic SHA of dataset/original key/arm/donor key. This controls a text-length nuisance, not GT quality. Donor reuse is allowed and reported; independence does not grow with repeated queries/conditions.
* Missing matches stay missing. They are never replaced by generic swaps or imputed as zero effects. Report all-arm common recipients and each arm's available cohort, exact same-video/same-segment strata and strict versus root-only cross-video matches. Primary event-versus-subject comparisons use the same recipients with both donors at tiers0–2. All-common/root-only/class-only pairs are secondary and never represented as exact event/identity controls.

The donor pool consists of561 official natural Vid queries on the fixed48 panel sources and the3482 existing HC2 official real-query metadata rows. Matching and signatures are locked before any new latent/readout or GT metric. Private captions, object IDs, parse tokens and original source identifiers stay private. Public mapping uses panel source indices, donor text/media hashes, tiers, lengths and reuse counts.

## Metrics and inferential limits

P=intersection/candidate duration, R=intersection/GT duration, tIoU=intersection/union. Report source-balanced pooled R²/MSE/MAE and within-cell R² separately. AUROC is undefined for single-class event cells, never imputed. Source macro aggregation is condition→order→source; paired10000 source bootstrap seed20261003 conditional on the locked donor mapping. Donor reuse creates additional dependence; explicitly report unique donors and interpret recipient-source intervals conditionally, not unconditional donor-population uncertainty.

Primary HC Contrast P/R/tIoU specificity contrast is `R²(subject intervention)−R²(event intervention)` on corrupt expert common_strict recipients (both tiers≤2); all-common is secondary. This equals event loss minus subject loss because the same original-query baseline cancels. Report true/event/subject/generic absolute values and paired original-minus-intervention gaps. Full and Vid use identical comparisons. Supplement Full-versus-Contrast difference of specificity contrasts with paired source resampling. Intervals are pointwise and unadjusted; correlated endpoints are not independent replications. Clean/search/confirm/two-order and linguistic tiers are reported, without target-based probe/donor/threshold selection.

Action-related changes exceeding subject changes support this operational query dependence only when valid matched coverage exists. Natural queries can change objects, clauses, attributes, length, segment and distribution simultaneously; cross-video noun/root matching is weaker than same-video same-referent intervention. Null or reversed effects do not establish pure priors/absence or failure of all nonlinear methods. This audit never certifies a deployable quality head or adds a new vIoU output.
