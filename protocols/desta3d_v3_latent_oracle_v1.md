## Question and fixed design
Can correct source temporal/spatial evidence, applied to the existing 3D branch representations, improve the native PTD policy? This tests one concrete actuation interface, not information sufficiency of all possible 3D representations.

Use the existing ordered PANEL16 in source_task_control_v2: 16 VidSTG source-training parents, one query each, 7–32 observed frames. Preserve order and every failure. Frozen official PTD4B and fixed v2 B1 checkpoint SHA 6fe8d07e2a11c16bcb68eed11264a18b71985e97fdbf7939422f306ba81bf0d1, adapter 4a2ef2cf87e1753fad7c0c5c1f582f499c14b0b2945a839680b296abb0d9c7eb. The cancelled v3 35-step checkpoint is excluded. RGB, preprocessing, physical frames, query tokens, shared stem, both readers, output projection/bias, gates, and PTD parameters remain unchanged. No optimizer/backward or new native supervision.

Four primary scientific conditions: original Z; temporal privilege; spatial privilege; dual privilege. Apply w=0.25+0.75*M to the actual 128-channel [B,T,H,W,d] branch feature after reader/LayerNorm/SiLU and before frozen branch output projection. This location avoids normalizing away the intended scale; it is a declared choice, not evidence that it is optimal. Alpha .25 is fixed before GPU, inherited from the pre-existing evidence attenuation convention, with no search. Projection bias, gate and original PTD residual stay unchanged. Evidence-head logits computed upstream of this hook are not privileged native policy logits.

Temporal M is the source physical half-open event indicator [begin_fid,end_fid), broadcast over HW. Spatial M is the fraction of each normalized THW cell overlapped by its corresponding valid GT referent box. Use all valid referent boxes independently of event_active; using only event boxes would conflate the two factors. A missing GT box gives a neutral all-one frame. Declared-valid invalid geometry fails the contract rather than silently changing support. No crop, interpolation, new pixels, time resampling or forced GT output tokens. Save both complete masks and physical support.

Native generation remains the established two-pass shared-reference cached path: event generates its own semantic reference/time, spatial starts a fresh KV cache and consumes that generated reference/time. Temporal changes may legitimately alter spatial output through this shared generated support; spatial-only must preserve the native event completion/time distribution exactly. No GT response string is passed to generation.

## Endpoints and decision scope

Report all v/s/t contrasts for all three interventions, 10,000 paired-parent bootstrap with seed20260927, descriptive 95% CIs without multiplicity correction, sign counts, >5pp negative tails and original v/t>.5 retention. One query per parent means query/parent means coincide here. No best-arm or case selection.

A positive result only establishes an opportunity for this source oracle and interface; external replacement, native positive controls, and student-prefix reverse-KL remain separate conditional stages. A null/negative result lowers this specified reweighting interface's priority; it does not prove all 3D latent reasoning impossible or authorize a gate/alpha/precision/steps grid. Preserve weak source preparation, small residual injection, downstream quantization/readout and label/native support as competing explanations. Do not call the narrative or OPD proven from a table alone.

## User refinement before registration: evidence-content controls
Add exactly two arms: wrong-temporal with ordinary spatial, and wrong-spatial with ordinary event. Temporal retains the GT integer physical duration and the exact foreground count on existing observations, hence the same mean latent weight. Enumerate feasible integer starts within observed physical clip support; choose smallest observed overlap, then smallest physical overlap, then largest displacement, then earliest start. Selection uses labels/metadata only, never model scores. If no different observed mask exists, preserve the episode with a non-discriminating flag; report full-panel and eligible-only correct-minus-wrong effects without sample substitution. Do not call a partially overlapping least-overlap interval completely wrong.

Spatial translates each valid normalized box to the farthest feasible corner with the same width/height, fixed TL/TR/BL/BR tie order, same box-valid frame support and neutral missing frames. Retain fractional cell occupancy, total area/mean weight (floating tolerance 2e-5), all translations and true/wrong box IoU. Full-frame boxes cannot move and are explicitly non-discriminating. Report true-minus-wrong t/s/v CIs as well as true-minus-original; attenuation alone must not be mistaken for correct evidence use.

S/wrong-S versus original naturally share exactly the same event-generated reference, interval, anchors and frame support; assert this as a structural control, not a discovered benefit. Their full coordinate logits permit fixed-support KL and box comparison. T/dual can change these conditions; report their final native tube metrics without attributing sIoU shifts solely to spatial correction. Any KL on changed support is marked unavailable rather than comparing unequal decisions.

GT masks contain answer-related evidence. Success supports correct-evidence utilization at this specified residual interface, not sufficiency of unmodified latent information. If a clear correct-evidence advantage is established, a separately registered small content-disruption control can distinguish mask answers from dependence on original features. Do not add that intervention or OPD automatically in this run. A source supervised native actuation control and final no-privilege OPD readout remain two separate future tests.

Terminology and literature: THW is not XYZ; shared identity/observations do not require identical corrective evidence. DUST is a variable-sharing design analogy, not a proof of STVG gradient isolation. PTD already separates temporal and time-conditioned parallel spatial blocks with shared context; previous unsuccessful objectives already included latent losses. Future OPD must use student's generated reference/interval/anchors and true temporal endpoint/coordinate positions, with matching action support, frozen episode-start teacher and branch-only parameter paths. Shared stem stays frozen initially; direct parameter isolation does not remove temporal-to-spatial conditioning. This is a branch-conditional divergence, not a proven exact KL of the full joint tube policy.
