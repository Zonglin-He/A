# Fixed LN state intervention (2026-10-13)

Human scope: one controlled mechanism experiment, using the explicitly selected
P9/P0 `previous_P6` 32 historical parents in each target domain. These parents
have previous diagnostic/GT exposure. They are not a new held-out test cohort.
The roster is selected by the old membership flag, never by scores or sign flips.

For each of the 64 fixed queries, use the original source checkpoint, clean
pixels, frame IDs, Native interval, Omega0 Grounding DINO pack, admission/Top-1
positions, OPD configuration and common antithetic random numbers. The only
intervention is the six decoder LN tensors (1536 coordinates) at query entry:
Source, Inherited-order1, Inherited-order2. All three arms have a zero 256-vector
Query Residual, a fresh empty Adam state, the original joint 1792-coordinate OPD
fit and the original final-round readout. No state is propagated to another
query. Actions may differ with state; the underlying random noise must agree.
The source/configuration is HC: lr .01, sigma .025, tau .05, 40 rounds, original
writeback field .0625; Vid: lr .03, sigma .1, tau .25, 10 rounds, writeback .125.
The writeback field is preserved, but this isolated-query intervention does not
commit a new online stream. No new DINO calls, teacher, gate, search, temporal
update, production promotion, main experiment or manuscript work is authorized.
P7-A and all old science/runtime/results are immutable. Cancelled baselines stay
in their original same-process T standby; this experiment cannot resume them.

Before formal work, run four fixed qualification queries: the first two HC
roster members, and the first nonempty/first empty Vid members in public-parent
order. This uses evidence presence only. Three arms and two genuinely fresh
complete frozen captures per query give 24 complete qualification episodes.
Require original source/native/pixel/input identity, exact LN transplant, empty
Adam at each query, the original objective/math/Adam/state audit, actual native
head VJP checks on nonempty episodes, complete repeat equality, and exact
reproduction of both original inherited Omega0 fits. CPU fixtures are not GPU
qualification and finite qualification is not a future OOM guarantee.

Then run all 64 x 3 = 192 new complete fits (no formal-result reuse), retaining
all round/path/gradient/Adam/action/sample witnesses and all empty/no-information
episodes. Seal every serialized prediction and receipt globally before GT
access. Score all three Before/After outputs without selecting steps or arms.

Primary outcome is Delta_U = mean real-frame IoU(After) - mean real-frame
IoU(Before), on the same genuine annotated decoder frames inside the GT event,
excluding **all actually visited Omega0 teacher positions**. This excludes
unadmitted observations too. Undefined U remains unknown, never zero. The fixed
Omega0+Omega1-union unobserved mask is a secondary outcome for exact P0
comparability. Additional observed-region and official full dense s/v/t readouts
are diagnostics, never an online decision rule. Before/After metrics are both
published so an initial-state prediction advantage is not mistaken for update
utility. HC conversion preserves the original lower-bound clipping convention.

For each domain separately (32 independent parents), report Source-order1,
Source-order2 and order1-order2 paired signed and absolute Delta_U differences,
complete positive/negative/neutral/unknown transitions, flips with both sides
at least 1/5 pp, differences at least 5/20 pp, and each arm's negative tails
below -5/-20 pp. Parent bootstrap: 10000 draws, seed 20261013, percentile 95%
intervals; no pooling across domains. These intervals are descriptive mechanism
estimates on a historically exposed fixed panel, not held-out generalization.

Predeclared interpretation: exact repeat noise is a technical control. A
nonzero state-induced utility difference on the controlled replay establishes
an effect of this LN transplant for that query. A domain-level lower 95% bound
of the mean absolute utility difference exceeding zero, together with actual
nontrivial (>=1 pp on both sides) sign reversals or >=5 pp differences,
supports practically material state dependence on this fixed panel. If these
conditions fail, report small/unstable or no measurable effects and stop this
fixed state route; do not add new states, gates, losses or parameter searches.
The signed mean need not be nonzero when heterogeneous effects cancel.
Even a positive result does not identify a deployable unlabelled signal and
does not authorize state selection by GT or a State-Conditional OPD method.

Completion requires independent full source/state/input/objective/dense/parent
statistics readback, actual pixel view of every exported PDF page, all anonymous
