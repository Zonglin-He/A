This is the user's newly authorized CPU-only diagnostic, not a reopening of the
failed posterior four-frame allocation or dense correspondence OPD. Final-q MBR
is selected as the fixed temporal research component by engineering tradeoff;

## Locked experiment

Use all original rollback32 exposed target-development queries (16 independent
parents/domain), original physical frame IDs, original Native Uniform4 positions
and original admitted DINO Top1 boxes. No new expert, image, model, optimizer,
training, candidate search, filter, source capture or online stream replay.

Time is the exact final-distribution MBR from the Source legal interval priors
already saved as projection.offsets.logp0 (no actionness values read). The two
independent-view distributions are merged by the same physical envelope and
full q, then the already-qualified exact MBR over all final legal intervals.
Native, projection and merged MAP are retained as fixed-clock sensitivity
controls; spatial corrections are never re-estimated by temporal readout.

Primary spatial start is each saved original query-start Before (including its
actual inherited LN effect); frozen Source is a separate sensitivity analysis.
No correction is inherited by another query. These are output interventions,
not actual Student parameter adaptation or new online performance.

Compare Base, LocalAnchor and GlobalError. LocalAnchor replaces only the
observed actual decoder nodes in normalized cxcywh and retains the original
benchmark xyxy interpolation at non-decoder positions. It is a matched
implementation of anchor-edit plus interpolation, not a rerun or numerical
reuse of the earlier source24 event-relative 32-knot equality projection.

The only new mode is z=(cx,cy,log w,log h), delta=mean(z(reference)-z(Base_at_anchor)),
z_corrected(t)=z(Base_t)+delta. Four parameters, unit weights, no smoothing,
robust estimation, temperature, clipping, error-speed or GT-based routing.
Widths/heights must stay positive and all output values finite. Out-of-image
centers remain valid outputs; only the unchanged official HC metric clips lower
pixel coordinates. With no reference both interventions are exact Base no-ops.

1. Seal all32 DINO_full outputs before this experiment reads any GT.
2. For the oracle input interface, extract GT at the original four planned
positions only, with exact frame annotations. No nearest-GT substitution.

Dense truth files are parsed by the existing loader, but only the locked sparse

All no-reference queries remain in denominators. Unknown GT is never zero-filled.

## Evaluation and decisions

Primary: GlobalError versus Base and LocalAnchor under final MBR, Before start,
full vIoU and sIoU on known unobserved actual decoder frames excluding all four
planned positions. Also report within-MBR unobserved support, benchmark
interpolation separately, observed anchors, Source sensitivity, all query signs,
95% fixed-seed parent-bootstrap intervals, severe negative tails below -5pp,
common bins for slow/fast motion and target area, counts/unknown groups.
Other clocks are sensitivity controls, never a GT-selected winner.

Inspect LS anchor residuals, held-out residual prediction error, constant-center
and log-size increment preservation, and GT-motion versus correction-error
variation. These are geometric diagnostics, not visual identity labels. A
constant correction preserves normalized pre-metric center increments by
construction, which does not prove correct object identity or event timing.

No statistical significance-only gate or new universal tolerance is invented.
The descriptive branch is prelocked: GT_common GlobalError must have positive
mean unobserved decoder sIoU and full vIoU in both domains to support this
constant-error ability in scope. If not, stop this four-parameter version. If
positive but matched DINO_common fails, reference reliability remains a
limitation. DINO_full must also improve both endpoints in both domains before
considering a separate structured-correction/OPD proposal; compare LocalAnchor
to distinguish ordinary anchor edits. CIs and subgroup risks remain visible and
no result automatically authorizes new TTA, smoothing, training or confirmation.
