# Original P3: separately pinned parameter-scope audit

This engineering bridge continues the originally locked P3 after actual P2 root,
visual, public and archive closing. It does not reopen parameter selection or
change the method, input roster, source checkpoint or scientific runtime.

P3 tests query-only (256 active parameters), LN-only (1,536), alpha-zero joint
(1,792 with zero writeback), and Full (1,792). Each new stream starts independently
from its original source, resets query residual and Adam per arrival, inherits only
its declared LN state, and reads the last round. HC2 retains 40 rounds and
lr/sigma/tau=.01/.025/.05; VidSTG retains 10 rounds and .03/.1/.25. Observation
budgets, antithetic 32 samples, Uniform4/admittedTop1, frozen DINO and Native WHEN
are unchanged. Full is eligible for exact complete P0/P2 stream aliases only;
qualification fits are not formal predictions or partial-stream substitutions.

Both target panels retain 128 historical parents with one predeclared query each.
Cross-domain clean uses two orders; same-domain uses the original five physical
burst types at 5%, one order. Each condition/arm/order starts at source. The original
four P3 stages together contain 7,168 logical rows, with 5,376 new formal fits and
1,792 exact Full whole-stream aliases. These panels have historical exposure.

The bridge records the original sampled actions and native head values for
independent CPU audit. The installed CUDA matched-reduction audit from P2 revision006
retains the 2e-5 CPU32 check, CPU64 independent formula and gamma48 interval;
the actual-action IoU check retains 3e-6. The chart, softmax, reward and allocator
bridges remain separately pinned. Only the existing independent audit assertion
uses the matched CPU32 reduction. Loss/actions/reward/weights/GPU gradients/Adam,
update scopes, scientific source and saved predictions are not changed.

CPU validation checks active optimizer names, every inactive state coordinate,
query reset, committed writeback and the 1,792-coordinate complete state. Twelve
no-information scope contracts and 36 malformed variants are separate from real
GPU qualification; four actual historical P2 joint fits and four changed-action
rejections establish the CPU audit's saved-data path, not P3 efficacy.

Real qualification runs all conditions, four arms and the first two original
queries: 96 arrivals and 192 complete original/new GPU fits. It checks the actual
source and expert process state hashes, complete tensor/scalar equality and native
head output VJP. Complete decoder Jacobians are not independently reproduced.
The original source is restored for each raw control, then the recorder is restored.
CPU root readback separately compares every complete qualified math dictionary,
active scope, reset/stream inheritance, writeback, input and original/new result.

Before a new formal stream's first two order1 fits are accepted, their complete
scientific result must equal that stream's actual qualified fit. Root then reads an
explicit bounded accepted prefix, verifies original bytes twice, complete math and
state/Native/input integrity, without GT or any new model call. Prefix counts are
snapshots and do not establish a global P3 seal or efficacy result.

All P3 arms/conditions/orders/directions must globally seal before original GT
scoring and finalization. CPU completion remains an actual root handoff: complete
source/paired bootstrap/math/state/dense/tails/cost/signal/cases, actual report view,
anonymous negative results publication, remote content verification and archive
closing must precede P4. P4–P6 and the full paper are not completed by this bridge.
EATA, its media/Fisher and all historical paused queues remain paused.
